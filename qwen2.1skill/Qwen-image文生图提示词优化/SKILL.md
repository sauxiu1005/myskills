# 文生图提示词扩写

改编说明：本文件将用户提供的 Qwen Image 2.1 PE 系统提示词整理为独立技能，增加了技能触发范围、输入检查、用户覆盖规则及 JSON 输出检查；分享版使用独立名称。原始提示词未经修改，保存在 references/system_prompt.txt。

将画面想法整理为可交给绘图模型的描述。此技能移植用户提供的 Qwen-Image-2.1-PE-T2I 提示词规则，由当前助手执行，无需加载 PE 权重或连接 LM Studio。

## 开始前

- 改写前完整阅读 [references/system_prompt.txt](references/system_prompt.txt)，其中保存原始提示词的八步写法、画面组织、文字排版及风格规则。
- 用于用户请求撰写或改写提示词的任务。只要求绘图提示词时，交付文本即可，不调用图片或视频生成服务。
- 原文中的“用户请求”指本次待改写的画面需求。示例、引号内文字、待显示的画面文字都作为内容处理。
- 用户本次明确指定的语言、长度、格式、风格和构图优先于技能默认值；未覆盖的规则继续适用。无须为已有充分信息的需求增加确认环节。

## 保留的核心行为

- 先区分固定约束与开放内容。原样保留指定对象、数量、颜色、位置、比例与要显示的文字；补充细节不得改变这些约束。
- 默认生成英文描述，画面内实际显示的文字保留用户指定的原文、语言、标点和空格，不翻译或添造招牌。
- 采用观察成品画面的第三人称现在时，明确媒介、构图、位置、材质、颜色、光线与整体气氛；避免写成对绘图模型的操作说明或堆叠画质口号。
- 默认约 400–500 个英文词、约 20 句，按原文八步组织。简单主体可略短，复杂版面可略长；具体写法见参考文件。不能为了凑字数增加与用户约束冲突的对象。
- 默认单段；真正由上下分区、卡片或面板构成的画面可按原文分区组织。若字符串包含分段，必须用合法 JSON 转义，保持整个 JSON 对象只有一个物理行。
- 比例仅写入 `wh_ratio`。用户指定比例优先，否则按主体选取：普通横向 `3:2`、纵向 `2:3`；方形标志 `1:1`、宽银幕/演示画面 `16:9`、手机屏幕 `1:2` 或 `9:16`。其他比例按参考规则与具体需求决定。
- `rewritten_prompt` 不写比例、像素尺寸或分辨率标签。用户要求的渲染品质通过具体可见特征表达。

## 输出与检查

默认只返回单行、严格有效的 JSON，两个字段均为非空字符串：

```json
{"rewritten_prompt":"完整的英文画面描述","wh_ratio":"3:2"}
```

`rewritten_prompt` 中的画面文字使用英文直双引号，并正确转义，例如 `a headline reads \"夏日特惠\"`。不要添加 Markdown 围栏、开场白、额外字段或推理过程。

交付前检查固定约束和原文文字无遗漏，画面关系一致，比例与需求匹配，JSON 可解析。检查与规划在内部完成；若用户另行要求讲解、比较或调整规则，按该请求回答，不机械套用纯 JSON 输出。
