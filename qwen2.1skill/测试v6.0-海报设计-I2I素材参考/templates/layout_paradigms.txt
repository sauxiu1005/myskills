# =============================================
# 常规型 Paradigm 1 - 标题压顶式
# =============================================
[范式描述]
标题以超大字号占据画面上1/3，人物主体位于画面中下部。标题与人物之间留有一定呼吸空间。标题通常水平直排或略带弧形。适合信息量中等、希望标题极强冲击力的海报。

[坐标参考]
- 主标题：基线对齐画面从顶部往下25%处的水平线，居中
- 人物：占据画面从30%到90%的区域
- 档期日期：紧贴标题下方，位于35%处
- 出演信息：位于画面底部5%-10%处

[绑定建议]
标题绑定"留白嵌入"方式，嵌入天空云层或大面积背景留白处。

[参考案例]
《你的名字。》《复仇者联盟》系列、《花木兰》。

# =============================================
# 常规型 Paradigm 2 - 标题基座式
# =============================================
标题在画面底部作为基座，人物主体在上方。标题通常以粗重字体横向排列，作为画面的"视觉地基"。适合正剧、传记片、史诗题材。

[坐标参考]
- 人物：占据画面从10%到75%区域
- 主标题：位于画面底部15%-25%处，居中
- 档期日期：标题正上方或正下方
- 出演信息：位于画面最顶部

[绑定建议]
标题绑定"地平线锚定"方式，与画面地平线平行。

[参考案例]
《肖申克的救赎》《阿甘正传》《绿皮书》。

# =============================================
# 常规型 Paradigm 3 - 中轴贯穿式
# =============================================
标题竖排贯穿画面中线，人物分列画面左右两侧。形成强烈的对称感与仪式感。适合武侠、历史、宫廷题材。

[坐标参考]
- 主标题：竖排，位于画面正中垂直线
- 人物1：位于画面左侧，占据30%宽度
- 人物2：位于画面右侧，占据30%宽度
- 档期日期：竖排贯穿式下方

[绑定建议]
标题绑定"轮廓跟随"方式，沿人物之间的中线垂直排列。

[参考案例]
《卧虎藏龙》《一代宗师》《刺客聂隐娘》。

# =============================================
# 常规型 Paradigm 4 - 左侧竖排式
# =============================================
标题竖排在画面左侧，人物占据右侧2/3区域。形成经典的"文字-图像"对位关系。适合文艺片、爱情片、人物特写型海报。

[坐标参考]
- 主标题：竖排，位于画面左侧5%-20%区域
- 人物：占据画面25%-100%区域
- 档期日期：竖排标题下方
- 出演信息：位于画面底部或右侧边缘

[绑定建议]
标题绑定"留白嵌入"方式，嵌入人物侧后方的负空间。

[参考案例]
《情书》《海边的曼彻斯特》《请以你的名字呼唤我》。

# =============================================
# 常规型 Paradigm 5 - 右侧竖排式
# =============================================
标题竖排在画面右侧，人物占据左侧2/3区域。与左侧竖排式构成镜像。适合亚洲电影风格、日式审美。

[坐标参考]
- 主标题：竖排，位于画面右侧80%-95%区域
- 人物：占据画面0%-75%区域
- 档期日期：竖排标题下方
- 出演信息：位于画面底部或左侧边缘

[绑定建议]
标题绑定"留白嵌入"方式，嵌入人物侧后方的负空间。

[参考案例]
《入殓师》《小偷家族》《驾驶我的车》。

# =============================================
# 结构型 Paradigm 6 - 双屏叙事式
# =============================================
画面上半部为图像区，下半部为信息区，中间有明确分界线（可以是水平线、色块或渐变色带）。上下两部分各自独立叙事，形成对比或呼应。

[坐标参考]
- 图像区：占据画面0%-55%
- 分界线：位于55%处，可加粗或换色
- 信息区：占据画面55%-100%
- 主标题：信息区居中，位于70%
- 档期日期：信息区下部，位于85%

[绑定建议]
分界线绑定"地平线锚定"，标题绑定"留白嵌入"嵌入信息区。

[参考案例]
《爱乐之城》《月升王国》《布达佩斯大饭店》。

# =============================================
# 结构型 Paradigm 7 - 蒙太奇拼贴式
# =============================================
多个人物/道具分散排列在画面各处，文字穿插其间。形成"群像叙事"的丰富感。适合群像剧、多线叙事、史诗片。

[坐标参考]
- 人物/道具：分散在画面各格位，每人占据10%-25%区域
- 主标题：位于画面中央或黄金分割点
- 出演信息：与各个人物相邻排布

[绑定建议]
文字绑定"碎片排列"方式，与人物形成视觉对话。

[参考案例]
《真爱至上》《撞车》《通天塔》。

# =============================================
# 结构型 Paradigm 8 - 框架包围式
# =============================================
文字形成矩形/圆形框架，主体被框在中间。文字作为"画框"包裹主体，形成强烈的仪式感。

[坐标参考]
- 主体：位于画面正中心，占据40%-60%区域
- 文字框架：环绕主体四周，形成矩形或圆形
- 主标题：通常位于框架顶部或底部
- 出演信息：沿框架边缘分布

[绑定建议]
文字绑定"轮廓跟随"方式，沿主体外轮廓环绕。

[参考案例]
《教父》《美国往事》《辛德勒的名单》。

# =============================================
# 结构型 Paradigm 9 - 对角线切割式
# =============================================
画面沿对角线分为两个区域，文字和人物各占一侧。形成强烈的动态张力与不对称美感。

[坐标参考]
- 对角线：从左下到右上（或反之）
- 人物：占据对角线一侧的60%区域
- 文字：沿对角线排列在另一侧
- 主标题：倾斜排列在对角线上

[绑定建议]
文字绑定"线条延伸"方式，沿对角线方向延伸。

[参考案例]
《谍影重重》《007》系列、《碟中谍》。

# =============================================
# 结构型 Paradigm 10 - 网格骨骼式
# =============================================
画面按3×3或4×4网格分布，文字和图像填充不同格位。形成强烈的秩序感与设计感。

[坐标参考]
- 网格：3×3或4×4
- 人物：占据2-3个网格
- 主标题：占据1个网格
- 其他文字：填充剩余网格

[绑定建议]
文字绑定"留白嵌入"方式，嵌入网格的空白格位。

[参考案例]
《她》《龙虾》《宠儿》。

# =============================================
# 反转型 Paradigm 11 - 日期巨字式
# =============================================
日期作为超大字号压在画面中央或贯穿画面，标题反而缩小。强调"时间"作为核心叙事元素。

[坐标参考]
- 日期：占据画面中央50%区域，超大字号
- 主标题：位于日期上方或下方，小字号
- 人物：环绕日期分布

[绑定建议]
日期绑定"遮挡交叠"方式，与人物形成前后关系。

[参考案例]
《降临》《信条》《时间旅行者的妻子》。

# =============================================
# 反转型 Paradigm 12 - 标题隐形式
# =============================================
标题极小，视觉重心完全交给图像。标题通常融入背景，需要观众仔细寻找。

[坐标参考]
- 人物/场景：占据画面90%以上区域
- 标题：位于角落，仅占画面2%-5%
- 档期日期：同样极小

[绑定建议]
标题绑定"留白嵌入"或"无标题式"，融入画面元素。

[参考案例]
《燃烧》《寄生虫》《小偷家族》。

# =============================================
# 反转型 Paradigm 13 - 信息主体式
# =============================================
演职员信息作为主体占据画面中心，人物反而缩小。适用于作者电影或特定实验性海报。

[坐标参考]
- 演职员信息：占据画面中央40%-60%区域
- 人物：位于边缘，占据20%-30%
- 主标题：与信息并列或融合

[绑定建议]
信息绑定"网格骨骼式"排列，形成视觉密度。

[参考案例]
《八部半》《假面》《野草莓》。

# =============================================
# 反转型 Paradigm 14 - 无标题式
# =============================================
只有图像和日期，标题融入画面元素中（如刻在墙上、写在路牌上、绣在衣服上）。

[坐标参考]
- 图像：占据画面90%以上
- 标题：作为画面元素一部分存在（如路牌文字、书籍封面）

[绑定建议]
标题绑定"遮挡交叠"，与画面中的实体元素融为一体。

[参考案例]
《闪灵》《2001太空漫游》《记忆碎片》。

# =============================================
# 反转型 Paradigm 15 - 文字碎片式
# =============================================
文字被打碎成单词/单字，分散在画面各处。形成解构主义的视觉风格。

[坐标参考]
- 文字碎片：分散在画面各格位
- 主标题：拆分到2-3个位置
- 演职员信息：碎片化分布

[绑定建议]
文字绑定"破碎排列"方式，与画面元素形成对抗。

[参考案例]
《猜火车》《搏击俱乐部》《发条橙》。
