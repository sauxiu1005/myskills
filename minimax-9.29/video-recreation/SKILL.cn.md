# 复刻视频

一个独立的视频复刻 Skill，内含“原视频输入重制/替换”和“仅分析后重制”两条路径。先提取需求与素材事实，只问缺失决策，再分析、写提示词、按授权执行。原样参考重制是有效目标，不是两个旧 Skill 的跳转入口。

## 国内客户端适配

- 面向国内客户端运行，模型、展示名称、输入组合、规格、声音能力与收费信息以当前会话实际开放的能力和界面为准，不沿用海外目录、固定双模型或旧版本的价格与速度排名，也不从中文界面推断某模型必然可用。
- 先识别当前模型筛选与账号实际可用范围；能力列表可能只是当前选择范围，不代表国内客户端全部库存。列表缺少用户指定模型时说明当前不可用；需要调整模型筛选时请用户决定，不擅自切区、切账号或调用海外服务。
- 只有制作视频时才进入模型选择。已有明确选择则先验证；未选时按输入路径、必要参考、输出与声音要求筛选可执行模型，再依据当前运行时推荐顺序提出推荐。没有依据时不声称某模型更快、更便宜或效果更好。
- 交互、问题和提示词说明跟随用户当前语言；国内中文会话用简体中文，用户明确要求其他语言时遵从。成片对白、画面文字和品牌文案保留用户指定内容，不因客户端地区自动翻译或改写。
- 上传文件与当前画布素材优先使用真实可读路径；公开视频链接仅在当前环境可访问且允许读取时使用。国内平台分享页、短链或登录页不当作媒体文件，读取失败可请用户上传原文件；不承诺任意平台下载、不绕过访问限制。
- 未取得可读媒体时只给有限分析并说明依据，不伪造下载、声音或帧级证据。预览封面和展示视频不是任务参考，也不是运行依赖；迁移展示素材需真实上传结果，不拼接国内域名冒充迁移成功。
- 不绑定作者电脑的目录、海外账号、存储地址或凭据。交付放入当前会话项目；复用主体时使用当前客户端可用的主体库与素材，不虚构库入口或连接状态。
- 本节只适配环境与能力发现，不改变 A/B 输入授权、自然适配、审阅、收费授权或逐接缝规则；不以适配为由替用户选模型或开始生成。

## 核心边界与会话状态

- 两条流程在本 Skill 内完成，不读取或跳转其他 Skill，不重新进入外部规划流程。分析视频不等于把视频提交给生成模型。
- 路径 A＝原视频作为生成输入；路径 B＝原视频仅供分析。由用户选择，不能凭上传文件、任务难度或“复刻”“换人”等词自动选路。
- 使用自然语言提示词，不用模型专用或固定通用提示词模板，不强制章节、镜头字段顺序或字数。模型推荐不改变写作方式。
- 外部格式自由，内部仍检查：用户目标、主体数量及关系、关键动作与时序、实际参考贡献、必要空间与声音要求；不适用项跳过。内部检查清单不是提示词模板。
- 不新增无依据的人物、道具、故事、光照、皮肤质感、镜头或强制全景开场。用户改动与实际素材贡献优先于模型偏好。
- 不读取模型提示词写作卡。能力查询用于工具参数、输入和音频限制，不用于重写提示词格式。
- 需要视频且模型未选时必须询问，不能以运行时默认模型绕过用户。只写提示词不强迫选模型；推荐不等于自动同意生成。

### 内部状态（不要求用户填表）

| 状态 | 记录内容 |
| --- | --- |
| 任务与素材 | 当前任务、源视频、独立参考及各自用途；文件版本变化需重查 |
| 交付目标 | 未定 / 仅分析 / 提示词与必要方案 / 视频；报告、字幕等额外要求单独记录 |
| 输入方式 | 未定 / A 原视频输入 / B 仅分析；绑定指定视频与范围 |
| 内容目标 | 未定 / 原样参考重制 / 已明确改动；含保留项、目标主体、时段 |
| 规格与声音 | 已确认模型、分辨率、时长、画幅、原音轨/新声音/静音及来源 |
| 当前待答问题 | 至多一个；记录问题类型、当时选项顺序、影响范围和回答后动作 |
| 方案审阅 | 不需要 / 等待审阅 / 当前版本已接受；用户要求先审时构成执行阻挡 |
| 生成授权 | 未授权 / 已授权当前范围；记录单次或多片段数量、预览、独立声音、追加尝试预算 |
| 执行与结果 | 未提交 / 执行中 / 成功 / 失败 / 状态未知 / 已取消；任务标识、输出与尝试数 |
| 分段与接缝 | 各相邻片段的切镜判断及证据、接续策略、依赖关系；衔接帧对应的生成结果版本、取帧位置、最终截点与获准用途 |

这些是当前会话状态，不是永久偏好。已完成结果和旧授权不能自动套用于新任务。入口停止点优先于后续通用步骤：仅分析完成 STEP 2 后直接交付，不进入生成路径或模型选择；提示词交付完成所需路径写作后停止，不进入收费执行。

### 短回复、授权与改动

- “第一个”“第二个”仅映射到当前唯一待答问题的选项；记录该问题当时的顺序，不借用路径编号或上一轮模型选项。
- “用推荐的”在模型问题上只确认推荐模型；不能同时确认输入方式、方案或追加付费。“可以”“确认”只接受当前明确提出的事项。“继续”在没有明确可继续步骤时澄清，不自动生成。
- 用户一次提供多个明确答案可以一并记录，但不同时发出多个待答问题。答非所问的明确新需求先处理，不将其当成确认。
- “生成一条”“直接生成”等明确指令可授权当前已知目标；等待补齐输入方式或模型后无需机械再问一遍。选择模型本身不新建授权。
- 若用户要求“先看提示词”，交付视频目标可以保留，但必须等当前方案被接受。接受方案只解除审阅阻挡；已有当前范围生成授权且未限定“暂不生成”时可继续，否则还需生成指令。
- 改路径、源视频、主要主体、模型、声音或时长时重验受影响部分，不重问无关信息。影响内容、输入、规格或费用的方案变更会使旧版本审阅标记失效；此前要求先审时，展示新版本并等待，除非用户明确允许按新版本直接生成。用户明确“按新改动生成”可构成新范围授权；只说“改下提示词”只修改文档，不生成。
- 当前在生成时先确认执行状态；能取消则使用现有取消能力，不能确认已停止就说明阻碍并等待，不与修改后的任务并行提交。不把状态未知当成已失败。

## STEP 1：轻量检查与最少提问

先读取当前需求和已给出的选择，再通过媒体工具读取真实视频元数据：时长、画幅、分辨率、音轨存在情况（工具能证明时）。这里只做轻量可行性检查，深入语义分析留到 STEP 2；源文件不变时复用已读事实。

附件路径已知就直接使用，不凭文件名猜内容。只有链接而尚未拿到可读媒体时说明现状，使用可用的媒体读取方式或请用户上传，不虚构下载成功。支持的视频内容工作使用媒体工具，不用 shell/Python 代替媒体分析或处理。

### 入口与停止点

- “只分析”→ 分析交付；不问输入方式或模型，不生成。
- “只要复刻提示词”→ 记录提示词交付；有原视频且提示词是否依赖模型看到视频尚未明确时，询问输入方式；不问生成模型、不执行生成。
- “生成新视频”→ 记录当前目标的生成授权；依次补齐缺失输入方式、内容目标、规格等，满足门槛后执行。
- 只有附件＋命令，或“复刻一下”但交付不明确→ 先询问输入方式，再询问“先出提示词”或“直接生成”；输入方式回答不视为生成授权。
- 只有截图/描述而无视频：默认作为分析证据，无需问一个无法执行的视频输入选项；不把它们自动当生成输入。用户坚持 A 路径时需要补视频。交付未明确仍须确认。

### 第一次路径询问

排除仅分析任务后，有真实原视频且输入方式未明确时，使用提问卡：**生成新视频时，你希望把上传的原视频作为生成模型的输入吗？**

1. **原视频作为生成输入**：需要动作完全一样时建议选择此项，以尽量贴合原动作、镜头和时序；这不是逐帧完全一致的效果保证。→ 路径 A，STEP 3A。
2. **原视频不作为生成输入**：原视频只供拆解，通过自然语言重新生成，动作细节可能变化。→ 路径 B，STEP 3B。

顺序固定，仍由用户选择；明确说过“不传入生成”“将原视频作为模型输入”就不重问。“参考一下”“换人”不是已选路径。多段视频用途不明时只澄清哪段及其范围，不能默认全传入。

路径选择后、长篇方案或收费准备前检查可行性。遇超长、输入过多或不支持的组合，说明需分段/补素材等选择，不静默改路径或裁掉内容。初步检查不依赖精确镜头边界；分段最终由语义证据确定。需要生成时，用户接受分段后记录调用数量、拼接目标及费用范围；单条成片可能需要多次生成，不能隐瞒。仅提示词任务只在必要时标注执行限制，不要求批准生成费用，也不因此强迫选择模型。

### 后续只询问缺失项

1. 交付仍未明确：提问卡 **这次希望先拿到什么？**选项“先出提示词”（停止在文档）和“直接生成”（授权当前范围的视频生成）。也接受用户自由回答仅分析。
2. 内容目标：纯“复刻”且无修改要求，采用原样参考重制；已要求替换但目标、对应主体或素材不清时先用必要的局部语义检查定位。仍有多个有效解释再询问，不让用户重述画面上已可确定的信息。两条路径都允许“不改内容”。
3. 需要视频且模型未选：使用 STEP 4 的实时模型选择问题。用户已选则不重问；未明确分辨率时采用当前模型在运行时规定的默认规格并告知，用户规格优先，冲突则澄清。
4. 只补足执行关键的缺失项；源视频时长、画幅可从元数据继承并简短告知，不重复问。尺寸、长度不兼容则让用户选择处理方式。
5. 用户要报告或先审时保留该要求；其余通过简短摘要沟通，不把内部检查清单变成长问卷。

## STEP 2：按需分析，区分内部检查与交付

- 用媒体分析读取主体及数量、角色锚点、动作与时间线、场景、镜头与切换、空间关系、接触遮挡、光照材质、景深、剪辑节奏和可听声音。元数据证明时长尺寸，语义证明内容，不能混用。
- 简单换杯子、换背景等任务：围绕变化对象及其接触、遮挡、跨镜稳定性做足内部检查，对用户只给修改摘要和必要风险，不默认创建长报告。
- 精确复刻、多镜头或用户要求深入拆解：增加分析深度。只在已有分析不足时补读缺失证据，不重复分析整片。
- 多段生成并拼接时，逐一检查每两个相邻片段的接缝，区分原片明确切镜与同一连续镜头内因执行限制产生的技术性分段。先判断切镜，再判断尾帧；不确定时补看接缝附近视频，不凭时长、同一人物或场景相似度猜测。明确切镜的接缝不使用前段尾帧作为后段参考或起始帧，具体执行遵守 STEP 5。
- 需要高密度证据时制作关键帧联系表：最长 15 秒区段通常 10–12 帧；密集变化适当加密。极短素材不得为凑数重复同一帧；长视频按可读连续区段拆表，注明数量与时间覆盖。
- 实际制作的联系表上画布并关联来源；未抽帧则如实记录未制作，不把抽帧当作所有任务的必经步骤。关键帧不会自动成为生成输入。
- 报告仅在用户要分析/报告时交付；内容涵盖依据、主体与场景、动作镜头声音、不确定项及风险。只要提示词交付提示词和必要说明；只要成片不额外堆文档。
- 主体命名稳定，检查跨镜、出入画、相似主体、透明前景和接触关系。风险说明定位到具体区域/动作，不能仅说“可能有瑕疵”。
- 截图、文字和无法读取的音频，不得伪造动作、时间或声音事实；标记推测与缺失。缺失若影响执行，问最短必要问题；能交付有限分析则说明范围。

## STEP 3A：原视频输入重制或替换

### 内容目标与修改范围

路径 A 同时支持原样参考重制与指定内容修改。用户说“照原片重新生成，不换东西”是完整目标，跳过替换目标和替换素材询问；生成不是逐帧复制。要求修改时支持人物、背景、产品、物体及多元素组合；人物可为真人、动物、拟人角色、玩偶、机器人或卡通角色，也可只换脸。只在修改要求确有缺口时询问，不能凭空添加替换。

有修改要求时明确替换内容、对应主体、整段或指定镜头/时间段；原样重制则记录保留原有内容。两者均检查必须保留的动作、关系、镜头、构图、背景和声音，多个相似主体分别命名绑定。

### 固定自然适配

- 固定使用自然适配，不询问“保守替换 / 自然适配 / 完全重塑”等强度选项。
- 默认保留原视频主要动作、镜头、构图、剪辑节奏、空间关系与故事含义；用户明确要求改变的部分按其要求处理。
- 新主体根据物种、体型、比例、结构、材质和视角自然适配原动作，不照搬不兼容的人体解剖。
- 保留新主体关键身份、轮廓、服装装备、标记和身体延伸结构；原人物有双手或人类服装不意味着可删除新主体特征。

### 素材适配与难度评估

有替换/独立参考素材时才评级；原样重制不要求虚构替换素材。检查主体数、身份特征、轮廓完整度、角度、姿态、清晰度、遮挡与比例差异：

- A 级：清晰且角度构图接近，可直接使用。
- B 级：身份外观清晰，但角度、姿态或比例差异较大，需要自然适配。
- C 级：严重遮挡、关键角度不足或视频运动过于复杂，建议补充素材或做短预览。

另行评估任务难度，不能只判断工具是否可调用：

- 低：单主体、小动作、少遮挡、近似参考角度，预计较稳定。
- 中：明显运动、角度变化、局部遮挡或较大比例差异，可能边缘不稳、闪烁或动作偏差。
- 高：多人统一替换、快动作、复杂舞蹈、透明遮挡、频繁出画、严重透视或跨物种大比例变化；说明身份漂移、肢体形变、服装闪烁、穿模和道具漂移风险。
- 极高：素材不足且多人重叠、快动作、透明材质、镜头变化或多个目标同时存在；说明更适合测试或创意预览，必要时需多角度素材、拆镜、遮罩或人工后期。

风险说明包括预计能保留什么、最容易出错的具体区域或动作、可能表现、适用用途以及是否建议补素材或预览。不得承诺完美、逐帧无瑕或百分之百稳定。风险不自动阻止执行，除非输入缺失或工具不支持。

### 素材角色与空间关系

- 原视频：主要动作、镜头、时间结构、空间关系和获准保留的声音。
- 人物图：身份、脸部、发型、服装、体型、角色结构与材质。
- 背景图或视频：新环境、空间结构、透视与世界设定。
- 产品图：产品身份、外形、比例、结构、包装、材质和品牌信息。

每份素材逐一绑定对应对象，素材标签与实际工具输入顺序一致。人物参考不自动改变背景；背景参考不自动改变人物；产品参考不自动改变手部动作。普通参考不自动成为首尾帧。

在自然语言提示词中说清改什么、保留什么、各素材作用、新元素如何匹配位置/比例/运动/遮挡/接触，以及跨镜头身份与声音处理。该内容清单只用于检查，不规定输出顺序或模板。

### 跨物种与非人主体

- 新主体物种、口鼻、口腔和身体比例优先于真人解剖；按新结构重定向口型、表情和动作，保留获准保留的表演情绪与说话节奏。
- 动物不能直接复制真人嘴唇、牙齿、舌头或下颌。稳定保留耳、尾、爪、角、翅膀等轮廓。
- 让新结构自然适配站立、拿取、采访等动作及遮挡，不为了原动作删去新角色的关键身体特征。

### 真实视频输入

原视频或已批准片段必须实际传入当前工具支持的视频输入槽；仅分析过视频、只写提示词或使用抽帧都不算采用原视频输入路径。视频与图片、音频各入对应槽，不把视频混入图片槽。

若执行模型不支持该视频、时长或输入组合，说明具体限制并让用户选择兼容方案，不静默降级为路径 B，也不假称已使用原视频。超长输入按镜头连续性及实际能力规划分段，共用身份锚点并记录衔接。原片在接缝处明确切镜时不使用前段尾帧；同一镜头的技术性分段才按 STEP 5 评估尾帧接续。尾帧不能替代本路径承诺的视频输入。

## STEP 3B：不使用原视频输入的拆解复刻

### 明确复刻目标

采用用户已指定的保留内容、替换目标和风格改动。用户没有要求改动时，以证据支持的主体关系、动作、构图、镜头顺序、节奏和声音意图为复刻目标。新的角色、产品或世界设计只来自用户目标与已批准素材。

### 自然语言提示词

- 用自然语言描述期望成片的画面、动作、运镜、空间关系、声音与连续性，按实际复杂度自然组织段落。
- 可按必要镜头或时间节点分段，但不强制章节、字段或固定时间片长。描述必须让模型在看不到原视频的情况下仍能独立理解，不能用“完全照原视频”代替内容。
- 按连续性组织片段，不机械地每 15 秒拆一段。主体、场景、动作与声音兼容时形成尽可能连贯的片段；仅在真实切镜、场景或风格改变、衔接依赖及执行限制时分组。
- 写清需要的起始状态、连续动作与可承接的结束状态。接缝明确切镜时，后段按新镜头的构图、机位与起始动作生成，不使用前段尾帧作为参考或首帧；无切镜的技术性分段才评估尾帧接续。仅提示词交付可说明接续方案，但不能声称已取得或验收尚未生成的尾帧。这些是内容检查项，不是提示词模板。
- 描述镜头、光源、材质和动作时使用证据，不能用“电影感”“高级感”等空词代替，也不能强行插入全景开场。

### 实际生成输入边界

- 原视频及用于拆解的片段、联系表、抽帧默认只用于分析；不得悄悄放进视频参考、图片参考或首尾帧槽来绕过用户选择。
- 用户另行提供或明确批准的独立角色、场景、产品和风格参考仍可使用。每个参考说明角色与具体贡献，按实际输入顺序分别绑定，不能只列文件名。
- 本次已生成的新视频尾帧与原视频抽帧分开记录。新视频尾帧可用于已说明并获准的分段接续，不等于批准原视频或其抽帧进入生成；原片抽帧仍遵守原有输入边界。明确切镜的接缝两种尾帧用途都不采用。
- 若用户后续明确要求以原视频抽帧作为图片输入，先澄清新的授权范围；批准某张抽帧不等于批准上传整段原视频。只要原视频文件不作为输入，仍可在路径 B 内使用明确获准的图片。
- 不隐含复用原片音轨。复刻声音意图不代表直接使用原音频；提取原音轨用于生成或后期需用户明确同意。

## STEP 4：模型、声音与执行门槛

### 模型选择：只推荐，不代选

用户需要视频且尚未选择模型时，在输入路径和基础可行性检查后提问，不等到长篇方案写完才查限制。先查询国内客户端当前会话的实时可用模型及逐模型能力；不读取提示词写作卡，不保留固定的海外双模型菜单。

提问卡：**请选择本次视频生成模型。**

- 只呈现当前路径与素材组合下可执行的模型，可按需求给出少量最相关选项；不为凑足两个选项加入不兼容模型，用户也可指定其他模型再验证。
- 模型选项标题逐字使用当前目录中的正式展示名称；规格、用途、推荐理由及已知限制写在说明中。推荐项放在首位并在说明中标记，不在正式模型名上追加括号、分辨率、推荐后缀、序号、价格或别名。
- 说明分辨率时采用用户已确认规格；未指定则采用该模型当前运行时默认值并告知。不要将某一模型的规格、最短时长或音频能力复制给另一个模型，也不把分辨率当成所有场景的质量排名。
- 推荐依据是当前运行时推荐顺序及本任务可执行性；同样可执行时尊重用户已表达的偏好。速度、价格或效果比较需有当前依据，实际收费以当前客户端界面为准，不虚构积分、货币换算或耗时。
- 记录本次实际展示顺序与推荐项。“用推荐的”仅接受本次明确提出且仍可执行的推荐；尚未提出推荐时先给出选择，不把旧会话的第一项带过来。

### 模型问题提交前检查

- 根据当前目录的正式展示名称匹配实际可调用模型；按当前路径、输入、输出与声音要求筛选，不仅检查是否存在同名菜单。
- 提交提问卡前检查每个模型标题与目录完全一致，规格与推荐信息在说明或问题正文中；内部标识不展示给普通用户。
- 用户已确认模型且仍可执行时，不为重复介绍规格再问一次；保留原选择、路径、素材和授权状态。
- 提问卡校验失败时区分标题拼接错误、目录变化和真实不可用。修正标题或刷新当前能力后最多重发一次必要问题，禁止原样重试或为测试卡片收费生成。再次失败则报告具体阻碍，不循环弹卡、不换模型或改变授权。
- 提问失败不等于生成失败；只有明确知道尚未提交生成任务时才说明未启动生成，不从此推断其他任务的计费状态。

### 能力适配与执行规格

- 实际模型与执行方式由运行时依据当前正式展示项解析，不把展示名称、推荐文字或旧版内部标识直接当作执行参数；严格区分同系列的标准、快速和其他变体。
- 路径 A 必须支持所承诺的真实视频输入及目标操作。视频参考重制、源视频编辑、动作迁移和视频延展分别检查实际语义与能力，不能因名称含“视频”便当作等价功能。动作迁移若不接收文字修改，说明限制；仅在目标图已承载获准外观与环境时采用，补做图片或更换操作需相应授权。
- 路径 B 使用不含原视频的文字或已获准独立参考。普通参考不自动成为首尾帧；明确首尾帧接续须用户指定或批准方案。检查两类输入能否共用，不能为接续丢掉已承诺参考；明确切镜仍不使用前段尾帧。
- 逐模型、逐操作验证输出时长、参考的单份与合计时长、数量、文件格式与大小、分辨率、画幅继承、声音支持及输入互斥限制；不只检查同系列能力并集。分段以实际镜头与有效限制为依据，不套固定秒数。
- 区分源视频时长、生成片段时长、延展新增时长与延展后总时长。操作继承原片时长或画幅时按继承规则处理；用户要求改变这些值而当前操作不支持时，先决定兼容方案，不假装设置已生效。
- 仅一项可用时仍说明限制并等用户选择；一项都不可用时保留已有分析与文档，说明阻碍并提供补素材、调整约束或仅交付提示词等兼容选择。更换模型、切换输入路径、删除参考、分段或改变已确认规格需相应决定，不擅自降级。
- 当前模型筛选或账号能力变化时仅重验受影响范围；原先推荐或已选模型不可用，不将用户的“用推荐的”偷换为剩余模型。
- 仅提示词任务不必选择模型，用户指定模型时可记录并说明必要限制，不因此开启生成。

### 声音策略与模型能力

内部将音频分成“保留原声音”“重新生成声音”“静音”，分别记录适用范围；背景音乐与对白有不同要求时分别记录，避免一个总开关覆盖全部声音。

- 路径 A 的原样重制/仅改画面，默认方案是保留原音轨且不重做对白；提交前简短告知此处理。用户说“只换人，声音不变”已足够，不再问音轨授权。若声音用途确有歧义或任务会改变原时序，先澄清。
- 路径 B 默认只复刻声音意图，不能隐含提取原音轨；需要直接复用时由用户明确同意。若该声音意图清晰且可随主视频一次生成，可列入当前生成范围；若需要额外付费音频任务则先说明并获得授权。
- 画面人物替换不等于声音替换。只有用户明确要求才换声、移除某类声音或静音；动物/非人角色按自身口鼻结构适配表演，不能以跨物种替换为由私自换台词。
- “无原生音频开关”不证明模型必然无声。按当前所选模型及操作核验声音生成、原音轨保留与音频输入支持，不跨模型借用声音控制。检查实际输出音轨，再采用已获准的声音方案；能力不明确时说明不确定性，不直接断言只能生成无声视频。
- 原音轨保留优先确定性合并，避免混入模型重做的对白。先比对生成视频和原片时间对应关系：剪辑重排、变速、长度变化时不能整轨盲贴，也不能为了对齐擅自改动作；需要调整方案时让用户决定。
- 原视频没有音轨时明确告知；保留不存在的原音轨意味着不另造声音。已要求添加新声音时另按该要求处理。
- 合并时可在容器兼容条件下复制原音频；若必须重编码，不宣称字节级一致。记录时长与同步检查，不能只凭总时长相同就声称口型同步。
- 用户未要求字幕时关闭；口播、对白或换声不隐含字幕。准确文字/UI按用户要求保留，必要的确定性叠加纳入已确认方案。

### 方案审阅与生成授权

提交前核对当前目标、路径、源素材、模型/分辨率、数量/时长、声音和支出范围。简单任务用短摘要告知即可，不强制创建报告或再确认一遍已授权的内容。

**同时满足以下条件才提交收费生成：**

1. 当前任务确实要求视频，且有覆盖当前内容和调用范围的明确生成授权。
2. 输入方式及素材使用范围明确，内容目标有效（原样重制也有效）。
3. 所需模型、规格、音频方案已确定并通过能力验证。多段生成时逐接缝明确是否切镜、是否依赖前段结果及尾帧用途；拟用首帧接续须获明确同意，实际输入组合可执行，不能为接续而静默删除原视频或其他已承诺参考。
4. 没有等待用户审阅、未解决的关键问题或支出超范围事项。
5. 同一工作没有执行中或状态未知的重复请求。

用户要求“先看提示词，再生成”时先交付当前版本并等待。接受提示词只有在原有生成授权仍有效时才允许继续；此前仅要文档，“可以”只是接受文档。用户明确说“现在生成”才扩展交付目标和授权。

### 预览与额外消耗

完整视频授权不包含额外付费预览。高风险可建议预览，但须说明时长、调用数量、费用/不确定性、它并非完整成片，用户同意后才执行。

预览授权与完整制作授权分开记录；已明确授权两阶段制作时，预览质检通过后可继续，否则交付预览并等完整制作指令。预览失败不得自动启动完整任务。预览时长必须满足模型限制，不能把建议的 4–6 秒当成所有模型通用参数。

同一成片需多段视频、额外身份锚点或独立音频生成时，先让用户知道需要哪些收费调用和范围；不能把“生成一条”解释为无限次尝试。已有明确的数量/预算授权可复用，不重复询问。

## STEP 5：执行与组装

1. 按 STEP 4 的门槛提交，记录每次工具返回的任务标识、范围、次数和结果。用户授权不改变模型/工具限制，存在冲突先解决。
2. 再核对实际输入：路径 A 必须有用户同意的视频输入；路径 B 不含未经批准的原视频、片段或抽帧证据。按图片/视频/音频分别编号，提示词逐项绑定真实素材，不依赖模型看不到的文件。
3. 长片按镜头与连续性规划，先确定分段数、顺序、身份锚点、逐接缝切镜判断与接续策略、音频及费用范围。素材不够时补足或取得选择，不能仅凭“保持一致”批量生成不同身份。
4. 分段内共享已确认锚点。独立准备和无依赖片段可批量；需要尾帧接续的片段按下述规则串行，须等前段实际可用结果及接续检查通过后继续，不提前提交后段。明确切镜的接缝不建立尾帧依赖。原视频输入超限不能静默截短；只生成部分内容须明确说明。
5. 输出工具自动上画布，不重复注册或复制文件；仅外部/路径-only输出按工具要求补上画布。文件名使用工具返回值，不移动或重命名已生成资产。
6. 多段合并使用专用合并工具；尺寸冲突先确定处理方式，不默认裁切主体。检查顺序、衔接、时长和声音连续性，缺失音频不以意外噪声填补。
7. 只做已确认的声音复用、混合、准确文字后期。最终补音替换临时输出节点，避免把临时片当第二个成片交付。处理重复音轨并检查音画对应。
8. 发生失败、未知状态或审阅阻挡时停在相应范围，保留成功输出，不继续提交依赖失败结果的工作。

### 相邻片段的尾帧接续判断

对第 1→2 段、第 2→3 段等每个接缝分别判断，不把第一处的结论套用全片。内部记录策略和依据，用简短说明沟通，不强制新增报告或提示词模板。

**第一关：接缝处是否明确切镜。**

- **明确切镜：不使用前一段尾帧作为后一段的普通参考图，也不作为起始帧。** 后段从原片新镜头对应的构图、机位、景别和动作阶段开始；即使仍是同一人物、场景或连续事件，也不改此结论。身份、产品与场景一致性由已确认的独立参考维持，不以尾帧代替。不得为了表面无缝而消除原片切镜、添加转场或改变剪辑节奏。
- **没有切镜，属于同一连续镜头的技术性分段：** 才进入尾帧接续评估，检查动作阶段、主体位置朝向、道具接触、背景空间及镜头运动是否需要直接延续。无切镜不等于必须使用尾帧。
- **证据不清：** 补看接缝前后短区段；遮挡、甩镜或匹配动作不能单凭静帧认定为切镜或连续镜头。仍无法判断且会影响生成时，说明缺口并问一个必要问题，不盲目接续。

**第二关：接续方式、输入能力与同意范围。**

- 需要从相同画面直接延续时，优先评估将尾帧作为后段明确首帧；只需辅助延续可见状态时，可评估普通图片参考。普通参考不能被宣称为精确首帧，无论哪种用途都不能保证动作无缝。
- 在分段方案中说明实际用途。明确首帧接续需用户明确指定或明确同意该方案；已获整条接续链同意且无变更时不逐段重复询问。使用本次生成结果不扩大原片素材授权，也不扩大付费调用预算。
- 检查所选模型是否支持该用途、参考组合、素材数量、尺寸和比例。若明确首帧与原视频或其他已承诺参考不能共用，不删除参考、不静默改输入路径。可提出兼容的普通参考、调整分段边界等方案，但必须说明与严格首帧接续的差异；改变已确认输入、模型、时长、剪辑或费用时先取得相应决定。

**第三关：取得真实衔接帧后再生成依赖片段。**

1. 前段成功产出后，检查末尾短区段而非只看一张图片。尾帧必须来自本次实际生成且检查可用的结果，不用原片尾帧冒充，也不根据提示词推断它已经停在预想姿势。
2. 默认使用前段最终保留画面的最后一帧，记录输出版本、取帧位置及最终截点。检查意外黑帧、变形、身份漂移和意外切镜；符合动作意图的运动模糊不自动视为坏帧。若生成结果意外切镜或偏离计划，不当成源片真实切镜来放行，应报告偏差并处理。
3. 末帧不适用时不传播缺陷。若建议改用更早的可用帧，必须同步提出前段截点与后段起点的对应处理；不得前段仍播到原末尾、后段却回到更早姿势。裁剪若改变已确认时长、动作、原音轨对应或费用，先取得决定；不能把付费修复或重生成当作自动步骤。
4. 根据前段真实末尾运动更新后段起始描述：从当前动作阶段继续，保留运动方向、速度趋势、镜头运动、主体和道具关系，不重复起势或从头重演。单帧只提供可见状态，运动判断必须来自末尾短区段；保持原片后续动作目标，不借接续擅改故事或新增动作。
5. 把实际衔接图片及其用途绑定到后段输入，检查通过且无审阅阻挡后才提交。未经实际提取、检视和传入，不能声称已用尾帧接续；仅提示词任务停在方案，不生成假想素材。需要用户审阅的方案若因真实末尾而发生实质变化，按原审阅规则处理。

## STEP 6：质量检查、失败与重试

使用真实输出检查；未检视就明确标记，不能把工具返回成功当作质量验证。检查目标是否复刻/替换正确、原元素是否回闪、身份重复或漂移、出入画/转身/快动作稳定性、空间遮挡接触透视、产品结构、边缘材质光照、对白/口型/音轨/字幕及实际输入承诺。

### 接缝质检与依赖更新

- 对每处接缝检查前段末尾和后段开头的短区段，不只比对两张静帧。连续镜头重点检查位置、朝向、姿态、道具接触、背景结构、身份与光照跳变，以及动作重复、停顿、回退、速度突变、运镜反向和重复帧卡顿。明确切镜则检查是否保留新镜头及原有节奏，不把正常机位变化判为接续失败。
- 尾帧不能解决声音连续性。单独检查对白或音乐的重复、截断、空隙和音画同步；去重、裁剪或声音调整必须在已确认后期范围内，不用擅自转场或变速掩盖接缝问题。
- 前段重生成、更换输出版本或修改截点时，重新核对使用其旧尾帧的直接后段；若后段因此更换，再沿实际尾帧依赖逐段检查。标记受影响结果，不宣称旧后段自动有效，也不自动重做整条链。明确切镜处没有尾帧依赖，不因该项变更自动牵连后镜头；身份或声音等其他真实依赖另行检查。
- 保留不受影响的成功片段。接缝不合格先报告和提出定向修复，追加收费遵守下述授权与次数上限；未知状态或不可用前段阻断其依赖片段，不继续提交。

### 失败类型与是否允许再提交

- **本地校验失败，明确尚未提交收费任务**：修正参数或缺失输入，在原授权范围内可再提交；不得改变用户约束。若新方案扩大费用或任务范围，先问用户。
- **超时、断线、缺少结果或计费未知**：标为状态未知，先用已有任务查询/结果工具核查，不直接再次生成。若无法核实，向用户说明，不声称未收费，不制造重复任务。
- **服务端明确失败**：检查是否收费和现有尝试预算。仅在已确认未收费且没有在途请求，或用户已明确授权相应重试预算时定向重试；其余先询问是否追加。
- **已成功产出但效果不满意**：不是调用失败。付费重生成需要用户明确修改并重生成的指令或已有有效重试预算；自动质检发现瑕疵只先报告/提出修复建议，不能擅自花费重做。
- 每个工作项首次提交之外最多两次定向重试；这是上限，不是额外付费授权。用户要求遇错停止时不自动重试。不能在次数耗尽后仅通过换工作项名称绕过上限。

只修复失败原因：身份→明确已知身份与角度；口鼻→适配物种结构；产品→结构与比例；穿帮→遮挡接触透视；动作→运动与承接；多对象→分别绑定；音轨→消除重复并对齐。保持成功片段与其他已确认约束，不重复相同请求，不改回模板，不重新生成全部成功内容。

新素材、更换模型或主要创意改动使旧结果不再匹配时，标明受影响部分；用户只要求改文字就更新文档，不将其变成生成授权。

## STEP 7：按用户目标交付

- 仅分析：交付拆解报告和实际制作的证据，说明不确定项；不附带模型选择或启动生成。
- 提示词：交付自然语言提示词及执行所需的简短素材/参数说明；用户另外要报告或分镜再补，不默认双文档。
- 视频：交付当前已授权范围的成片，说明输入路径、保留/修改内容、时长画幅、声音处理及已知问题。简单任务不堆分析长文；用户明确要求的报告仍交付。
- 只完成预览、部分片段、无声临时结果或未检视输出时必须如实命名状态，不声称完整验收完成。最终媒体按实际文件名引用；遵守画布自动分组规则。
- 当前任务完成/取消后关闭待答问题，后续“继续”不能自动复活旧授权。修改请求只影响相关范围；明确的新独立任务不携带旧任务的输入选择、素材用途或收费授权。

## 不适用

普通字幕、剪辑、调色、压缩转码、单纯影评或静态图片动起来不属于本 Skill。附带视频不等于要复刻，不强迫进入本流程。旧入口是否禁用是安装状态，本 Skill 不依赖旧入口；没有重载工具时只说明文件已保存，不能声称已热加载。
