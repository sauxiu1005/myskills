## 交付与运行结构

- 简单修改：内部完成必要分析，对用户给短摘要、必要风险和成片，不默认双文档。
- 用户要求报告＋视频：两者都交付；少报告规则不能删除明确要求。
- 提示词外观不套模板，内部仍检查目标、主体关系、动作时序、参考贡献、空间和声音。
- A＝原视频输入，B＝仅分析；子标题不用 B1–B6 等交叉编号。
- 正式模型名只用于展示；执行方式与规格由当前目录解析，不把推荐标签当作模型身份。
- 本次未修改其他 Skill 或安装开关，不推断国内目标环境中旧入口已禁用。
- 当前包独立，不依赖旧 Skill。缺少热重载工具时不能声称应用已加载更新。
- 验收按当前任务状态承接短回复；完成/取消后不把旧“继续”当新收费授权。

### 静态检查范围

- 模型标题只含当前正式模型名，规格与推荐留在说明。
- 明确模型选项标题与当前正式展示名称完全相等。
- 明确提问失败不等于生成失败，不调用付费生成验证卡片修复。
- 原有触发范围、路径顺序、声音策略与生成授权规则保持；固定两模型规格改为当前能力验证。

## 分段切镜与尾帧接续回归（1.2.2）

以下为规则静态检查与桌面场景推演，不是实际抽帧、模型兼容性或成片质量的端到端验证。

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| T01 | 同一镜头因单次时长限制拆成三段 | 分别判断两个接缝；无切镜才评估接续。选择尾帧依赖后按实际前段结果逐段串行，不预先并发生成后段。 |
| T02 | 两段交界正好是原片硬切 | 不把前段尾帧用作后段普通参考或起始帧；按新镜头生成。 |
| T03 | 同人物同场景，由全景切特写或正反打 | 仍视为明确切镜，不用前段尾帧；独立角色/场景参考维持一致性。 |
| T04 | 1→2 段连续，2→3 段切镜 | 仅第一处评估尾帧依赖，不把结论推广全片。 |
| T05 | 遮挡或甩镜导致切镜证据不清 | 补看接缝短区段；不凭单帧猜测，必要时澄清后再生成。 |
| T06 | 路径 A 的原视频参考与明确首帧不能共用 | 说明冲突，不能删除原视频或静默转 B；兼容方案由所需用户决定约束。 |
| T07 | 路径 B 已同意使用本次生成结果续接 | 可按获准用途使用生成尾帧；不得因此上传原片或未经批准的原片抽帧。 |
| T08 | 只有普通尾帧参考而非明确首帧能力 | 不宣称精确起始画面或保证无缝；若与已确认目标冲突，先取得处理决定。 |
| T09 | 计划连续但生成末尾黑屏、身份漂移或意外切镜 | 不传播坏帧，不把意外切镜当源片切镜；报告并在授权内处理。 |
| T10 | 拟取更早的好帧，前段原末尾仍保留 | 拦住时间回退；联动截点及后段起点，影响时长/声音时先取得决定。 |
| T11 | 前段尾帧吻合，但后段重演动作或运镜反向 | 接缝质检不通过；单帧相似不等于运动连续，定向修复须遵守预算。 |
| T12 | 前段重做，后段曾使用旧尾帧 | 核对并标记实际受影响依赖，保留其他结果；不自动重做全部片段。 |
| T13 | 后段以明确切镜独立生成 | 前段尾帧变更不自动使后段失效；其他身份/音轨依赖另查。 |
| T14 | 已同意整条连续镜头首帧接续链 | 无实质变更不逐段再问；真实末尾引起实质方案变化时遵守原审阅约束。 |
| T15 | 只要多段复刻提示词 | 写明逐接缝策略后停止，不收费生成、不声称已取得衔接帧。 |
| T16 | 接缝有卡顿或对白重复，画面看起来一致 | 检查短区段及独立声音连续性，不仅比较静帧，不擅自变速或添转场。 |
| T17 | 前段失败或状态未知 | 保留已有成功输出，阻断依赖片段；无额外授权不追加收费重做。 |

### 不同输入的流程走查

假设用户提供一段连续运镜的玩偶视频和独立机器人图，要求只换主体、保留原音轨，先审提示词再生成：只补缺失输入路径和当前可执行模型；分析肢体适配与道具接触；提示词保留机器人结构并分别绑定素材；先交付审阅，不能因选模型跳过。若超出当前单次能力，说明分段、费用和尾帧用途；连续镜头才评估接续，实际前段可用后串行生成依赖片段。失败保留成功结果，原音轨按真实时序映射复用。此为桌面推演，不是模型效果测试。
