# 反应躲手掌游戏

## 何时使用

- 用户上传任意照片（人物、动物、卡通角色、物体都行），想做成"按方向键躲手掌"的快节奏反应游戏视频
- 用户想做 **10 秒、4:3 横向** 的极简可爱 2D 手绘风格反应游戏
- 用户要 4 张同款关键帧（按 上 / 下 / 左 / 右 四个方向躲闪）作为分镜 / 截图 / 海报
- 视频需要明显的游戏反馈感（箭头高亮 → 手掌伸入 → 主角躲闪 → 回弹特效）

## 不适用

- **超过 10 秒**的长视频（节奏与时长锁死在 10s）
- **3D / 写实 / 真人实拍**风格（硬约束排除）
- **横屏 16:9**（视频锁死 4:3 横向）
- **多主角 / 多角色**（只能一个主角，且 10 秒内形象必须一致）
- **带文字 / 带现代电子 UI**（玩法是手绘 HUD 装饰，不是真游戏 UI）

---

## 输入与输出

### 输入
- **主角照片** 1 张：必填。可以是真人、动物、卡通、物体。skill 提取其核心特征（生物类型、毛色/肤色、关键轮廓、辨识度高的部位），用 2D 蜡笔/彩铅 Q 版重画。
- 风格微调：可选（默认米色纸张 + 蜡笔 + 主角原始配色）。

### 输出（4 + 1）
| 编号 | 产物 | 规格 | 用途 |
|---|---|---|---|
| 1 | 关键帧 · 上躲 | 4:3 图 | 视频 0-1s 上箭头动作截帧 / 单独发布 |
| 2 | 关键帧 · 下躲 | 4:3 图 | 视频 1-2s 下箭头动作截帧 / 单独发布 |
| 3 | 关键帧 · 左躲 | 4:3 图 | 视频 2-3s 左箭头动作截帧 / 单独发布 |
| 4 | 关键帧 · 右躲 | 4:3 图 | 视频 3-4s 右箭头动作截帧 / 单独发布 |
| 5 | 视频 · 10s 游戏 | 4:3 视频 / 10s | 主交付物 |

> 图1是全套视觉锚；图2、图3、图4生成时必须同时参考用户照片与图1，确保画面风格、UI图标、背景、装饰、手掌造型统一。4 张关键帧可同时作为视频生成的"形象锚"（参考图）。视频必须参考关键帧 1、2、3、4 的画面内容，分别锁定对应角色动作、箭头反应、带手臂手掌方向与整体风格；关键帧 1 可作为 first_frame。

## 工作流（5 步）

### Step 1 · 主体特征提取
读取用户上传的照片，输出一份 **subject_brief**，落到 `references/prompt-template.md` 的 `{{SUBJECT}}` 槽位：

- 生物类型（人 / 猫 / 狗 / 角色 / 物体 / 拟人化 X）
- 主体颜色（base + accent）
- 辨识度高的特征（耳朵形状、眼睛大小、尾巴、毛色块分布、独特配饰）
- 可被"夸张拉伸 / 压扁 / 拱起 / 侧闪"的部位（哪个身体部位最 Q 弹？）

> **关键转换**：写 subject_brief 时不要写真实感描述，必须用 2D 蜡笔/彩铅 Q 版的口吻。例如"一只圆润 Q 版的比格犬"而不是"一只写实比格犬"。

### Step 2 · 拼装 4 张关键帧 prompt
4 张图共享同一份 **画布 prompt 模板**（详见 `references/prompt-template.md`），只替换 4 个变量：

| 变量 | 图 1 上躲 | 图 2 下躲 | 图 3 左躲 | 图 4 右躲 |
|---|---|---|---|---|
| `{{DIRECTION}}` | up | down | left | right |
| `{{HAND_SOURCE}}` | from below | from above | from right | from left |
| `{{DOG_POSE}}` | 向上拱起成夸张半圆桥 | 压低贴地，前半身扁平后半身翘起 | 向左拉长身体，耳朵甩飞前爪抓地 | 向右滑行，身体像弹簧压缩侧闪 |
| `{{HIGHLIGHTED_ARROW}}` | 底部最左的上箭头 | 底部左二的下箭头 | 底部右二的左箭头 | 底部最右的右箭头 |

调用 `hub_generate_image` 分两步跑：先跑图1；图2、图3、图4必须把图1也加入参考，参数：
- `aspect_ratio = "4:3"`
- `image_paths = [用户上传的照片]`
- 图1参考用户照片；图2、图3、图4参考用户照片 + 图1（保持主角身份、画面风格、UI图标、背景、装饰完全统一）

### Step 3 · 拼装 H3 视频 prompt
视频 prompt 必须包含 **4 段信息**，缺一不可：

1. **画风与镜头硬约束**（放在 prompt 头部，作为总基调）
2. **主角完整描述**（直接把 Step 1 的 subject_brief 嵌入）
3. **HUD 与装饰布局**（顶部 HUD + 底部箭头 + 基于角色元素生成的稀疏装饰）
4. **10 秒时间线**（节奏分 3 段：固定序列 / 清晰随机连打 / 反馈收尾）

完整模板见 `references/video-prompt-template.md`。10 秒时间线按以下节奏写死：

```
0.0-0.5s 开场待机: 角色正常位于画面中心，无互动手掌，底部箭头普通线框，顶部 HUD 就位
0.5-5s  固定序列: 上 → 下 → 上 → 左 → 右（5 个动作，每个 ~1s，节奏清楚利落）
6.1-9.5s 清晰随机连打: 方向可随机安排，不需要固定，但每次必须严格遵守“箭头-手掌-动作”对应
9.5-10s 反馈收尾: 手掌彻底消失，箭头恢复线框；主角停在画面正中央、保持原比例不放大，露欠揍坏笑 + 基于角色元素生成的小图案/通关成功涟漪
```

### Step 4 · 生成视频
- 工具：`hub_generate_video`
- `first_frame_image` = 关键帧 1（作为 first_frame）；`reference_image_paths` = 关键帧 1、2、3、4；同时把关键帧 1、2、3、4 作为画面动作参考，锁定四个方向的角色动作、箭头高亮与带手臂手掌方向
- `prompt` = Step 3 拼出来的完整 prompt
- `duration = 10`、`resolution = "1080P"`、模型默认

### Step 5 · 交付
按以下顺序交付，全部用 `<media>` 标签发给用户：
1. 关键帧 1-4（4 张图）
2. 10s 视频
3. 一句话总结：4 张分镜对应哪个方向 + 视频用了哪张作为 first_frame

## 硬约束（不可破坏）

任何 prompt 必须包含以下硬约束，缺一项视频就会跑偏：

- ✅ **2D 蜡笔 / 彩铅手绘**（不许 3D、不许写实、不许真人）
- ✅ **4:3 横向**（构图比例锁死）
- ✅ **固定镜头**（不许运镜 / 缩放 / 推拉）
- ✅ **HUD + 底部 4 箭头必须画**（不是装饰，是反应游戏的核心 UI，缺一不可）
  - 顶部 HUD：3 颗心 + 进度条 + 骨头/鱼骨
  - 底部 4 箭头：↑↓←→ 永远从左到右，**且每一张图必须指明哪个箭头当前高亮**
  - 写法陷阱：写"无现代电子 UI"时**不能**简单写成 "no UI, no arrows, no symbols"——HUD 和箭头是手绘装饰，不是电子 UI，必须保留
- ✅ **无现代电子 UI**（不许有按钮光晕、屏幕反光、霓虹、矢量干净线条）
- ✅ **无文字**（HUD 是手绘装饰，不许出现可读字符）
- ✅ **纸张颗粒感 + 蜡笔笔触**（背景和线条都要保留手绘抖动）
- ✅ **单一主角**（10 秒内身份一致，最多夸张形变）
- ✅ **带手臂的手掌-箭头-动作严格对应**（按上躲从正下方带手臂伸入的手、按下躲从上方带手臂伸入的手、按左躲右侧带手臂伸入的手、按右躲左侧带手臂伸入的手，不许错位）
- ✅ **单手臂与安全距离**（每个节拍只出现当前方向的一只带手臂手掌，靠近制造压迫感，但不能触碰、重叠、遮挡或穿过主角）
- ✅ **完整同步反馈链**（对应箭头高亮并出现短促手绘涟漪、星星或爪印反馈 → 手臂伸入 → 主角向同方向躲闪 → 快速回弹；不能只亮箭头不移动）
- ✅ **参考继承边界**（图2–4只继承图1的画风、主角、背景、HUD、装饰、箭头与手臂线稿，不得残留上一方向的攻击手臂）
- ✅ **稀疏装饰**（不得遮挡主角、手掌、手臂或方向箭头）

## 失败处理

- 视频生成后若主角形象跑偏 → 重新调 `references/prompt-template.md` 的 subject_brief，强化"2D 蜡笔 Q 版"措辞，再跑一次
- 视频生成后若节奏错位（箭头和动作对不上）→ 检查 `references/video-prompt-template.md` 的时间线段，重写时用绝对时间戳（"at 0-1s"）而不是"first"这种相对描述
- 4 张关键帧之间主角形象不一致 → 4 张图都把 `image_paths` 设成同一张用户照片，并使用相同的 `subject_brief` 措辞
