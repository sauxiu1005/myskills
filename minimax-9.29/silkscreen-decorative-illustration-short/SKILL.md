# 丝印装饰插画风格短片

当用户希望制作一支具有奢侈品创意广告片质感的丝印装饰插画风格短视频时使用本 Skill。它强调精细均匀线稿、高密度装饰叙事、克制的 TVC 镜头节奏，以及与画面动作严格同步的自然音效。正文、提示词、确认语、产出说明都跟随用户语言输出；字段名、模型 ID、文件路径和信号代码保持原样。流程从主题确认开始，依次产出 `Final_Video_Spec.md`、分镜、key_element 元素图、逐镜视频、精准音效与最终组接成片。

本 Skill 的创作范围是原创、非品牌化装饰插画，不以复刻具体品牌 Logo、在售丝巾图案或现有商业产品设计为目标。“高级丝印装饰插画语言”只作为线条纪律、装饰密度、优雅构图、克制冷暖宝石色和平面丝印质感的宽泛简称。

这一创作范围不等于“任何 Logo 或相似纹样都违法或被平台禁止”。出现疑似标识、在售图案或文字时，按 STEP 8 先核验证据与适用限制，再决定是否需要变更；模型识别结果本身不是权利结论、拒绝理由或重生成授权。

## STEP 1：确认主题与 Final Video Spec

如果用户尚未明确主题，先请用户确认整体主题与故事场景。可选方向包括中式庭院茶道、欧式宫廷宴会、巴黎公寓日常、花园动物寓言、沙漠商队、植物沙龙等。

创建或更新 `Final_Video_Spec.md`，包含：

- 视频主题与一句话故事前提
- 宽高比
- 成片时长预估
- 画面风格定义
- 语言策略
- 音频策略：只保留画面同步音效；无 BGM、无旁白、无对白、无字幕
- 已知的场景数量与预计镜头数量

- 约定的非品牌化范围、允许保留的文字（如用户明确要求的标题）、用户提供的素材来源说明与尚未核验项；首轮产物数量、追加修复是否预授权及其具体范围/次数/费用上限。未明确授予的返工额度视为没有授权，不推定首轮批准覆盖额外生成。

完成 `Final_Video_Spec.md` 后暂停，请用户确认，再进入分镜设计。

## STEP 2：分析参考图

当用户提供参考图时，在设计分镜或撰写 prompt 前先分析参考图。只提取可安全泛化的风格与设计证据：

- 线条风格：线稿密度、轮廓粗细、粗细是否均匀、闭合轮廓、建筑硬直线、人物动物植物有机曲线
- 填色方式：平涂色块、有限点描或颗粒、无强渐变、无戏剧化投影
- 装饰密度：织物、地毯、挂毯、建筑彩绘、植物、器物、几何纹或卷草纹
- 色彩体系：象牙白、石灰白或沙色底；冷暖宝石色并重；记录饱和度与对比范围
- 叙事结构：前景细节、中景主体、远景建筑或自然
- 人物与动物造型：服饰时代或文化背景、发型、动物品种、姿态语言

输出精简的结构化风格描述，供 storyboard 和媒体 prompt 使用。若生成工具会直接接收参考图，不要把参考图颜色完全转写成文字，让图像本身承载精确色彩。

参考中的疑似 Logo、文字或具体商品纹样单列为待核验观察，不自动认定为受保护设计或在售复刻。区分图像载体上的水印/UI、场景内标识、通用几何/花卉纹样与用户明确保留的文字。需要来源事实时请用户补充具体来源或授权说明；未取得的外部材料保持未核验，不能声称已排除风险，也不能据此自动删参考或生成替代素材。

## STEP 3：设计 Storyboard 与 Key Elements

设计分镜表，明确每个 `key_element` 与每条 final shot。

### 全局视觉风格

每个场景遵循：

- 奢侈品丝印装饰插画风格
- Ligne Claire 均匀黑色细线勾边；建筑使用硬直线，人物、动物和植物使用有机曲线
- 轮廓清晰闭合，无毛边、无水墨晕染
- 象牙白、石灰白或沙色底色
- 冷暖宝石双色并重：皇室蓝、普鲁士蓝、翡翠绿、深紫，与赭金、朱红、酒红、橙红共存
- 平涂色块；织物、地毯、挂毯、建筑彩绘与复杂表面必须有高密度图案纹样填充
- 只在需要轻微体积感时使用极细点描或颗粒；不使用渐变、强高光或强阴影
- 高密度叙事装饰构图：前景器物 / 植物，中景人物或动物主体，远景建筑或自然
- 柔和均匀光感，哑光丝绸或高级印刷品质感
- 奢侈品 TVC 的精致克制气质；每帧都应像可丝网印刷于真丝之上

### Key Element 规则

- `element character`：明确服饰时代或文化风格、发型、可见服装轮廓、姿态和配色关系。
- `element animal`：明确动物品种、毛色或羽色、身体姿态、动作语言及其与场景的关系。
- `element scene`：明确前景标志性装饰物、中景核心活动区、远景建筑或自然、时间氛围与光线方向。

### 每个叙事场景的双分镜结构

每个叙事场景必须固定包含两条镜头，并按以下顺序排列：

1. `Shot A — 全景建立镜头`
   - 宽景构图，前景、中景、远景都可读。
   - 主体人物或动物处于中景，比例适中。
   - 运镜只做一个克制动作：缓慢横移或轻微推进。
   - 目标成片约 3 秒。只有空间阅读或关键动作会显得仓促时，才延长至 4–5 秒。

2. `Shot B — 局部近景跟随镜头`
   - 聚焦上半身、动物、手部、器物互动或动作细节。
   - 镜头跟随主体动作方向缓慢移动，可带轻微手持感或弧形环绕。
   - 只保留一个精确动作，用明确动词和肢体细节表达。
   - 需要时加入微表情、手部细节、羽毛 / 布料运动或器物触碰。
   - 目标成片约 3 秒。只有动作需要完整起势、过程与收势时，才延长至 4–5 秒。

### 音频层规则

全片只使用与画面同步的音效，不设计 BGM、旁白、对白或字幕。

有音效的 shot 需写独立 `audio_layer`，包含：

- 触发动作
- 声音材质
- 远近层次：近、中、远、环境
- 持续时间或时间范围
- 奢侈品广告式克制：细腻、稀疏、有触感，不过度堆叠

合适的声音包括丝绸摩擦、皮革轻响、瓷器轻触、茶水倾倒、鸟羽振动、翻书、珠宝轻碰、帘幕拂动、庭院微风、远处水声、石板轻步声等。

Storyboard 完成后暂停，请用户确认，再生成元素图。

## STEP 4：生成 Key Element 元素图

先批量生成所有 key_element 元素图，再进入视频生成。

推荐图像生成配置：

- Text-to-image
- 可用时使用 GPT Image 2
- 默认使用 2K 分辨率；只有用户明确要求更高规格静帧资产时才使用 4K

元素图格式：

- 人物或动物参考图：横向并排 reference card；左侧为面部 / 上身特写，展示五官、发型、服饰领口或动物头部细节；右侧为全身，展示服装全貌 / 身体轮廓、配色与姿态。
- 场景参考图：完整全景图，清楚体现前景、中景、远景三层空间，并包含代表性装饰细节。

Prompt 结构：

1. 可见主体描述
2. 环境或空间层次
3. 全局丝印装饰插画风格锚定
4. 构图指令，例如“横向并排参考图”或“完整场景全景图”

只描述镜头可见内容，不写画面外叙述。

元素图完成后暂停，请用户确认人物、动物与场景设计，再生成逐镜视频。

## STEP 5：生成 Shot 视频

按场景顺序生成 shot 视频，每个场景两条：先 `Shot A`，再 `Shot B`。

推荐视频生成配置：

- Multimodal-to-video
- 默认使用 MiniMax H3
- 只有用户明确选择、H3 不可用，或硬性能力需求排除 H3 时，才改用其他视频模型

生成时长策略：

- 若目标成片约 3 秒，生成 4 秒源片，供剪辑预留余量。
- 若镜头需要 4–5 秒才能保证动作完整，则按需要生成并保留 4–5 秒。
- 不额外拉长无叙事价值的停顿。

Reference 输入：

- Shot A 必须引用对应 `element scene` 图像，以及所有可见人物 / 动物元素图。
- Shot B 必须引用对应主体元素图与场景图。
- 如需强调连续性，Shot B 可额外引用同场景 Shot A 的源片或 final shot 作为连续性参考。

### Shot A Prompt 要求

每条全景 prompt 必含：

- reference 绑定：`<<<image_1>>>` 为场景图；`<<<image_2>>>` 及之后图像为人物 / 动物元素。
- 一个克制运镜：缓慢向右横移、向左横移或轻微向前推进。
- 一个约 3 秒可读清的视觉节拍。
- 极简主体动态：衣袂微动、鸟羽轻扇、手停在器物上、身体轻转等。
- 固定负向短语：`no subtitles, no text overlay, no dialogue, no voice-over, no music`。

### Shot B Prompt 要求

每条近景跟随 prompt 必含：

- reference 绑定：`<<<image_1>>>` 为主体图；`<<<image_2>>>` 为场景图。
- 跟随方向：向左、向右、向前或轻微弧形环绕。
- 一个精确动作，写清身体细节与节奏。
- 必要时加入微表情或触感细节。
- 可选音效提示使用尖括号，例如 `<茶水倾倒声，轻微>`。
- 固定负向短语：`no subtitles, no text overlay, no dialogue, no voice-over, no music`。

## STEP 6：仅为标注镜头生成 Final Audio

只有 Storyboard 明确标注 `audio_layer` 的 shot 才生成 final audio。

音频生成目标：

- 细腻、同步的自然音效
- 精确贴合画面中的材质与动作
- 保留奢侈品创意广告所需的空间感与动态范围
- 不生成 BGM、旁白、对白、人声或字幕轨

如果视频模型已经生成原生声音，最终组接时避免重复声轨。必要时移除原生声轨，或让生成的 `final_audio` 干净替换原声。

## STEP 7：组接最终视频

严格按以下节奏排列：

`场景 1 Shot A → 场景 1 Shot B → 场景 2 Shot A → 场景 2 Shot B → ...`

剪辑规则：

- 只使用直接硬切。
- 不使用叠化、渐黑渐出、擦除或装饰性转场。
- 从每条 4 秒源片中选择动作和运镜最完整的连续段，常规镜头修剪为约 3 秒。
- 只有剪短会破坏动作完整性时，才保留 4–5 秒。
- 将每条 `final_audio` 精确对齐对应触发动作。
- 没有音效标注的镜头在 clean version 中保持稀疏留白，不用音乐填充。
- 按 `Final_Video_Spec.md` 的宽高比与分辨率导出。

默认 clean final output 不得包含 BGM、旁白、对白、字幕或文字覆盖；除非用户明确要求标题文字作为平面设计的一部分。

## STEP 7.5：可选 BGM 推荐与 BGM 版成片

完成 clean final video 组接后，先判断是否适合追加 BGM 版，并向用户做推荐。这是后期可选分支，不进入单镜头视频生成 prompt。不得自动添加 BGM；必须先询问用户是否需要在保留 clean SFX-only 版本的基础上，额外交付一个 BGM 版。

推荐内容包括：

- 概括最终视频的情绪、视觉节奏和故事弧线。
- 根据实际视频内容推荐 2–3 个 BGM 方向，例如亲密室内弦乐、柔和巴黎清晨钢琴、极简竖琴与钟琴、克制奢侈品 ambient。
- 推荐必须贴合既有画面风格：优雅、稀疏、有触感；无 vocals、无 lyrics、无戏剧化预告片鼓点，不压过画面。

如果用户需要 BGM：

1. 读取或使用已组接最终视频的精确时长。
2. 生成一条与最终视频同等时长的 instrumental BGM，匹配故事内容、剪辑节奏和情绪曲线；不得生成歌词或人声。
3. 将 BGM 混入已有 SFX 床下方。动作音效必须在触发点清楚可闻；纸张、瓷器、脚步、窗帘、风声、液体等材质声出现时，应降低或 duck BGM。
4. 导出第二个明确命名的 BGM 版成片，同时保留 clean SFX-only 成片作为独立交付物。
5. 如果 BGM 破坏奢侈品克制感或遮蔽 SFX，优先降低 BGM 音量，而不是增加音效密度。

BGM 版输出规则：

- Clean version 保持主母版地位。
- BGM version 是可选附加版，必须明确标注。
- BGM 时长必须与最终视频完全一致，包括结尾停留。
- BGM 仅限 instrumental：无 vocals、无 lyrics、无 dialogue、无 narration。
- 绝不把 BGM 写入 H3 / 单镜头视频 prompt；BGM 只在最终组接后生成和混音。

## STEP 8：质检与失败修复

最终交付前检查：

- 每个场景是否都包含一条全景建立镜头和一条局部近景跟随镜头？
- 所有镜头是否保持同一种奢侈品丝巾插画语言？
- 线稿、平涂、装饰密度、冷暖宝石色平衡、哑光丝绸质感是否稳定？
- 每条近景是否只承载一个清晰动作，而不是多个动作竞争？
- Clean 版声音是否与可见动作同步且无 BGM、人声或对白？已获批的可选 BGM 版按 STEP 7.5 单独验收，不把允许的器乐误判为 clean 版缺陷。
- 转场是否全部为硬切？
- 是否存在疑似 Logo、具体在售图案或不需要的文字？先记录并按下述协议复核；不能从一次识别直接跳到修复、删除或重新生成。用户已明确要求的标题不属于“不需要的文字”。

### 证据核验与内容返工分离协议（v1.0.1）

**1. 先观察，不直接定性。** 记录资产/镜头、文件版本、时间段与画面区域、可见形状或可读文字、实际检查覆盖范围。识别模型或 OCR 的一次输出、模糊局部、单帧相似感仅是候选线索，不足以证明品牌身份、作品来源、在售状态、侵权或实际禁止。视频中的疑似标识需检查对应时间段及相邻清晰帧；必要时对同一源文件做只读局部复核，不生成新内容来“验证”识别。

**2. 核对限制来源。** 分开记录：用户确认的无品牌/无多余文字创作约束；本 Skill 的原创非品牌化范围；有具体依据的当前政策或工具限制；用户陈述的素材来源/授权与仍未确定的权利问题。Logo 可见不自动等于侵权；通用卷草纹、几何边饰、马具或植物题材不自动等于某在售图案。确认“具体在售复刻”需能对应的来源及可核对的构图/纹样细节；相似画风不是证明。用户授权陈述不自动成为法律核验结论，也不能豁免真实适用限制。只索取本任务必要说明，不默认要求所有普通装饰元素提供权利证明。

**3. 给出三类结论。**

| 结论 | 下一步 |
|---|---|
| 误识别或未违反已批准约束 | 记录依据，保留原素材；不删除合法标题、通用装饰，不返工 |
| 未核验/有歧义 | 报告具体疑点与缺失证据，必要时请用户补充来源或确认创作意图；暂停该争议项的合格声明，不自动重跑，不扩大成整批失败 |
| 已确认不符创作约束，或已有依据的实际限制 | 说明具体条款、事实和影响范围；提出最小合规修复。限制结论不授权生成，继续执行下一步授权门槛 |

若明确请求超出本 Skill 的非品牌化范围，说明范围并请用户选择原创替代方向或另行处理，不虚构平台禁令。若确有适用政策/工具限制，则遵守它，不以换模型、换词或用户付费来绕过。

**4. 修复先定范围，再核对授权。** 展示受影响镜头/区域、保留项、拟改内容、实际失效依赖、操作类型、新增产物数量、次数、已知费用或费用未知、停止条件。预算有余额不等于有权限；只有精确覆盖该镜头/改动/操作且未用尽的既有返工授权可直接复用，否则先请用户确认。首轮生成批准、质检不通过、泛称“继续”或不回复，都不自动批准内容重生。默认一次批准只覆盖列明产物各一次追加尝试。

### 其他失败修复建议

以下是诊断后的修改提案，不是自动执行队列；凡涉及新增媒体、删改内容或扩大范围，均遵循上述授权与局部修复规则。

- 如果镜头过于写实，强化平面装饰艺术、闭合细线、哑光印刷质感与无强阴影。
- 如果画面过于稀疏，增加前景 / 中景 / 远景装饰细节，以及织物、建筑、器物纹样密度。
- 如果色彩偏成单一暖金色，恢复冷暖宝石双色并重。
- 如果 Shot B 动作不清，简化为一个动词与一个触感物件互动。
- 如果音频像音乐或氛围填充，移除，只保留动作触发的材质声音。
