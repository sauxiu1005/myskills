# 场景参考图

同一地点需要跨镜头复用，或用户要求场景设定图时，为实际拍摄方向建立空间依据。已有参考足够就复用；一次性过场可直接在镜头提示词中描述，不必另做场景卡。

- 用户未明确指定场景参考图画幅时，默认 16:9 横版；用户明确指定时按其要求。参考图画幅独立于成片比例，提示词与生成参数保持一致。
- 先明确空间结构、出入口、地标、固定家具和关键道具的位置关系，以及尺度、材质、时段和光源位置。以具体固定物建立方位基准；区分已有参考可见的事实和仍需设计的区域，不把未展示的背面当作已知布局。
- 按镜头需要覆盖视角：同方向只切远近景时，一张全景通常足够；正反打、侧拍或走位会露出不同方向时，只补实际需要且尚未覆盖的方向。多个方向都需要复用时，可采用同一空间的 2×2 四视图。
- 采用四视图时，左上为主视角，右上为反向视角，左下、右下为两侧视角。逐一写清相机相对固定物的位置和朝向，避免只写“正、反、左、右”；四格展示同一个空间，不是四种装修方案。默认呈现干净空场景，保留固定陈设和剧情所需道具，不额外加入人物、标题或方向标签。
- 换机位改变画面左右、遮挡和透视，不改变物体实际位置、数量、尺度和材质。光源在空间中的位置保持一致，其在画面中的投影随机位变化。
- 逐视角描述时，用门窗、地标与家具的相互关系锚定同一布局；四宫格形式本身不保证空间一致。用户反馈视角对不上，且影响下游取景或剧情所需空间关系时，修正对应视角或空间描述；未采用视角的瑕疵不单独触发补图。地点发生破坏、搬动陈设等变化时，沿用基础布局并明确当前状态。
- 下游引用时说明采用的地点、状态和拍摄方向，参考用于空间结构、陈设和材质，不把四宫格排版带入单个镜头。人物站位与动作按当前镜头单独描述；需要复用的空间事实保留在已有场景记录中。

例如：从入口朝舞台拍时窗在画面左侧，反打时可以出现在右侧，但仍位于同一面墙上。

规划时按本轮镜头所需方向判断参考是否够用：所需方向都已覆盖，且描述中写清了固定物的相互位置，就不再补图。
