# 直接交付与用户反馈 / Direct delivery and user feedback

确认方案生成视频→必要角色图→视频→直接交付。用户自己查看效果，不设置自动审片、听检、评分、精确测时长或验收报告。角色图不独立跑、不默认停下来审图。

不要因为自行发现或推测的问题追加候选、裁切、重编码、补帧或重生。平台返回的微小时长差异不是自动后处理理由。用户明确要求的剪辑、拼接或返修按其授权范围执行，不自行扩大范围。

用户指出问题后再针对该处修改，保留已有版本；没有成功返回的生成任务就如实说明失败或中断，不声称完成，不盲目重复提交。只有必要输入、工具兼容性与实际执行错误会阻塞制作，它们不是新增的媒体质量检验流程。

Confirm video production → necessary character images → video → direct delivery. The user reviews the result. Do not add automated viewing, listening, scoring, duration probes or acceptance reports. Do not automatically trim, transcode, pad, regenerate or add alternatives for self-detected defects or small provider timing differences. Perform expressly requested editing or assembly only within its approved scope. Retain previous versions when responding to user feedback. Report tool failures honestly; missing inputs and execution errors are not media quality-review stages.
