v0.2.7保留史前手绘、剧情角色身份、动作运镜、短英文对白、无字幕标题与道具连续性要求。最新反馈：缺失时长先询问，不默认60秒；视频确认覆盖角色图前置；生成完直接交付，由用户检查。移除自动审片、验收和自行裁切重生。全局安装不变。

本版不绑定任何校准截图或生成样张。历史试验仅保留为本地测试记录，不在执行路径上，不进入分发包；不据此宣称无参考生成已实测。全局安装只读，不重载、不修改。

Version 0.2.7 retains the shared style and story identity rules. Latest corrections: ask for missing duration, never default to 60 seconds; video confirmation covers internal character images; deliver successful generation directly for user review, without automatic inspection or unsolicited trimming/regeneration. Global installations remain untouched.


v0.2.8：仅规范中英文名称、触发描述、市场介绍与结构化展示文案，不改变固定画风、时长收集、视频确认及直接交付流程。
Version 0.2.8 updates naming, trigger descriptions and bilingual display copy only; creative and execution rules are unchanged.

At the user's explicit request, the identifier migrates from `prehistoric-cave-director` to `prehistoric-hand-drawn-animation-generator`, with the title Prehistoric Hand-Drawn Animation Generator. The previous installation is backed up and retired; the creative workflow is unchanged.

用户进一步简化名称为“史前动画生成” / Prehistoric Animation Generator，标识为 `prehistoric-animation-generator`。只精简名称；已锁定的手绘画风、输入输出范围与制作流程不变。
The user further shortened the name to Prehistoric Animation Generator (`prehistoric-animation-generator`). Only naming changes; the fixed hand-drawn style, scope and production rules remain unchanged.
