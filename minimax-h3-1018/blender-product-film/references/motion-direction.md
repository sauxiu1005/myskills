# 运动设计与验收

适用：用户明确要求丝滑、明显运镜、相机加产品动画，或反馈成片像静态图切换。静态广告与刻意锁机镜头不强套此规则。

## 先写运动意图

每段指定观众要看到什么发生变化：相对观察角度、画面占比、目标部件位置、产品姿态/悬浮位移。相机与产品分别记录起终状态和幅度，二者同向同速抵消导致画面不变时不算有效运动。

整机悬浮、平移、旋转、倾斜是美术展示，可在不改装配的前提下执行；应注明不是产品具备悬浮/自转功能。资料不足时不虚构拆解、铰链行程、按钮响应或内部机构，但仍应完成已授权的外观动画。用位于产品中心的展示 Root 统一驱动，母模型保持静止装配，维持部件间相对变换。

## 按信息选择连续移动或切镜

可见表面之间有可行的摄影路径时，可用环绕 → 推近 → 沿部件上升 → 拉远组成一条连续轨迹，不必把每个信息点切成一个镜头。空间跨度太大、路径穿模或方向不可读时，使用动作方向匹配的切镜；写出切点前后运动方向、速度和构图接力，不要求整片一镜到底。

避免所有镜头等长、所有段落都从零加速又完全停住。强调节点可减速停留，连接段应保留速度。使用有明确切线的曲线/Hermite/Bezier 或路径约束，检查速度连续；不要只给线性位置叠一个笼统 ease-in-out。相机推进与镜头变焦分开记录。

幅度从产品与画幅决定。作为试做起点，完整展示可以尝试相对观察角变化 25–50°、画面占比变化约 20% 或清楚可见的整机倾转；它们不是通用硬阈值。微距的几毫米移动也可能足够，必须以画面上的变化判断。产品和相机都动时控制主次，给纹理/功能信息留可读时间。

## bpy 落地

- Root 在装配中心，parent 前后保留 matrix_world；用局部坐标定义观察目标，再经 Root 世界变换得到相机目标与焦点。
- 同一连续镜头用一条摄影轨迹。更新位置、目标、roll、焦段与焦点时保持对应关系；避免追踪极点、Euler 跨圈、插值过冲和微距穿模。
- 保留实际帧率；运动模糊仅在当前引擎支持且检查后开启，适量 shutter 可尝试 0.2–0.4 帧，不用模糊掩盖跳变或让文字失读。字体可单独分层。
- 灯光/文字动画配合主运动；至少说明是否需要，不为了堆效果强加变化。

`scripts/camera_rig.py` 是独立镜头的基础辅助，默认 smoothstep 会在首尾停住；它不是连续镜头规划器。需要穿过多个信息节点而不停顿时，应编写共享切线的连续路径，不能把该辅助对每个节点重复调用来冒充连续运镜。

## 动态验收

先做完整时长的低成本运动预览，再花时间正式渲染。逐段记录：

1. 起、中、末帧与对应对象位置/旋转、相机距离；屏幕上究竟发生了什么变化。
2. 相机相对产品的角度或画面占比变化，不能只测世界坐标移动。
3. 连续轨迹有无突然加速、停顿、方向折返，切镜前后的运动是否有意衔接。
4. 整机镜头全程入画、需要看的局部清晰、无穿模/错误装配、无意外地面相交。
5. 文字在运动后的背景上也可读，运动模糊没有影响 Logo/细节。

若主张“一镜到底”，核对不存在相机切换或隐藏的瞬间姿态重置。若没有实际播放器能力，说明使用了连续抽帧与轨迹数据检查，不能声称已完整实时观看。即使数值检查通过，画面仍像固定机位时也要修改，不用合格的关键帧数据替代视觉结果。


## 混合运镜与切镜

用户要求兼顾运动和切镜时，采用多段内部连续运动的镜头，不自动改成整片一镜到底。可用15秒的4+3+3+2+3秒节奏作为起点，按信息量调整，禁止机械套用。相机与产品动画分开设计：整机根动画贯穿全片，镜头切换不能把产品姿态重置。每镜记录首中末画面、轨迹范围、进入/离开速度及与下一镜的信息关系。

切镜可以实现有意的空间或景别跳跃；需要运动匹配时，以画面中的特征移动方向与速度验证，不能仅比较世界坐标相机向量。中间运动段保持非零进出速度，独立相机为切点保留至少两帧运动模糊余量；仅在有停留目的时减速归零。首镜启动和末镜收尾可独立缓动。先审查每个切点前后连续帧，检查切错相机、姿态重置、意外闪帧和模糊拖影，再完成全片预演。


## 已验证的混合编排示例

AURA 15秒横版项目中，用户认可的运动编排为：4秒整机绕行并推进 → 切入3秒耳垫表面滑移 → 切入3秒连接杆上移 → 切入2秒头带横移 → 切回3秒整机绕行拉远并减速。借鉴信息节奏和运动主次，不照搬产品尺度、焦段或帧数。

- 整机Root悬浮、转向、倾斜贯穿全片，相机使用独立镜头和时间线camera markers；保持同源产品装配。
- 开场明确改变相对观察角，局部镜头用目标点移动带动构图变化，末镜拉远恢复完整产品并留出品牌阅读空间。
- 中段切镜前后仍在运动；切镜服务信息转换。方向匹配需要画面验证，不将所有硬切描述成无缝连续。
- 可采用每帧采样轨迹实现稳定重建，但关键帧数量不是质量指标。主次运动不能相互抵消。
- 用户认可运镜只代表运动编排通过，不代表材质、背景、阴影、模型精度等同时通过；局部修复保留已认可运镜。

## 背景时序稳定性

柔阴影、悬浮产品的投影、大面积亮度渐变和反射区域要单独验收。Workbench只验证几何与运动；正式引擎用连续24–48帧短片检查背景底部，并检查切点前后。不能用每秒一帧或解码通过来宣称没有闪烁。

发现跳亮、阴影斑块或噪点游走时，固定已认可相机和产品动画，保留原渲染。先确认PNG序列是否已有问题以区分渲染和编码；检查灯光/材质是否被动画驱动。用同帧段单变量对照：提高采样、隔离各灯阴影、关闭反射/间接光诊断或换引擎短测。记录支持哪个原因；未经对照不能笼统归因于“采样太低”。

关闭阴影可用于定位问题，但不自动作为最终修复；需保留产品落地/悬浮的空间感。最终按短片验证选择稳定软阴影配置、足够采样或其他渲染引擎。不要把本例16采样预览设置固化为广告最终质量。修复后检查受影响镜头的完整时序，避免只修一张静帧。
