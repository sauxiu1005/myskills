# 广告分镜 / Shot List

先完成 PRODUCT_MASTER 验证；本表填写实际对象，不是自由虚构产品的脚本。

- 母模型版本与验证报告：
- 总时长、fps/fps_base、分辨率、画幅、起始帧：
- 信息节奏与卖点证据：

| Shot ID | 时长 / 起止帧（含端点） | 核心信息 / 证据 ID | 景别 | 机位角度 | 焦段 mm | DOF / 焦点对象 / f-stop | 构图 | 运镜（起止位置/幅度/缓动） | 产品动作（对象/轴/行程/复位） | 灯光 | 切镜理由 / 前后关系 |
|---|---|---|---|---|---|---|---|---|---|---|---|

## 每镜执行卡（为每个 Shot ID 复制填写）

- Shot ID、场景/相机名、母模型对象、shot asset 映射：
- 起态 → Action → Reaction（执行主体）→ 结果停留 → 末态：
- 相机：传感器、目标点、世界坐标或轨迹、焦段、DOF 开关/焦点/f-stop：
- 灯光：主/辅/轮廓灯位置、尺寸、功率起点及目标反射：
- 文字/UI/Logo、内容依据、入出帧、阅读时间、示意标识：
- 上一镜末态、本镜首态、屏幕方向/匹配关系、下一镜信息：
- 所需新增资产 / assumption IDs / Shot Asset Check 状态：
- 验收：应读清的信息、静帧与动态预览路径、实际结论：

帧范围采用闭区间：N = end - start + 1，时长 = N / (fps / fps_base)，下一镜 start = 上镜 end + 1。先分配整数帧再回算时长，总片不缺帧/重帧。镜头内停留包含在总帧数中，不能额外叠加。

## 运动卡（动态广告时填写）

- 相机起/中/终轨迹、相对产品观察角、景别或画面占比变化：
- 产品 Root 起/中/终位移与倾转；真实功能动作或美术展示：
- 连续段切线/速度、减速停留节点、切镜运动接力：
- 运镜与产品运动有无互相抵消；为何能在屏幕上读出运动：
- 运动模糊/灯光/文字动画及理由：
- 完整低清预览、起中末帧、动态检查方法与结论：
