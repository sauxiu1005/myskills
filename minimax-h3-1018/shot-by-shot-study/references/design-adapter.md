# Design 能力映射与画布操作

首次执行时读取当前环境暴露的真实工具说明，再填写能力表。不要照抄其他平台的工具名，也不要把网页里的工具示例当作已连接接口。

| 所需能力 | 查验内容 | 缺失时 |
| --- | --- | --- |
| 素材读取 | 能否取得当前选中视频、素材 ID、版本、元数据和访问方式 | 请用户提供视频或明确目标素材 |
| 时间测量 | 是否返回时间戳、切点、帧时间及其精度 | 获准时导出后本地测量；否则观察草稿 |
| 画面理解 | 能否实际观看视频/关键帧，是否支持定位回放 | 只提供检测底稿，不填写看不到的内容 |
| 音频读取 | 能否播放核听或 ASR，是否有对应时码 | 留空台词，标记未核听 |
| 画布组织 | 文本/表格/图片/视频节点，分组、更新、资产绑定 | Markdown/JSON/图片文件交付 |
| 用户选择 | 是否能显示真实单选卡并取得明确回答 | 如实说明卡片不可用，征求明确回答，不假装显示过卡片 |
| 交互报告展示 | 是否有可运行 JavaScript 和视频的 HTML 预览/浏览器 | 在已确认 HTML 且可构建时提供完整网页报告包；不能声称已交互展示 |
| 文件上传 | 是否可上传 HTML、JSON、图片、MP4，文件大小限制 | 上传支持格式，保留其余附件 |
| 时间轴合成 | 图层、字幕/面板、时间控制、原音轨、输出规格 | 获准时本地确定性合成 |
| 导出与状态 | 可查询任务 ID、完成状态、可访问结果 | 不编造最终文件或链接 |

以“已发现能力 + 可执行范围 + 限制”保存到 `analysis-state.json.capabilities`。没有 Design 工具时，能力列表应如实为空或记录不可用，不必为制作分析文件而寻找无关生成服务。

## 依赖失败时的单次回退

随包命令因本地 `ffprobe`、`ffmpeg` 或 Node.js 缺失而失败时，不原样重试。若平台有确定性媒体处理能力，改走以下最小闭环：核验元数据 → 场景变化探测 → 全片联系表 → 疑似区间高频联系表 → 锁定切点 → 每镜双参考帧 → 结构校验 → 同步 MP4 导出与验收 → HTML 用户选择卡 → 确认需要后构建交互报告。保存原始候选与排除理由；没有运动差分轨迹时把对应质量门标为 skipped，而不是补造数值。若平台也无法提供时间戳或抽帧，则降级为明确标注估算时间的观察草稿。

HTML 不是 MP4 的制作或验收前置条件。供视频渲染的 HTML/CSS 面板与用户可选的交互 HTML 报告是不同产物。

## 画布落地

1. 定位当前项目和选定素材，创建或复用本任务分组。素材 ID 仅使用实际返回值。
2. 先上传图片/文件并取得真实资产 ID，再创建引用它们的节点。将本地文件路径当云端 URL 传入不会完成上传。
3. 节点引用表以逻辑键保存，例如 `summary`、`shot-table`、`frames-batch-01`、`sync-video`；值为平台真实 ID/链接。
4. 上传或创建超时先查询当前结果，确认不存在后再重试。一个具体失败最多自动重试两次，每次须有可解释修正；持续失败则保留已完成资产并交代缺口。
5. 用户改标注时更新表格、已有报告和同步面板；用户改切点时还需重算时长、重新编号、重抽帧并失效旧面板。以新版本保留旧数据供回退。
6. 创建分组和节点时采用当前项目习惯；上述 01–06 只是默认顺序，不宣称平台支持固定坐标、连线类型或特殊播放器交互。
7. MP4 实际导出验收后先交付，再弹 HTML 单选卡。只有用户确认需要且报告真实可访问后，才添加交互报告入口；不为未选择的分支建立空节点。

## 中间计划不等于平台导入

`scripts/canvas-plan.mjs` 输出：

- `canvas-plan.json`：逻辑节点、每镜卡片内容、关键帧相对路径、摘要和状态。
- `canvas-table.md`：可以粘贴到文本节点的镜头表。

两者均不包含真实 Design 写入调用。执行代理逐项映射到已发现工具；没有对应工具时，交付它们作为“待导入制作包”。HTML 附件只有在平台支持 HTML 预览时才可交互，不能把普通附件上传说成嵌入式播放器。

## 恢复任务

复查素材版本与分析范围，再从状态文件恢复。原片改变时旧切点和帧不得直接复用；只有布局改变时可复用镜头数据。持续写入 `artifacts` 和 `nodes`，把 pending、created、verified 分开。用户已有授权与偏好跨恢复保留。

记录 HTML 选择及其原片/分析版本。相同版本已确认或已拒绝时不重复弹卡；未回答时停止等待，不自动制作；确认需要后只补齐未完成 HTML，不重做 MP4。已拒绝的 HTML 不算整个分析任务未完成。

## 交互报告与文字报告分开

用户明确只要 HTML，或在 MP4 完成后的卡片选择需要时，执行 [interactive-report.md](interactive-report.md)。canvas-plan.mjs 只生成画布内容计划，不会生成视频播放器或跟随滚动页面。通过获准的构建路线生成真正页面，并在支持脚本的预览/浏览器运行。构建器存在不等于环境可运行；文件生成不等于交互验收通过，必须分别验证。
