# 质量检查与交付标准

逐项记录 passed / failed / skipped / unverified 及证据。上游脚本的 15 项校验只作为其中的程序检查，不代替实际观看或平台验证。

| 检查 | 判定依据 |
| --- | --- |
| 素材一致 | 原片身份/版本、分析范围、画面抽查匹配 |
| 时间来源 | 每个时间来自实际测量或明确标估算，未知不填零 |
| 时间覆盖 | 从分析起点 0 连续覆盖至片尾，无重叠/缺口、负时长；容差符合来源精度 |
| 时长与镜号 | end-start 与 seconds 一致，S01 起连续编号 |
| 边界证据 | 检测候选经疑点复核；闪光、爆炸与高速运动误检保留原始时间并写明排除原因，人工边界有位置与原因记录 |
| 关键帧 | 每镜两张可访问且属于该镜；缺失不冒用邻镜图 |
| 视觉分类 | 分类与所见相符；不能把主体运动认作机位运动 |
| 文本/音频 | 台词和屏幕文字有来源，未知声音与说话人不编造 |
| 语义完整 | 描述可核对、相似镜头可区分，节奏分析覆盖所选范围 |
| 统计口径 | 镜头频率与切换频率分清，分布说明按数量或时长 |
| 画布一致 | 节点/表格/已有报告来自同一数据版本，文件已上传而非仅有本地路径 |
| 合成画面 | 实际输出比例正确、文字可读、无裁切遮挡 |
| 合成同步 | 切点前后、快切、长镜、片尾的面板与画面匹配；源时间码连续，恒定帧率素材的帧号单调递增 |
| 合成音频 | 原音轨保留，实际核听无明显错位；无音轨注明 |
| MP4 可访问性 | 导出文件或链接真实存在，必需成片检查通过后才报告完成 |
| HTML 选择点 | 先交付已验收 MP4，再显示两选项单选卡；视频失败或未验收时不得触发 |
| 交互报告（确认需要后） | 播放器与关键帧可用，跨切点高亮、超出可视区自动跟随、点行跳转、向后拖动和片尾同步均经实际验证；文字节点不能替代 |
| HTML 可访问性（确认需要后） | 真正的报告文件或链接存在，所需帧/视频路径完整 |

观察草稿仍可交付，但标题与表头必须注明估算/未知时间，测量和同步项目保持 unverified。缺少视觉工具时只交“检测底稿”，不能称已完成逐镜视觉分析。

如果上游校验与真实证据冲突，记录具体 gate、镜号、测量值和复核依据。可以修正错误边界或标注，不能悄悄放宽阈值、补假台词、伪造 cast 或把失败改成通过。任何有依据的参数修改须在状态中留痕。

默认交付内容：原片引用、shots.json、analysis-state.json、关键帧/联系表、画布分析表、质量记录和同步拉片 MP4。用户明确取消视频时，合成项目标为 skipped 并写原因，不伪装成失败或已完成。

## HTML 分支状态

- MP4 实际导出并验收后，交付视频，再显示运行文件第 7 节 HTML 选择卡。
- HTML 不属于 MP4 的完成前置条件；用户未选择 HTML 时不提前进行交互构建。
- 尚未回答记录 `awaiting_user`；关闭卡片与超时不等于拒绝或同意。
- 用户拒绝记录 `skipped_by_user`，不记为 failed，不把它当作默认交付缺口。
- 用户确认后立即执行制作；实现或依赖受阻记录 `blocked`，保留已完成 MP4。
- 文件实际生成但未完成交互验收记录 `created_unverified`；交互通过后为 `verified`。
- 用户只要文字或已明确拒绝 HTML 时不反复弹卡；明确只要 HTML 且取消 MP4 时，不强制制作视频。
- 相同原片与分析版本恢复时复用已有选择与成功产物，不重复确认、不重做 MP4。
- 源码、Markdown 和带面板 MP4 不能充当已完成交互报告；源码替代交付需要用户明确接受。

## 选择卡回归检查

1. MP4 失败、在执行或中文裁切尚未修复：不显示“视频已完成”的选项卡。
2. MP4 验收通过：实际视频先交付，然后出现“需要，开始制作 / 暂不需要”的单选卡。
3. 选择需要：立即复用既有数据开始 HTML，不再次问是否开始。
4. 选择暂不需要：正常结束，可选 HTML 不算失败。
5. 不回答：停止等待，不自动进入 HTML。
6. 重复点击或恢复：不重复弹卡，不生成重复产物。
7. HTML 受阻：精确报告阻塞与保留成果，不让用户误以为缺少脚本实现或 MP4 也失败。

## 自动化回归检查

1. 已知原片与单帧齐全：确认 HTML 后执行者生成实际文件并自动关联，用户无需复制、另存或再次选片。
2. 只有 Markdown 源码：提取真实 HTML、移除围栏、修复依赖文件选择事件的初始化，打开后直接载入已知原片。
3. 只有联系表或缺少单帧：按已核验台账补齐缺失帧，不冒用联系表、邻镜或估算时间，不重做 MP4。
4. 原片可播但禁止自动播放：正常点击播放后验证；不误报成素材丢失或要求重新选择视频。
5. 原片编码不支持：记录实际解码错误，在许可范围内制作可播放副本，保持时间映射；冲突时先询问，不用带面板成片顶替。
6. 预览/写入受阻：先核验实际能力并报告证据，保留已生成文件；仅请求必要解阻操作，不擅自退成手工教程。
7. 检查中段及片尾高亮、越过初始视口的列表滚动、点行跳转、反向定位和跟随开关，记录真实结果；程序测试不能替代。
8. 交付完整依赖包和实际入口；服务停止时说明预览链接失效，不把源码节点或 index.html 单文件冒充完整报告。

这些是运行验收用例，未实际执行时不得把用例存在宣称为通过。
