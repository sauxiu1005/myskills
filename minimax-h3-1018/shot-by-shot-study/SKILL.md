# 镜头拉片

将已有成片转换为可追溯的镜头数据、真实参考帧、同步拉片视频和简明画布摘要。MP4 完成后，通过用户选项卡提供交互 HTML 报告的追加制作。沿用用户选择的原片、范围、语言和交付目标。英文运行入口见 [SKILL.md](SKILL.md)，来源与许可见 [NOTICE.md](NOTICE.md) 和 [LICENSE](LICENSE)。

## 交付要求

除非用户明确只要文字或取消视频导出，默认拉片交付包含画布摘要与逐镜表、真实参考帧、质量记录和分镜信息同步学习 MP4。MP4 实际导出、验收并交付后，显示第 7 节用户选项卡。仅在用户明确选择需要后制作 HTML；未选择或选择不需要时，HTML 不属于缺失的必交付项。

用户确认需要后，交互报告必须有：

- 可播放原片与真实关键帧。
- 由视频当前时间驱动的镜头表。
- 当前镜头高亮，以及仅在镜头列表容器内部进行的自动跟随滚动。
- 跟随开关与点击镜头行跳转。

Markdown 文档、画布文字/表格节点、截图、HTML 代码块和动画 MP4 均不能替代可交互页面。缺少受支持的运行或预览条件时，交付能够生成的文件，明确哪些实现或预览尚未完成；不得把纯文字称为已完成的交互报告。源码交付只可作为用户明确接受的替代方案，不是默认替代成品。

## 1. 确定范围与实际能力

使用选中或附加的原片。默认分析全片，沿用用户交互语言；仅在缺少原片、素材有歧义、未定的重要输出选择影响工作，以及 MP4 完成后的必需 HTML 选择点提问。默认媒体交付为分镜信息同步学习视频，不增加生成画面、配乐、配音或无关剪辑。

读取 [references/design-adapter.md](references/design-adapter.md)，检查真实工具后再映射素材读取、元数据、带时间戳帧、确定性处理、文件创建、画布写入和浏览器预览。

记录所用路线：

- 平台工具能够返回可靠元数据、候选切点与带时间戳帧时，采用平台原生测量。
- 宿主确实提供并允许所需执行环境时，才采用随包本地辅助脚本。先检查依赖；本技能不授予工具权限，也不覆盖宿主限制。
- 只能观看原片时，交付观察草稿，明确时间估算或未知，不承诺精确同步。

若随包分析器因本地依赖缺失而无法启动，不重复执行同一失败命令，也不直接放弃分析。改用当前可用的确定性媒体处理能力：读取已核验的流信息、运行场景变化探测、保留全部原始候选、抽取带时间依据的复核联系表，并明确运动曲线校验不可用。这条回退路线仍可提供实测切点，但不能伪造随包运动轨迹。

安装或适配时保留完整 scripts、渲染资产和 references。缺少某项依赖时标明对应路线不可用，不要删除实现后用文字替代用户已要求的交互交付。原生替代实现也必须满足相同交互要求并经过验证。

## 2. 确立原片与权威数据

记录真实素材身份/版本、可访问路径、时长、宽高、帧率/时间基准和音轨情况。未知保留未知，文件名、缩略图或语义摘要不等于已经观看视频。

对片段记录已核对的源片偏移，使用准确裁出的片段或经验证的时间映射。分析时间从零开始；可变帧率边界使用实际呈现时间戳，不由平均帧率推算。

按 [references/data-contract.md](references/data-contract.md) 维护权威 shots.json 与独立 analysis-state.json。画布表、用户选择制作的 HTML 和视频面板由同一版本派生。保留实测时间与原始证据；边界通过实际测量或可追溯的 recut 修正，不能伪造数值。

## 3. 测量并复核镜头

读取 [references/analysis.md](references/analysis.md)。检测候选切点，在每镜约 15% 和 85% 处抽取参考帧，再复核疑似边界；这两帧不是真正的首尾帧。

按以下顺序复核：

1. 先制作全片联系表，理解动作发展和暂定镜头顺序。
2. 对候选点密集、闪光、爆炸或高速运镜区间制作更高频的连续帧联系表。
3. 只把确认后的边界写入权威镜头表，同时记录每个被排除候选及其视觉理由。
4. 边界锁定后，再为每个确认镜头批量抽取前后两张真实参考帧。
5. 按阶段批量抽帧，不逐镜交替执行分析、标注和报告渲染。

检查闪光、暗场、叠化、近似反打以及异常长短镜。连续长镜内可以改变运镜而不形成切镜。不确定的运动或内部切点需要额外带时间戳帧或动态回放。

仅在依赖与执行路线可用时按 [references/local-tools.md](references/local-tools.md) 操作。随包分析工具需要 Node.js 18+ 与 FFmpeg/FFprobe。上游运动曲线是采样图像差分，不能证明摄影机移动；不为通过检查器而改证据或编台词。

## 4. 依据证据逐镜标注

每镜记录镜号、起止/时长、景别、主要叙事类别、运镜、可见内容、证据和置信度。按需增加转场、画面文字/声音、项目内人物编号与节奏判断，词表见分析参考。

区分主体运动与摄影机运动、变焦与实体移动。描述可见动作和空间关系。对白来自核听、转写或有来源标记的字幕；字幕不证明声线身份。未核听时明确说明。

节奏标签属于解释，不是观众留存测量；启用时覆盖整个所选范围。N 镜、T 秒对应镜头频率 N/T×60 和切换频率 (N−1)/T×60；上游 cutsPerMinute 使用前者口径。

## 5. 整理画布

能力允许时创建或更新一组连贯的项目产物：

1. 原片与范围说明，包含证据等级和素材版本。
2. 实际抽出的参考帧或联系表及镜号。
3. 逐镜分析表：时间、景别/类别、运镜、画面、文字/声音、节奏与置信度。
4. 简明、有依据的结论；仅在用户确认制作且报告实际可访问后追加交互报告入口，不创建空入口或猜测链接。
5. 质量记录和待复核项。
6. 确定性导出成功后的分镜信息同步学习视频；用户明确取消时除外。

优先复用真实素材/节点 ID 和已有节点。内置工具输出可能已在画布中，不重复登记。抽帧结束后，把全片联系表、高频切点复核图和确认镜头关键帧整理为一个证据分组；另建简明摘要节点与结构化逐镜表，用户选择的交互报告本体仍作为完整独立包交付。scripts/canvas-plan.mjs 只生成本地节点内容计划与 Markdown 表格，不写入 Design，也不渲染交互报告。

## 6. 导出并验收同步拉片 MP4

读取 [references/sync-video.md](references/sync-video.md)。除非用户只要文字或明确取消视频导出，否则在镜头数据、准确素材身份与范围通过校验后导出 MP4。HTML 制作和验收不是先决条件，不得阻塞本步骤。片长相同不等于素材相同。

采用确定性编辑，保留画幅比例、原片时长和原音轨。无其他要求时，横/方片画面在上、面板在下；竖片画面与面板并排。画面固定显示当前镜号、源时间范围、镜长、景别、运镜和简洁动作描述，并始终显示源时间码；只有确认恒定帧率后才附加帧号。面板变化绑定镜头区间，滚动只在切换附近短暂发生，确保暂停、拖动和逐帧学习时信息清楚。

上游 video-sync 的面板渲染还需要受支持的无头浏览器，只能通过可用且获准的执行路线使用。完整合成前必须探测运行时 crop/overlay 动画命令是否真正生效；进程成功但命令回复 `Function not implemented` 仍属于动画失败。若不支持，改用 `scripts/compose-sync-video.mjs`：逐帧计算滚动、补足透明尾部安全区，并让最后一镜在切点立即进入安全锚点。两条合成路线均复用生成面板时保存的布局，并随原片画面结束，包括无音轨素材；缺少布局计划或改变几何时重新生成面板。原生替代必须保留用户要求的结果，不把明确要求的滚动静默改成静态卡片。

导出后立即执行第 9 节中的成片像素、同步、文字可读性和原音轨检查。只有真实文件可访问且必需检查通过，才能报告“同步拉片 MP4：已完成”。先交付该 MP4，再进入第 7 节选项卡。如实说明实际版本，不把无滚动的信息卡版称为滚动版。

交互 HTML 与同步 MP4 是不同交付：前者可点击导航，后者只有渲染出的动态画面，镜头表不可点击。

## 7. 显示 HTML 用户选项卡

第 6 节完成后，显示真实的单选用户选项卡，不能只用普通聊天问题代替。MP4 仍在执行、导出失败或必需检查未通过时，不显示完成后的选项卡。卡片按用户交互语言呈现，保留两个选项及其顺序。

- 标题：**交互 HTML 报告**
- 问题：**同步拉片 MP4 已完成。是否需要继续制作支持点击镜头跳转、当前镜头自动高亮和镜头列表自动滚动的 HTML 报告？**
- 选项 1：**需要，开始制作** — 复用已完成的分镜数据、原片与关键帧，制作并验收可交互 HTML 报告。
- 选项 2：**暂不需要** — 保留已完成的 MP4、分镜表与关键帧，本次不制作 HTML。

必须明确单选，不预选，不把关闭卡片、超时或无回复视为同意。

- **需要：**记录当前原片与分析版本对应的确认，立即执行第 8 节。不只答应稍后制作，不再次询问是否开始，不重复完成的分析或重新导出 MP4。
- **暂不需要：**记录 `skipped_by_user`，保留已完成资产，正常结束；HTML 不属于失败或交付缺口。
- **没有回答：**记录 `awaiting_user`，停止在此处，不开始制作 HTML。
- 卡片等待期间，用户在普通聊天中明确说“需要”“生成 HTML”“开始制作”等，与肯定选项等效；含糊时只澄清一次，不推定同意。
- 用户先前已明确拒绝 HTML 或只要文字时，尊重已有选择，不反复弹卡。用户明确只要 HTML、取消 MP4 时，执行其明确请求，不强制生成 MP4。
- 默认流程中，早先笼统的“全套”要求不能替代 MP4 完成后的选择。同一原片与分析版本已经选择后，不因恢复会话、重复点击或查询状态再次弹卡；用户主动改变选择时只继续未完成分支。

选择和版本状态按 [references/data-contract.md](references/data-contract.md) 记录。

## 8. 制作、打开并验收用户选择的 HTML 报告

仅在第 7 节确认需要或用户明确只要 HTML 时执行。复用已核验原片、镜头台账、标注、关键帧和质量记录。先检查包内构建器、预览服务、跟随资源及真实数据，再核验获准的执行、文件写入、依赖与预览能力。分别说明“实现存在”“环境可运行”“文件已生成”“交互已验收”；用户确认不覆盖宿主限制。

读取 [references/interactive-report.md](references/interactive-report.md)。有获准的本地执行环境时，通过 scripts/build-report.mjs 构建完整报告目录：封装上游 HTML 渲染器、附加跟随滚动扩展，将原片与关键帧复制到相对路径。构建器不重新分析视频，也不核验素材身份。

报告必须在支持 JavaScript 的真实 HTML 预览或浏览器中运行。需要本地服务时，scripts/serve-report.mjs 仅绑定回环地址，并支持可靠跳转所需的 HTTP 字节范围请求；打开它实际输出的地址，不假设不同机器共用 localhost。

画布文字节点只作摘要和入口，不是执行 HTML 的容器。交付包含视频和关键帧的完整目录或 ZIP，不只上传 index.html。平台仅支持文字、表格、媒体时，交付报告链接或可下载包，在真实浏览器交互；遵守浏览器工具本身的前置要求和权限。

若不能执行 shell，但确有受支持的网页产物工具，可把随包渲染器作为实现参考，保留同样的播放器、时间驱动、高亮、跟随和跳转功能。先检查这条路线是否存在。若执行或依赖受阻，把 HTML 标为 `blocked`，保留已完成 MP4，说明精确的缺失条件。不得默认退化为 Markdown 源码交付；仅在用户明确接受该替代时提供，并注明未构建或未验收。

实际验证跨切点播放、高亮、超出初始可视范围的自动滚动、点击跳转、向后跳转、最后一镜和跟随开关。推荐验收顺序：确认原片和全部关键帧加载；跳到中段镜头并播放跨越多个切点；检查末镜高亮和列表滚动位置；关闭跟随并向后跳转，确认列表不被强制拉回；重新开启跟随，确认列表回到当前镜头。把真实结果写入报告检查文件；生成文件及语法检查不等于交互验收。

### 自动完成，不把操作交回用户

确认后按 [references/automatic-html.md](references/automatic-html.md) 直接执行，不再次询问是否开始。执行者负责生成真实 HTML 文件，以可迁移的相对路径关联已知原片和核验后的关键帧，按需启动获准的预览服务，在受支持的浏览器打开实际地址，验收交互并交付完整素材包与真实入口。不得停在源码、操作说明或未经核验的“浏览器不可用”判断。

若只有 Markdown 源码，使用获准的文件写入能力提取真实 HTML、去除 Markdown 围栏，把强制选择文件的初始化改为已核验的相对路径绑定，并检查实际网页。联系表不能冒充独立关键帧：优先复用已核验的单帧文件，确实缺失时才通过可用媒体能力从原片补抽。不得用带信息卡 MP4 替代原片、编造测量时间，或为了运行报告改动已有源文件及生成资产的路径；报告包可保存明确记录来源的副本。

文件选择器可以保留为可选恢复入口，但不得阻塞正常启动。复制代码、另存文件、重新选择已知原片、点击提取关键帧按钮，不是默认交给用户的任务。浏览器禁止自动播放时，验收中的正常点击播放与“未关联素材”是不同问题。若存在真实的能力、编码、权限或浏览器界面阻塞，记录准确证据并保留已生成文件，只请求解除阻塞所必需的最小用户操作；源码或人工步骤替代必须由用户明确接受。文件生成只记 `created_unverified`，不得记为 `verified`；结构测试通过不等于真实播放通过。

## 9. 验证、恢复与交付

按 [references/quality.md](references/quality.md) 分开记录通过、失败、跳过和未验证。数值检查不能证明视觉准确。必须对成片实际像素抽帧：覆盖首镜、各切点后的稳定帧以及末镜早/中/晚三帧；最后一镜高亮行、缩略图和全部文字都要完整可见。保留已完成资产，超时后先核对状态再重试；最多两次有针对性的重试后仍失败则报告具体阻塞。

标注变化使受影响的报告/面板失效；边界变化还使镜号、时间、帧映射和相关标注失效；原片变化使不兼容证据失效。保存版本与真实节点映射，恢复时不重复创建画布。HTML 选择仅复用于其绑定的原片与分析版本，不把旧产物冒充新版本。

交付真实文件或可访问报告链接，说明分析范围、镜头数、时间精度和未决项。默认产物包含画布摘要与逐镜表、证据帧、质量记录和同步拉片 MP4。视频完成后显示第 7 节选项卡；只有用户选择需要后，交互 HTML 包才成为追加交付要求。已拒绝的 HTML 不算缺失；已确认但受阻的 HTML 如实报告，不影响已完成 MP4 的可用状态。不声称未实际发生的安装、浏览器验证、画布交互或视频导出。
