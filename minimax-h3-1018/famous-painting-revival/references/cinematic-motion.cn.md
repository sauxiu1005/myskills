# 电影运镜与动作预算

两条视频路线及修改时长时使用，并结合空间连续性。路线定义叙事／摄影结构，视觉媒介另行约定。

## 路线 A：FPV沉浸入画

必需链条：低机位穿行 → 接近主要人物 → 近距离环绕 → 拉远回原画构图 → 定格。从画内地面／水面附近进入，明确可辨前景经过点和真实通道，不用慢速缩放冒充穿行。环绕须有绕主体的侧向位移、观察面变化及背景遮挡／视差，不能用主体转身、原地摇镜或前后推拉代替。穿行和环绕时，人物须有自然行动、视线和表情变化，与同步运镜分别设计，不得全程保持终场静姿。无人画用主要对象与合理环境变化，不虚构演员或拟人化静物。

一镜到底可选而非强制；一旦批准，失败不授权切镜。拉远时人物自然完成画中姿态，同时让机位观察方向、相对尺度、主体位置、物件关系和环境框景归位。不以瞬移、换脸／背景或突然插入原画代替抵达。

环绕明确世界空间圆心、方向、符合场景的弧度、半径、高度、景别、时长及进出状态，不强制整圈或进入物理上不可达空间。先让环绕本身清楚可读，再叠加推进或升降。人物转身与相机绕行是独立运动；近景植物、中景地形和远景应产生不同视差，仅凭人物脸和背的变化不能认定完成环绕。过轴通过可见的连续位移交代，不镜像场景。相机路径避开身体、牵手手臂、道具及实体植物。

特写从环绕退出轨迹自然接入，不突然换观察面；以目光或行动引出下一次移动，状态记录保留画外伙伴，相机后撤时让出人物奔跑路径。不靠缩小人物或突兀变焦代替真实后撤。

## 路线 B：画前故事演绎

必需链条：画面／背景 → 有据或明确演绎的前因 → 人物目标与行动 → 可见后果 → 自然形成原画瞬间 → 定格。开端与终场有意义地区别。必须有动机的切镜和不同视角／景别，每镜揭示事件、细节、反应或后果，不对静姿反复换角度；不沿用FPV可选一镜到底。镜头数依故事和时长，不固定模板；不为丰富而随意增加人物、地点、动物、冲突或通用动作。

关键动作与结果可读，不用切镜、水花或遮挡隐藏未完成行动。下一镜继承动作进度、身体位置、视线、道具归属、运动方向及环境状态，不重演或复位。由剧情后果形成原画构图，不贴无关静帧。

## 人物表演与环境
每镜写清起始状态 → 目标／动机 → 主动行动 → 支撑／接触／重心变化 → 身体／物件／环境回应 → 结束状态 → 下一镜继承项。人物与摄影机运动分别描述，并说明时间关系；道具从持有者释放后有连续轨迹，不无故换手、复制或返回。水花、发丝、布料及环境运动辅助而不替代行动。保留目的明确的简单动作，删减超量重复，不抹掉活力或全程慢动作。

表情由发现、决定、靠近、回应、放松等具体事件触发。视线、头部、肩膀、重心与脚步自然重叠衔接，避免摆好姿态再逐条执行。接触交代靠近、支撑和松开，道具始终有持有者，换手先接稳再放开。保留衣料重量与脚底承重。

地形、光照和风向在世界空间中连续，屏幕方向可随环绕变化。草叶、发丝、面纱、厚裙料对同一阵风作出不同反应。不可见环境属于设计补全，不冒称历史现场证据。

## 自然材质与风格时间

视觉媒介依获准项目。前段写实、末段转画时，区分皮肤、发丝、织物、水与植物的真实材质；避免过度磨皮／蜡感、通体高光、塑料质地、HDR式锐化和提前出现厚重油彩涂抹。自然不等于全部哑光，保留湿布料、水面或服装合理局部反光。原画提供外观、服饰、环境与颜色依据，不锁定静止姿态或提前笔触。背面服装和画外空间仍是设计补全；所选模型留在项目状态，核查实时能力，不固定供应商。

## 修改时长
先预算收束、定格、转画和停留，再分配动作；冻结后的转画计入静止片尾。剧情持续推进，不让后半段靠漂浮、拉远或停留撑时长。时间分配和镜头数按项目，精确区间是目标，不保证逐帧遵守。动作耗时和相机路径耗时都要计算；缩短成片要重新设计节奏，不能简单加速或将长提示词塞进短时长。保护用户核心动作和主运镜，优先缩短移动距离与重复手势；删减剧情要明确说明，不悄悄删除要求或改变已批准环绕角度。

核对隐含速度：角度除以时间是平均角速度，半径决定行进距离。几秒完成一圈会有明显运动感，不能同时承诺极慢环绕。若动作无法连贯容纳，生成前说明具体冲突，提出增加时长或明确简化的方案。用户接受的紧凑方案可以尝试，但不能承诺每个动作精确发生。

分别记录源片请求时长、实测返回时长和最终成片时长。源素材可留稳定余量，但最终按实际文件组装，标称片长相加不证明最终时长。秒数、环绕角度和帧率均为项目参数。一轮失败不授权给获准一镜到底方案增加切镜。

## 资产与执行
检查现有身份参考是否覆盖侧背、场景是否支持路线；复用充分人物／场景资产，由动作文字和空间约定处理运动。缺动作静帧不是自动阻断项；仅未解决关键几何或具体输入限制才补最少获准参考，不默认每动作／每镜出图。竖幅关键帧不能悄悄硬裁为横屏首帧，区分设计参考与强绑定首帧。执行时查询当前模型时长、画幅、参考上限和接续能力，不将某平台或能力表固化为skill要求。

分段时继承实际末端姿态、机位、方向、速度、道具、光线和风。单张末帧不能保证运动连续，支持时优先视频接续；检查接缝，不把拼接成片冒称原生一镜到底。

## 验收

实际动作、声音、片尾及报告冲突统一使用[证据与验收](evidence-acceptance.cn.md)。环绕段需足够密集地观察连续位移和视差，零散正背面帧不能证明完整绕行或精确角度。检查分段接续接缝，如实说明制作方式。
