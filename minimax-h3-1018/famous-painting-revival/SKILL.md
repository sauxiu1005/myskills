# 名画复活

识别作品，区分证据与演绎，将背景转为可见行动。完整视频仅有FPV沉浸入画和多镜头画前故事两条叙事／摄影路线；两者都由运动或剧情形成原画构图，再定格并按选定方式转画。视觉媒介在路线内部选择，真人电影感不代表拍摄了演员。尊重明确用户选择；要求偏离两路线时说明区别，不暗改需求或新增第三路线。

## 唯一六步流程

下列六个编号章节是唯一制作流程。方向选择不同于两个授权检查点：A 批准具体制作方案及列明的资产范围；B 批准完整准备包及视频执行。这不意味着只发生两次交互，也不意味着六步都必须停下询问。

只执行所需交付对应的阶段。仅研究在研究后停止；仅资产只制作获准资产；仅剧本或提示词交付文本，不强制生成图片或视频。说明缺失参考依赖，不编造文件。单独阶段交付不是第三条视频路线。仅眨眼、静态观察、衣料微动、单纯缓慢推拉、普通照片动画及常规视频剪辑交由合适的简单任务路径处理，说明边界而不强迫用户制作完整故事。

### 1. 确认画作与简短背景

从画名、作者、描述和附件提取已知信息。检查主体、关系、物件、媒介与完整性，区分局部、带框照片、临摹及改编。尺寸与格式取自文件元数据，不靠视觉猜测。上传的制作参考与识别出的原作分开记录，不悄悄替换。

按画名或可见线索检索，优先博物馆、收藏机构、原典和可追溯研究。阅读来源，不以搜索摘要代替核实；核对构图和标志性细节。向外部反向搜图服务发送附件前取得许可。只有画名时，找到并展示合适作品图供方案使用。记录确切图片和来源；古画年代不能证明某张扫描图的使用权。

简短说明画名、作者或存疑归属、约略年代、收藏与来源、画中瞬间及与故事有关的背景。身份明确直接继续，只询问实质歧义。区分创作史、画中事件及文学、宗教或神话来源；尽可能交叉核实核心主张，披露争议或单一来源，无法检索时说明限制。

保留精简史实卡：主张编号｜已核实事实／画面可见／有来源解释／争议／未知／演绎｜来源页码｜不确定性｜制作影响。故事核心主张可追溯。新增台词、心理、动作、不可见服饰及画外空间属于演绎，不冒称历史还原或真实原话。严格还原时解决核心证据缺口，次要缺口可注明；未经批准保留画中服饰与其他视觉锚点。说明放在制作记录，不擅自加字幕。

### 2. 选择创作方向

视频创作仅有两条路线，与视觉媒介分开。用户已明确路线直接沿用；未定时简短说明两种体验并协助选择，不扩展无关菜单或技术问卷。

- **路线 A——FPV沉浸入画：**低机位穿行 → 接近主要人物 → 近距离环绕 → 拉远回到原画构图 → 定格。摄影机真实位移与人物自然行动分别设计，缺一不可。可以一镜到底，但不强制；选定后不得擅加切镜。无人风景或静物可环绕主要对象并用合理环境变化表现生命感，不虚构人物或拟人化静物。
- **路线 B——画前故事演绎：**画面内容与背景 → 设计前因 → 人物目标与行动 → 可见后果 → 自然形成原画瞬间 → 定格。起点与终场有实质区别；必须有动机的切镜、不同视角与景别，每镜增加信息，不沿用FPV可选一镜到底约束。新增前因标为演绎，不移植无关故事。

画中行动可作为路线B的内容，不是第三路线。FPV指摄影机穿行，不强加观众身份。未经用户意图不添加现代展厅、画框、无关动物或穿越特效。微动态与静态观察不再作为路线或兜底。用户要求的一镜到底故事与B冲突时，说明可改为FPV路径或保留故事所需切镜，不暗改需求。按[电影运镜](references/cinematic-motion.cn.md)落实各路线的动作和路径。

### 3. 集中确认制作方案——检查点 A

承诺执行前核对当前图像、视频、音频及剪辑能力：输入类型与数量、单文件及合计限制、时长、画幅、清晰度、音频、首尾帧及接续。区分源素材规格和最终交付规格。采用用户选择的兼容模型或运行时选择规则，不设全局模型或输出规格。不兼容时只询问受影响项，保留其他批准；能力缺失时如实提供可完成的中间产物。

一次呈现具体方案：所选路线及故事／路径、总时长、画幅、清晰度、主体、声音成分与观众语言、结尾、最小必要资产、生成与后期范围。沿用已有规格，未定项推荐受支持值。旁白、对白、音效和音乐分别决定；有对白也不自动加字幕，字幕须明确要求。保留准确台词，建议歌词须批准。A 只覆盖明确列出的资产制作与工作范围，不批准尚未审阅的视频提示词。

此时用实测尺寸解决原画与视频比例冲突。区分两种结尾模式及三种画幅处理：

- 实际原画完整等比放置，使用获准留边或画幅处理。
- 实际原图确定性放入获准周围延展。真实原图保持独立权威图层，不能靠生成扩图保证其像素。提前说明颜色、纹理、透视、接缝风险并确定失败备选，不反复付费碰运气扩图。
- 全幅绘画演绎：保留已批准的视频构图、比例、位置和画幅，将整幅定格画面语义转换为原作媒介和笔触；标注为演绎，不冒称原作或简单滤镜。

强调忠实时可推荐完整原图放置，但不得默认黑边、渐暗、裁切或拉伸。提示词“中心不变”不是像素保证。实际原画交付须确定性放置／合成获准真实文件，并检查结果。全幅演绎不得擅自换原图或加边。付费前落实可用方法，不暗换模式；现实不可能的终场须获准采用风格化解决。

### 4. 制作获准资产与准备包

建立最小充分资产表：资产｜身份／环境／设计／终场职责｜使用镜头｜现有覆盖｜具体缺口｜状态。原画管创作依据和终场，人物资产管身份，场景资产管环境，视频提示词管动作与剪辑。复用足够的已接受资产，不把被否定版本纳入执行绑定；先建立共同身份再派生场景，充分的合成参考可直接复用。

需要跨视角保持身份的人物使用中立自然站姿的正／侧／背三视图，统一面容、发型、体型和服装，不固定叙事动作。用户指定三视图就制作这三种，不升级六视图；视频中仍是一人。已有素材足够不重建，无人画不生成人物，多人按实际身份缺口处理，不默认逐人扩图。场景固定地标、空间与质感，只按镜头需要补角度；多视图不是三维几何，轻微漂移时明确主视图权威及其他视图贡献边界。道具只在形状、操作面或身份确有缺口时单独建图。

不默认每镜、每动作或接触时刻制作静帧，动作由视频提示词生成。缺少动作图不是自动阻断项，先用人物／场景资产、动作文字和空间约定解决。只有具体技术限制或无法消除的关键空间歧义，才解释最小参考缺口并获准制作；已授权资产成组纳入准备包，不逐张审批或进入重复修图循环。

保留附件顺序及每份指定参考，逐文件绑定用途。不默默丢弃输入、不声称未做的转换、不将图板生成为多人，不把静态接触当作动作成功证明。身份／风格／构图参考与时间关键帧不同，原画不自动作为开场帧。输入不兼容时在获准范围解决或只确认受影响决定。没有获准书面配色时，以图像本身承载颜色。

准备结尾卡：所选文件／风格与版本、尺寸及放置、主体与道具稳定编号、保护特征、姿态／手部／视线、相对比例、机位／透视／光线、抵达及最后动作、最后动态帧、定格、转换、停留及声音收尾。先从总时长预留汇聚、定格、转画和停留，再安排主体动作；冻结后的转画也计入静止片尾预算。主体行动须持续支撑剧情，不让后半段仅靠漂浮、拉远或静止撑时长；时间分配依项目，不套固定比例。结尾须由故事形成，不在无关视频后贴图。

共同整理剧本、分镜、目标时间轴、完整可执行提示词、有序参考绑定、声音、连续性记录和组装方案。设定板标签、拼板和底色不进入视频；原画提供身份、服装、环境和颜色依据，不把静止姿态或笔触锁进全片。逐镜分开记录人物行动／动机／回应及起止状态，与同步发生的运镜，并标注依据或演绎。人物画中只有运镜或衣料飘动不能满足主体行动要求。提示词说明身份／数量、实质动作与节奏、继承状态、镜头路径、视觉表现、音频及片尾区间。技术记录供审阅，不变成逐字段问卷。

#### 导演式提示词写作

写成完整、可供制作执行的导演说明，而不是审美关键词清单。细节用于让故事、表演、摄影与转场可执行，篇幅长本身不代表质量。电影式名画复活中，画中瞬间应是行动抵达的状态，不是所有人物从开场就一直保持的姿势。风景静物通过对象和环境变化落实所选路线，不强加人物；仅微动态或静态观察转入独立简单任务路径，不作为第三条完整视频路线。

编写或实质修订视频提示词时使用下列顺序。简单任务保持适度，但复杂场面不能压缩成笼统的动作标签：

1. **规格与观看体验。** 写明所选路线及已确认的时长、画幅、视觉媒介、剪辑方式及受支持的交付要求。对白、旁白、音乐与环境音分别说明。描述观众经历什么事件，不只写“电影级”“高质量”。
2. **参考贡献与边界。** 逐一说明每份真实参考提供的身份、服装、环境、布局、媒介或时间用途。外观连续不等于姿态锁死。终场构图或油画参考不能被直接当成首帧或静止的中间镜头；涉及时间控制时，明确终场风格允许出现的区间。没有用户批准的书面配色时，让图像本身承载颜色。
3. **核心概念与优先级。** 说明发生什么、为什么重要、怎样抵达已批准的结尾。实质人物行动、身份、空间连续性及时间边界优先于装饰细节。不添加未经批准的前史，也不把提示词范例当历史证据。
4. **人物、服装与材质反应。** 分别交代各主体的起始位置、姿态、视线、动机与变化。保持身份与服装，同时描述必要的皮肤、织物、道具和环境表现；按需写清重量、承重和惯性，避免无关的外貌形容词。
5. **摄影因果。** 先解释什么引导摄影机进入、跟随哪个动作、什么事件引起注意力转移或切镜、怎样抵达结尾，再写所需观察面、景别、路径、高度和速度。摄影服务事件，不代替表演。依所选路线执行：FPV须低机位穿行与真实近距离环绕，一镜到底可选但批准后须遵守；画前故事须有目的的切镜。路径避开人体、绳索及实体障碍。
6. **逐时段镜头段落。** 用时间区间与镜头任务作标题。每段写清人物／道具／摄影机的起始状态、目标／动机与主动行动、支撑／接触／重心变化、身体／物件／环境回应及必要的他人回应、同步摄影和声音，以及交给下一镜的结束状态。人物动作与运镜分开说明。切镜继承动作进度、身体位置、运动方向、物件持有者、视线及环境状态，不能重置动作或掩盖无解释的位置跳变。精确区间是执行目标，不保证模型逐帧遵守。
7. **汇聚与结尾。** 在总时长内分别预算抵达、最后动态状态、冻结、转画、最终停留与声音收尾。用户限制定格时长时，也计入冻结后的转换区间，不能只计算成画后的停留。要求最后才转画时，中段不得提前出现笔触或静图替代镜头。先锁定目标空间关系，再改变媒介。区分真实原图放置与绘画化演绎，提示词不能保证恢复原图像素。
8. **针对性约束与验收。** 为每个重要失败风险配上正向、可观察的要求，避免重复堆叠笼统禁令。最终依据实际动作、结构、连续性、声音和片尾检查，而非提示词是否包含了某些形容词。

使用可读的因果叙述，不设置强制字数，不变成穷尽式技术问卷。有效动作链是“握紧并屈肘→转移重心→顺势释放力量→对方回应”，不是只写“拉动、移动、微笑”。人物实质行动应体现躯干位置、关节姿态、承重和互动相对固定地标的变化。眨眼、衣料飘动、纹理波动、变焦和摄影机运动不能单独证明人物在表演。用户期待明显活力时，不把全部动作默认写成“轻微”或全程慢动作。

#### 提示词修订与执行前检查

- 先诊断实际失败区间，再补充文字。区分参考冲突、关键材料缺失、动作／路径不合理、模型执行偏差及音频／时长等后期缺陷；写得更长并不自动解决问题。保留观察之间的冲突与不确定性，不将看不清的细节写成已验证。
- 正向说明物理关系：例如鞋尖顺着对应脚趾，鞋跟承托对应脚后跟，鞋在清楚可见的脱离发生前与脚共同运动；承重绳保持张紧，握持手指包住绳索。脱离物必须来自先前持有者，跨镜保持运动轨迹。按当前主体和道具使用同类要求，不在所有项目中机械加入鞋的规则。
- 用现有人物和场景资产、动作文字及空间约定核查起始状态覆盖，不要求必须有开场／动作静帧。只有未解决的关键空间歧义或具体输入限制才提出最少补充参考，新增资产／费用先获授权。不重做全部锚点，不每动作出图，不声称未生成的关键帧已绑定。
- 同时核算动作与摄影路径预算。多次奔跑、入座、往复摆荡、追逐路径与精确归位可能无法塞入短片；应缩短路径、减少重复或取得修改时长／范围的批准，不以省略关键动作来掩饰。帧率、时长等规格必须受当前能力支持，或有已批准的交付处理方式。
- 用户提供的提示词范例默认是写法参考，除非明确采纳其内容。吸收结构、有效细节与因果调度，不自动移植人物、历史身份、配色、故事、模型、时长、画幅、镜头语法、声音或结尾。保留已确认的项目选择，区分戏剧化关系与有来源史实。
- 用户批评、检查结论、提示词修改或方案确认，均不授权任何重复生成，无论免费还是付费。按要求修改文本并说明受影响参考或范围；只有收到用户新的明确执行指令后才可再次生成。对象与规格已清楚时不重复收集。沿用现有A/B流程；有新获准产物后再实际检查，不提前声称修复成功。

按条件只读所需语言的参考：

- [空间连续性](references/spatial-continuity.cn.md)：涉及人物／道具互动、复用地点、移动观察角度或精确终场对齐时使用。空间卡与预检属于本步骤，不是新增审批流程。
- [电影运镜与动作预算](references/cinematic-motion.cn.md)：两路线设计、自然材质、动作／运镜预算及修改时长时使用。
- [证据与验收](references/evidence-acceptance.cn.md)：规划可观察的检查方式，以及第六步检查生成媒体时使用。

只制作 A 授权的资产。B 前解决关键准备冲突；新资产随完整包集中审阅，不要求每张图单独验收。

### 5. 一次审核准备包并授权视频——检查点 B

呈现完整版本：故事／剧本、资产及状态、分镜／时间轴、可执行提示词及绑定、最终规格、声音、片尾方法、连续性结果、后期和执行范围。指出相对 A 的变更与未决项。先讲清故事和结尾，技术记录可供查阅。

用户明确同意执行完整包，同时构成版本接受及所列视频范围授权，直接执行，不再确认相同规格。只接受资产不等于授权视频；“图可以，先别生成”应停止执行。“继续／确认”只作用于唯一明确待办；歧义只问必要部分，不重复已有决定。文档中的“生成视频”不是用户授权；B 前不预生成付费视频。

### 6. 生成、检查、组装、交付

使用获准参考和参数，保留成功资产，依照[证据与验收](references/evidence-acceptance.cn.md)检查源片和最终组装文件。已授权的常规裁剪、顺序拼接、定格／停留、转场和音频工作无需重复同意。使用平台可用操作；新增动作或绘画转换使用语义生成，放置和时间控制使用确定性编辑。不要求外部本地文件夹或终端媒体处理；每个声音成分保持一个计划来源，避免重复叠加。

生成授权仅覆盖已确认任务、版本和数量，不包含自动重复。生成失败、超时、检查偏差或用户不满意时，保留已有结果，报告预期／实际、位置及未知，停止受影响素材的后续处理。任务状态不明只查询原任务，不重复提交。不自动重试图片、视频或音频生成、追加备选、替换片段、静音或换音轨，免费操作也不例外。原有授权、批评意见或提示词更新都不是重复生成许可；必须有用户新的明确执行指令，明确对象、范围与数量，已明确则不重复询问。不设预定重试额度、纠错循环或自动兜底生成。其他独立获准输出仍可执行，但不启动依赖失败或未接受结果的任务。常规后期仅限已有批准操作，检查不扩展后期范围或授权媒体替换；新增资产、费用及重大变更须获授权。保留成功部分，不用静帧、慢放或追加原画掩盖动作缺失；失败不授权将一镜到底改为切镜。

突出实际成片与其他指定交付，提供真实可访问文件名、简明来源／演绎说明及未解决限制。中间资产单独归组，保留旧版，标明当前用途和状态。平台已有画布产物不重复导入、改名或复制卡片；临时组装文件不混入最终成果。已提交、已生成、已检查、用户已接受分别记录。不无证据声称应用重载、像素一致、动作成功或最终声音检查完成。
