# 制作记录与提示词模板

按实际镜头填写，删除不适用项。模板不是Design API请求体；规格要进入真实工具字段，不能仅写进prompt。

## 项目规格卡

```text
项目/标题：
输入故事或有序素材：
原文语言与BCP 47标签：
文字系统 / 书写方向：
原文策略：逐字保留 / 用户要求翻译至__
混合语言片段：无 / 按段或行内片段记录
字体与回退链：待字符覆盖验证
断行、塑形与阅读时长规则：
交付层：脚本 / 制作包 / 成片
画幅比例：
最终像素宽高：用户指定值 / 待平台映射
图片清晰度：待用户选择1K/2K，或已有选择+来源+范围
视频清晰度：待用户选择768P/2K，或已有选择+来源+范围
视频能力：运行时核实当前实际入口、模式与参数
风格ID与参考图：
模式：手绘揭示 / 翻书 / 手绘剧情
总时长与镜头数：
声音：静音，或用户明确要求
字幕/正文：原文，独立文字图层 / 原页自带文字；记录语言、字体、方向、断行与字形覆盖检查
实际源尺寸、合成适配、最终导出尺寸：生成后填写
```

## 角色与场景卡

```text
角色ID / 版本：
年龄外观、头身比例、发型、服装配色、区别特征：
持有道具与惯用手：
跨镜必须保持的特征：
场景ID：时间、地点、人物方位、必要道具、留白：
风格参考职责：仅线条、色板、笔触，不继承示例剧情
实际资产ID / 来源 / 宽高 / 选择状态：
```

## 图片prompt

```text
用途：角色参考 / 镜头S__彩色关键帧。
风格：使用[style id]的实际配方与示例约束。
主体：[角色ID的稳定描述]，正在[单一具体事件的关键姿态]。
场景：[必要背景、人物相对位置、关键道具]。
构图：[实际画幅]，[景别、机位]，主体完整置于安全区。
文字留白：[顶部/底部/侧栏的归一化位置]；按原文语言与书写方向预留，画面内不生成字幕、日期、水印或多余字形。
笔触与色彩：[所选配方具体要求]。
参考绑定：[实际资产ID及角色/风格/场景职责]。
禁止：[与当前风格或连续性相冲突的具体特征]。
```

工具字段另记：用户图片选择、真实档位参数、比例或像素参数、参考资产列表。完整上传页面模式保留原字，不套用“删除画面内文字”。

## 逐镜视频 prompt

```text
镜号S__，计划采用时长__秒；提交时长使用当前视频能力真实支持档位。
视觉：二维手绘，[所选配方的线条/笔触/色板]，保持参考角色、衣服与场景。
参考职责：[资产A为构图/起始姿态，资产B为角色，仅在接口支持时分别绑定]。
开始状态：[人物位置、道具归属、朝向、表情]。
0–__秒：[动作起势、固定或具体运镜]。
__–__秒：[动作完成与可见结果]。
__–结束：[停留/自然收尾；供下镜承接的明确状态]。
镜头：[景别、机位、单一可行运动；保持字幕安全区]。
保持：[角色特征、纸面留白、风格笔触、物体数量]。
避免：风格转成3D或真人、额外人物、文字漂移、形体突变、无动机切镜。
画内文字：无新字幕；准确文字后期叠加。原页有文字时保持原样并逐帧核验。
声音：默认无对白、旁白、音乐；最终导出静音。
```

工具字段另记：当前视频能力的真实入口与参数、视频选择的真实参数、生成尺寸、合法时长、真实参考文件/ID。逐秒时间范围必须覆盖该片段且无冲突；模型并非保证逐帧执行，生成后测量采用区间。

## 揭示与剪辑单

```text
S__ / 原文：逐字保留；语言标签__；文字系统__；书写方向__
字体 / 回退链 / 覆盖检查：__
断行、塑形、标点与阅读时长检查：__
文字层区间：__–__秒；揭示从该语言逻辑起点开始，LTR 从左、RTL 从右，混合方向保持双向文本顺序，揭示后保持可读
线稿层区间：__–__秒；与彩色关键帧相同坐标/缩放，可见区域从左边缘向右扩展
彩色层区间：__–__秒；可见区域从左边缘向右扩展
方向检查：文字层按语言逻辑起点检查；线稿/彩色层默认前期只显示左侧起始部分、中点显示部分图层、结束帧完整显示。不得根据转场名称猜方向；用户可另行指定视觉揭示方向
视频片段：实际资产 ID/版本；源入点__、出点__
关键帧→视频衔接：实际对齐点与检查结果
下一镜：直接切 / 翻页 / 用户指定；转场重叠__秒
目标画布：W×H；适配方法与背景
```

翻书模式不使用线稿/上色区间。时间轴按实际采用区间扣除重叠计算，不简单相加生成时长。长句字幕可分行或分屏呈现，保留全文与顺序。

## 当前节点用户验收卡

每个当前节点的资产生成完成后显示；一组资产属于同一节点时可作为一批确认。先做轻量技术检查，不以主观审美或轻微偏差自动判失败。

```text
标题：请确认当前节点效果
问题：当前节点资产已生成，是否通过？
选项1：通过，继续（推荐）
说明：接受当前版本并进入下一节点。
选项2：需要修改
说明：保留当前版本，请用户说明具体修改点；未取得明确修改或重试授权前不生成新版本。
```

用户未回答、取消或只表达模糊感受时，保持当前节点待确认，不自动重生成，也不推进依赖节点。

## 有限恢复

- 任何修改都以用户在当前节点明确选择“需要修改”并给出具体反馈为前提；不得因自动质检意见自行重做。
- 仅文字错：经用户确认后只修文字层，不重生成整段。
- 仅线稿错位：经用户确认后修同源派生和蒙版，不重做角色参考。
- 仅动作错误：经用户明确授权后修改该镜视频动作；影响后续连续段时更新尾帧依赖。
- 改尺寸/风格：经用户确认后标记受影响的构图和资产版本，未受影响资料继续复用。
- 未知任务状态：查原任务，不能盲目再提交。
