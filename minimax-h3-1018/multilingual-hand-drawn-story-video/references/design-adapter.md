# 制作能力与尺寸适配

## 制作能力核对

首次制作时核对以下创作能力；只在使用时检查对应能力，不因尚未连接生成服务而阻塞故事与分镜整理。

| 环节 | 核对内容 | 缺失时 |
| --- | --- | --- |
| 制作资料 | 故事、素材和已确认版本是否完整 | 提供待执行制作资料 |
| 图片 | 参考约束、清晰度、画幅与构图 | 保留图片提示词，说明待制作项 |
| 视频 | 参考图约束、清晰度、时长与音轨 | 不擅自换模型，不虚构已生成 |
| 制作进度 | 哪些资产已完成、待确认或失败 | 保留已有结果，不重复未知状态任务 |
| 素材 | 文件可读、版本正确、链接可访问 | 不把本地路径当远程链接 |
| 合成 | 文字、蒙版、擦除、剪辑、卷页、静音、画布尺寸 | 标明欠缺环节，交时间轴说明 |
| 导出/核验 | 编码、宽高、时长、音轨、实际播放/抽帧 | 标明未验证，不能称最终通过 |

所需视频清晰度必须以实际可用能力为准，不能仅凭档位名称承诺原生像素尺寸。

每个角色、场景与镜头维护制作记录：参考素材、版本、使用它的镜头以及待制作、待选择、制作中、待确认、已接受或失败状态。先确认参考可用，再制作依赖它的资产；状态不明确时先核实，用户明确要求重试后才制作替代版本。

## 自定义尺寸

分开四件事：**画幅比例、所选清晰度档、模型源像素、最终导出像素**。

1. 用户仅给比例：保持该比例；依已选档位和平台支持确定源宽高及最终宽高。无尺寸偏好默认3:4。
2. 用户给精确W×H：作为最终画布目标，计算其比例；不要覆盖为仓库原有1080×1440。接受任意正整数目标，实际导出还受编码器/平台限制。
3. 当前视频能力支持该比例与档位：按已确认的交付规格制作，并核验实际源像素。
4. 当前视频能力不支持目标比例或精确宽高：优先选择可用源画幅并在目标画布内contain排版，以背景留白/排版补足边缘，不拉伸。若因此明显改变呈现或需要裁切，先给具体适配方案供用户选择。
5. 达到目标宽高需要放大：说明原生源尺寸与放大后尺寸，取得用户对放大方案的明确选择。仅把小视频装进大画布不能称为原生2K。用户选2K却原生只支持768P时按清晰度参考中的不支持流程处理。
6. H.264或导出器要求偶数宽高、对齐倍数、像素上限时，提供最近的可用尺寸并说明差异，不暗改用户的精确数字。支持其他合适导出格式时可给具体替代方案。

例如“9:16、图片1K、视频2K”包含独立的三个选择；“1080×1440、图片2K、视频768P”则指定最终画布，但768P源宽高需实测，可能涉及后期适配。两例均不推断平台2K等于2560×1440或2048×1080。

生图尺寸同理：角色参考可用适合身份辨认的比例，逐镜插画优先匹配最终镜头比例；图片档位不决定视频档位。按新画幅重排人物、动作空间、字幕位置及留白。

## 保真合成边界

当前视频能力承担生成式动态，所有语言的准确原文和可控擦除由合成完成。未连接合成工具时，不能承诺已经实现精确蒙版、卷页或特定字幕字体。当前已授权的其他可用工具能补足时可处理后上传，记录该环节的来源；不能暗中改用其他视频生成模型。

无Design连接时仍可交付完整待执行制作包，不必阻塞故事编写；有连接但缺某功能时复用已成功素材，只补缺的环节。

## 固定 5% 纯白安全边框

每次新建视频画布或修改最终宽高后，都按最终画布重新计算安全边框：左右边距各不低于 0.05 × W，上下边距各不低于 0.05 × H。边框必须在全片中固定、纯白、无遮挡；内侧矩形是唯一有效内容区。所有插画笔触、人物及完整肢体、文字、道具和关键细节都必须完整位于其中。

插画只允许使用 contain 等比完整收纳。源比例与内容区不一致时，通过等比缩小、重新排版和增加白色留白适配；禁止 cover、拉伸、放大裁切或自动居中裁切。人物动作、镜头推拉、画面位移、揭示动画、转场和翻页在最大幅度时也不得越界。无法完整容纳时缩小插画、重新构图或拆镜，不得用裁切替代。

生成与合成后检查三类画面：静态构图、动作最大幅度、转场代表性关键帧。全部确认无越界、无裁切、无文字遮挡且边框完整后，才能标为通过。
