# 视频尺寸与图片/视频清晰度选项卡

## 时机与有效选择

三次独立规格选择，分别控制最终画布与两类生成任务：

1. 故事或有序图片范围确认后、生成任何新角色/场景/道具/分镜资产前，询问 **视频尺寸**。
2. 图片提示词和资产清单准备好后、首次模型生图前，询问 **1K / 2K**。
3. 视频提示词和参考资产准备好后、首次视频提交前，询问 **768P / 2K**。

视频尺寸卡为单选：`9:16 竖屏`、`16:9 横屏`、`3:4 竖版绘本`、`1:1 方形`、`4:3 横版绘本`；保留自定义回答入口，允许输入 `W:H` 或精确 `W×H`。已有明确项目级尺寸时记录并沿用，不重复询问。取消、空回答、超时或只说“默认”均不构成选择。尺寸一经改变，必须依据新的最终画布重新布局并重建固定5%纯白安全边框。

同一项目中已明确的用户消息或卡片提交均有效，保存原始来源和适用范围；后续同类生成、重试、补镜沿用。新项目重新询问，除非用户明确要求沿用。只说“高清”“最高画质”“默认”“快一点”不构成具体档位选择。宽高或画幅也不替代档位选择。

仅编写技能/提示词、复用素材、读取元数据或确定性处理不触发卡片。没有模型生图任务时不为凑流程显示图片卡；直接用现有图片生成视频只需视频卡。

## 视频尺寸卡文案

```text
标题：请选择最终视频尺寸
问题：请选择本项目最终视频的画幅；该选择将用于角色、场景、分镜、动态片段和最终合成。
选项：9:16 竖屏（短视频）；16:9 横屏；3:4 竖版绘本；1:1 方形；4:3 横版绘本
自定义回答：输入 W:H 或精确 W×H
```

## 清晰度选择文案

分别展示以下问题，环境支持时使用单选卡，否则以文字列出选项：

- 图片：请选择本项目的图片资产清晰度（适用于后续角色、场景和分镜图片）。选项为 1K、2K。
- 视频：请选择本项目的视频清晰度（适用于后续全部视频片段）。选项为 768P、2K。

问题已呈现，**不代表用户作答**。预选、空回复、取消和等待超时都不能提交生成。等待期间可继续不依赖该规格的故事和提示词工作；必须保持依赖任务待选。文字选择时不声称已显示选项卡。

用户只回答图片选项时，视频仍待选。用户一次明确给出“图片1K、视频2K”可同时记录，不强迫重复点击。用户限定为某批次时不能外推到全项目。

## 不支持的档位

询问前核对实际入口的模型、档位、比例与限制。用户要求的两组标签不能当作所有工具都支持的能力声明。不支持某选项时在题目或卡片说明中写明。

用户选了不支持的档位，先查同模型的可用支持入口；仍不可用时，明确给出可执行选择，例如等待支持该档位的入口、改选已支持档位，或在已有真实放大能力时选择“原生较低分辨率 + 后期放大”。必须取得新选择才能执行改变规格的任务。不得静默降级、换模型或以“2K”提示词冒充真实参数。

## 保存状态

在项目规格节点或制作记录里保存：

```text
video_size: null | 9:16 | 16:9 | 3:4 | 1:1 | 4:3 | 自定义 W:H | 自定义 W×H
video_size_choice_source / video_size_choice_scope: 用户消息或实际卡片返回 / 项目ID
image_quality: null | 1K | 2K
video_quality: null | 768P | 2K
image_choice_source / video_choice_source: 用户消息或实际卡片返回
image_choice_scope / video_choice_scope: 项目ID或指定批次
requested_aspect_ratio: W:H
requested_output_px: null 或 {width, height}
image_mapping / video_mapping: 用户可见模型名称、所选清晰度、源尺寸与目标尺寸
actual_source_px: 生成后实测宽高
final_output_px: 合成导出实测宽高
processing: 原生 / 缩小 / 留白适配 / 经明确选择的放大或裁切
```

`null` 表示未选，不是默认第一个选项。只有有明确选择来源、已核实的制作能力与有效提示词/参考时，才能开始对应任务。图片2K和视频2K的像素定义分别核实，不假定相同。
