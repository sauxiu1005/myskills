# 多语言手绘故事视频制作

把多语言故事、故事分镜、手绘资产与准确文字组织为可编辑的 Design 制作包。输入可以是 UTF-8 故事文本、用户选中的画布素材或有序图片；用户未要求翻译时保留原文语言。动态片段在运行时使用平台当前视频能力；本 Skill 不依赖 Remotion、Node.js 或本地渲染入口。

## 核心约定

- 原文逐句保留，默认一句一个叙事节拍；长句可拆镜，不能擅自改写事实、对白、拼写、标点、大小写、专名或图片顺序，不自动翻译。只有用户明确要求时才创作、改写或翻译。
- 逐段或按混合语言片段识别原文语言、文字系统与书写方向。选择字体或排版前读取 [多语言识别、字体与排版规则](references/language-typography.md)。用户明确指定的成片语言优先；聊天语言、界面语言、市场和内部 Skill 语言不能覆盖原文。
- 默认彩铅日记漫画、3:4、静音 MP4；用户给出的风格、比例、像素宽高、时长和声音要求优先。默认比例不是固定输出分辨率。
- **视频尺寸、图片 1K/2K 和视频 768P/2K 均无自动默认值。** 故事或有序图片范围明确后、生成任何新故事资产前，先取得明确的视频尺寸选择；两类清晰度则在各自生成提交前分别选择。不得以预选、超时或“先出预览”为由跳过任何选项卡。
- 选择能够满足已确认参考图、动态、清晰度与声音要求的视频生成能力。尊重用户指定的模型，更换前说明实质性能力差异。所需能力不可用时，完成文字制作包并说明待执行项。
- 所有语言的准确正文、日期、数字、专名与标点都使用独立可编辑文字图层；视频模型只负责动态画面，不能依赖图像或视频模型拼写文字。纯静图轮播不能标为“视频已生成”。
- 每次新建视频画布或修改尺寸后，依据最终宽高重建固定纯白安全边框：左右边距各不低于画布宽度的5%，上下边距各不低于画布高度的5%。边框内侧才是有效内容区，所有插画笔触、人物、文字、道具及关键细节必须完整位于其中。插画只允许 contain 等比完整收纳，禁止 cover、拉伸、放大裁切或自动居中裁切。
- 当前节点的资产生成后，只做轻量技术检查：确认文件存在且可打开，仅指出损坏、全黑/全空、必需文字缺失、关键主体被严重裁切等明显阻塞。不要以严格的自主审美标准否决轻微风格、动作、构图或连续性差异。展示当前节点结果并询问用户“是否通过”；用户确认是主要验收依据。用户未明确要求修改或重试前，不得自动重生成、替换或创建新版本。
- 当前任务仅为创建/修改技能、写脚本或提示词时，到该交付层结束，不弹实际生成选项卡、不消耗媒体生成额度。

## 1. 读取项目与能力

首次执行读取 [制作能力与尺寸规则](references/design-adapter.md) 与 [多语言识别、字体与排版规则](references/language-typography.md)。检查参考图约束下的图片与视频制作、准确的可编辑文字、合成与导出能力是否满足已确认的创作要求。制作前记录缺失能力及受影响的交付物。

取得故事、已有素材、交付深度、风格、尺寸与声音要求，并记录原文的 `language_tag`、文字系统、书写方向和保留/翻译策略；混合语言按片段记录。缺故事、无法判断图片顺序、语言身份、书写方向或翻译意图确实不清时，只询问阻塞项；普通创作细节可自行补全，已有规格不重复问。

故事或有序图片范围确认后、制作角色、场景、道具或分镜图片前，必须显示单选的 **视频尺寸** 用户选项卡。选项为：`9:16 竖屏`、`16:9 横屏`、`3:4 竖版绘本`、`1:1 方形`、`4:3 横版绘本`，并保留卡片工具自带的自定义回答入口，允许用户输入 `W:H` 或精确 `W×H`。用户此前已明确本项目尺寸时记录并沿用，不重复询问；取消、空回答、等待超时或只说“默认”均不构成尺寸选择。精确尺寸与比例冲突时只澄清冲突项。**视频尺寸、图片清晰度、视频清晰度是三个独立决定**，宽高不能推定1K/2K或768P/2K。

建议画布分组：`01-故事与规格` → `02-角色与风格` → `03-分镜和图片` → `04-视频片段` → `05-合成与交付`。沿用现有分组与节点，更新真实节点 ID，不重复创建项目。

## 2. 拆故事与锁定风格

为人物、场景、关键道具、镜头分配稳定 ID。先写简短角色卡与逐镜表：

`镜号｜原文/字幕｜叙事事件｜时长｜构图与动作｜参考资产｜揭示/转场｜视频动态｜声音｜起止状态`。

区分角色变化与时间跳跃；"她""后来""小时候"等依故事上下文确定，不能让每镜人物外观随机重置。时长按对应语言的阅读速度、文字密度与动作共同安排，不用统一“每秒字数”覆盖所有语言，也不把复合长句硬塞进一小段视频。生成长度按平台当前实际支持档位安排，最终入出点另行记录，不预设模型固定上限。

选风格时按需读取 [风格配方](references/handdrawn-style-library.json)。包内附20种风格的配方、示例和总览；编号、id、本地化名称、别名均可匹配。用户指定风格则直接使用；要求比较时展示包内实际示例或 [总览图](references/style-examples/handdrawn-style-library-contact-sheet.jpg)，推荐与故事相关的少量选项。风格库中的 `prompt_blocks`、`color_hint` 与 `avoid` 可用于图片外观；`text_layer_style` 只用于后期独立可编辑文字层，严禁加入图片生成提示词。

默认 `colored-pencil-diary`：读取 [默认风格说明](references/target-diary-style.txt)，实际查看 `references/style-approved.png`，按需查看 `style-bw.png`、`style-color.png`、`style-layout.png`。白底、笨拙黑轮廓、大头短身、稀疏彩铅笔触、低饱和配色与大量留白；参考板只管风格，人物身份和剧情以当前项目为准。随包的参考是上游参考，不能声称当前用户已经批准。

其他风格只绑定该配方及其示例，不混入默认彩铅板。改变风格时新建资产版本并检查依赖，避免复用旧画风镜头。不要把示例图中的人物、文字、动作复制成用户故事。

## 3. 图片规格选择与资产制作

先完成待生成资产清单及可执行提示词，再执行 [清晰度选项卡](references/resolution-choice.md)。首次生图前显示 **1K / 2K** 单选卡，明确用户答案后才能提交；包括角色参考、场景参考、分镜关键帧、彩色插画以及需要模型生成的线稿。用户已提供本项目明确选择时记录并沿用，不重复询问。

纯文本故事优先建立足够约束连续性的角色参考与关键场景图，再制作逐镜干净插画。画面中不生成故事字幕，为对应文字系统的独立文字图层保留布局空间。合成前确认字体真实存在，覆盖全部字符与标点，支持正确塑形和书写方向，并在目标字号下清晰可读。使用 [提示词模板](references/production-templates.md)，绑定实际上传后的参考资产 ID，不能只写"参考上一张"。

上传图片分两种：

- **完整页面/翻书**：保留原图、原字、顺序和边缘；已有文字不重复叠加。不自动拆掉标题、改写或翻译原文，也不重新上色。
- **文字→线稿→彩色揭示**：优先从同一彩色画面派生对齐线稿与蒙版，文字区和插画区可在保留母版的前提下拆为派生层；不能用两次独立生图假装像素对齐。复杂背景无法可靠拆分时，简化为原图揭示并说明效果差异，或取得用户对实质性改造的选择。

复用现有图片、提取视频帧或确定性派生线稿不属于模型生图，不为此索要图片清晰度，也不宣称旧图已变为原生2K。需要重新生成任一图片才触发图片选项卡。

## 4. 视频提示词与视频规格选择

依据每镜彩色插画、角色约束与首尾状态，编写视频提示词：实际参考职责、构图、逐阶段动作、运镜、画风保持、结束状态与声音模式。读取 [提示词模板](references/production-templates.md)，确保提示词要求处于已核实的创作能力范围内。

动画幅度服从手绘叙事：例如递信、抬头、风吹衣角、灯光变化或克制推近；保持线条、笔触和留白，避免默认变成3D角色或写实摄影。每镜一个主要事件，时长不足则拆镜。静止停留和确定性文字揭示可在合成阶段补足。

首次视频提交前执行 [清晰度选项卡](references/resolution-choice.md)，显示独立的 **768P / 2K** 单选卡。图片2K不代表视频2K。等待明确回答并验证尺寸映射后，用当前视频能力生成片段；预览、测试片、重试与补镜也遵守此规则，不暗中用低档位试生成。

图生视频优先传入实际参考图；多图/首尾帧仅在真实接口支持时使用。只有文字输入的视频入口无法满足严格参考绑定时，先寻找支持参考的同模型入口；没有则说明限制，不能声称角色参考已绑定。

连续动作跨段时先验收前段，从实际采用片段的出点提取尾帧与状态，再生成后段。普通故事切镜使用对应镜头参考，不强迫不同场景共享同一尾帧。任务超时先查询状态，不重复提交状态未知的收费任务。

视频片段或其他当前节点资产生成后，不要因轻微动作、画风、连续性或构图差异自行判定失败。只说明明确技术阻塞或显著问题，展示结果并询问用户“是否通过”。严禁自动重生成；只有用户明确要求修改或重试后，才能提交替代版本。在此之前保留当前资产，不擅自补做新版本。

## 5. 在 Design 合成

默认输出静音画面轨。文字排版遵循已识别语言：正确的从左到右或从右到左顺序、文字系统塑形、语言安全断行、标点禁则与混合字体回退。提示视频模型不加旁白、对白或音乐；导出时检查并移除不需要的音轨。用户明确要求声音时落实到每镜，并检查实际声音；不要把提示词写了"静音"当成媒体确实无音轨。

按故事选择表现方式：

- **手绘揭示（默认）**：准确文字揭示 → 对齐线稿揭示 → 彩色画面揭示 → 视频动作/停留。文字揭示服从已识别的书写方向与双向文本规则：从左到右文字从左侧逻辑起点开始，从右到左文字从右侧逻辑起点开始；混合方向文本保持正确视觉顺序，禁止逐字倒序。线稿和彩色层默认从左向右揭示，除非用户另行指定视觉方向。每个视觉揭示阶段都要检查真实可见像素，不能只看效果名称：前期只显示起始小部分，中点显示部分图层，结束帧显示完整图层。文字、线稿、颜色顺序和擦除边界由合成能力控制，不能依赖模型重新绘制准确原文。用彩色锚点或匹配帧衔接视频，并检查切点是否跳变。
- **翻书**：完整页面停留后从右下角卷页，保留完整原页；不叠加重复字幕或额外线稿阶段。页面动态可使用视频能力，文字和精确卷页优先用合成图层；视频能力模拟卷页需要复核字形与边缘，不能承诺数学精确。缺卷页能力时告知差异再确定转场，不把普通淡化标为卷页。
- **手绘剧情**：直接用视频动态镜头叙事，叠加准确字幕；用户指定此模式时无需强加线稿揭示。

生成画幅与最终画布分开核验。每次新建画布或改变尺寸，都必须按最终宽高重新计算固定纯白安全边框：左右边距分别至少为 0.05 × W，上下边距分别至少为 0.05 × H；边框内侧矩形是唯一有效内容区。所有插画笔触、人物及其完整肢体、文字字形、道具和关键细节必须完整位于其中。

插画只允许以 **contain（等比完整收纳）** 方式适配内容区。比例不一致时，通过等比缩小、重新排版和增加白色留白完成适配；禁止 cover、拉伸、放大裁切或自动居中裁切，不能裁掉人物头部、四肢、文字、道具或其他关键细节。纯白安全边框在整段视频中保持固定且无遮挡；人物动作、镜头推拉、画面位移、揭示动画、转场和翻页效果在最大幅度时也不得越出安全区。无法完整容纳时应缩小插画、重新构图或拆分镜头，不得以裁切替代。视频能力不支持任意尺寸时，先使用受支持源尺寸，再按上述规则 contain 合成到最终画布；涉及放大、裁切或档位不支持时不能隐瞒。

## 6. 验证、恢复与交付

生成后记录所选模型、已确认的制作规格、源宽高、时长、音轨、选中资产版本和最终宽高。针对当前节点，只执行上述轻量技术检查，然后展示已生成资产，并以当前工作语言询问二选一确认；业务含义固定为 `通过，继续` 与 `需要修改`。需要用户验收时，在用户回答前不得生成替代版本，也不得进入依赖其结果的下一节点。

用户确认是主要质量门。自动检查只辅助用户判断，不取代用户，也不进行穷举式审美审查。只核对避免资产不可用所必需的事实：文件可打开、必须出现的文字存在且可读，没有缺字方框、乱码、错误书写方向或复杂文字塑形破损，没有完整黑屏/空白，所选尺寸正确，关键主体没有被严重裁切。动作幅度、轻微风格差异、小范围连续性漂移、揭示细节或主观构图偏好，应交给用户确认，不能作为自动重生成理由。

用户确认通过后，标记当前节点已接受并继续。用户要求修改时，先记录明确修改点；只有用户明确授权修改或重试后，才生成新版本，并保留当前资产及成功依赖。相同修改连续两次仍无改善时，说明限制并提供更小调整或合成修正方案，避免循环。

交付真实可访问的 Design 项目或节点、最终视频，以及可编辑文字/字幕和镜头资料。报告视频尺寸、图片与视频所选档位、当前视频能力实际入口、总时长、成片语言及未解决问题。没有Design连接或视频能力时，交付故事、资产卡、分镜、视频提示词、字幕与合成说明，并明确标为"待 Design 执行"；不得编造生成结果、项目链接或已通过平台导入验证。

来源、许可证和改造边界见 [来源说明](references/source-notes.md)。
