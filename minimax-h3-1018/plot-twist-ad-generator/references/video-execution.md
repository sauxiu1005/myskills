# Video Execution Reference / 视频执行参考

## Compile, do not narrate / 编译而非复述
Turn the approved script into isolated event shots suitable for the confirmed duration and selected model. Use an executable director brief rather than a long plot paragraph. / 把确认剧本编译成适合已确认时长和所选模型的隔离事件镜头，使用可执行导演简报，不复述长剧情。

## One shot, one action / 一镜一动作
Each shot carries one primary action and one new fact. Separate opening, taking out, activating, using, reacting, state inversion, and product ending when combining them would make the causal chain unreadable. / 每镜承载一个主动作和一条新信息；开场、拿出、启动、使用、反应、状态倒置和商品结尾若合并后会破坏因果可读性，应拆成不同事件。

## State handoff / 状态交接
For every shot record: `time | only action | visible people/speech | start state | end state | new information | object state`. The next shot inherits identity, wardrobe, screen position, product structure, prop count, container state, and world state—not unfinished gestures, lip movement, or camera motion. / 每镜记录：`时间 | 唯一动作 | 可见人物／对白 | 开始状态 | 结束状态 | 新增信息 | 物件状态`。下一镜继承身份、服装、站位、商品结构、道具数量、容器状态和世界状态，不继承未完成手势、口型或运镜。

## Product entrance / 商品入场
Keep the product hidden in the opening by default. Its first clear appearance should belong to the turning sequence and be immediately followed by a valid activation or use. If the approved script allows early display, preserve that explicit exception. / 默认开场隐藏商品；第一次清楚出现应属于转折序列，并立即进入有效启动或使用。确认剧本若明确允许提前展示，则保留该例外。

## Space, speakers, and camera / 空间、说话人与摄影
- lock a stable screen axis and character silhouettes;
- identify one visible speaker for each exact line and list silent characters;
- finish each line inside its assigned time window;
- use hard cuts for major state changes that would otherwise morph;
- specify camera movement only when it increases readability or tension, and declare its start frame, end frame, subject, speed, and required visible elements.

/
- 锁定稳定摄影轴线和人物轮廓；
- 每句准确台词只对应一位可见说话人，并列出闭嘴角色；
- 台词在分配时段内结束；
- 重大状态变化若连续拍摄会变形，则使用硬切；
- 只有运镜能提升可读性或张力时才使用，并写清起始构图、结束构图、主体、速度和必须保留的可见元素。

## Product and physical continuity / 商品与物理连续性
Use every supplied product reference for identity. Lock total count, holder, location, support, contact point, container occupancy, lid state, attachments, and action path. Contents cannot simultaneously remain worn and stored. When an omitted action changes state, hard cut and declare the new starting state. Do not invent controls, compartments, automatic movement, or unsupported functions. / 使用全部指定商品参考锁定身份。锁定总数、持有人、位置、支撑、接触点、容器占用、盒盖状态、附件和动作路径。内容物不能同时处于佩戴与收纳状态；省略动作改变状态时，用硬切并声明新起始状态。禁止发明控制部件、暗格、自动运动或不支持的功能。

During struggles, assign hands to load-bearing surfaces and protect lids, hinges, delicate attachments, worn body parts, and loose contents. Preserve gravity and contact shadows. / 争抢时让手抓承力表面，避开盒盖、铰链、脆弱附件、佩戴身体部位和松散内容物，并保持重力与接触阴影可信。

## Direct reversal / 直接翻转
Prefer large observable state differences and one visual verb per beat. For value swaps, keep both old and new targets readable in the same sequence; reuse composition or action when it makes the target change obvious. Do not make tiny details, eye movement, or a closing line carry the reversal. / 优先大尺度状态差和每节拍一个视觉动词。价值目标替换时，让旧目标和新目标在同一序列中可读；必要时复用构图或动作，让目标变化一眼清楚。不要让微小细节、眼神或结尾台词承担翻转。

## Dialogue and direct text / 对白与直出文字
Keep dialogue short and assigned to its shot. Leave enough time for spoken lines and subtitles to finish before the product ending. For direct-rendered copy, specify exact wording, layout, safe margins, hierarchy, and stable reading hold; forbid all other readable text. / 对白简短且归属当前镜头，为口语和字幕在商品结尾前结束留足时间。直出文案需锁定原文、排版、安全边距、层级和稳定阅读停留，并禁止其他可读文字。

## Failure reduction / 降低失败
If a shot contains several precise actions, simplify or split it. Prefer stable cuts and large state contrasts over long negative-prompt lists. / 单镜包含多个精确动作时，先简化或拆分；优先稳定硬切和大状态差，不依赖冗长负面提示词。
