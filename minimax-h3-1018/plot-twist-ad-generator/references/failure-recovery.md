# Failure Recovery Reference / 失败修复参考

## Use / 使用时机
Read only after a matching risk or observed failure. Preserve the approved concept when execution alone failed. / 仅在出现对应风险或实际失败后读取；只有执行失败时保留已确认创意。

## Common failures / 常见失败
- **Product pickup or wearing morphs:** isolate the first product entrance and the handling action in a stable insert; do not move the product into the opening unless the user approves changing the entrance structure. / 拿取或佩戴变形：用稳定插镜隔离商品首次入场与操作；除非用户批准改变入场结构，否则不能把商品提前到开场。
- **Worn and stored duplication:** define a hard cut, remove the product from the character in the new shot's start state, and declare every container slot. / 佩戴与收纳重复：使用硬切，在新镜头起始状态中从人物身上移除商品，并逐一声明容器槽位。
- **Container or support errors:** simplify to one stable lid state and one supported placement; assign hands only to load-bearing surfaces. / 容器或支撑错误：简化为一个稳定盒盖状态和一个有支撑的位置，双手只抓承力表面。
- **Target remains unclear:** reuse the opening composition and replace only the contested or valued object; remove competing gestures and props. / 争夺目标不清：复用开场构图，只替换被争或被重视的物件，并删除竞争性手势和道具。
- **Detail-to-whole morphs:** hard cut from the detail to an already-stable wide reveal. / 局部到整体形变：从细节硬切到已经稳定的大全景。
- **Tiny comparison disappears:** redesign around a large state contrast rather than retrying the same micro-detail. / 微小差异消失：改成大状态差，不重复重试相同细节。
- **Effect replaces the product:** remove secondary effects and restore the product action as the cause. / 特效抢商品：删除次要特效，让商品动作重新成为原因。
- **Dialogue crosses shots or the hero boundary:** shorten the line or move it earlier; subtitles must finish before the product ending. Merge adjacent cues from one uninterrupted utterance instead of delivering several short blocks. / 台词串镜或跨入商品段：缩短台词或提前安排；把同一句连续台词的相邻转录条目合并，不要交付多个短字幕块，且字幕必须在商品结尾前结束。
- **Punctuation or paragraph clutter:** remove punctuation from subtitle text only, keep the spoken audio unchanged, and use one readable block per utterance; line-break only when necessary for safe width. / 字幕标点或段落过碎：只删除字幕文字中的标点，不改变实际语音；每句对白尽量使用一个可读字幕块，只有超出安全宽度才换行。
- **Subtitle layer is invisible:** discard the invisible render and perform one deterministic burn with an opaque text layer; never hide subtitles by setting alpha to zero or by overlaying a transparent subtitle source. / 字幕层不可见：废弃不可见版本，用不透明文字层做一次确定性烧录；禁止把透明度设为零，也禁止把透明字幕源叠加到成片上。
- **Direct text fails:** retry with shorter exact copy and a stable hold; use post only after that or when deterministic legal accuracy is required. / 直出文字失败：缩短原文并稳定停留后定向重试；之后或法务要求确定性准确时才用后期。

## Decision / 决策
If the silent story remains clear, repair only the failed execution. If the reversal itself is unclear, reject the script and return to ideation; do not add explanatory dialogue to rescue an unreadable reveal. / 静音故事仍清楚时只修执行失败；翻转本身不清楚时淘汰剧本并回到创意，不能增加解释对白补救。
