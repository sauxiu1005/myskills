# Evidence Twist Reference / 证据型翻转参考

## Use / 使用时机
Only for theft, planted evidence, hidden objects, documents, identity, quantity, or knowledge traps. Never load for ordinary benefit-created-surplus ideas. / 只用于偷窃、栽赃、隐藏物件、文件、身份、数量或知情陷阱；普通卖点余量创意禁止加载。

## Minimal audit / 最小审计
- Relationship: what each person wants now and who initially has power. / 人物当前目标和开场权力。
- Knowledge: what each person and the audience can see and know. / 人物与观众分别能看见、知道什么。
- Ownership: who created, carried, placed, or discovered the clue. / 线索由谁制造、携带、放置或发现。
- Exact proof: one clue proves one fact only. / 一条线索只能证明一个事实。
- Alternative explanation: state and visibly exclude the strongest plausible alternative. / 写出并用画面排除最强替代解释。
- Occlusion: if a secret action must be unseen, lock camera side, occluder, observer eyeline, and separate coverage. / 秘密动作必须锁定机位、遮挡、观察者视线并分镜拍摄。

## Duration fit / 时长适配
Fit the evidence chain to the user-confirmed duration. Keep one misunderstanding, one reveal mechanism, and one decisive proof visible long enough to understand at normal viewing speed. Reject unseen backstory, surprise witnesses, new identities, or multiple documents introduced only at the reveal. / 按用户确认的时长安排证据链。只保留一个误会、一个揭示机制和一个在正常观看速度下足够看懂的决定性证据；禁止只在揭晓时新增前史、证人、身份或多份文件。

## Silent test / 静音测试
The decisive action or object relation must still reveal who is exposed or who gains control. If dialogue carries the proof, simplify. / 静音时决定性动作或物件关系仍须成立；若必须靠对白证明，继续简化。
