# Creative Twist Reference / 创意翻转参考

## Use / 使用时机
Read only when first-round options are generic, indirect, hard to understand, or product-replaceable. / 仅当首轮选项普通、间接、难懂或商品可替代时读取。

## Creative search / 创意搜索
- Reinterpretation: the selling point visibly changes the meaning or status of an established action; the changed state must still read without an explanatory line. / 重新解释型：卖点用可见结果改变既有动作的意义或地位；没有解释台词时，新状态仍须成立。
- Constraint inversion: establish one real limit, then let the benefit visibly remove or reverse it. / 限制倒置型：建立一个真实限制，再让卖点清楚解除或反转它。
- Rule inversion: establish one simple world rule, let the benefit change who or what now operates under it, and show the new relation directly. / 规则倒置型：先建立一条简单规则，让卖点改变谁受该规则约束，并直接展示新关系。
- Target swap: reuse one clear composition or action while replacing the valued target after the benefit. / 目标替换型：卖点前后复用一个清楚构图或动作，只替换被重视的目标。

## Reject / 淘汰
- product works -> opponent is merely silent;
- benefit is only tested, measured, stated, or privately appreciated;
- unrelated punishment or a separate climax supplies the memorable moment;
- tiny visual differences, documents, wordplay, or final copy carry the reveal;
- an ordinary object could replace the product without changing the causal chain.

## Option format / 选项格式
`world pressure + opening state; product enters and performs the confirmed benefit; the same event produces a large visible state inversion.`
The user should understand each option without a paragraph of explanation. / 每个选项无需长段解释即可看懂。

## Silent check / 静音检查
At minimum, the opening target, product entrance, benefit action, and changed target or state should remain understandable without dialogue. Dialogue may sharpen the idea, not create it. / 至少在静音时，开场目标、商品入场、卖点动作和改变后的目标或状态仍须可懂；对白负责强化，不能负责凭空制造翻转。
