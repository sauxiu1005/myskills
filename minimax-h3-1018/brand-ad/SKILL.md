# 品牌广告

用一个清晰的视觉创意和充分展开的音画表现，完成一条官方品牌或产品展示广告。保留视觉表现 reference 中的展示表现和用户要求的同类视觉表现。剧情 TVC、系列广告策略和多片制作超出本 Skill 范围：说明边界后停止本 Skill，不指定其他 Skill 或 workflow。

## 内容归属边界

品牌主导的展示内容，指品牌控制信息表达，产品或品牌保持画面主体。人物、手部、带脚本的功能演示和产品使用可以作为官方导演、尺度参照或证据出现；它们本身不会变成达人内容。判断重点是内容是否服务于品牌识别、产品记忆或官方视觉主张，同时不以创作者个人测评或受众行动为核心。

达人原生内容通常包括真人或数字人测评、推荐、比较、开箱、个人体验口播、第一人称 POV、教程，以及通过平台 Hook 争取互动、关注、咨询或转化的内容。即使产品仍是画面主角，口播带货和体验式演示仍属于达人内容场景。

官方产品演示属于品牌主导的展示场景，前提是它由品牌主导，使用已核验事实和文案，展示产品行为或视觉识别，不引入达人身份、个人结论或社交带货行动号召。

核心交付物属于达人原生内容时，说明超出本 Skill 范围，然后停止本 Skill，不指定其他 Skill 或 workflow。

## 1. 从用户已有成果继续

先读取 brief 和实际可用素材，再规划新工作。保留核验身份、已有脚本或故事板、逐字文案、时长意图、画幅和已采纳美术方向。区分用户要求与可发展的创意选择。只补问实质影响身份、主张或交付的缺口，沿用已有决策和授权。

没有创意时，发展一个能让观众记住品牌或产品的可见关系或事件。用创意卡说明记忆点、视觉想法、重要事件与节奏、结尾和剩余准备。已有脚本或故事板已经表达这些决策时，直接从它继续，只说明缺失选择；不为符合流程模板重做创意卡或故事。

从 [homepage-visual-routes.md](references/homepage-visual-routes.md) 选择适用表现，详细音画写法使用 [showcase-prompt-core.md](references/showcase-prompt-core.md)。规划精简不等于生成提示词简略。

## 2. 按需准备一致性锚定图与场景锚点图

### 区分必须准确与可以创作

开始生图前，只在既有方案中整理两类信息：

- **必须准确**：真实主体的外形、人物身份、品牌标识、指定文字、已确认状态及其他已采纳要求。明确相关事实的来源，没有依据的细节保持未知。
- **可以创作**：已采纳方向内的环境、光影、构图、配色、视觉隐喻、空间尺度与情绪。除非需求明确要求，原始照片中的普通背景和照明不构成创意限制。

不能用“看起来合理”的内容补造真实身份。需要时补充来源、澄清，或通过构图避开未知细节，同时继续不依赖它的创意工作。表现性的空间尺度变化不构成真实尺寸或产品功效的依据。

### 按创意缺口准备两类锚点

根据已采纳创意和后续镜头，区分两类图片职责：**一致性锚定图**承接人物、产品等需要跨镜头保持的身份与外观；**场景锚点图**承接场景设计、空间关系、光影、构图和创意状态。场景锚点图不承担产品外观、Logo 或文字的一致性要求，不再另设 KV 制作环节。

按实际需要的角度、状态和细节可读性检查已有素材。先确认产品素材是否足以可靠识别轮廓、比例、部件、标识和所需状态。如果素材过于模糊或不明显，必须在创意生图或视频制作前，依据已有可靠素材生成一张产品资料卡；无法由素材确认的细节继续标为未知，不能让场景锚点图代替这次身份核验。原图足够清晰就直接使用；素材分散但清晰时，只有整理后更便于使用才制作身份卡；确需缺失角度或状态时，只依据可靠素材补这一处。细节需要准确识别时，保留清晰原图或局部裁切，不把细节缩进过密宫格。目标是降低识别歧义，不是制作大而全的资料卡。需要准备产品锚定图时读取 [product-anchor-card.md](references/product-anchor-card.md)。

人物需要跨镜头保持一致时，检查脸部辨识、体型比例、发型、服装和随身物品是否覆盖后续镜头。已有定妆图足够就复用；需要侧面、背面、面部近景或特定状态且现有素材未覆盖时，只补相应视图，保持同一人物和已确认造型，不把单张全身照默认当成所有视角的充分依据。原创人物按已采纳设定建立外观；真实人物依据可靠来源，不补造身份。视图数量、排布与画幅服从辨识用途，不固定宫格。

一张已有图片可覆盖多个职责。缺少名为“锚点图”的文件本身不等于缺口；已有成果清晰覆盖身份与已采纳场景设计时，**不生成新图片**。如果真实产品身份仍不清晰，即使创意方向已经确定，也要先生成产品资料卡。保留已有脚本、故事板和批准图片，不因换排版或泛化的审美升级重复制作。尊重纯文本或减少准备的明确要求，但不能用不清晰的真实素材直接猜造产品。

### 用场景锚点图发展完整场景设计

创意需要的场景、关键变化状态或美术关系尚未被已有素材覆盖时，补充对应场景锚点图；有较大美术创作空间或用户要求重设计时，用它探索完整场景方案。表现环境、空间尺度、材质、光影、构图、情绪和可发生的变化，可以不出现人物或产品。确需示意主体来表达尺度或动作关系时，只用作构图参照，不据此确定人物或产品身份，也不要求准确品牌文字。主体一致性由独立锚定图承接，进入视频制作时结合使用；不因成片含产品、Logo 或中文就给场景图附加这些精度要求。

按图片职责选择模型。一致性锚定图优先考虑准确保留人物或产品外观、来源细节和所需视角的能力。场景锚点图先从当前可用、擅长装饰性或编辑感审美、艺术印刷或绘画方向、抽象实验和氛围探索的图像模型中评估首选。这是软偏好：用户指定的模型优先；符合这些特征的路线无法承载场景本身所需参考或输出限制时，可以选择具备相应能力的替代模型，并说明具体原因。同一项目和同一组参考允许按职责混用模型；不要求用同一模型完成主体锚定和场景设计。

不要在已经默认使用通用身份或写实模型后，只把上述场景设计能力列为可选项。需要新场景锚点图且没有场景本身的硬性要求排除它时，将其记录为推荐的首个候选，先评估并在满足需求时使用。优先纯文构建场景，确需参考时只加入必要素材；不默认把产品资料卡或人物定妆图作为每张场景图的生图输入。准确产品、人物、品牌标识与指定文字仍在各自的一致性依据和成片要求中保留。

每张图先确定具体视觉主张，再选镜头和光线：巨大空间与微小主体可以表达孤独或力量；极近接触可以表达触觉；前景遮挡与深处亮区可以制造发现感；形态呼应可以联系两个意象。先回答“为什么这样拍”，再选择表现手段。“高级、电影感、强张力”不能代替设计。按当前视觉缺口使用 [tvc-moodboard-creative-guide.md](references/tvc-moodboard-creative-guide.md)。

### 组图按视觉节奏设计

第一轮场景探索通常从 **3–4 个互补的视觉状态**开始，结合需求、已有覆盖和约定范围调整，不设生图配额，也不作为一致性锚定图的数量要求。每增加一张都应带来新的发现或有用反差。

| 变化 | 要解决的问题 |
| --- | --- |
| 景别与主体占比 | 是否始终从同一种距离、以同样大小看主体？ |
| 信息与动作状态 | 每张是否带来新发现，而非重复展示？ |
| 能量与情绪 | 是否有张弛，而非每张都强烈或每张都安静？ |

远、中、近景不机械轮换，距离变化带来新信息才值得换景别。同机位可以用于有意的状态对照，但连续性不要求所有图片采用同一构图。独立提案不必拼成宫格，也不直接等于固定镜头表或等长视频段。用户已有故事板就直接沿用，可执行的文字分镜也可能已经足够。

每条视频只选当前能力允许的相关互补输入：一致性锚定图提供人物、产品等准确身份，场景锚点图提供空间、美术与状态，提示词说明二者如何结合。场景图里的示意主体不能覆盖真实身份；宫格、标签、偶然背景和无关身份不带入成片，普通参考不隐式绑定首尾帧。不为合并两类职责而额外生成完整广告静帧。优先复用适合的结尾图；单独 Logo 只提供身份，不等于结尾构图，只补实际缺失的收尾画面，标识位于上方安全区，品牌相关背景能够运动。带准确标识的收尾图属于品牌身份露出所需准备，不作为每张场景锚点图的要求。没有明确要求不用纯白静态 Logo 屏，也不后期叠加品牌名或 Logo。

## 3. 展开音画并制作

所需输入可用后，为完整局部发展写自包含提示词：构图与纵深、对应材质的光线、主体动作与结果、摄影机起点/路径/速度变化/揭示/落点、切镜与前后画面线索、逐字文案与读字时间、原生音乐/旁白/拟音/环境声和品牌收束。提交时保留完整细节。

每个生成单元在生成前记录一条自包含的最终 Prompt。实际发送的提示词字符串必须与已记录的最终稿字符级一致，确保已确认的创意细节完整进入生成。任何后续环节不得缩短、摘要、改写、翻译、调序或静默润色。需要修订时，先在既有决策和授权范围内更新并记录最终稿，再提交同一字符串；两者不一致时停止提交并修正差异，不发送摘要版。

按注意力、动作、情绪、说话和阅读需要组织节奏。密集插入可打开宽阔揭示，长段落靠内部发现获得停留价值；不固定镜头数、不均分时长、不设转场配额。选定效果按需读取 [product-visual-techniques.md](references/product-visual-techniques.md)，文案、空间字、Logo 包装、产品展示动效或旁白按需读取 [voice-keyword-typography.md](references/voice-keyword-typography.md)。该卡已吸收片头字体规则，负责字体角色、空间绑定、准确文字、Logo 保护、完整阅读和转场继承。不预读无关方法。

能力、范围与连续性见 [production-and-delivery.md](references/production-and-delivery.md)。单次生成能承接整片时保持整体，需要拆分时选完整动作边界；每段保留各自相关参考、声音连续性和完整的广告详细提示词。这里创意文案随画面生成，品牌露出使用已准备图片；不能让通用后期文字默认值静默改变已采纳方案。只有计划使用共享配乐时才统一铺设，不重复音乐或旁白。

交付实际成片、完整提示词及相关已有或新增素材，注明实际时长、尺寸与已知限制。复用素材也算完成准备，不为交付另生成副本。保留已完成成果，报告时长差异，不自动重生、裁切、补帧、循环或变速去凑名义时长。
