# 角色参考

为后续图像和视频建立可复用的角色外观依据。已有角色图覆盖所需视图且外观一致时可复用，单次人物创作不必另做角色卡；只出声不露面的角色（如一直在电话里说话的母亲）不做定妆图。

- 用户未明确指定角色参考图的画幅时，默认使用 16:9 横版；用户明确指定时按其要求。角色参考图的画幅独立于视频成片比例，提示词中的横竖版描述与生成设置保持一致。
- 通用角色定妆图默认包含正面、侧面、背面全身三视图及面部近景，清楚呈现脸部身份、全身体型、侧面轮廓、背面服装和随身物品。
- 多个视图表达同一个人的转向，保持身份、体型、发型和当前服装一致。全身视图可统一站姿与人物高度，近景则留足辨认五官的面积；包带、饰物等不对称细节随机位投影，不镜像换边。
- 视角写具体，如全身左侧面、全身背面，避免都变成相似的三分之四侧身。需要完整轮廓时给头顶和鞋底留空间；在已确定的画幅内，布局按视图数量和下游参考能力选择，不固定左右比例或宫格。
- 作为通用身份母版时，干净背景、均匀照明与自然姿态有助于看清外观。强情绪、手持物、伤势或特殊光效可按剧情另作状态参考；若它们本就是本次要求，则保留。
- 后续场景引用时说明使用人物外观，不把设定图的多人物排布一起带进画面。

新建通用定妆图时，在提示词中写明约定视图，以及各视图需要一致的身份与外观要点；用户反馈视图缺失或外观不一致时，只补或改对应视图。复用已有参考时，仅补充下游镜头实际需要且缺失的视角或关键外观信息。
