# Research a real object

触发指令：`Use Anatomy to research [object] from real sources: true dimensions, part list, teardown order`。
目标是建立可追溯的实物依据；只要求研究时，完成研究后直接交付，不自动扩展成图解、建模或视频。

## 对象与来源

- 先记录对象名称、制造商、型号、代际/硬件版本及研究范围（整机、某个总成或用户指定拆解深度）。已有信息直接沿用；影响尺寸或拆法的型号缺失时，先查可用资料，再询问必要区别。不能悄悄拿相近型号的数据替代。用户只给“相机”“飞机”等大类时，提出可研究的具体型号，或交付明确标为通用的结构资料，不宣称存在唯一真实尺寸。
- 实际打开并阅读来源。优先制造商规格表、尺寸图、维修/服务手册、零件目录与官方拆解资料；缺少官方步骤时可采用有实拍证据的第一手拆解记录。搜索摘要、转述文章、AI输出只能提供线索，不能单独证明关键尺寸或拆解步骤。专利和相近机型仅作背景，除非证据能确认与目标实物一致。
- 每份来源分配 `S1` 等ID，保存标题、发布者、URL或本地资料路径、对应型号/版本、访问日期，以及支持事实的页码、图号、章节或视频时间戳。尺寸图和拆解图片要实际查看；不要仅据OCR猜测箭头端点或部件遮挡。
- 来源冲突时保留各值和适用条件，解释采用哪个以及依据；无法消解则标为 unresolved。找不到资料时列出已查范围和缺口，继续完成能确认的部分，不补造“真实数据”。

## 三项研究结果

### 1. True dimensions：有证据的尺寸

给出尺寸ID、部件ID、量的定义/测量端点、原始值和单位、来源定位与状态。宽×高×深需说明轴向、装配状态，以及是否包含镜头、手柄、接口或其他突出物；圆件区分直径/半径，螺纹规格与长度分别记录。换算值保留原值与换算方法，精度不得超过证据。

使用 `verified`（该型号来源明确给出或有记录的实测）、`derived`（由已知量计算，附公式）、`estimated`（图像标定/比例推测，附假设与误差范围）、`unknown`、`conflicting`。`true dimensions` 指尽可能查得有证据的值，不是把每项强行填满。未经标定的照片、透视图、爆炸图不能量出可信尺寸；图上距离不能直接当毫米。不得把估算写成 verified，缺失值用 null。

### 2. Part list：零件与总成清单

给每个零件/总成稳定ID（如 `P01`），记录名称、作用、父总成、数量、官方零件号（若有）、材料/连接方式（若有依据）与来源定位。区分“官方零件目录”“实拍可见件”“机构推断”；零件号、材料、内部件数未知时留空。数量要区分每个总成与整机总量。

按研究范围说明清单覆盖程度。仅能确认主要总成时，标为主要部件清单，不称完整BOM；不要沿用图解的细节数量建议来虚构零件。

### 3. Teardown order：有依据的拆解顺序

把拆解组织为依赖顺序，而不是按爆炸图的空间位置排序。每步记录 `T01` 等ID、前置步骤、目标零件ID、动作、紧固件/连接器、来源确认的工具或条件、来源定位和证据状态。能并行的支路保留支路；来源只证明相邻步骤时不要把完整流程都标为 verified。

保留来源明确要求的断电/释放储能、密封件更换或不可逆操作等前提，只记录与当前对象和步骤有关的内容。不可见的卡扣、隐藏螺丝、胶合结构不能凭直觉补成可执行拆法；未获证实的顺序标为 proposed/unknown，并与来源证实的步骤分开。爆炸动画顺序与实物拆解顺序分别命名。复装不是天然“倒放拆解”，只在用户要求且有资料时单独说明。

## 交付与核对

在项目目录保存：

- `research.md`：对象范围、来源目录、尺寸表、零件表、拆解步骤/依赖、冲突与未知项；在每行或每步附近链接具体来源。
- `facts.json`：便于图解与视频复用的同一批结构化记录。顶层采用 `object`、`sources`、`dimensions`、`parts`、`teardown`、`gaps`；各事实有稳定 `id`、`status`、`evidence`。`evidence` 中保存 `sourceId` 和 `locator`；尺寸关联 `partId`，拆解步骤用 `partIds` 与 `dependsOn` 关联。未知数字为 null，不用0或猜测占位。报告和JSON内容保持一致。

交付前核对：每个 verified 项都有对应型号的直接证据；来源ID/零件ID可解析；尺寸定义、单位和总成数量无混用；拆解依赖无环，后续步骤不会先于其明确前提；冲突和缺口可见。需要说明未能打开/确认的资料，不能把“找到链接”当成“已经查证”。

若继续制作 HTML/SVG 或视频，按原语言选项卡选择/沿用作品语言，再把研究事实映射到文案、几何和拆解动作。对视觉强调所做的放大、间距调整和非比例爆炸图标明“schematic / not to scale”的本地化文字；源尺寸不随画面缩放改变。教学模型、机构隐喻与真实产品结构分别标注，不能把通用示意套上具体型号后称为真实拆解。
