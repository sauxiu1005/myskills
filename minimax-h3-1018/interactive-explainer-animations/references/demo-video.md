# 机构图解的演示视频

本分支用于把已验证的交互图解制作成可观看、可重渲染的说明视频。视频不能代替实际交互检查。先沿用项目 [语言选项卡](language-choice.md) 的明确选择；没有选择时先完成选择，HTML 与视频共用文案模块。默认无旁白、无音乐、带所选语言的可读字幕；用户指定音频、画幅、长度时沿用其要求。不要擅自调用付费视频生成来重画精确机构。

## 编排与状态

先写时间表，每段绑定具体动作、预期模型状态、字幕及镜头。常见结构：初态、单次操作、连续操作/边界、恢复、复位；按主题调整。每段字幕留足阅读时间。数字、部件显隐、指针、运动和字幕来自同一状态；不得手写一套不一致的数值动画。机制发生得太快时可慢放，但明确标注倍速；真实速率说明与播放速度不可混淆。

继承已有模型和几何源码。录制时复位再开始；离线渲染时采用固定步长和事件时间表，不能依赖机器实时速度。保留深度顺序、遮挡、裁切和动作缓动，不能只对整张静态图推拉运镜。长字幕放图外安全区域，避免压住机构和计数窗。

Three.js / ISO-GLOW 作品另读 [进阶三维的视频路径](iso-glow-3d.md#视频与交付)，特别检查 DOM 标签和字幕是否进入成片；本页 SVG 适配器不能直接渲染 WebGL。

## 两条制作路径

1. **真实交互录制**：仅使用宿主明确获准的浏览器/录屏工具，执行时间表并录制干净画面。不要把shell、CDP或其它自动化当作绕过宿主浏览器限制的备用通道。实际点击验收和录屏证据分开保存。
2. **离线逐帧渲染**：适用于纯SVG/可导出帧的图解。场景适配器直接import纯模型和几何，不控制浏览器。输出每帧SVG，再用Sharp和FFmpeg编码。本包提供通用脚本，实际业务场景须编写自己的 `scene.mjs`。

`scene.mjs` 接口：

```js
export const width = 1920, height = 1080, fps = 30, duration = 28;
export const checkpoints = [0, 5, 10, 16, 24, 27.5];
export function frameAt(seconds) {
  // 对任意时间返回确定性结果；关键帧预览可能乱序调用。
  return { svg: '<svg xmlns="http://www.w3.org/2000/svg" width="1920" height="1080">...</svg>',
           state: { /* 模型读数，供验收记录 */ } };
}
```

适配器输出完整SVG，显式指定像素尺寸、字体、颜色和背景。离线SVG渲染器的CSS支持与浏览器不同：按选定主题解析CSS变量，检查所选语言的字体覆盖、阅读方向和非缩放线宽；不要全局破坏其它主题。必要时把字体转路径或使用已获授权的本地字体。验证处理后仍与原图解语义一致。

执行前发现真实Node、Sharp、FFmpeg、FFprobe位置。常规构建仍不需要这些视频依赖。渲染脚本用 `SHARP_MODULE` 指定可解析的模块/目录、`FFMPEG_PATH` 指定编码器；未设置则从常规环境解析。不能把某一电脑安装路径写死为通用要求。

```sh
node /actual/skill/scripts/render-video.mjs /project/video/scene.mjs /project/video/demo.mp4 --preview
# 查看生成的demo-qa关键帧和states.json，再正式导出：
node /actual/skill/scripts/render-video.mjs /project/video/scene.mjs /project/video/demo.mp4
```

脚本输出H.264 / yuv420p / faststart MP4，无音轨；已有成片不覆盖，选择新版本文件名。失败保留.partial.mp4供定位，不把它当作成片。若主题确实需要WebGL或浏览器专有功能，SVG适配器不适用，应使用获准录制工具，不伪造通过。

## 验收与交付

- 对关键时间点的模型状态做有意义断言，例如满桶5、6请求5放行1拒绝、恢复2秒后2枚、复位计数清零。
- 用FFprobe读取实际编码、尺寸、帧率、帧数和时长；执行完整解码检查。时长按帧数/fps核对，不能只凭文件存在宣告完成。
- 从编码后的MP4抽取关键帧与连续动作帧，亲自查看所选语言字幕、缺字/连写/双向文字、数字同步、层次与遮挡，确认存在机构运动而不只是字幕变化。静态停留段无需强求每帧不同。
- 在可用播放器/Design视频节点实际打开并播放。只有视频资源成功导入且节点可见，才记录画布交付通过；本地MP4仍作为可下载成片保留。
- 交付MP4、时间表/字幕、场景源码与依赖说明、视频验收日志和关键帧；`design-state.json` 增加 `videoRender`、`videoChecks`、`videoDelivery`，证据写真实路径/资源ID。视频标明是离线模型渲染还是浏览器录屏。

示例分段（可变更）：0–4秒满桶；4–8秒暂停补充并发单次请求；8–14秒复位后暂停，6次请求间隔0.12秒；14–22秒恢复每秒1枚；22–28秒复位。此示例是解释用机构动画，不是物理工程仿真。
