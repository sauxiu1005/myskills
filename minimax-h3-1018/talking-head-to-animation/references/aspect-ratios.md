# 多画幅构图与导出

支持输出比例与当前模型原生比例是两回事。先核验模型/合成器实际能力；模型不支持目标比例时可用已有素材重构、扩展场景或代码渲染，不能把参数传入成功当成画幅正确。

## 输出约定

| 比例 | 示例像素尺寸 | 布局起点 |
| --- | --- | --- |
| 9:16 | 1080×1920 | 上方完整叙事区；字幕与右下真人错层 |
| 16:9 | 1920×1080 | 横向概念关系与适中主体尺度；真人靠侧下方；底部字幕 |
| 1:1 | 1080×1080 | 叙事主体集中；下方文字与真人并列避让 |
| 4:5 | 1080×1350 | 比长竖屏更紧凑；减少同屏元素并保留留白 |
| 4:3 | 1440×1080 | 横向但空间较紧，重新安排多人距离与字幕行宽 |
| 自定义 | 用户给定 W×H 或比例 | 按真实尺寸计算，逐镜重构并检查 |

这些是可调整的制作预设，不是平台已验证的导出上限。用户指定分辨率优先；编码器需偶数宽高时，记录实际取整尺寸。禁止把横屏/方形机械拉伸成竖屏；有意保留边框须符合用户的版式要求。

## 共享什么，重做什么

共享实际音轨、测量时间戳、角色身份、道具和语义事件。每个比例重新计算：镜头取景、人物站位、气泡位置、字幕换行、标题大小、圆框位置和动画运动端点。音轨时间不因画幅改变。

每个比例记录 `width / height / fps / safe_rect / scene_rect / scene_content_safe_rect / caption_rect / presenter_rect / shot_overrides`。位置使用比例锚点或布局函数，实际渲染时计算像素。自定义比例使用实际宽高，不复用1080×1920的绝对坐标。

`scripts/plan_layout.py` 可生成初始矩形区和文字尺度（只依赖Python标准库）：

```bash
python3 scripts/plan_layout.py --ratio 16:9 --short-edge 1080
python3 scripts/plan_layout.py --ratio 4:5 --short-edge 1080
python3 scripts/plan_layout.py --width 1600 --height 1200
```

脚本是本地构图辅助，不是Design工程格式或渲染器。输出只是无碰撞的版式起点；每镜应按内容移动主体、展开横向关系并保留留白，不能把整段竖屏动画缩放塞进 `scene_rect`。没有执行脚本时可依据相同原则手工布局。

## 主体、画中画与字幕

- 叙事主画面是主角。减少占空间但无信息的固定大标题和重复装饰线，不用过大的真人头像代替动画。
- 圆形画中画的直径依据短边和实际可读性设置，保持正圆；使用源视频的人脸/头肩安全裁切，人物偏移时跟踪或扩大裁切范围。不要将“右下”写成所有镜头不可变的像素位置；用户明确固定时再固定。
- 字幕必须与圆框和关键图形分开。窄竖屏可把字幕放在圆框上方；方形可以字幕居左、真人居右；横屏可留右侧真人区和底部字幕带。已有用户布局优先。
- 字体以短边作为尺度起点，在实际目标显示大小核验；重测文字边界后换行，通常一至两行。中文不把句号、逗号孤立到下一行，不裁切结尾，不以极小字号塞满。
- 默认四边安全区为左右各8%画宽、上下各8%画高。所有动画对象和局部场景线都在内侧，真人与字幕同样不触边。已知发布界面覆盖区或用户更大边距要求优先，通用边距不等于已验证所有平台安全。
- 图形运动起点和终点都需在目标画幅可读；气泡箭头必须继续指向正确角色，多人互动改画幅后不能失去关系。

## 每个请求比例的验收

核对像素尺寸、显示宽高比、像素纵横比及圆框形状；检查最密场景、长字幕、镜头转折和首尾。缩小到实际观看尺寸检验人物表情、图标和标签。记录与源版相比做了哪些布局改变。

几何检查可发现越界和重叠，但不能证明风格或视频合成质量。只验证了布局脚本时，报告“多比例布局已验证”，不宣称所有比例的成片均已渲染测试。

## 彩色线稿的适中密度

`safe_rect`先从画幅四边内缩，再在其中排除真人与字幕得到`scene_rect`，之后内缩约5%形成`scene_content_safe_rect`。主体、气泡、箭头、场景线及完整运动包络均保持在内层动画区，纯色背景可铺满画幅，动画内容不可。主概念组、小人和图标按[手绘解释动画](illustrated-explainer.md)的新版尺度与配色起点安排，不沿用“主体15–25%、一半以上留白”的旧预设。横屏放大并横向组织关系，方形和竖屏重排主辅图形；不裁断主体，不靠缩小整片适配，不让新增宽度变成无意义的空白。每个比例均在手机尺寸检查主体分量和颜色可读性。

背景统一用纯净浅色，彩色放在主体内部。场景变化仅以1–3个较细较浅的局部线稿线索提示，不画全屏地平线、复杂房间、渐变或装饰色块。每个比例独立计算四边安全区，复核最长字幕时刻及运动极值。

## 关键词图层适配

每个比例重排的是“解释对象＋标签载体＋文字＋连接线”的完整图解组，不单独指定统一关键词带。逐镜`keyword_events`记录解释职责、关联对象ID、吊牌/卡面/气泡等载体、对象局部锚点与偏移、共享变换/跟踪、准确文本、时序、字号和运动包络；这些是制作记录，不是布局脚本自动输出。横屏可展开关系图、竖屏可上下组织，但标签始终附着于其对象或明确指向它，不能变成底部逐句更换的短字幕。最长词和对象移动极值均保持在`scene_content_safe_rect`内，避开真人与底部字幕。详见[手绘解释动画](illustrated-explainer.md#7-口播关键词与动态文字)。
