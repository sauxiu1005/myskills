# 文字分镜与视频 Prompt

本 Skill 不制作分镜图片、多格分镜板或逐镜关键帧图。分镜只是文字镜头安排；只准备角色卡、场景卡与必要道具/形态参考图，通过全能参考直接生成视频，不另做开场正式首帧。

## 七列文字镜头表

| Shot ID & Duration | Continuity Handoff | Reference Anchors (Spatial + Identity) | Hook Type | Shot Description (Per-Second Directives) | Audio & Dialogue Track | Audio Mode |
|---|---|---|---|---|---|---|
| 镜号与全片时间窗 | 上镜结束到本镜开始的站位、持物和动作 | 实际 CH/SC/必要道具素材及版本 | 引入/反应/转折/结尾等功能 | 动作、表情、景别、机位、运镜与切镜 | 台词、说话人、时间窗与音效 | 无对白/对白/音效/完全静音等实际方案 |

七列表与片段 Prompt 已经覆盖文字分镜，不必再抄写一套逐镜文档。只写剧情需要的信息；每镜有对白时明确唯一说话人，其他人物不做说话口型。完全静音意味着移除全部音轨。

## 人物站位与镜头轴线

写 Prompt 时使用 [空间连续性](spatial-continuity.md)：在现有 SC 卡定义固定朝向和地标，为 CH 绑定地标附近的站位/座位；每段带上简短空间块，每次切镜说明摄影机所在侧、人物动作和切后状态。画面左右不等于房间左右，机位变化不能被误写成人物换位。以下示例演示这类写法。

## 将镜头分成生成片段

先写完整片镜头安排，再按动作、场景、连续性与实际支持时长分组，编排建议不超过15秒。一个片段可含多个镜头，不要求一个镜头一次生成。记录每段对应的全片时间窗和内部镜号；片段 Prompt 从局部0秒起计时。仅当前模型支持15秒时，30秒短片可以是两段15秒；否则采用更短的完整动作片段组合，不用无意义动作凑满上限。

## 片段 Prompt 模板

此处是叙述格式，不是平台 API schema。图片占位在提交前必须替换为真实支持的引用。

```text
片段：P01；全片时间：0–12秒；本段时长：12秒；画幅/规格：按项目设置。
素材用途：图1=CH01身份与服装，图2=CH02身份与服装，图3=SC01环境布局；实际传入全能参考。
画风：GH-01，二维蓝橙平涂、夸张人物、细墨线和彩铅排线、哑光纸感。
空间：从入口朝后墙看，窗在左墙，门在右后，桌在中央。
CH01坐靠窗椅位，CH02坐靠门椅位，两人面对面。轴线是两人连线，摄影机全段留在入口侧。
初态：两人中景中CH01画面左、CH02画面右；杯在CH01右手，本段两人不换座、不交接杯子。

0–4秒，镜头1：入口侧双人中景，平视固定机位。
CH01看向CH02，右手把杯从胸前抬至嘴边；CH02在原座位看着CH01，双手留在桌上。
4秒直接切镜，延续同一动作，不省略时间。
4–8秒，镜头2：摄影机仍在轴线入口侧，切至CH01面部与持杯手近景，固定机位。
CH01位置和朝向不变，视线仍朝画面右侧的CH02，接上杯沿到嘴边的状态，小啜一口。
CH02只因取景变窄而在画外，仍坐靠门椅位，不移动、不复制到背景。
8秒直接切回原入口侧双人中景。
8–12秒，镜头3：与镜头1相同机位和左右关系，固定镜头。
CH01仍在靠窗椅位，将杯从嘴边放低至胸前，始终握在右手；CH02仍在靠门椅位轻轻点头。

声音：无对白；仅轻微饮水和衣料声，两人不做说话口型。
终点：两人原座面对面，杯仍在CH01右手胸前；下一段如连续发生，按此状态开始。
排除：未安排的换座、瞬移、背景镜像、重复人物、道具跳手、3D画风或意外字幕。
```

此例仅说明空间写法，不是固定故事、杯子道具或固定机位限制。时间分配和镜头数按故事改写，不固定三镜头。每镜必须明确景别、机位/角度、运镜方向/速度/停止位置或固定镜头；每次切镜明确时间与方式。切到特写是换镜头，推近到特写是连续运镜；多镜头片段不能写“一镜到底”。表达畸变时写清变形过程与保留的身份特征，颜色和表情变化须服务剧情。

## 图片输入与连续性

推荐 H3 的多图参考能力，遵循主流程的用户选择与实时能力核验规则，按 [h3-reference-production.md](h3-reference-production.md) 实际输入本片段所需 CH/SC 与必要道具/形态图片；不制作开场首帧或分镜图。简短素材记录可直接放在镜头表引用列或生成日志。

全能参考用于保持身份、空间和画风，不表示固定视频第一帧。连续后段必须按 [片段衔接模板](segment-handoff.md) 抽取前段实际结尾参考，和本段所需CH/SC一起传入全能参考，并写入结尾状态与后段独立开镜。结尾图不得进入首帧控制字段；后段不定格展示参考图、不重播已完成动作。抽帧不是新增生图或分镜图。新场景/形态缺少素材时补参考卡，不按镜头表逐项配图。

## 合成

生成段可用后按全片时间线拼接，保留已写明的动作和切镜。按方案处理对白、音效与音乐，导出成片后完整查看一次。项目只需保留故事文档、资产卡组、文字镜头表/Prompt 和成片；任务记录附在已有文档即可，不另做审核档案。
