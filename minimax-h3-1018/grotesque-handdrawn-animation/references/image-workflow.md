# 生图工具与参考图

选择支持风格图片参考的模型制作角色、场景和必要道具，用户明确选择优先。先核验实时参考能力；确认后项目内沿用，不逐张追问。视频模型独立按主流程的多图参考与声音要求选择。

## 首次生图前选择清晰度

首次生图前，若用户尚未明确选择图片清晰度，读取当前所选工具已有说明或界面的可用选项，向用户展示并等待选择。仅列真实支持的档位或像素尺寸，不固定写死1K/2K/4K，也不把画幅或质量权重当作分辨率。平台支持选项卡时用选项卡，否则用普通消息列出选项；未选择前继续文字准备，不提交生图，不代选默认值。

已有明确选择且当前工具支持时直接沿用；将选定档位、实际参数和值及用户选择记在项目规格中。角色卡、场景卡、道具图、补图和重绘全项目沿用，不逐张询问、不静默升降清晰度。仅用户主动修改，或更换工具后原选项不再支持时，重新说明可用选项并让用户选择；原有可用图片不因此自动重生。

若当前工具只有一个固定输出选项，也如实告知该选项并获得用户选择；看不到选项时只读取必要工具说明，不猜测、不付费测试。此步骤是图片输出设置，不重启图片参考能力核实，也不改变独立的视频分辨率设置。

## 实际引用包内风格图

每次生图通过所用工具的图片参考输入，实际传入 [S0 风格参考图](../assets/style-reference.png)，同时使用 [style-bible.md](style-bible.md) 的固定 STYLE_CORE。本地图片按平台正常上传/素材方式引用；仅在文字中写“参考 Skill 图片”、写文件名或留下占位符不算传图。

S0 用于蓝橙配色、细墨线、排线纸感和二维画法，不复制其中具体人物、姿势、背景或构图。无人场景卡仍须无人。角色身份来自本项目 CH，空间布局来自 SC；已有身份或环境参考时按需要一并传入，明确每张图的用途。

包内群像和环境示例用于理解画风，不随机轮换取代唯一 S0，也不当作同一角色的不同视图。停用的原用户截图不作生成输入。当前 S0 的历史来源仍按母版清单保存，更换模型不重做或篡改其生成记录。

## 使用与切换工具

按当前工具实际参数提交，不将其他模型专用语法直接移植。直接正常调用，不新增入口验证、付费测试或能力证明环节。遇到真实报错时处理对应输入；如果用户指定工具实际无法接收参考图，说明这个具体限制，不把纯文字生成冒称为已引用图片，也不悄悄换回默认工具。

同一项目沿用已选工具、固定风格文本与可控设置。用户中途换工具时，已有可用素材继续使用，后续图使用新工具和相同 S0/CH/SC；不自动重生全套资产。关键设置可放在项目文档或 [风格模板](../assets/style-lock.template.yaml)。

## 提示词结构

```text
参考用途：S0仅用于画法、配色与纸感；CH用于人物身份；SC用于空间布局。
内容：本次角色、无人场景、道具或必要形态的具体内容。
身份与空间：角色识别特征、固定地标、姿态与光源。
风格：固定 STYLE_CORE，二维蓝橙平涂、细排线、哑光纸感。
排除：误复制参考图人物/背景、意外文字、UI、水印、写实或3D漂移。
```

输入图片按用途实际绑定，输出沿用用户画幅/清晰度和预算。查看结果，选到可用图即继续；明显问题按 [qa.md](qa.md) 修正，任务未结束先查状态，不盲目重提。

普通裁切、排版、加字、缩放和格式转换可用常规工具；生成式修图沿用当前选定生图工具。本流程不制作开场首帧、分镜图片或逐镜关键帧。
