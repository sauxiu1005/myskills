# 前段结尾画面参考与后段独立开镜

连续后段采用“结尾画面参考 + 文字状态交接 + 独立开镜”。前段生成并可用后，提取真实结尾画面，连同本段所需 CH/SC 一起实际传入全能参考；不把它设为后段首帧。不新增生图、分镜图片或审批表。

## 1. 从实际结尾抽取参考

- 等前段完成并查看实际结果，再提交依赖它的后段；文字 Prompt 可提前准备，但素材绑定和交接状态必须随后补齐。前段重生成或剪辑出点改变时，更新对应抽帧和后段交接，不引用旧版本。
- 使用实际用于成片的片段结尾，优先选接近结束、能清楚体现最终状态的一帧。不机械使用模糊/黑场的最后一帧，也不能为了清晰选到人物尚未走到终点的旧画面。
- 若结尾特写无法交代空间，可补一张结尾附近的全景；仅在确认到结束时相关站位未改变时使用。注明两图时序与用途，不把不同时刻的动作状态混在一起。一般1张，确有需要时2张，不制作拼板。
- 抽帧是从已有视频提取，使用平台抽帧或常规视频工具，不用生图模型重绘或补全。保留源片段ID/版本、视频时间点和提取图片ID/路径；写入已有日志即可。
- 画外人物不猜测其位置改变，可依据片段中最后可见关系和无人移动的连续动作说明状态。无法辨认必需关系时先查看结尾附近视频；仍不明确或前段已有明显错位，按原有修正规则处理，不把错误当成新设定。

## 2. 简短记录结尾状态

从实际画面记录后段需要的信息：CH编号、相对窗/门/桌等地标的位置、人物前后关系、朝向、坐/站/形态、道具与左右手、动作进行到哪一步，以及已有镜头所在轴线侧。只写有依据的信息。

空间来自地标关系，不把“前段画面左侧”当作永远固定的位置。角色卡提供身份/服装，SC提供固定布局，结尾画面提供当前动态状态；如果彼此出现非剧情性冲突，修正冲突来源，不让后段把矛盾素材混合重排。

## 3. 真正放入全能参考，禁作首帧

后段请求包含本段必要CH、SC、道具/形态图与前段结尾参考图。每张图都说明用途，并将占位映射为平台真实图片输入。

**结尾图只放入全能参考图片列表/槽位，不传入专用首帧、起始帧或首尾帧控制字段，不启用会将该图强制设为第一帧的模式。** 用实际工具字段落实这一区别；仅在 Prompt 中写“不是首帧”但仍传首帧字段是不合格的。

提交时顺手检查素材角色与实际输入位置，记录使用的图片、源片段时间点、输入用途、任务和输出。不另做截图证明或审核文件。上传图的顺序不能被误认为首帧控制；若实际入口会强制固定第一张图，应说明该模式不符合本方案，而不是继续提交。

参考名额不足时先去除重复或无关图片，保留本段必要CH/SC与结尾空间参考。仍放不下、抽帧不可用或当前工具不能以全能参考接收时，报告具体限制并继续不依赖它的工作；不静默丢掉结尾参考、改成纯文字，或降级为首帧模式。

## 4. 独立写后段开镜

Prompt 分开写“承接状态”和“本段开镜”：前者继承真实站位、朝向、持物与动作，后者明确新的机位、景别、运镜和第一个动作。

后段可由全景切至近景，也可同侧反打；遵循 [空间连续性](spatial-continuity.md)，不要求复制前段像素构图或让人物永远处在同一画面左右；剧本需要时也可沿用原机位继续动作，不能为了换镜而擅改分镜。直接从后段设计的镜头与动作开始，不先展示参考图、不定格等待、不重播已经完成的动作。角色因近景在画外时仍保持实际位置。

```text
【参考用途】
图1：CH01身份与服装；图2：CH02身份与服装；图3：SC01布局。
图4：P01结尾参考，仅参考人物空间关系、朝向、持物和动作状态；
不作为本段首帧，不要求复制构图。实际传入全能参考图片输入。

【承接状态】
从入口看，窗在左墙、门在右后、桌在中央。
CH01坐在靠窗椅位，CH02站在桌的靠门一侧，两人隔桌相对。
文件在CH01右手，已经抬至胸前，尚未交出；两人无人换位。

【本段开镜】
0–3秒：直接以CH01胸部近景开始，摄影机在两人连线的入口侧，固定机位。
CH01看向画面右侧的CH02，从文件已在胸前的状态继续，将文件向对方伸出，
本镜末仍由CH01右手握住。CH02只因取景而在画外，仍站桌的靠门一侧。
不重演拿起文件，不先展示或定格图4。后续切镜继续按本段局部时间轴写明。
```

例子只说明交接写法，不是固定故事或站位。跨场景或明确跳时按剧本建立新关系，不强行继承旧房间的站位；在片段说明中简短标明该切换即可，无需额外批准。

## 5. 与正常片段检查合并

查看后段时顺便比较前段结尾与后段开头：是否无故换位/跳手、身份或形态是否改变、动作是否重播、是否错误地先定格参考图。正常机位变化和裁切不算空间错误。出问题只修受影响片段，沿用现有预算与重试规则。

这些参考提供连续性依据，并非坐标或像素锁定；不能仅凭 Prompt 宣称已经消除漂移。首段无需前段参考，连续后段则必须完成以上抽帧与实际引用后再生成。
