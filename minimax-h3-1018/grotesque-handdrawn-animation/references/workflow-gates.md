# 正常制作流程与续接

本文件用于顺序和恢复任务，不增加逐阶段审批。

| 顺序 | 完成内容 |
|---|---|
| 1 故事与剧本 | 故事大纲、可见动作、转折结尾、逐字对白与声音 |
| 2 角色卡 | 主要角色说明、实际参考图及必要形态 |
| 3 场景卡 | 无人环境图、布局地标与光线 |
| 4 全片文字分镜 | 七列文字镜头表、片段分组、视频 Prompt 和素材引用（不生成分镜图片） |
| 5 全能参考视频 | 推荐 H3 并核验当前参考与声音能力，实际传入 CH/SC 等图片，每段按完整动作和真实支持时长分配，编排建议不超过15秒且可含多镜头 |
| 6 成片 | 拼接、声音、导出、完整查看并交付 |

用户要求完整短片即按已授权范围推进至成片；首次生图先完成当前工具支持的清晰度选择；已有选择直接沿用。其余阶段完成后展示简短进展并继续，不默认等待“确认”。用户指定审稿/造型选择节点时遵循。重大方向改变、超出预算或确实缺少能力时，说明具体问题再询问。修正与重试统一按 [qa.md](qa.md) 执行。

恢复时查看已有文档、素材与任务状态，从未完成处继续。已完成资产直接复用，正在生成的任务先查询，避免重复提交。连续后段等待前段完成并提取真实结尾参考后再提交；已有抽帧需与当前片段版本和剪辑出点一致。旧候选符合当前故事和引用要求即可选用，无须重走流程。

可用 [项目状态模板](../assets/production-state.template.yaml)，或在既有文档中记当前阶段、产物位置、未完成事项和预算。无需单独记录每一步“批准/放行”状态。不制作开场首帧或分镜图片；视频实际图片引用见 [h3-reference-production.md](h3-reference-production.md)。
