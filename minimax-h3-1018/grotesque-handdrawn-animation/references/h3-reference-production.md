# 全能参考生成视频

推荐 H3，以支持多图身份参考和原生声音。用户明确选择优先；执行前核验当前参考、声音与时长能力。不满足硬要求时说明差异并取得决定，再采用等效模型或调整方案。直接使用角色、场景与必要道具参考生成视频，不额外生成开场首帧或逐镜关键帧。

## 提交方式

1. 核验当前是否支持所需参考用途、参考数量、片段时长与声音。具体接入交给运行时处理，不在此维护供应商参数。
2. 按片段选择所需 CH、SC 和必要道具/形态素材，使用干净源图或子图，避免卡片说明文字和分栏进入视频。
3. 实际提供选定图片，并在 Prompt 中逐张说明其角色、环境及用途。只写人物描述、文件名或未解析占位不等于使用了参考。
4. 连续后段先按 [segment-handoff.md](segment-handoff.md) 提取前段实际结尾参考，和CH/SC一起传入全能参考；确认没有绑定首帧/起始帧字段，再提交片段 Prompt。记录实际素材、来源时间点、用途、输入位置、任务/输出即可，不另填逐项验收表。

全能参考不等于逐像素首帧锁定，不要求一张图包含整个开场，也不额外调用生图工具拼合角色与场景。入口能力不明先核实；确实不支持所需全能参考时说明具体限制，不悄悄改成纯文或首帧模式。

## 空间信息随 Prompt 一起传入

按 [spatial-continuity.md](spatial-continuity.md) 给每段加入固定地标、CH站位/座位、轴线与起始状态。参考图分别用于身份、服装和环境，不把人物在角色卡中的排版位置当作视频站位。同一场景选择一个明确 SC 布局版本，避免同时输入互相冲突的房间布置。

内部切镜写清摄影机所在侧；人物移动则写起点、路径和终点，其他人物保持位置。跨片段交接依据前段实际结束状态，后段重新带上必要空间说明。图片引用与文字站位共同指导生成，不宣称全能参考能硬锁坐标。

## 时间与镜头

每段依据真实支持时长与动作容量分配，编排建议不超过15秒，一个片段可以包含多个镜头。先写完整片文字镜头安排，再分组。每段局部0秒起计时，明确景别、机位、运镜方向、速度与停止位置，以及切镜时间和方式。模板见 [production.md](production.md)。

每个对白镜头绑定唯一说话人、台词、时间与声线，其他人物不做说话口型。片段之间沿用人物与环境参考，在 Prompt 交接站位、持物、形态、光线、动作和声音。连续后段必须引用前段结尾画面作为全能参考，不能只写文字交接；独立设计后段开镜，不把抽取画面设为首帧。

查看返回片段，明显问题按 [qa.md](qa.md) 修正。完成片段后继续拼接、处理声音与导出成片，不等待逐镜人工批准。
