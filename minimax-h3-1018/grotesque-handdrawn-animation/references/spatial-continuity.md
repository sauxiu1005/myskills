# 人物空间与切镜连续性

用于多人、移动、正反打或连续片段。把以下信息写进现有场景卡和视频 Prompt，不新增分镜图片、首帧、空间图或审批表。图片参考负责提供人物和环境依据，人物具体站位与路径仍须在文字中说清；这些是生成指导，不是确定性坐标控制。

## 1. 场景固定，画面随摄影机变化

每个 SC 选定一个布局版本，用现有场景图中的2–3个清楚地标建立方向，例如“从入口朝后墙看，窗在左墙，门在右后，长桌在中央”。没有清楚显示的区域不编造；按已知空间安排动作。

区分三种方向：场景方向相对上述固定朝向；画面左右相对当前镜头；角色左右手相对角色自身。不要把三者混写。摄影机换位时画面左右可以改变，人物与窗、门、桌椅的实际关系不能无故改变。

为人物写“CH01 在靠窗椅位、面向长桌；CH02 在靠门椅位、面向 CH01”等地标关系，不只写“A左B右”。座位、桌位和道具归属按 CH ID 绑定；未安排移动的人保持原位置。离开画面只是被裁掉或遮挡，不等于离开房间，回到全景时仍回到原有关系。

## 2. 切镜先明确摄影机所在侧

对话用两人连线作动作轴，行走用主要运动方向作轴。同一连续段默认从轴线同一侧拍摄。写清摄影机朝向及所见人物/地标；“侧面近景”“反打”不能替代这个说明。

- 改景别优先用同侧切近或推近，不同时无说明地改变轴线、站位和朝向。固定摄影机、推进、平移、跟随分别描述，禁止用“镜头向右”同时表示人物向右移动。
- 正反打写明拍谁、从谁的哪侧肩后拍、当前人物视线朝哪边。同侧反打可以让人物在画面中的位置变化，不能因此交换真实座位。
- 剧情需要越轴时，用可见连续运镜跨过轴线，或用能重新交代双方关系的正面/全景过渡。更新该镜画面方向，不机械要求所有角度“A永远画面左”。
- 需要看懂人物关系时用一小段建立空间的全景/双人中景，可直接是视频中的动作镜头，不额外生成图片，也不强制每段都加建立镜头。

## 3. 位移要有起点、路径和终点

每次移动写“谁、从哪个地标、经过哪条通道、停在哪里”，同时写其他人物的位置是否保持。出画标方向/出口，再入画标相应入口；切镜后的起点承接上一镜终点。

涉及交换位置、交叉走位或道具交接时，给关键动作足够可见时间。将多人同时走动改成有先后的行动节拍；复杂位移可占一个连续镜头，仍可与其他镜头一起生成。需要更短片段时按叙事分组，不强制一镜一次生成，也不一律减少镜头或禁止运动。

每镜写当前关键状态，再写变化；不要用片段结尾位置代替开头。交接道具说明哪只手接触、何时松开、最后属于谁。允许明确的叙事跳时，但须写明时间省略和新的空间关系，不把连续动作失误当成跳时。

## 4. 怪诞变形与空间分开写

把允许的畸变和保持的空间关系写在同一句附近。例如“身体被纵向拉长，双脚仍踩在靠窗椅位前；背景透视被挤压，但窗仍在左墙、门仍在右后，桌椅归属不变”。形体、表情和颜色可以夸张，只有剧本安排了移动时才改变人物所在位置。

## 5. 每段 Prompt 带简短空间块

```text
素材用途：图1=CH01身份与衣服，图2=CH02身份与衣服，图3=SC01环境布局；
角色卡上的姿势、背景与人物排版位置不决定本段站位，场景布局使用 SC01 当前版本。
空间：从入口看，窗在左墙，门在右后，桌在中央；CH01在靠窗椅位，CH02在靠门椅位。
轴线：两人连线；摄影机留在入口侧，两人中景中CH01画面左、CH02画面右。
初态：两人坐着面对面，杯在CH01右手；本段无人换座。
```

随后每镜只补“摄影机变化、人物动作与位移、未移动人物、切后状态”。同一镜头表引用 CH ID 和地标名称，避免更换称呼。每段提交完整的必要空间块，不只写“接上一段”；后段仍实际传入相同 CH/SC 图片。跨场景时明确切换 SC 和重新站位，不强行继承旧房间坐标。

后段依赖前段结果时，按 [segment-handoff.md](segment-handoff.md) 抽取能体现实际结束状态的画面，实际放入全能参考图片输入，并填写位置、朝向、持物与动作交接。后段独立设计开镜；抽帧只作空间参考，不设为首帧。前段若已有明显错位，按原有修正额度处理，不把错误位置当成新设定。

查看视频时重点看切镜前后人物是否无故换座/瞬移、视线是否指向正确对象、地标与道具归属是否合理。正常换机位、裁切或透视变化不判为人物位移。发现错误优先修对应切镜/走位描述，必要时简化该段并重生受影响片段；不增加独立空间验收流程。
