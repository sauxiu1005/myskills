# 怪诞手绘风动画短片

目标是完成用户要求的成片。按故事 → 剧本 → 角色卡 → 纯环境场景卡 → 全片文字分镜 → 全能参考视频片段 → 合成成片的顺序持续制作。用户只要剧本、Prompt 或资产时，按其限定范围交付。

## 制作原则

- **固定 GH-01 画风。** 二维平涂、深蓝青与孔雀蓝对照珊瑚橙和朱红、不对称夸张人物、细墨线与彩铅排线、哑光纸感、舞台式空间。使用 [风格规范](references/style-bible.md) 与包内 S0，不使用停用的原截图。
- 选择支持图像风格参考的生图模型，用户明确选择优先，制作前核验实时能力。将包内 [S0 风格参考图](assets/style-reference.png) 与 GH-01 提示词实际用于角色、场景和必要资产，遵循 [生图工作流](references/image-workflow.md)。推荐 H3，以支持多图参考和原生对白；满足已确认要求的等效模型同样可用。核验参考模式、支持时长和声音能力；重要能力缺口先说明并取得决定。每段以不超过15秒为编排建议，再按真实支持时长和完整动作边界细分。
- **已有授权内直接推进。** 不逐阶段、逐图片要求用户确认，不建立独立校准任务或繁重的验收记录。首次生图前完成清晰度选择，之后不重复询问；用户指定必须确认的节点才等待；重大故事/造型变更、超预算或无法完成的工具限制才询问。常规技术修正按 [简短检查与修正](references/qa.md) 执行。
- **保留必要产物，减少重复工作。** 在项目中维护故事文档、资产卡组、文字分镜与 Prompt 文档，随后放入片段和成片。复用合适素材，角色卡与场景卡不能被一张剧情图代替；不要求每个镜头单独生图或生成视频。

## 1. 故事与剧本

沿用用户故事、时长、画幅、声音和规格；图片清晰度未选时，首次生图前提供当前所选工具实际支持的清晰度选项，等待用户选择后再生图；选择后全项目沿用，不逐张询问。用户此前已明确选择且工具支持时直接沿用。其他普通参数缺失时采用常规配置并说明。明确成本或额度限制时优先遵守。用户未给故事，可推荐讽喻题材并保留自定义选项；用户授权自由创作时直接选择方案。

先写简短故事大纲，再写可拍的剧本：场景、人物、可见动作、因果转折、结尾和声音。对白写出逐字台词和说话人。默认不添加旁白、字幕或配乐，除非用户或故事方案需要。

按 [工具准备](references/preflight-and-calibration.md) 整理素材、视频设置及合成路径，直接开始制作；不另设工具能力证明或付费测试。

## 2. 角色卡

为每个独立表演角色准备 CH 卡：名字与角色功能、脸型/鼻形/发型/肤色、体型、服装和一张清楚的主参考；只为剧情必需的变形、持物或表情补充参考。背景群体可共用群组图。保持干净源图，说明文字放在卡片排版中。需要时读 [角色一致性](references/identity-lock.md)。

## 3. 场景卡

每个独立地点准备一张无人 SC 主图，写明空间布局、出入口、固定道具、光线和配色。用图中2–3个清楚地标固定场景朝向，人物站位随后按 CH 编号绑定这些地标；不另生成空间图。先完成角色与场景，再进入分镜。已有素材能覆盖时直接复用；详见 [资产复用](references/asset-economy.md)。

角色和场景由代理查看并选定可用版本后进入制作；若用户要求亲自选定则遵循。无需为每张卡额外增加审批轮次。

## 4. 文字分镜与视频 Prompt

不生成分镜图片、多格分镜板或逐镜关键帧图。先写全片七列文字镜头表，再把镜头分配到生成片段；镜头表和片段 Prompt 即为文字分镜，无须重复写一套文档。使用 [分镜与 Prompt 模板](references/production.md)。每镜写清动作、表情、景别、机位、运镜、切镜、声音及与前后镜的衔接。

以每段不超过15秒为编排建议，并满足所选模型实时支持的时长。支持15秒时，30秒短片可分成两段；否则按完整动作拆成更多短段，不通过变速挤压动作。片段 Prompt 从局部0秒起计时，必须明确每次切镜的时间和方式、景别变化，以及运镜方向、速度与停止位置，固定机位也须写明。“切到特写”和“推近到特写”分开表达，不把多镜头片段写成一镜到底。

按 [人物空间连续性](references/spatial-continuity.md) 在文字中固定地标、人物站位、镜头轴线和移动路径。每段 Prompt 带简短空间块；每次切镜交代机位所在侧与人物位置变化，未安排移动的人保持原位置。区分角色移动、镜头移动和因裁切出画，避免反打被理解为换座。怪诞变形可夸张形体与透视，但无剧情依据不改变人物与地标的关系。

## 5. 全能参考生成视频

**不制作开场正式首帧，也不制作分镜图片或逐镜关键帧。推荐 H3 用于多图参考与原生声音，沿用上述能力核验及用户选择原则。** 将本片段所需的角色卡、场景卡及必要道具/形态图片实际传入视频入口，Prompt 明确每张参考图对应的人物、环境与用途，然后直接生成视频。

全能参考用于约束人物、场景与画风，不要求某张参考图成为视频第一帧。不要把参考卡拼成首帧，也不以“缺少开场图”为由增加生图步骤。仅在提示词中描述人物、环境或留下未解析占位符不算实际传入参考。

按 [全能参考制作](references/h3-reference-production.md) 核实当前支持的参考用途和数量限制，记录实际素材和输出即可，无需独立验收表。每段满足实际支持时长和动作容量，按文字 Prompt 明确切镜、运镜、景别和动作。每个对白镜头写明说话人、台词、时窗和其他人的嘴部状态，保持角色声线。

连续后段按 [片段结尾参考与独立开镜](references/segment-handoff.md) 执行：前段完成后抽取能体现实际结束状态的清晰画面，连同所需 CH/SC 实际放入后段全能参考图片输入。结尾图只用于空间、朝向、持物和动作交接，不要把它用作锁定首帧或首尾帧。后段单独写机位、景别与开场动作，不要求复制尾帧构图、不先定格、不重播已完成动作。首段无需此参考，明确换场/跳时按新场景安排。

查看返回片段，只修正影响故事、人物身份或动作理解的问题。不要为轻微纹理差异反复重生；修正遵守用户范围与预算。素材不足时补充必要角色/场景/道具参考，不按镜头数新增图片。

## 6. 合成并交付成片

片段生成后继续拼接、安排用户需要的对白/环境音/音效/音乐，统一画幅和输出规格。按已定分镜切镜，不擅自用变速、删情节或填充空镜凑时长。

完整查看成片，检查故事是否讲完、接头是否连贯、声音是否正常、导出文件是否可用，然后交付成片链接或文件及已有剧本、卡片和分镜。不要停在“片段已生成”或“等待逐项验收”；工具确实阻塞时说明缺项，交付已完成素材。不能播放或听音的部分如实说明，不宣称已验证。

恢复任务时按 [流程续接](references/workflow-gates.md) 从未完成处继续，不重做已有合格内容。所有 YAML 模板均为可选记录格式，信息已在画布或日志中就不重复填写。
