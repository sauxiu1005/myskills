# 带镜头号的多格分镜图与视频参考绑定

第 5 步生成分镜时读取本文件，第 8 步按本文件绑定参考图。布局为本技能默认排版约定，可按镜头数量调整。

## 1. 总图排版

默认一页 6 格，2 行 × 3 列；每格一个镜头，按阅读顺序排列：

```text
B001
┌────────────┬────────────┬────────────┐
│ S001 画面  │ S002 画面  │ S003 画面  │
│ 框外信息栏 │ 框外信息栏 │ 框外信息栏 │
├────────────┼────────────┼────────────┤
│ S004 画面  │ S005 画面  │ S006 画面  │
│ 框外信息栏 │ 框外信息栏 │ 框外信息栏 │
└────────────┴────────────┴────────────┘
```

- 白色页底、统一细边框、明确留白，所有画面框同尺寸；每格内部按最终视频画幅构图，默认竖屏 9:16。横屏项目使用 16:9 单格，不挤压或拉伸画面。
- 页眉：页号。每格框外信息栏：`S001 | 5s | 全景 | 靠近门口 | 缓慢推进`。对白、旁白及完整时间表保留在镜头合同中，避免往图上塞长文本。
- 2K 为默认生图规格，不等于六格内每格均有 2K 细节。裁出单格后若身份、手部或道具细节不足，应依据该格构图和最终角色/场景卡补生成足够清晰的单格图，再复核并更新映射；不能把低清裁片称作 2K 单格图。
- 同一镜头的多个状态标为 `S003-A`、`S003-B`，并记录如 `00:00 起点`、`00:08 终点`。禁止让同一无后缀镜头号对应多个不同画面。镜头总时长只在合同中计一次。

## 2. 生成提示词模板

```text
制作一张标准影视分镜板，页号【B001】，采用【2行3列】网格。
每格画面为【9:16】，整页尺寸适配网格、留白和框外信息栏。
画面为真人写实摄影参考，使用最终角色卡【实际资产】和场景卡【实际资产】。
每格独立成画，人物与环境不跨格延伸；不用漫画气泡、装饰拼贴或海报排版。
按左到右、上到下顺序：
- 第1行第1列，S001：【在场角色、站位、景别、动作起点、空间与光线】。
  框外信息栏：S001 | 【时长】 | 【景别】 | 【动作】 | 【运镜】
- 第1行第2列，S002：【该镜头独立画面描述】。
  框外信息栏：S002 | 【时长】 | 【景别】 | 【动作】 | 【运镜】
【按实际镜头数继续，未使用格保持空白且不编号】
编号与信息栏清晰且只位于画面框外；画面内部不出现编号、字幕、水印。
保持人物身份、服装、道具状态、空间轴线与光线连续。
```

优先分别生成干净画面，再用可用排版工具组装总图、确定性地添加编号。若直接生成整页，复核实际画面和标注，而非假定模型已严格遵循提示词；标签错误时修正排版，不为修字重生成正确的人物画面。

## 3. 映射表

每个实际使用的格子必须建立记录，不从文件返回顺序猜测编号：

| 字段 | 要求 |
|---|---|
| shot_id / panel_id | 合同镜头号 S003 / 格子编号 S003 或状态编号 S003-A |
| board_id / version | 页号 B001 / 当前确认版本 v1 |
| row / column | 从 1 开始的行列位置 |
| board_asset / source_size | 实际总图路径或资产 ID / 原图宽高像素 |
| picture_bbox | 原点为总图左上角，像素坐标 [left, top, right, bottom)，仅含画面内框，排除边框及文字 |
| clean_asset | 已实际导出或生成的干净单格图路径或资产 ID |
| reference_role / local_time | 起点、终点或构图参考 / 所属镜头内时间 |
| character_assets / scene_asset | 当前确认的角色卡与场景卡 ID |
| duration / timeline | 合同总时长 / 计划成片时间范围 |

替换某格后更新该格资产与版本；若网格重排或整页重新生成，重新测量受影响的裁切范围。不能沿用旧坐标或失效资产 ID。

## 4. 生视频绑定

1. 按当前 `shot_id` 取图，核对画面中的人物、地点和动作，再把真实素材引用填入视频提示词；图号随实际上传顺序绑定，不能照抄模板中的 `@ImageN`。
2. 默认只传当前镜头的干净图及必要角色/场景卡。指定每张图负责身份、空间还是构图；有冲突时先修正分镜，不能要求模型自行混合不一致参考。
3. 单格起点只约束初始状态，镜头内动作、时序和运镜用文本写明。A/B 状态只有在接口支持并确认对应能力时才作为首尾帧或有序参考；不支持时使用 A，B 转为文字。不要将多格拼图送入只接受首帧的字段。
4. 如已验证模型能读取分镜总图，可额外使用总图，但必须写明：`仅使用 B001 第1行第3列 S003；忽略其他格；编号、信息栏、边框不是成片内容；输出单幅连续视频画面，不要九宫格、分屏或翻页。` 未验证时保持单格路径。
5. 当前环境无法裁切时，优先单独生成并核对对应镜头的干净图；也无法生成时说明缺少可用参考素材，不得假装裁切完成或悄悄把整页当首帧提交。
6. 生成后核对当前镜头的主体、起点、顺序和连续性，检查是否混入其他格人物、分屏、编号或边框。失败时按主流程只重试该镜头一次，优先纠正映射或参考角色；模型切换仍需验证对应参考能力。

一页六格是分镜审阅组织方式，不意味着要将六个镜头一次性塞进同一个视频任务。保留已确认镜头合同、逐镜头时长与成片顺序。
