- 本清单保留七项 Issue 的验收标准；未勾选项不代表已经运行或通过。
- 文档规则可以静态核对；实际生成、音画同步、宿主恢复和导出须另行授权验证。不得以提示词检查、格式通过或分支推演代替实测。

- English: this checklist specifies acceptance cases, not proof of media execution. Static checks and planning walkthroughs must be reported separately from authorized live generation/export tests.

## Issue 1：单镜头必要后期与缺失补音 / Required finishing

修复位置：两份入口的 STEP 0、STEP 5b、STEP 7。

- [ ] 单镜头目标 3 秒、模拟模型最短 5 秒：计划包含生成后裁到 3 秒，实际时长由另行授权的导出测试确认。
- [ ] 单镜头使用无声模型且需要对白：计划包含对白制作及时间对齐，不声称自动获得口型同步。
- [ ] 多镜头使用无声模型：已确认所需的对白、拟音与环境声均有补制路径。
- [ ] 不以“保留已有音轨”替代“补制缺失音轨”。
- [ ] 单镜头无必要后期时直接交付已确认片段，不强制新增配乐或封面。
- [ ] 完整音轨与已裁切音轨分别处理，画面与关联声音使用同一源区间和起点，不重复裁切；变速使用同一时间映射。
- [ ] 中英文一致；所需能力缺失时暂停并报告未交付内容。

## Issue 2：全片声音策略 / Whole-work audio intent

修复位置：两份入口的 STEP 0、STEP 5b、STEP 6、STEP 7、STEP 8；metadata。

- [ ] 全片静音：不产生不必要的声音任务，最终无可听声音；不支持静音的源片段提前约定后期去音。
- [ ] 不要配乐、保留环境声：不生成或混入音乐，保留已确认声音。
- [ ] 正常声音：按确认方案制作与混音。
- [ ] 三种意图产生不同执行计划；原生音频开关不是唯一控制点。
- [ ] 静音作品交付清单不强制包含配乐。
- [ ] 不需要的音乐与所需对白无法分离时，先说明限制并取得解决方案授权。
- [ ] 中英文与 metadata 不再无条件承诺配乐成片。

## Issue 3：必需参考保护 / Essential reference preservation

修复位置：两份入口的 STEP 2c、STEP 3、STEP 6。

- [ ] 提供重新上传、兼容能力或明确授权的文字重建等选项。
- [ ] 决定前说明身份/结构损失；纯文字重建须取得明确授权。
- [ ] 可选风格参考与必需身份参考采用不同规则；舍弃可选参考也须处于适用授权内。

- [ ] 新结果内部一致不能代替原始身份保持。

## Issue 4：授权与任务恢复 / Authorization and recovery

修复位置：两份入口的“执行边界与失败恢复”、STEP 2d、STEP 3、STEP 4c、STEP 6。

- [ ] 模拟失败后不自动产生第二次付费生成；用户请求重试后按宿主支持的恢复方式处理。

- [ ] 无明确核查请求时不主动验收式分析自生成媒体。
- [ ] 核查授权不等于重生成授权；修正表不直接触发生成。
- [ ] 只授权修改一镜时，保留其他镜头与无关资产。
- [ ] 保留成功结果，遵循取消状态与费用确认。

## 流程推演 / Workflow walkthrough

场景 A：用户要一段 9:16、3 秒、全片静音的六十年代空街镜头，模拟视频能力最短 5 秒且支持该比例。

1. 确定空街与现代片种、目标 3 秒和全片静音；说明源 5 秒、后期裁切方案。
2. 先图后视频按单图路径制作并确认空街；无可辨识人物不强制三视图。
3. 中文正文与后缀用竖向构图；若生图用 D，同步替换英文宽银幕构图。
4. 当前能力与参考清单通过关卡后，取得生成确认；音频可关闭则关闭，不能关闭则先说明去音。
5. 用户确认片段后进入必要后期，不因单镜头跳过裁切；裁到 3 秒并保证无可听声音，不新增配乐和封面。
6. 展示实际成果供用户审阅，不主动分析或追加生成。

场景 B：三名人物、一张分镜、三张必需面部图，模拟上限为 3。

1. 计算必需参考为 4，数量关卡不通过。
2. 暂停本镜头，不默默删掉人物面部图；其他不依赖该决定的工作可保留。
3. 说明可行调整及影响，用户决定后更新方案并重新校验；不在决定前生成替代图或视频。

推演核对：输入输出有衔接；场景和比例不是固定项目数据；高成本与创意变更有确认点；失败/超限有出口；同阶段独立任务批量执行，不逐镜头交替全部流程。
