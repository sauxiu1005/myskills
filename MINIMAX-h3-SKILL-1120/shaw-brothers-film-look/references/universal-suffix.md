# 邵氏通用画面后缀（固定质感层）

本文件内容是每一次图片 / 视频生成都必须附加的固定后缀，用于稳定画面质感。
版本分工：场景图与资产图用 D 版；分镜与视频在所选能力支持中文及相应长度时用 A / B / C 版 + 中文负面词；仅英文或短提示词能力按 D 版规则适配。人物三视图只取对应后缀的“风格定调”“胶片质感”两句加负面词。模型选择以入口的“模型配置”为唯一策略依据，视频不固定模型；本文件不另行指定模型。
**保留质感措辞，应用明示例外后使用**：黑白按 C/D 规则，模型长度受限时按文末压缩顺序，构图按下方画幅规则。不得以“逐字使用”为由保留与用户画幅冲突的指令；这些受控适配不改变核心胶片质感。

---

## 画幅与构图适配（同时作用于片种主体、译文和后缀）

先确认交付画幅与当前能力支持范围，再组装提示词。下面 A/B/D 块是默认宽画幅母版，不是所有画幅都必须逐字复制的成品。替换只调整画幅与空间组织，保留人物身份、已确认站位、胶片、光线和材质要求；不得直接裁掉关键人物或改变镜头含义。构图无法兼容时先征求决定。

| 画幅 | 中文替换 | D 版及英文主体替换 |
|---|---|---|
| 21:9 | 可保留宽银幕构图，明确 21:9；支持时按该比例生成 | 可保留 `layered widescreen composition`，明确 21:9 |
| 16:9 | 可保留横向构图，明确 16:9，不暗示额外裁成 21:9 | 可保留横向构图措辞，明确 16:9 |
| 9:16 | 将“横向宽银幕”与“宽银幕”替换为“9:16竖向”；“横向”单独残留时也改为“竖向”；组织上下层次与完整主体 | 将 `layered widescreen composition` 替换为 `layered vertical 9:16 composition`；英文主体的 horizontal/widescreen 构图描述同步改为 vertical 9:16 |
| 1:1 | 将“横向宽银幕”与“宽银幕”替换为“1:1方形”；“横向”单独残留时也改为“方形”；保持主体与空间层次 | 将 `layered widescreen composition` 替换为 `layered square 1:1 composition`；英文主体的 horizontal/widescreen 构图描述同步改为 square 1:1 |
| 其他用户比例 | 明确实际比例及横/竖方向，替换冲突构图描述 | 明确实际比例及方向，替换冲突构图描述 |

替换长短语在前、短词在后，避免只改一处留下冲突。处理片种里的“宽银幕群像构图”“宽银幕展示完整布景”等同类表达，不只处理后缀。提示词发出前核对正文、后缀和参数画幅一致。三视图是独立参考表，默认 16:9，不因成片竖屏而自动改为竖排。能力不支持的比例须先确认其他能力或后期方案，不静默变更交付规格。

## A. 通用后缀（默认 · 古装类片种使用）

适用片种：①黄梅调与戏曲爱情 ②宫廷与历史 ③古装志怪与幽情 ④神话与神魔奇幻 ⑤新派武侠 ⑨战争与家国（若为古代战争）

```
风格定调：1960年代香港邵氏电影的片厂摄影美学、复古港片质感、老电影颗粒感、特艺彩色（Technicolor）、伊士曼彩色胶片（Eastmancolor）。
光影布光：戏曲化棚拍布光、高反差伦勃朗光影、硬侧逆光、轮廓光、非自然主义布光、发黄钨丝暖光与深青冷色调碰撞。灯光方向明确，人物面部柔润，衣料纹理清晰，背景具有明暗层次。
胶片质感：35mm胶片颗粒、轻微胶片漏光、老电影褪色质感、柔焦光晕、镜头眩光、画面边缘柔化。
场景氛围：舞台式人工布景、手绘古风背景、中式古亭/竹林/古刹、烟雾缭绕、戏剧化构图、留白。横向宽银幕构图，中远景，完整呈现人物姿态，利用门窗、柱廊与前景遮挡组织空间。
画面色调：精心搭建的中式布景，服装、器物与建筑形成协调而鲜明的色块，保留场景本身的配色与冷暖关系，色彩饱满、扎实、层次分明，鲜艳部分集中在有意义的局部，整体配色协调。中间调丰富，适度增强明暗反差，暗部沉稳并保留细节，高光过渡柔和，明亮物体保留材质与纹理。
人物肤色自然、柔润，与环境颜色清楚分离。
```

## C. 黑白摄影变体（仅在用户要求黑白，或明确以《不了情》《后门》为参照时）

以 B 版为基础，删除与彩色冲突的描述：“特艺彩色（Technicolor）、伊士曼彩色胶片（Eastmancolor）”改为“黑白胶片摄影”；删除“发黄钨丝暖光与深青冷色调碰撞”；整段“画面色调”和“人物肤色……”替换为片种⑦提供的黑白追加句。其他句子保持原文。

## D. 英文精简版后缀（仅英文模型 / 短提示词模型）

适用条件：入口默认场景图与资产图使用 D 版，替代 A/B/C 与中文负面词。分镜与视频按当前所选能力的语言和长度支持使用 A/B/C 或 D，不在本文件固定视频模型。
若用户临时指定其他只接受英文或提示词上限过短（约 1000 字符以内）的模型，同样使用 D 版。

```
1960s Hong Kong Shaw Brothers film aesthetic, vintage 35mm color-film texture, rich coordinated colors, balanced warm–cool separation, theatrical directional lighting, subtle rim light, natural skin tones, deep detailed shadows, soft highlight roll-off, fine film grain, delicate halation, gentle optical softness, layered widescreen composition. Preserve the scene’s palette and material details. No plastic skin, oversharpening, heavy fading, excessive bloom, CGI sheen, text or watermarks.
```

使用规则：
- 保留质感句，按本文件明示规则适配画幅与黑白；已自带负面要求（No plastic skin…），无需再附加中文负面词。
- 片种主体需译成简洁英文（约 40–70 词），放在 D 版后缀之前；整体保持在模型上限内。
- 现代片种：D 版不含古风场景词，可直接使用；时代感由英文主体描述（如 1960s nightclub）。
- 黑白需求：把 “vintage 35mm color-film texture, rich coordinated colors, balanced warm–cool separation” 换成 “vintage 35mm black-and-white film texture, soft tonal gradation”，其余不变。
- 人物关键特征（独臂、左右手、朝向、人数）写在英文主体最开头。英文模型对靠前的词权重更高，测试中把这些放在后面会出现双臂、左右手颠倒、背对镜头。

## 负面提示词（必加，所有片种、图片与视频都附加）

```
无仙侠特效、无现代妆容、无3D渲染、无卡通二次元、无柔光磨皮、无华丽光效、无现代摄影、无数码画质光滑。塑料皮肤，过度磨皮，过度锐化，HDR光晕，强烈橙青调色，全画面泛黄，重度褪色，大量划痕污渍，过强背景虚化，夸张镜头光斑，游戏渲染感，海报排版，字幕，水印。
```

放置方式：
- 所选生成能力提供独立的负面提示词参数时，原文填入该参数。
- 不提供时，以“画面避免：”开头，整段附加在正向提示词末尾。

说明：负面中的“无仙侠特效、无华丽光效”针对现代 CG 特效。片种④神话奇幻要求的“局部彩色灯光、薄雾、早期电影特效的朴素想象力”指实拍棚景与手工特效，两者不冲突，不要因此删掉负面词。

## 拼接顺序

```
[片种主体提示词（已填好方括号）] + [片种追加倾向（如有）] + [视频动态描述（仅视频）] + [通用后缀 A/B/C] + [负面提示词]
```

主体放在最前，因为生成模型对开头内容权重更高；后缀负责统一质感，不应抢占主体描述。

## 长度超限时的压缩顺序

只有当模型提示词上限放不下时才压缩，按以下顺序逐步删减，删到够用即停：
1. 片种主体中重复后缀已有的质感句（如“细腻彩色胶片颗粒”“无文字”）
2. 后缀“场景氛围”中与片种主体重复的构图句
3. 负面提示词后半段的细项（从“大量划痕污渍”往后）
永远保留：风格定调、光影布光、胶片质感三行，以及负面提示词前半段。
