# 邵氏电影画面质感

当用户希望生成的图片或视频呈现 1960 年代香港邵氏电影的片厂摄影质感时使用。本 Skill 的核心是**两层提示词**：

| 层 | 来源 | 用法 |
|---|---|---|
| 固定质感层 | `references/universal-suffix.md` | **每一次**图片 / 视频生成都附加质感层；仅按明示例外适配，包括画幅替换 |
| 片种内容层 | `references/genre-prompts.md` | 根据用户需求智能匹配九类片种之一，填写方括号后作为提示词主体 |

开始前必须读取这两个 reference 文件，保留质感措辞；允许按本文与参考文档明确规定进行情绪、黑白、动态、长度和画幅适配，不凭记忆改写。构图措辞不属于不可修改的质感要求。

## 执行边界与失败恢复

以下规则适用于所有步骤，也适用于 STEP 6 中的每一条修正建议：
- 生成结果交由用户审阅，不主动对自己生成的媒体做质量验收式分析，也不据此发起追加生成。只有用户明确要求核查时，才按指定范围分析；核查授权不等于重生成授权。
- 修正表是供讨论的方案，不是自动执行命令。追加生成或降低输入要求前，先说明范围与已知费用，并取得适用的用户授权；认可创作方向不等于无限重试授权。
- 失败时保留已成功结果并说明问题。仅在用户要求重试时，通过宿主支持的恢复流程处理；结果未知时先查询原任务，不盲目重新提交。不绕过取消状态或尚未完成的费用确认。
- 局部修改保留未受影响的资产、已确认设定和产物，只更新用户要求的对象及必要下游；宿主规则更严格时遵循宿主规则。

## 模型配置

前期生图（场景图、人物资产图、三视图、分镜图）的模型由用户指定并固定，不按默认推荐自动更换——不同模型对胶片质感的表现差异很大，同一作品中途换模型会破坏系列一致性。视频生成不固定模型：

| 用途 | 模型 | 对提示词的影响 |
|---|---|---|
| 场景图、人物资产图（及道具图） | **Midjourney 8.2（MJ8.2）** | 只接受英文、上限约 921 字符 → 一律使用英文精简版后缀 **D** |
| 人物三视图（全身白底造型三视图、面部三视图） | **GPT Image 2** | 支持中文、最多 16 张参考图；白底定妆用途，只取后缀中的质感句（见 STEP 3） |
| 画面分镜图 | **GPT Image 2.5 Sunburst** | 支持中文、可传多张参考图 → 使用中文完整后缀 **A / B / C** + 中文负面词（见 STEP 4） |
| 视频生成 | **不固定**：用用户本次指定的视频模型；未指定时用当前可用的默认视频模型 | 使用中文完整后缀 **A / B / C** + 中文负面词；参考图数量、时长范围、提示词上限、音频与多镜头等按所选模型的能力调整（见 STEP 5） |

分工原因：
- **前期不生成关键帧**。MJ 单独出关键帧时，同一人物在各镜头之间的脸、手臂、持物经常不一致，还要靠裁脸、反复挑候选来补救；改为先用 MJ8.2 定下场景与人物造型，把造型锁死后再出分镜，一致性从源头保证。
- MJ8.2 的造型与美术气质最接近邵氏片厂画面，用它确定场景与人物的整体观感。
- MJ 对人物身份还原不严格，写了全身也常只出到大腿，独臂等肢体特征也常画错；GPT Image 2 能稳定出头到脚的全身像，并严格执行左右手、配饰位置等要求，所以用它把人物资产图整理成白底三视图。
- GPT Image 2.5 Sunburst 多参考图组合能力强，能同时遵循场景图与多个人物的三视图，适合把已锁定的资产组装成分镜画面，且能严格执行人数、左右手与持物。

- 选定模型或准备生成前，发现当前可用能力并读取所选模型的现行限制，包括参考素材类型与数量、画幅、时长、提示词长度和音频支持。下文名称与历史限制不能证明当前可用性，不假定宿主必有某个工具，也不沿用失效参数。前期生图的固定模型当前不可用时，告知用户并等待决定，不要自行更换，因为不同模型的质感表现差异会破坏系列一致性。
- 用户在某次请求中明确要求换生图模型时，仅本次按用户要求执行，并按新模型的语言与长度限制选择后缀版本。
- 视频模型可以按用户要求随时更换，也可以对已确认的分镜改用另一模型重做；同一作品的各段尽量使用同一视频模型，混用时提醒用户各段质感可能略有差异。

## STEP 0: 理解需求

从用户请求中提取：
- **产出类型**：图片 / 视频 / 先图后视频
- **内容**：人物、场景、动作、情绪、时代（古装或现代）
- **参考**：用户点名的邵氏片名、导演倾向（胡金铨 / 张彻）、是否要黑白
- **规格**：画幅（默认 21:9；用户明确指定时，场景图、分镜图和视频遵循用户画幅）、数量、目标视频时长（支持时默认 5 秒）。区分目标时长与生成时长。目标短于模型最短时长时，生成前说明需先生成较长素材再裁切；单镜头和多镜头都在 STEP 7 裁到目标时长。合并相邻镜头会改变镜头方案，须先确认。现有能力无法交付用户画幅或时长时，生成前说明方案并取得决定。
- **声音策略**：记录已确认的全片意图：全片静音；不要配乐、保留所需对白/拟音/环境声；或已确认的声音与配乐方案。分别记录对白、拟音、环境声、配乐及明确不要的声音，贯穿生成、后期和交付。全片静音不得发起声音生成，最终交付不得含可听声音。用户改变声音策略时，只更新受影响步骤，不改动无关画面。

已经能判断的不要再问。片种完全无法判断时按 STEP 1 提问；交付规格、必需参考、能力限制、输入降级或恢复授权需要决定时，也应先对齐。

### 用户上传详细文档时：拆分镜头

用户上传或粘贴剧本、分镜脚本、剧情大纲等文档时，先读完全文，再拆成镜头清单；每个镜头走 STEP 1 匹配片种，再按 STEP 2–7 依次制作场景与人物资产、人物三视图、分镜图、视频，最后完成必要后期及已确认的可选配乐、封面。

1. **拆分依据**：文档已有镜头或场次编号时按原编号拆；没有编号时，按“地点、时间或核心事件发生变化”切分，一个镜头只承载一个主要画面事件。
2. **每个镜头整理出**：编号、场景（地点 + 时间 + 天气）、出场人物与关键特征（外观、服装、道具、缺失肢体、哪只手、朝向、人数）、核心动作、情绪、产出类型（图片 / 视频及时长）、是否需要运镜。
3. **资产清单**：同时列出全片需要的场景、人物和重要道具，标明各自出现在哪些镜头；这份清单是 STEP 2 制作资产的依据。
4. **区分可画内容与可听内容**：心理活动、背景说明不进入任何提示词，只转化为可见的表情、动作或环境。对白在图片（资产图、分镜图）中转化为口型、视线、手势等可见表演；在视频中作为台词保留（见 STEP 5b 第 9 条），因为常用视频模型能生成原生对白；所选模型不支持声音时，对白留到后期配音。
5. **镜头数量**：文档拆出的镜头超过 6 个时，先向用户确认是全部制作还是挑选重点镜头，避免一次产生大量生成成本。
6. **给用户确认**：把镜头清单、资产清单连同每个镜头预判的片种、后缀版本一起展示，用户确认或修改后再进入生成。用户已明确说“直接生成、不用确认”时可跳过。

每个镜头独立匹配片种（如同一短片中歌舞、犯罪、文艺各一个镜头），但同一产出类型使用同一后缀版本，保证全片质感统一：场景图与资产图统一 D 版；分镜图与视频在同一短片内统一 A 或 B（古装短片用 A，现代短片用 B），不按镜头切换。

## STEP 1: 匹配片种与后缀版本

按 `references/genre-prompts.md` 的“匹配速查表”和“判定规则”选择片种。

后缀版本按“产出类型 → 片种”确定：

| 产出 | 条件 | 后缀 |
|---|---|---|
| 场景图、人物资产图、道具图（MJ8.2） | 所有片种 | **D** 英文精简版（黑白需求按 D 版说明替换色彩短语） |
| 人物三视图（GPT Image 2） | 所有片种 | 与视频同版后缀的“风格定调”“胶片质感”两句，加负面词（见 STEP 3） |
| 分镜图（GPT Image 2.5 Sunburst）与视频 | 古装类（①②③④⑤，古代战争⑨） | **A** |
| 分镜图与视频 | 现代都市类（⑥⑦⑧，近现代战争⑨） | **B**，避免 A 版“中式古亭 / 竹林 / 古刹”造成时代错乱 |
| 分镜图与视频 | 黑白需求或以《不了情》《后门》为参照 | **C**，并追加片种⑦的黑白句 |

- **画幅适配**：生成前按 `references/universal-suffix.md` 的替换规则，同时处理片种主体和后缀，包括 D 版及英文译文。用户要求 9:16 或 1:1 时，不得残留强制横向/宽银幕指令。保留质感、身份与已确认站位；三视图版式仍为 16:9，除非用户另行修改参考表格式。不支持的画幅须先决定处理方案，不静默裁切或拉伸。
- 武侠片按用户倾向决定是否追加“大醉侠”或“张彻”倾向句。
- 多片种混合时只取一个主体片种，另一片种只借一两句，不整段叠加，避免提示词互相冲突。
- 片种主体中描述基调的词（如⑥的“光线明亮”“轻快活泼”）与本镜头情绪冲突时（如告别、挽留等安静段落），把这几个词换成符合镜头情绪的说法，其余句子保持原文；因为镜头情绪才是观众感受的依据，照抄会让画面气氛与剧情相反。

## STEP 2: 制作场景图与人物资产图（MJ8.2）

前期不生成关键帧，直接为资产清单中的场景、人物（和重要道具）生成资产图，由它们定下全片的场景、造型和整体质感。

**单张图片或单镜头**：只做一张图、后续不再延展时，不走 STEP 2–4，按下方“单图流程”出图。只做一个镜头的“先图后视频”时，先按单图流程出图并请用户确认；画面中有需要看清的主要人物时，再以这张图为资产图做 STEP 3 三视图，然后把这张图当作分镜进入 STEP 5；没有可辨识人物（如空镜、背影、远景群像）时跳过三视图。

**单图流程**：用 MJ8.2 出图，提示词结构为 `[人数与关键特征] + [片种主体英文精简译文（方括号已填）] + [倾向句英文（如有）] + [按规则适配画幅/黑白的后缀 D]`。人数、缺失肢体、持物的手、朝向写在最开头，背景写明无其他人；其余写法（不写带字物件、写出地点标志性实物、不超过 921 字符）同 2c。展示实际返回的候选供用户选择，不自行发起验收式分析或下一轮生成。

### 2a. 确定资产清单

- **场景**：每个镜头的拍摄地点各出一张场景图（同一地点多镜头共用一张）；场景图是分镜阶段的空间与布景依据。
- **人物**：所有出场的主要人物都要做；同一人物换装时，每套造型各一张。
- **重要道具**：推动情节或反复出现的物件（如断刀、金怀表、折扇），按需制作。

### 2b. 编写资产卡

每个资产整理一张资产卡，汇总成一份文本文档放到画布上，后续每次生成都从这份文档逐字取用固定描述：

| 字段 | 内容 |
|---|---|
| 资产名 / 类型 | 如“独臂刀客 / 人物”“雪夜客栈院落 / 场景”“金怀表 / 道具” |
| 出现镜头 | 该资产在哪些镜头出现 |
| 不可变特征 | 必须在每个镜头保持的特征：脸型与发型、服装款式与颜色、缺失肢体及左右、持物的手、配饰位置、道具形状材质、场景的建筑结构、主色与时间天气 |
| 中文固定描述 | 一段 40–80 字的描述，用于三视图、分镜图与视频提示词 |
| 英文固定描述 | 一段 15–30 词的描述，用于 MJ8.2 资产图提示词 |
| 参考图 | 场景图、资产图与人物三视图 |

剧本没有写明的细节（如鞋、发饰、背面、表盘）按片种与年代补全，并在资产卡中标注“补全”，方便用户确认或修改。同一人物换装时，服装按造型分开写，脸型、发型只写一份。

### 2c. 资产图提示词（英文）

```
[人数或“无人” + 英文固定描述 + 姿态与背景] + [片种主体英文精简译文（仅场景图需要）] + [按规则适配画幅/黑白的后缀 D]
```

- **场景图**：开头写 `Empty, no people`，接场景英文固定描述与片种主体的英文精简译文（布景、配色、光线、时间天气），画幅与全片一致（默认 21:9）。写出能一眼认出地点的实物（如电车站的顶棚、铁柱、长椅、轨道），只写地点名称时画面常看不出是哪里。
- **人物资产图**：开头写人数（如 One man alone），接人物英文固定描述，单人、三分之四侧面、尽量全身、简洁的深灰片厂背景，画幅 2:3，双手空着、不拿道具。缺失肢体、哪只手等关键特征写在最开头——测试中放在后面会出现双臂、左右手颠倒、背对镜头。MJ 对脸型、五官记不住，对发型、妆容、配饰更稳，描述中多写这类特征。
- **道具图**：开头写 `Empty, no people, no hands`，单独特写、深色简洁背景，清楚呈现形状、材质、颜色和开合状态，画幅 1:1。
- 不描述带字的物件，写成 plain unmarked lanterns、blank sign 等，因为 MJ 会把多词英文 / 汉字画成乱码。
- D 版自带负面要求，不再附加中文负面词；总长不超过 921 字符。
- 所有资产图保持 `chaos 0`，stylize 使用同一数值，减少资产之间的风格差异。
- **参考图**：先区分必需的身份/结构依据与可选风格参考，在资产卡记录用途和已确认来源。不得用文字描述直接替代必需参考。参考不可读时保留输入、暂停依赖它的生成，提供重新上传、兼容能力或明确授权的文字重建等选择；决定前说明身份/结构损失。可选风格参考也只在适用授权内舍弃，并记录影响。任何重试都遵循“执行边界与失败恢复”。含无关人物的整图可能干扰参考，应讨论合适的裁切或来源，不静默丢弃身份依据。后续资产图与三视图须可追溯至用户认可的身份来源；与新编人物保持一致不等于保留原始身份。

### 2d. 生成与挑选

- 生成前告知用户张数，确认后一次性批量生成全部场景图、人物资产图和道具图。
- 将实际返回的候选与资产卡一起交给用户选择，提示可关注人数、缺失肢体与左右手、文字、地点辨识和背景人物。用户反馈不符时，先说明针对性修改方案，获得授权后再生成，遵循“执行边界与失败恢复”。
- 人物资产图常只出到大腿或膝盖，可接受——全身由 STEP 3 的三视图补齐，挑选时优先看脸、发型、服装和肢体特征。
- 所有资产图集中放在画布的同一个资产组中，按资产名命名；把场景图、人物资产图、道具图与资产卡一起展示给用户，确认人物造型与场景后再进入 STEP 3。

## STEP 3: 制作人物三视图（GPT Image 2）

根据用户确认的人物资产图，为每个人物（每套造型）制作两张三视图，作为分镜与视频阶段保持人物一致的主要参考：

| 三视图 | 内容 | 画幅 |
|---|---|---|
| 全身造型白底三视图 | 同一人物的正面、侧面、背面三个全身像并排，头顶到脚尖完整入画，三者同一比例、同一身高，自然站立、双手垂在身侧、不拿道具，纯白背景 | 16:9 |
| 面部三视图 | 同一人物头部与肩颈的正面、侧面、四分之三侧面三个特写并排，发型、妆容、耳饰清晰，纯白背景 | 16:9 |

1. **参考图**：传入该人物确认的 MJ 资产图；提示词开头写明“参考图1提供人物的脸、发型和服装”，要求外观与参考图一致。
2. **提示词**：中文。写人物中文固定描述和不可变特征，逐项写清缺失肢体与配饰在哪一侧（如“没有右臂，右袖空荡扎进腰带”“银色手表只戴在他自己的左手腕”），写明“画面中只有这一个人物的三个视角，没有其他人、道具和文字”。资产图未画到的部分（下半身、鞋、背面）按资产卡补全。
3. **质感**：只附加视频所用后缀版本中的“风格定调”“胶片质感”两句和负面词，不加布景、舞台布光与宽银幕构图的句子，光线写成均匀柔和的正面光。黑白作品使用 C 版改写后的“风格定调”（“黑白胶片摄影”替换两种彩色胶片名称），并追加片种⑦的黑白句，保证三视图与视频同为黑白。提示词写纯白背景，以便看清人物结构。
4. **张数与确认**：生成前告知实际张数（每个人物的每套造型各两张），确认后批量生成。交给用户审阅三个视角的身份、头脚完整性、肢体与配饰左右及文字。米白背景或轻微地面阴影可以接受。用户反馈布景、强光效、其他物件或身份错误时，先提出局部修改方案；按“执行边界与失败恢复”取得授权后才重生成。
5. 三视图展示给用户确认后锁定。之后修改人物时，先更新资产卡、资产图与三视图，再重做受影响的分镜与视频。

## STEP 4: 制作画面分镜（GPT Image 2.5 Sunburst）

用锁定的场景图、人物三视图和道具图，为每个镜头生成一张分镜画面。分镜图定下每个镜头的构图、站位、动作瞬间和光色，是视频阶段的画面依据。

### 4a. 参考图组合

| 传入顺序 | 作用 |
|---|---|
| 本镜头的场景图 | 空间、布景、主色与光线 |
| 每个出场人物的全身三视图 + 面部三视图 | 固定人物：脸、发型、妆容、服装、肢体特征 |
| 本镜头的道具图（如有） | 道具样式 |

### 参考容量关卡（分镜与视频共用）

两个阶段生成前，都列出有序参考清单，记录来源、用途、人物/造型、必需或可选状态。在付费生成前，按当前模型及模式校验解析后的素材类型、数量与其他适用限制；生图上限不能代替视频上限。

- 已确认方案所必需的场景/分镜和身份参考不得静默删除。只能移除已获授权舍弃的可选参考，并记录替代描述及剩余数量。
- 视频可考虑先减可选道具图，再减次要人物的可选全身图，但两者并非天然可选。分镜与各人物面部图若均为必需，就全部保留。
- 必需集合仍超限，或无支持的输入模式能表达方案时，暂停依赖它的生成。说明拆镜、经确认的合并参考表（须受支持且仍可用）或更换兼容能力等选项及影响，取得必要决定后更新方案、重新校验。不超限提交，不默默牺牲身份。
- 边界示例：假设上限为 3，一张必需分镜加三张必需面部图共 4 张，必须暂停，不得直接删掉一张脸。调整顺序不能解决数量超限。

### 4b. 分镜提示词（中文）

```
[参考图分工] + [人数与站位] + [片种主体（方括号已填，含资产中文固定描述）] + [追加倾向（如有）] + [本镜头的动作瞬间与景别机位] + [按规则适配画幅/黑白/长度的通用后缀 A/B/C] + [画面避免：负面提示词原文]
```

1. **参考图分工**：按传入顺序写明，如“参考图1是本镜头的场景，布景、空间和光色以它为准；参考图2、3是刀客的全身三视图和面部三视图，他的脸、发型、服装和独臂特征一律以这两张为准；参考图4是断刀”。
2. **人数、持物与朝向**写在主体前：画面中共几人、各自位置、谁用哪只手拿什么、面朝哪里，背景写明无其他人。
3. 片种⑤主体中的“画面定格在……一瞬”可保留，分镜本身就是该镜头最有代表性的一瞬。
4. 不描述带字的物件，写成素面无字的灯笼、牌匾等。
5. 画幅与全片一致（默认 21:9）；不新增资产卡以外的人物、道具。
6. 片种主体的方括号填成具体内容；主体正文中的“X或Y”类选项（如⑥“宽银幕全景或中景”、⑦“窗光、台灯或室内主光”）按本镜头选定一项、删去其余，同时允许本文明确规定的情绪、黑白、动态、长度和画幅适配，不进行无关改写；留着选项会让模型自行取舍，导致镜头不一致。

### 4c. 生成与确认

- 生成前告知镜头数，确认后批量生成全部分镜。
- 将分镜交给用户审阅人数、肢体与左右手、持物、身份、场景连续性和文字。用户指出不符时，提出局部修正方案，获得授权后才重生成；不主动验收式分析生成图。
- 把全部分镜图按镜头顺序展示给用户，**用户确认分镜后才进入视频制作**；用户要求修改的镜头单独重做，再次确认。

## STEP 5: 生成视频（模型不固定）

视频模型优先遵从用户本次指定且满足确认要求的选择；未指定时优先使用 MiniMax H3，以支持参考人物连续性与原生对白。生成前核实参考、时长、声音及多镜头能力。不可用时选择具备同等能力的模型，明显改变已确认质感或声音前先取得决定。失败后在已有授权内定向修正一次，随后换用兼容模型，不反复重复同一失败。下述步骤按所选能力调整。

### 5a. 参考图组合

视频一律使用**参考图（多参考）模式**，不使用首帧模式：所选模型同时提供两种模式时选参考图模式；所选模型只支持首帧时，先告知用户人物一致性会变弱，再由用户决定：

| 传入顺序 | 作用 |
|---|---|
| 本镜头确认的分镜图 | 构图与画面参考：景别、站位、布景、灯光、色调参照它，**不是首帧** |
| 每个出场人物的全身三视图 + 面部三视图 | 固定人物：脸、发型、妆容、服装、配饰一律以三视图为准 |
| 本镜头的道具 / 场景图（如有） | 道具样式、场景结构 |

提交前执行 STEP 4a 的“参考容量关卡”，每个镜头都遵循必需/可选分类与暂停条件。用户要求以场景图代替分镜图作画面参考时，更新已确认的参考清单，把场景图排第一位，人物站位与动作写进提示词，再次校验。

原因：所选能力支持时，参考模式可区分构图依据与身份依据。首帧和参考模式的行为随模型而变；以往关于运镜不足或无法追加参考的观察不是普遍保证。以当前契约为准，在用户决定前说明实际限制。

### 5b. 视频提示词（中文）

```
[参考图分工] + [片种主体（方括号已填，含资产中文固定描述）] + [追加倾向（如有）] + [动作与镜头] + [声音策略允许时的声音] + [按规则适配画幅/黑白/长度的通用后缀 A/B/C] + [画面避免：负面提示词原文]
```

1. **参考图分工**：按传入顺序、用所选模型的引用写法（如 @图片1 或 @image_1）写明，如“@图片1 是本镜头的分镜，是构图与画面参考，不是首帧，景别、站位、布景、灯光和色调参照它；@图片2 是歌女的全身三视图，@图片3 是她的面部三视图，她的脸、发型、妆容和服装一律以这两张为准；@图片4 是金怀表”。必须写明“人物以三视图为准”。
2. 方括号必须填成具体内容，主体正文中的“或”字选项按本镜头选定一项（同 4b 第 6 条），不得残留；用户的具体要求写进主体；保留后缀质感措辞，并应用 STEP 1 与后缀文档明确允许的适配。
3. 所选模型没有独立负面参数时，负面提示词以“画面避免：”开头整段附在末尾；有独立负面参数时填入该参数。提示词超过所选模型的长度上限时，按 universal-suffix.md 的压缩顺序删减，风格定调、光影布光、胶片质感三行始终保留。
4. **动作**：按“前态 → 触发 → 连续动作 → 人物与环境反应 → 收尾”写出具体动作，5 秒约 3–4 拍、10 秒约 4–6 拍、15 秒约 5–7 拍；参考图模式需要运镜时，运镜会占用时长，动作少写一两拍。写明持物的手和交接方向（如“怀表从青年的右手交到歌女的右手”）。不新增人物、道具或剧情。
5. **镜头语言**：采用邵氏片厂常用的快速变焦推拉（zoom）、缓慢横移、固定机位中远景，避免现代手持晃动和无人机航拍。
6. 片种⑤主体中的“画面定格在……一瞬”在视频里改写为动作展开（见 genre-prompts.md 注释），否则容易生成静止画面。
7. **声音**：执行 STEP 0 的全片声音策略。全片静音时，有开关就关闭原生音频，不发起声音或音乐生成；源片段无法静音时，提前说明移除方案，在 STEP 7 去掉音频。不要配乐时，明确禁止背景音乐，只保留已确认的对白/拟音/环境声。其他情况按需显式开启支持的原生音频，并写年代相符的声音。所需声音不受支持时，视频生成前说明后期补制方案及授权需求；单镜头和多镜头都在 STEP 7 补制、对齐缺失的对白/拟音/环境声。仅已确认方案允许时，单镜头可带原生器乐；多镜头通常不生成分段音乐，随后按授权加入统一配乐。此惯例不得覆盖不要配乐或静音要求。
8. 多镜头生成时，每一条都附加同一版本的后缀，这是保证系列质感一致的关键。所选模型支持单段内多镜头时，可按剧本把一个镜头拆成 2–3 个分镜头，每个分镜头写明时长，总和等于输出时长。
9. **对白**：仅声音策略允许有声对白时，台词用引号原文写入，注明说话人和语言（如国语、粤语），并补一句语气提示（如“轻声带一点笑意”）；台词量与时长匹配，5 秒内一般不超过一句短句。剧本中跨镜头的对白可以合并到同一镜头里，合并时在镜头清单中注明。
10. **肢体特征**：独臂、残疾等特征在每条提示词开头单独写一段，写明“任何角度都不出现缺失的肢体”，并在画面避免中写入对应的肢体（如“右手、右臂、断臂残肢、第三只手”），因为视频运动中最容易穿帮。
11. 血腥描写（胸前有血、血溅、染血）可能被视频模型拒绝而生成失败，改写为负伤、捂胸、踉跄等可见动作。

### 5c. 生成

- 视频成本较高，生成前向用户简要展示所选片种、后缀版本、模式、参考图、时长和动作描述，确认后提交。展示内容包含本次使用的视频模型。分辨率使用默认档，提高档位前先征得用户同意。
- 多镜头时批量提交全部视频，不逐条交替。
- 画幅与分镜一致；时长按镜头清单设置，短于所选模型最短时长的镜头按最短时长生成。

生成前向用户简短说明“已匹配片种：X，后缀版本：场景与资产 D，分镜与视频 A / B / C”，便于用户纠正。

### 整体顺序

```
理解需求 → 匹配片种 → 镜头清单 + 资产清单确认 → MJ8.2 场景图 + 人物资产图（+ 道具图）+ 资产卡 → 用户确认 → GPT Image 2 全身造型白底三视图 + 面部三视图 → 用户确认并锁定 → GPT Image 2.5 Sunburst 批量分镜图 → 用户确认分镜 → 参考图模式批量视频（视频模型按用户选择）（分镜作画面参考，三视图固定人物）→ 用户确认各段 → 所有视频按需必要后期，按确认方案制作可选配乐与封面
```

用户明确要求直接文生视频时，跳过 STEP 2–4，照常拼装视频提示词后直接生成。

## STEP 6: 用户审阅与授权修正

展示结果并等待用户反馈，不主动进行质量验收式分析。下表仅用于针对用户反馈或明确要求的核查提出修正建议。表中所有“重做”均以“执行边界与失败恢复”中的授权为前提；分析请求不授权生成。保留未受影响结果，执行前说明输入变更与已知新增费用：

| 现象 | 处理 |
|---|---|
| 皮肤塑料感、过度磨皮、数码光滑 | 视频 / 分镜：把“画面避免：”段前移到后缀之前；MJ 图：主体补充 film-like skin texture |
| 胶片感不足、画面过于清晰数码 | 主体补充颗粒更明显、清晰度略低、暗部细微噪点的描述，后缀不动 |
| 全画面发黄 / 过度褪色 | 主体补充“色彩饱满、暗部沉稳、保留场景本身冷暖关系” |
| 出现现代元素或古风建筑进入现代场景 | 检查后缀是否选错（现代片种必须用 B）；MJ 图在主体中写明年代与场所 |
| 神话片出现现代 CG 光效 | 主体强调“实物搭建、手工特效、舞台美术” |
| 灯笼、招牌、画面出现文字 | 主体改写为素面无字物件，去掉含文字的描述 |
| MJ 资产图左右手颠倒、肢体特征丢失、背对镜头 | 关键特征移到最开头并明确写出（如 no right arm, empty right sleeve, three-quarter front view），从 4 张候选中挑选 |
| MJ 场景图或道具图混入人物 | 开头写 Empty, no people, no hands；不要传含人物的整张画面作参考 |
| MJ 场景图看不出地点 | 补写该地点标志性的实物（顶棚、轨道、柱廊、楼梯栏杆等） |
| 参考图无效或获取失败 | 暂停依赖它的生成并按 STEP 2c 处理：保留必需身份依据，提供可恢复输入或经授权的替代方案，不静默删图或重试 |
| 三视图三个视角不像同一人、全身未到脚 | 补写“三个视角是同一个人、同一服装、同一比例”“头顶到脚尖完整入画、双脚和鞋完整”，重做 |
| 三视图背景带布景或强烈光效 | 删去布景与舞台布光句，只保留质感两句，写明“纯白背景、均匀柔和的正面光”；米白或轻微地面阴影不必重做 |
| 分镜人物与三视图不一致 | 参考图分工中写明人物以三视图为准，三视图排在场景图之前重做 |
| 分镜人数、持物或左右手不对 | 人数、位置、哪只手拿什么写在主体最前，背景写明无其他人 |
| 画面像现代电影、景深过浅 | 主体补充“中远景、完整呈现人物姿态、背景清晰可辨” |
| 视频画面静止不动 | 补充明确的动作节拍与镜头运动 |
| 视频没有声音 | 先看已确认声音策略，静音可能正是要求。需要声音时，确认源能力是否支持，再提出 STEP 7 补音或授权重试，不自动重生成 |
| 视频里各段配乐风格不一、剪辑点音乐断开 | 仅按声音策略提出去除或替换方案；允许配乐时才在 STEP 7 统一制作，全片静音或不要配乐时不得补音乐 |
| 台词没有念出或念错 | 台词用引号原文写入并注明语言与说话人，减少单段台词量，必要时拆到相邻镜头 |
| 视频中人物外观漂移，或沿用了分镜里的脸 | 确认已传入全身与面部三视图，参考图分工中写明“分镜不是首帧、人物以三视图为准”，必要时把三视图排在分镜之前 |
| 视频构图或质感偏离分镜 | 确认分镜已传入并写明其作为构图与画面参考，提示词仍附加完整后缀 |

授权修正时保留质感措辞，允许本文明确规定的情绪、黑白、动态、长度和画幅适配。画幅变化须同步处理主体与后缀，不能以“原文不动”为由保留冲突构图。

## STEP 7: 必要后期与可选配乐（所有视频作品）

用户确认片段后，按目标时长和声音策略判断必要操作。单镜头只跳过不需要的拼接，不跳过必要裁切、去音或补音。没有处理需求时直接保留已确认片段作为成片，不额外生成无必要的音乐或封面。

1. **方案与能力关卡**：列出源版本、源/目标时长、裁切需求、缺失的已确认声音与交付项，确认当前可用编辑和声音能力。昂贵操作前说明限制并取得必要决定，不承诺能力不支持的口型同步、声音分离或精确画幅。最终合成前确认组装方案。
2. **剪辑与时间对齐**：每段按目标时长裁切，包括因模型最短时长而多生成的单镜头。仅多镜头按已确认顺序拼接。画面与其关联声音使用同一源区间并一同重置起点；区分完整源音轨和已裁切音轨，避免重复裁切。经授权变速时，画面与相关声音采用相同时间映射。这是交付要求，不代表导出实现已被实测。
3. **缺失声音**：非静音作品识别缺失的已确认对白、拟音和环境声，先展示制作/选取与时间对齐方案，授权后补制或取得声音并对齐已确认剪辑。明确台词、说话人/语言、事件时刻和入出点。台词时间对齐不等于口型同步；无法完成所需同步时说明限制并取得决定，不静默改成旁白。所需声音能力不可用时暂停相关工作，说明仍未交付的部分。
4. **可选配乐**：仅声音策略允许音乐时，说明风格、编制、入乐点和时长，确认后生成。使用年代相符的原创器乐，不模仿具体原片配乐。多镜头可用一条统一配乐；全片静音或不要配乐时，不生成也不混入音乐。
5. **按策略混音**：全片静音移除/静音所有源音频和新增声音；不要配乐时只保留已确认的对白/拟音/环境声。不需要的音乐与需要的对白无法分离时，先说明取舍，确认替换或其他方案后再处理。允许配乐时，音量低于对白，关键剧情声处压低并按方案淡出。保留有效原声，不重复叠加同一声音。
6. **封面/片名与展示**：只有约定交付包含时才制作封面或片头卡，单镜头不强制额外制作。片名不写入视频生成提示词，而在后期用已确认图片叠加已确认文字。展示成片与实际制作的声音资产、裁切和混音说明供用户审阅；不主动验收式分析产物或重生成。用户要求的核查与修改按 STEP 6 处理。

## STEP 8: 交付

向用户交付生成结果，并附上：
- 各阶段实际使用的模型、匹配片种、后缀版本、画幅适配及已确认的参考替换/舍弃，不把计划模型写成实际已使用模型
- 资产卡、场景图、资产图与人物三视图，便于后续续拍或补镜头
- 分镜图与实际使用的完整提示词（便于复用或微调）
- 符合约定时长和声音策略的最终结果，包括单镜头；配乐、其他声音资产和封面仅在属于约定交付时提供，并说明裁切/混音及尚未解决的限制
- 如有修正，说明改了什么
