# 参考图与 H3 提示词

H3 看不到分镜和其他文档。每组提示词要自己说清楚这一组的全部画面。

## 人物与场景参考图

参考图的作用是让同一个人物、同一个地点在不同镜头组里保持一致。只为需要跨组重复出现的人物和地点做参考图。

### 人物

- 用户给了完整角色卡（清楚的脸，加正、侧、背全身）：直接用原图。
- 只有一张脸照或单张人像：用它做一张新的角色卡，保留脸和身份。
- 原创人物：按歌曲、声线和风格设计。唱跳和表演类人物要有辨识度：鲜明的发型、两层左右的服装层次、一两个标志配饰。剧情人物按时代、职业、身份做得可信。
- 歌手和画面人物是同一人时，人物外观和声线一致。
- 一个角色只保留一个当前版本，重做后旧图不再使用。
- 剧情需要年龄变化（少年和成年、初遇和多年后），给同一人物做两个年龄版本。
- 有关键戏份的配角也做一张卡，保证他在各组里是同一个人。

### 角色卡版式

单张 16:9 横图，白色背景：

- 左侧约三分之一是正脸特写，五官、妆发清楚。
- 右侧三等分：正面、侧面、背面全身，从头顶到鞋底完整入画。
- 四个区域是同一个人、同一套服装；卡上不加文字和特效。

提示词里逐字写出这四个区域，只写“三视图”或“角色卡”往往得不到这个版式。

### 场景

- 普通地点不需要参考图，在提示词里写清空间就行：在哪里、有什么标志物、光从哪来。
- 同一个地点反复出现在多个组里，并且方位决定故事是否看得懂时（灯楼、教室、站台），做一张场景图：同一空间的 2×2 四个角度，不含人物。

### 风格句

所有图片和视频提示词用同一句媒介风格句收尾，全片一致，画风就不会漂移。这句从用户的参考和要求里提炼，写参考真实的媒介、影调和质感，例如“高反差黑白胶片摄影，浓重颗粒，慢门拖影”或“日系动画电影画风，干净线稿，赛璐璐平涂”。不默认写成普通的写实摄影，见 [从参考和要求里定风格](style-from-references.md)。

## H3 规格

- 优先用 MiniMax H3：支持参考图、音频参考、原生声音，一次生成组内多个镜头。
- 每组时长 4–15 秒整数，和分镜一致；默认 2K；画幅按方向。
- 每组提示词上限 7000 字符。在上限内写得越具体，画面越精致、越丰富：每镜的场景空间、人物动作和发力、景别机位运镜、光色材质、包装特效的出现和变化过程、衔接与终态都可以展开写。
- 篇幅花在画面上：具体的动作、空间、光色、材质、特效过程。分镜有几个镜头，提示词就逐个完整展开，不压缩成摘要。
- 平台限制不同时以平台为准。

## 结构

按这个顺序写，标题可以用自然的说法：

```text
参考素材
图片1 = <人物或场景参考>，锁定<脸、发型、服装或空间>。
音频1 = 定稿音乐<绝对起止>的<N>秒切片，本组从 0 秒开始，用于节奏<和口型>。

本组内容
<这一组在全片里讲什么或表演什么，承接上一组的哪个画面，交给下一组什么。>

音乐与演唱
<这段音乐的节奏和能量；哪些镜头演唱、唱哪几个词；其余镜头为画外音。剧情组不唱时写“人物不唱歌，只表演”。>

画面风格
<媒介、光色、材质、包装手段；本组如有上屏文字，逐字写在引号里。>

镜头
镜头1｜0–3秒｜近景，固定
<一段连续画面：人物动作、运镜、演唱、包装、最后一帧和交给下一镜的状态。>

镜头2｜3–6秒｜中景，侧跟
<……>

整体要求
<人物身份服装全程一致；画面只出现上面列出的文字，或全片无文字；生成的声音只作同步参考。>
```

## 要点

- 不合并成一句“依次完成若干镜头”或“按分镜执行”，H3 看不到分镜。
- 人物外貌写一两句关键特征（发型、服装、标志配饰），配合参考图保持一致。
- 风格名和效果名展开成画面过程，比如不写“故障风转场”，写“画面切成几条横带，一条慢半拍滑开，下一拍全部吸回，露出新场景”。
- 参考里拆出来的光、影调、质感、运动和构图，逐镜写出来，每镜都要有，不只在“画面风格”里写一次。
- 光按风格写：硬光、顶光、剪影、彩色光、特效作用在人身上都可以；只避免脸上出现不合理的发光，演唱镜头保证嘴部看得清。
- 写正向的画面描述。需要限制的东西放到“整体要求”里一句话说清，不在每个镜头里反复写“不要”。
- 风格句（媒介和质感）全片保持一致，每组一字不差地复用，避免各组画风漂移。

## 提交

- 提示词编好直接提交生成，不需要给用户审阅，也不存到画布；用户主动要看再给。
- 各组之间相互独立，同时并发提交。
- 某组失败时只重试这一组，原样复用提示词和参考；不需要单独问用户积分。响应丢了先查原任务，不重复提交。

## 示例：表演组（12 秒）

```text
参考素材
图片1 = 主唱角色卡，锁定脸、短银发、黑色短夹克和银色耳饰。
音频1 = 定稿音乐 24–36 秒的 12 秒切片，本组从 0 秒开始，用于节奏和口型。

本组内容
第一段副歌。主唱从昏暗走廊冲进有光的空间，能量从克制到释放；承接上一组她推开铁门的动作，结尾她向画右继续推进，交给下一组的侧面脚步。

音乐与演唱
强劲四拍底鼓，副歌开头一记重拍。镜头2、3、5 主唱演唱，其余为画外音。0–6 秒唱“Move with me”，6–12 秒唱“Keep it rolling”。

画面风格
高反差电影摄影，暗部压黑，冷灰走廊里一束硬质品红侧光把她半张脸切进黑暗，背景墙有黑白杂志剪影图形。重拍时墙上的剪影复制成三层错开，下一拍合回；镜头4 的立柱贴满撕开的海报。镜头3 墙上出现白色粗黑体“MOVE”，唱到这个词时贴上墙面，随后被她肩膀掠过遮住一角。

镜头
镜头1｜0–1秒｜鞋部特写，低机位固定
走廊地面一道品红光线。她的右脚压地后蹬向画右，快速出画，离地瞬间切出。

镜头2｜1–4秒｜侧前近距离全身，摄影先定后退
接住蹬地方向，她跨进品红光区，人物几乎占满画高，低重心弹一下后突然顶肩，迎向镜头唱“Move with”。重拍时身后墙上的剪影复制成三层错开。摄影先让她冲近，再后退保持距离。肩和外套仍向右摆时切出。

镜头3｜4–6秒｜正面近景，固定
肩部余势收回，她直视镜头唱“me”，嘴部清楚无遮挡，身后墙面贴上白色粗黑体“MOVE”。身体开始右倾时切出。

镜头4｜6–9秒｜侧面中景，同向跟拍
接右倾，她连续弹步向前，前景贴满海报的立柱快速掠过，人物始终清楚，画外唱“Keep it”。最后她转头看向镜头。

镜头5｜9–12秒｜前侧中近景，摄影斜向后退
接住视线，她向画右推进，从中近景逼近到近景，唱“rolling”。切出时右脚承重、身体继续右移。

整体要求
同一位主唱，脸、发型、服装全程一致，单人，肢体正常。画面中只出现“MOVE”一个词，其余地方无文字。生成的声音只作口型同步参考。高反差电影摄影，暗部压黑，冷灰与硬质品红侧光，黑白杂志剪影图形。
```

## 示例：剧情组（14 秒，人物不唱）

```text
参考素材
图片1 = 歌女角色卡（成熟版），锁定脸、发髻、月白襦裙和披帛。
图片2 = 灯楼场景图，锁定灯楼、石阶和街道方位。

本组内容
桥段，故事转折：最后一年的上元夜，她仍来到灯楼下，终于决定不再等。承接上一组人群从她身边涌过；结尾她转身走入人群，交给下一组的空石阶。

音乐与演唱
钢琴和弦乐收弱，后半段鼓点重新进入。人物不唱歌，只表演。

画面风格
电影感古装实拍，暖橙灯笼光与冷蓝夜色，薄雾，前景偶有飘过的灯笼和纱幕。

镜头
镜头1｜0–5秒｜中景，缓慢推近
她站在灯楼下的石阶旁，身边人潮流过，她手里拢着披帛，抬头看向灯楼最高处的那盏灯。摄影缓慢推近到中近景，她的视线停住。

镜头2｜5–9秒｜近景，固定
她低头，松开一直拢紧披帛的手，把衣襟自己理好，动作很慢。嘴角轻轻放松。手指离开衣襟时切出。

镜头3｜9–14秒｜中景转全景，摄影升起后退
她转身走下石阶，汇入人群，纱幕从前景擦过；摄影缓缓升起后退，她的背影在人群里越来越小，灯楼留在画面上方。最后一帧是灯楼和空出的石阶。

整体要求
同一位歌女，脸、发型、服装全程一致；画面无文字。电影感古装实拍，暖橙灯笼光与冷蓝夜色。
```
