# 从参考和要求里定风格

用户给的参考图、参考视频和风格描述，是这部 MV 的美学依据，比本 Skill 里任何一般建议都优先。一般建议（景别、光线、口型、连续性）只用来保证片子成立，不能用来把用户要的风格改得更保守、更平均、更写实。

最常见的失败是：看过参考，从里面摘了几个元素（“黑白”“蓝色”“群像”），然后拍成一个干净的棚拍或写实场景，参考里真正有冲击力的东西（光、质感、运动、构图、特效作用在人身上的方式）全被冲淡了。

## 用户只给了名字时，先去找参考

用户说“像某部电影”“某个导演/歌手/MV 的风格”“某个时代或流派的感觉”，却没给图时，凭记忆写的风格往往空泛又不准。先找真实画面：

- 能搜图时，直接搜。作品名用英文或原名，加上画面维度，如 `All About Lily Chou film stills`、`Shunji Iwai rice field green`、`Daido Moriyama street photography`，从剧照、截图、同类摄影几个角度各搜一次。
- 有网页搜索时，查一下作品的摄影、调色、拍摄方式、配乐风格，补充画面之外的知识。
- 搜到的图就是参考：按下面的表逐项拆，挑几张作为生成图像和视频时的风格参考图，拆出来的规格写进每一镜。
- 没有任何搜索工具时，请用户发几张截图或参考，同时说明你目前对这个风格的理解，用户可以直接纠正。不要凭记忆写成“已参考原片”。

参考的是影调、光、质感、构图和氛围，不复刻原作的具体镜头、人物或剧情。

## 先把参考拆成看得见的规格

每张参考图、每段参考视频都看完，逐项写下它在画面上具体是什么，而不是它“是什么风格”：

| 维度 | 要写清楚的东西 |
|---|---|
| 影调与曝光 | 整体偏暗还是偏亮，暗部压到多黑，高光是否溢出，反差多大 |
| 光 | 光从哪来、几盏、多硬、什么颜色；人物是被照亮、半张脸在黑里、剪影，还是逆光勾边 |
| 色彩 | 主色和点缀色，饱和度，黑白还是单色调，色彩是否只出现在某个物体或某个段落 |
| 质感 | 胶片颗粒、噪点、柔焦、光晕、雾、水汽、低清、印刷网点等成像质感 |
| 运动与时间 | 慢门拖影、残影、抽帧、变速、手持晃动、静止；运动是在人身上、在人群里还是在摄影机上 |
| 构图与机位 | 主体在画面里多大、在哪；仰、俯、倾斜、微距、对称、大面积留空；前景遮挡 |
| 人和特效的关系 | 特效是否直接作用在人身上（脸被拉成条、身体碎成粒子、皮肤变成别的材质），还是只在背景 |
| 画面点子 | 参考里让人记住的那个具体画面：一个反常的物体、处境、装置或人群形态 |

参考视频还要看：切镜有多快，对口型的镜头占多少，大部分时间画面在做什么。

## 把规格原样落到每一镜

- 拆出来的规格写进全片的风格设定，再落到每一组、每一镜的提示词里：这一镜的光怎么打、暗部多黑、颗粒多重、拖影在哪、机位多极端，逐项写出来。只写一次风格总述，后面的镜头会退回平均画面。
- 用参考的原话强度写，不打折。参考是暗到看不清脸的剪影，就写剪影；参考是人物被拖影包裹，就让拖影作用在人物身上；参考是浓重颗粒，就写浓重颗粒。
- 多张参考时，分清哪张管人物、哪张管光色、哪张管构图或运动，各自落到对应的镜头上；可以按段落分配，让不同参考主导不同段落，形成变化。
- 风格收尾句从参考里提炼，写参考真实的媒介和质感，比如“高反差黑白胶片摄影，浓重颗粒，慢门拖影”。不默认写“写实真人电影摄影，自然皮肤质感”，除非参考或用户要的就是这种。
- 参考里的人物长相、Logo、文字和具体作品的镜头顺序不照搬；照搬的是影调、光、质感、运动和构图方式。

## 用户只说了美学方向时

用户说“先锋”“艺术感”“迷幻”“冲击力”“炸裂”“有美学”这类词，但没给足参考时，这些词要落到具体的手段上，否则就会拍成普通的写实片：

- **每组先想一个画面点子。** 一个具体、反常、能被记住的画面：人物被几十根绳子吊在半空、人海里伸出上百只手、巨型物体出现在不该出现的地方、人站在一片纯色空间里、身体被光或材质改造。先有点子，再排镜头。只有“人站在场景里唱”不算点子。
- **光要有态度。** 硬光、顶光、单一强逆光、剪影、彩色光、大面积暗部。自然柔光是一种选择，不是默认。
- **特效可以直接作用在人身上。** 脸和身体被拉伸、碎裂、拖影、扫描、换材质、复制分身，都是这类 MV 的核心手段。只有在演唱镜头的嘴部需要看清时，才让嘴部这一小块保持清楚。
- **机位和构图要极端。** 微距、极低仰拍、正顶俯拍、倾斜、超广角贴脸、大面积留空的小人物。
- **对口型只是其中一部分。** 正对镜头演唱的镜头够用就行，大部分时间让画面点子、光、特效和人群在表演。

## 提交前对一遍

把每组提示词和参考规格表并排看：参考里最有冲击力的两三个特征，在这一组里有没有清楚出现？有没有哪句一般性的要求（自然光、写实质感、背景干净、正脸演唱）把它冲淡了？冲淡了就以参考为准改回来。

也看一下自己加的限制：用户只提了一个局部问题（比如脸色太灰、某个镜头太暗），修正只落在那一处，不在每一镜里反复强调，更不变成压住整体风格的总规则。像“特效不作用在人身上”“闪光要少”“动作要小”这类用户没要求的保守限制，删掉。
