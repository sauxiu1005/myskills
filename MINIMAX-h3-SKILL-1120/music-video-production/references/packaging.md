# 包装

包装是 MV 的风格层：光色、成像质感、图形、纸片、粒子、特效、转场，偶尔加一点上屏文字。它服务人物和音乐，让画面有记忆点。

## 怎么定风格

1. 用户指定的风格、参考图、参考视频最优先。先按 [从参考和要求里定风格](style-from-references.md) 把参考逐项拆成看得见的规格，再原样落到镜头上，不打折、不被一般建议冲淡。
2. 没有指定时，从音乐（曲风、能量、声线）和内容推导，从下面的风格速查里选一个主风格打底，再借一两个手段点缀。
3. 把风格写成画面上看得见的东西：用什么成像、什么光色、什么材质、什么图形、怎么转场。只写“赛博朋克”“拼贴风”，模型会给出很平均的结果。
4. 全片风格统一，随段落升级：主歌克制，副歌放开，桥段换一种状态，结尾回收。

## 风格要落在镜头和剪辑上

只把风格写成环境光和形容词，画面会很平均。一种风格能被看见，靠的是它在镜头、剪辑和转场上的表现。任何风格都可以从同样几个问题推出来：

- **它的材料是什么。** 这种风格的画面由什么构成：一种介质、一种质感、一类物件或一种成像方式。
- **这种材料怎么动。** 它会怎样出现、生长、扩散、碎裂、变形、消失。把这种运动做成镜头里的特效事件，并在重拍或段落变化时发生。
- **镜头和剪辑怎么动。** 这种风格的运镜速度、切镜频率、变速、闪切和停顿是什么样，和音乐的速度、律动对应起来。
- **它怎么连接两个空间。** 用风格自己的材料完成转场：上一组最后一镜由这种材料接管画面，下一组第一镜从它里面显出新空间，两边各写一半，后期接上。

全片按段落升级：前段建立风格的材料和动作，副歌放大尺度和频率，桥段换一种状态，结尾回收。具体有哪些材料和手段，查下面的风格速查和效果列表，或从用户给的参考里提炼。

## 包装以图形和特效为主

- 包装主要靠图形、形状、纸片、贴纸、光、粒子、色块、转场和成像质感，放在人物周围、背景或前景，跟着拍子出现和变化。
- 包装落在空间里会更有质感：贴在墙上、投在身上、从道具里长出来、被人物推开。平面图形直接压在画面上也可以，拼贴、zine、Y2K 界面本来就是平面的。
- 特效也可以直接作用在人物身上：脸和身体被拉伸、碎裂、拖影、扫描、换材质、复制分身，这是先锋和 VFX 类 MV 的核心手段。演唱镜头里保证嘴部看得清即可。

## 文字是设计，不是字幕

上屏文字（歌词、片名、关键词）是包装的一部分，要像平面设计一样做，跟画面同一套审美。默认字体的白字压在底部或正中，是最常见的“朴素”来源。

**有歌词的歌，成片默认带歌词。** 用户没说不要，就安排上屏文字；分镜和方案阶段就决定好字用视频生成还是后期加、风格和位置，不要到最后才想起来或干脆漏掉。纯音乐、用户明确不要字时才不做。

**先从主题定文字的性格**，和定画面风格一样逐项想：

- **字形**：粗黑、窄长、衬线、手写、毛笔、像素、等宽、描边空心、变形拉伸、碎裂、手绘涂鸦。
- **材质**：霓虹灯管、金属、铬、液体、玻璃、纸片剪贴、印刷网点、喷漆、刺绣、烫金、火焰、扫描线、LED 点阵。
- **排版**：大字占满半屏、竖排、斜置、贴边出血、逐字错位、叠层重复、和画面里的线条或物体对齐、包在人物周围。
- **动效**：随重拍砸入弹开、逐字跳出、打字机、抖动、故障撕裂、拉伸、扫光、溶解、跟随运镜移动。每一句都要有动效，不只是大字；小字只是排上去、淡入淡出，就会显得像字幕。
- **主次**：普通句也要设计，只是比 Hook 克制；Hook 和关键词做成大号花字，在重拍上出现。高能段可以大字主句加小字副词条同屏，用大小、颜色、角度形成对比。
- **酷不酷**：风格要求“炫酷”“有冲击力”时，字本身就要是画面的主角之一：大、粗、有材质（铬、霓虹、喷漆、故障），占画面相当比例，跟着拍子动。小字加阴影不算炫酷。

可以借的方向（不是固定配方，按主题自己定）：古风用书法字、竖排、印章、宣纸和墨晕；说唱用粗黑大字压画面、贴纸和涂鸦、逐字砸入；电子和 VJ 用 LED 点阵、扫描线、故障、频闪跳字；Y2K 用铬金属立体字、泡泡字、界面窗口和像素；抒情用细字、低对比、大面积留白；日系青春用手写、日文假名与汉字混排、胶片边。

**做法：**

- **在视频里直接生成文字（大屏、VJ、歌词视觉型首选）。** 文字是画面主体、要和画面里的光、材质、空间一起动的时候（字变成隧道、霓虹灯管点亮成字、字被液体冲碎、字在 LED 屏上扫描出现、镜头从字腔穿过），把它写进视频提示词让模型生成，比后期叠出来的字更有冲击力、更融入画面。写法：原文逐字放在引号里，每个镜头一两个短词或一句短句，写清字形、材质、大小、位置和怎么动（从哪出现、怎么变、怎么消失）。生成的字偶尔会错，抽帧检查，错了重生成这一组。选了这种做法，文字就全部交给视频生成，后期不再加字幕、花字或任何文字层。
- **花字图层。** 用图像模型把关键字、片名、Hook 做成带透明底的花字图（写清字形、材质、颜色、光效，逐字给出原文），后期用 ffmpeg `overlay` 叠到画面上，配合缩放、位移、闪现卡拍。系统字体做不出材质和造型，这类字值得单独做。
- **ASS 字幕（数量多的歌词）。** 字体、颜色、描边、阴影、位置、逐字动效都按上面的性格设计，做法见 [后期包装](post-production.md)。
- 视频生成文字和后期加字二选一，不叠在一起。后期加字时，花字做 Hook、ASS 做普通句可以混用。
- 无论哪种，做完抽帧看：字有没有设计感、和画面是否同一风格、有没有错字、有没有压脸、画面颜色有没有被叠层改变。像普通视频字幕，就重做。

## 能量跟着音乐走

包装的强度跟随音乐能量和速度。安静段落可以只有光色和质感；能量高、速度快的段落放开：切镜更密、运镜更猛、特效更频繁，强镜头卡在重拍上。高能段的切镜密度见 [分镜](storyboard.md) 的镜头密度表，按拍子切，不要因为每镜想写得丰富就把镜头拉长。生成时写进提示词的是画面里的事件；卡在拍点上的闪白、冲推、色差和转场在后期用 ffmpeg 叠加最准。

全屏整片闪白每秒三次以内，这只是照顾光敏观众的频率上限，管的是整屏强闪；切镜、局部闪光、跳字、图形和特效的频率不受它限制，不要把它当成“闪光要稀疏、节奏要慢”。

舞台大屏、夜店 VJ、Livehouse 歌词屏、产品道具展示、动态字体、3D 抽象循环、二次元特效等视觉模式的知识，见 [视觉模式](visual-modes.md)。

## 写进提示词的样子

把每个包装事件写成看得见的过程：什么触发 → 出现什么 → 和人物或空间怎么互动 → 怎么退出或交给下一镜。

> 军鼓落下时，墙上的海报被从中间撕开，露出后面红黑两色的人物剪影，剪影复制成三层向右错开，下一拍合回一层；人物从剪影前走过，撕开的纸边被风掀起，盖住镜头，揭开时已是下一镜的舞台。

> drop 第一拍画面白闪，接着激光从舞台中心向外炸开扫过烟雾，人群剪影齐举双手，镜头沿光束高速前冲，“JUMP”三个字母随底鼓逐拍砸进画面中央又弹开。

## 风格速查

下面是常用风格和效果的词汇，用来构思和写提示词。可以组合，也可以不用。格式：名称｜关键画面元素｜包装手段｜适合的音乐和情绪。

### 风格

#### 主媒介底盘
- **电影感真人实拍**｜真实皮肤与发丝、浅景深与柔和焦外｜图形、纸面、光效叠在实拍外层或作用在人物身上；光可以自然也可以硬、暗、有色，按参考定｜几乎所有曲风，适合表演、叙事、时尚片
- **电影级实时 CG（UE 质感）**｜PBR 材质、物理光照、体积雾、可信的空间尺度｜舞台装置、超现实世界、立体字作为空间构件，环绕镜头揭示尺度｜史诗电子、科幻和奇幻概念、大型舞台
- **日系动画电影**｜干净线稿、赛璐璐平涂阴影、分层背景美术、天空和云的光色、夏日逆光、城市黄昏｜天气和时间推进情绪，背景随情绪换天光，风、花瓣、光斑作为二维特效，十字路口、电车、天台这类场景｜J-pop、动画歌、青春抒情、情感叙事

#### 印刷与拼贴
- **杂志拼贴 / zine**｜平面剪纸图形：人物剪影复制后错位分层，形成分身；半调网点、条码和票据、接触印三联格、红色油墨遮挡条、套印偏移抖动、印刷定位标记、复印颗粒、胶带与毛边；杂志封面和翻页；配色三色以内（墨黑、纸白加一个专色）｜纸片在重拍上贴入或撕开，剪影分身随节拍错位，网点扫描经过背景，翻页转场，红条扫过遮住画面再揭开；可接打歌舞台的 LED 光框、T 台和聚光灯，让纸面与舞台互相接管｜rock、punk、说唱、indie、态度型 pop、dance-pop，适合律动硬、Hook 有冲击力的歌
- **街头大字报 / 印刷实验**｜警示红或工业黄配墨黑，斜栏、粗边阴影；或者双色专色、瑞士网格、丝网墨层｜字块和色块压进画面，套印先错开再对齐，纸边翻面接到下一栏｜宣言型副歌、hardcore、art-pop、post-punk
- **暗黑杂志**｜炭黑空间、脏白纸面、深红强调、锐利衬线字标｜硬切、跳切、红色扫描边短暂横错后恢复，最后落成杂志封面构图｜dark-pop、trap、cyber-grunge
- **Fashion 编辑拼贴**｜照片缝、带白边和接触影的剪纸贴片、胶带角、粗框｜甩袖或转身划开纸缝，人物停下时纸在动、人物动时字块不动｜dance-pop、时尚单曲、走位表演
- **超现实意象拼贴**｜报刊影像、抽象色面，有含义的尺度错位｜纸缝、相似轮廓或重复动作把不连续的空间连起来，比如地图线延伸成窗框｜art-pop、实验音乐、歌词意象跳跃的歌

#### 可爱与手绘
- **糖果梦境**｜巨型甜品、软雕塑、毛绒、果冻、透明糖纸、充气塑料；奶油白、泡泡糖粉、薄荷、柠檬黄，用深可可色勾轮廓；云海、小船、甜品城｜按压后变扁回弹，泡泡从果冻里鼓出，drop 时拉远镜头揭出身边的巨物，倒影下潜后转到下一场景，贴纸和糖珠做短促爆点｜K-pop、bubblegum pop、梦幻 pop、俏皮情歌
- **手绘涂鸦实拍**｜蜡笔、粉笔、马克笔线沿真实轮廓逐笔生长，带接触阴影；小漫画分格、小角色、旅行手账式相片｜线条绕过道具后变成边框，边框变成纸卡，纸卡色面再成为下一镜的遮罩；pluck、clap 时添一笔｜lo-fi、校园、旅行、卧室流行、轻快 pop
- **怪趣块面**｜紫黄或钴蓝配珊瑚，圆角和短尖角并置的超粗字块｜手势停点时块面轻轻横拉后回位，块边的小涂鸦长成下一框｜幽默、反差萌、口号式副歌

#### 舞台、光与现场
- **韩流打歌舞台**｜主舞台、升降台、LED 主屏和地屏、镜面地面、光束、彩带；整齐队形和服装惯性｜副歌时灯扫全场打开，俯视网格里的队形落位，走镜面通道，冲镜头后跪滑起身，切点放在 killing part，舞台轮廓光换成高潮专色｜K-pop、dance-pop、偶像群舞
- **Club / DJ / VJ 夜店大屏**｜频闪、激光扫过薄雾、烟雾、LED 网格墙、人群举手剪影、DJ 台上的唱盘和推子、高饱和霓虹｜跟着拍子频闪，激光在 build 时收拢、drop 时炸开，镜头穿越隧道，万花筒式对称，VJ 素材铺满大屏，人群剪影随底鼓起伏｜house、techno、EDM、电子 drop、派对歌
- **Livehouse 动态歌词屏**｜小场地的暖钨丝灯和烟雾、后墙 LED 屏、近处观众的后脑和手机光、手持摄影｜屏上歌词跟着唱逐词点亮，主唱剪影投在字前，副歌时全场灯亮起，镜头扫过人群｜indie、乐队现场、独立流行、合唱型副歌
- **乐队 / 摇滚表演**｜排练室、后台通道、俱乐部舞台，乐器特写，夹插高反差黑白镜头｜鼓手一记重击后灯牌整排炸亮，光冲进下一空间，甩琴动作接动作匹配切｜rock、乐队编制、吉他和鼓驱动的歌
- **投影 / 感官舞台**｜深色基底，投影纹理落在身体和后墙上，轮廓光、镜面双像｜地屏纹理向外扩散后爬上身体，副歌时主屏亮起，人物剪影落在图形中心｜电子、R&B、氛围音乐、渐强型 build
- **透明材料剧场**｜冷灰玻璃、薄膜、磨砂面、一处青色或品红折射、焦散｜光扫过后穿透字腔投到后墙，玻璃竖边接下一镜｜冷静电子、art-pop、极简 R&B

#### 年代与复古
- **Y2K / 千禧**｜低清 DV 质感、4:3 画框、直闪、鱼眼；翻盖机、MP3、像素 UI 窗口、早期网页弹窗、贴纸、亮片、贴钻；粉色和银色、铬银、果冻 PVC；主体清楚锐利，低清味来自画框、颗粒和插入镜头｜窗口逐级弹出后扩满全屏进入表演，光标点开相册，椭圆轨道和四角星芒，snare 时直闪定格成杂志拼页，亮片在 hi-hat 上闪｜千禧 pop、2-step、UK garage、R&B、hip-hop
- **胶片复古**｜35mm 颗粒、蓝灰阴影配暖橙高光、带色的黑位、轻暗角、片框和过片呼吸、漏光、划痕｜漏光从画边擦过，回忆段片框露出，烧灼边做遮罩转场，闪回时过曝成白｜indie、folk、lo-fi、青春与回忆
- **港风暖复古**｜橙黄暖调、霓虹倒影、车窗、窄标题、慢快门拖影｜反光沿车窗滑动，用抽帧印片（step-printing）拍人群｜粤语流行、复古情歌、城市夜色
- **CRT / 像素游戏**｜旧电视、掌机、扫描线、磷光绿、像素块｜从屏幕穿入，像素溢出铺满房间，回到现实后还留着一块像素色｜chiptune、合成器流行、童年和游戏题材
- **蒸汽波**｜粉紫到青绿的渐变、低清扫描、浮动窗口、重复透视面｜窗口缓慢侧移，扫描带经过时留下延迟副影｜vaporwave、city pop、慢速电子

#### 地域与街头
- **古风水墨**｜宣纸肌理、浓淡墨晕、留白山水、竹影、雾、朱砂印章、绢和纱的飘带；墨、纸、朱红、石青｜墨滴入水后晕开转场，笔势扫出的线变成山脊或河岸，卷轴展开，印章落下定格，纱幕前景擦接，花瓣或墨点随风飘走｜国风、古风、民乐融合、东方抒情
- **嘻哈街头**｜涂鸦墙、铁丝网、篮球场、地下通道、车灯、金链和宽松衣着、鱼眼低机位｜喷漆字与 stencil 印在墙上，贴纸炸弹，snare 时硬闪，鱼眼贴脸，人群和车辆前景擦接，套印错位｜hip-hop、trap、drill、说唱快段

#### 数字与未来
- **赛博霓虹**｜紫粉和电青发光面、湿地面倒影、玻璃与金属、局部 bloom、窄巷招牌｜灯管逐段点亮，扫描条经过时局部错位，反光沿着边缘移动，背景条带出现局部故障｜darksynth、电子、trap、夜色城市
- **故障信号切片**｜纯黑、电子白加一个信号色、栅格、扫描带｜画面切成窄条，其中一条慢半拍，drop 时全部吸附回位，时间切片｜glitch、IDM、hyperpop、drop 前后
- **机器视觉追踪**｜低饱和底片，上面叠大小错开的纯色空心框和节点连线｜框锁住手腕、鞋尖等身体局部，重拍时替换小框，被遮挡时消隐｜techno、舞蹈 MV、AI 和监控题材
- **精密科技粒子**｜冷白、深墨加一种能量色，细网格、冷光板、机械光阑｜光线从指尖沿着手臂聚成形状，停稳成实心后原路收回｜techno、minimal、build-up
- **冷亮未来铬银**｜冷白、钴蓝、铬银，蓝玻璃有厚度，液态金属｜延音时金属横向拉长，落拍时收回，留下的银边成为地平线｜future pop、hyperpop、清亮电子

#### 电影、叙事与心理
- **线性叙事 / 青春记忆**｜逆光、窗帘、风、空教室、站台、旧物件｜靠物件和声音桥触发闪回，曝光呼吸，母题物件在不同段落改变含义｜叙事抒情、民谣、青春、失去主题
- **室内表演概念**｜可信的房间，加照片、线缆、CRT、投影等母题｜母题状态随段落改变，光从冷蓝转成暖橙｜R&B、唱作人
- **时间折叠 / 心理空间**｜同一空间的不同状态、反向动作、冷暖突变｜推拉变焦（dolly zoom），重复镜头每次换含义，水倒流｜Bridge、心理题材、实验 pop
- **时尚电影强光学**｜镜面柱、硬闪、强背光、halation、棱镜、雨雾水幕｜穿过镜面后换装，用 step-printing 表现顿挫，棱镜色散擦过｜时尚单曲、R&B、art-pop
- **高反差黑白**｜纯黑白层级，逆光轮廓｜鼓点停住的一拍掉成黑白，颜色再从一件道具开始回到画面｜后朋克、硬核、严肃抒情
- **末日废土冷调**｜蓝绿冷调、强颗粒、锈蚀表面、风沙｜光从裂缝推进，锈片随鼓声剥落后露出天空｜工业、metal、史诗电子

#### 超现实与迷幻
- **迷幻变形 / 流体**｜线稿生长、喷枪渐变、液态、凝胶、虹彩、镜像｜手掌轮廓长成花，花心又变成舞台圆灯；慢门副影跟在人物后面｜psych rock、shoegaze、dream pop
- **写实异象**｜写实世界里的一条异常法则：影子立起、悬浮水体、巨物｜先让影子和焦散动起来，再揭示全貌，后续段落扩大同一法则的尺度｜概念 MV、独立音乐、冷幽默
- **轻邪典蛊惑**｜墨黑、冷银、酒红，黑漆反光，尖刺衬线｜镜中轮廓慢半拍才合回，字从暗处的反射里显出｜dark R&B、witch house

#### 极简、编辑与手工
- **极简材质空间**｜主色加一种材料色、留白、墙地交线、光带｜一次尺度变化就是事件，光边沿着线条收束｜ballad、钢琴、氛围音乐
- **清透诗性 / 浪漫先锋**｜自然漫射光、薄纸纤维、肤色和酒红、烧灼纸边｜细线沿袖口延伸成下划线，照片副层错开后再贴合｜民谣、唱作人、脆弱主题的 R&B
- **奢感编辑**｜纸白墨黑配酒红或暖金属灰，高反差衬线，大面积留白｜细笔显出后填实，一道光擦过把画面带走｜时尚、jazz、neo-soul
- **冷峻工业**｜混凝土、炭黑、金属、警示橙、硬光｜墙板沿竖缝随 kick 错开，旋转后止动，切口亮起｜industrial、techno、EBM
- **日记档案 / 手工微缩**｜暖纸、铅笔、旧照片、胶痕；纸板、木片、浅景深｜铅笔线翻页后接到下一张照片，模型逐个立起，镜头钻进门洞后变成真实尺度｜回忆、亲情、童话感民谣

### 包装效果与转场

格式：名称：画面上能看到什么｜适合用在音乐的哪里

- 形状匹配：杯口切到圆门，唱片切到隧道口，运动方向延续｜所有切点，尤其段落交界
- 字腔 / 形状入口：推镜穿过圆孔、门洞或字腔，进入下一空间｜Hook 进入、主歌转副歌
- 动作匹配：转身到一半切换空间，在下一镜完成同一个动作｜舞段、跑动、乐队重击
- 前景擦接：公交、人群、门板、纸页擦满画面，退出时已经换景｜快节奏段、城市叙事
- 撕纸揭开：照片沿斜线被撕开，露出下一镜，胶带拉直后变成画框｜扫弦、鼓击、主副歌交界
- 墨晕 / 墨渗：墨滴落到纸上或水里晕开，铺满后变成下一画面｜长音、国风段落转换
- 纸片贴入 / 翻页：纸片卷角进入后压平，或整页翻过换景｜snare、句首
- 剪影分身错位：同一人物剪影复制成多层并错开，随节拍再合回｜重复歌词、Hook 回声
- 半调网点扫描：扫描边掠过背景，照片变成粗网点后恢复｜kick、硬切节拍
- 套印偏移：专色层朝动作方向偏开，下一拍贴回原位｜808、snare、急停动作
- 丝网刮印：刮刀刮过，专色油墨盖住半个画面｜副歌前一拍
- 非规则分栏 / 分屏：斜面板依次落位，其中一块扩满全屏｜说唱快段、多人轮唱、对唱
- 镜像 / 万花筒对称：画面对折或旋转成对称图案｜drop、器乐段、Club 段
- 镜面通道：两侧反射无限延展，镜头跟着人物走进去｜Hook 前的上行音阶
- 频闪卡拍：随拍黑白闪断，动作被切成定格｜四拍底鼓、drop
- 激光收放：光束在 build 时收向中心，drop 时向外炸开｜军鼓滚奏到 drop
- 灯扫与 LED 点亮：光束扫向全场，地屏一格格亮起｜副歌第一拍
- 霓虹逐段点亮：灯管一节节亮起，光色交给下一镜｜副歌进入、推门时
- 粒子聚散：尘、纸屑、光点从来源升起聚成形状，读清后落回原处｜pad 渐强、高潮释放
- 投影上身：图形随衣褶起伏，人物走开后在墙上重新组合｜慢拍、现代舞段
- 甩镜（whip pan）：急速横甩带动模糊，落到新画面｜重音、段落跳转
- 变速（speed ramp）：动作先拉慢，在重拍上猛然加速｜drop、甩发、跳跃落点
- 时间切片 / 冻结：一条画片停住，drop 时追上主画面｜drop 前的空拍
- 多重曝光残影：旋转时拖出副像，落定时合回｜长音、旋转舞段
- step-printing：低帧顿挫拖影，帧率恢复时人物落稳｜迷离段、夜生活
- 闪回过曝：画面白场后进入回忆，再以白场返回｜记忆触发、副歌转折
- 漏光 / 烧灼边：暖光擦过画边，烧穿处露出下一镜｜停顿、Bridge 前
- 局部故障：一条窄带横向错位并偏出色边，扫过后恢复｜808、短促瞬态
- 窗口级联：弹窗逐级展开，主窗口扩满后进入表演｜主歌逐句、Y2K 段
- 像素溢出：像素从屏幕铺到实景｜Break、切分鼓
- 直闪鱼眼：一帧过曝定格，鱼眼贴近人物｜snare、拍手
- 玻璃折射擦过：磨砂玻璃滑过镜头，竖边接下一镜的门框｜长元音
- 光色 / 蒸汽介质接力：蒸汽、雾、水膜遮满后换景｜合成器渐强
- 碎片重组：海报碎成网格后重新对齐，变成屏幕｜drop、心理断裂
- 平面抬起：纸上的图形立成薄片后再压回｜kick 上的小事件
- 关系线：细线从一人手边爬到另一人｜对唱交接、合唱
- 巨物尺度揭示：急速拉远，看出人物坐在巨物上｜bass、drop
- 隧道穿越：沿 LED 或灯环隧道高速前冲｜build 末段、drop 进入

### 字体气质（需要文字时）

- 粗黑体压字：超粗方黑整块压在人物身后的纸面或墙面，适合说唱 Hook 和拼贴冲击。
- 手写涂鸦：马克笔或蜡笔线从发梢、道具甩出并写成短词，适合青春、Vlog、生活感的歌。
- 像素字：点阵字在掌机或 CRT 窗口里逐块点亮，适合 Y2K 和 chiptune。
- 霓虹灯管字：实体灯管逐笔点亮，光落在墙面和湿地面上，适合夜色和赛博风格。
- 印刷剪字：报刊剪下的字块拼贴成词，套印微微错开，适合 zine 和杂志拼贴。
- 书法：一笔浓墨扫出单字，带飞白，末笔拖成画面线条，适合国风和抒情爆发。
