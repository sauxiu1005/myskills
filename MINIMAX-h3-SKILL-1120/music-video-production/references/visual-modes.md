# MV 视觉包装模式

知识参考，供按歌曲情绪与结构挑选。提示词可按 空间/载体 → 主体 → 运动 → 镜头 → 光色 → 质感 → 节奏 组织；具体名词 + 物理动词 + 光源颜色有效，“很炫”“高级感”几乎无效。卡拍闪白、歌词字幕与转场的后期做法见 [后期包装](post-production.md)。

## 通用概念

- **黑 = 关掉的像素**：LED 上黑色不发光，大面积黑作负空间，图形像悬浮在空气中、屏幕边框消失。黑底 + 少量高亮图形比满屏彩色更有舞台感，也便于后期叠加（黑底素材用 screen 叠加时黑色自动消失，前提是在 RGB 里混合，见 [后期包装](post-production.md)）。
- **分层视差**：前层透明屏/纱幕放稀疏线条、粒子，后层实心大屏放细节，表演者站在两层之间，两层速度不同产生全息悬浮感（Eric Prydz HOLO）。
- **IMAG**：大屏放大现场机位画面，每首歌叠一层不同实时特效“换皮”：棱镜彩虹拖影、动作生成粒子、线框描边、像素马赛克、热成像、时间切片多重曝光（Coldplay《Music of the Spheres》）。
- **Hero shot 与起伏**：每首歌一两个构图最强、最有主题性的画面放在高潮，其余段落为它铺垫；峰值分散，避免全程同一强度。一首歌像一整场演出：前奏一种元素，每段加一层，尾声逐层撤掉；可设一个贯穿全片的视觉签名（呼吸的细光框、同一种金色尘埃）。
- **节奏换算**：一拍 = 60/BPM 秒，4/4 一小节 = 240/BPM 秒（128 BPM 一小节 ≈ 1.875 秒，90 BPM ≈ 2.67 秒）。闪白 1–3 帧，冲击帧约 2 帧最脆。
- **光的写法**：写光源、颜色、烟雾中的光束、物体表面反光。

## 风格落在镜头事件上

以下每种模式的“运动”和“镜头”部分，就是这种模式在镜头和剪辑上的表现。写提示词时把它们写成具体的镜头事件，卡在音乐的重拍和段落变化上；组与组之间的转场用这种模式自己的材料（光、屏幕、粒子、图形）来做。

## 1. 舞台 / 演唱会大屏

**构成**：一块屏不是一张画。中央超宽主屏、侧屏/塔屏（光柱、瀑布、上升字幕流）、LED 地屏（光圈从脚下扩散、地面裂开）、异形/机械屏（圆形门洞、滑动圆盘如日食）。写清屏的形状、分块、位置和各自在放什么。
**母题**：粒子聚散成形、几何隧道、液态铬、烟雾中的激光扇面与光柱、屏幕尺度的巨型角色/图腾、云海极光等自然奇观、占满整屏的超大单词。
**运动**：对称镜像展开、亮线扫描擦除、整屏随底鼓呼吸、网格追光、隧道推进、揭幕（黑屏 → 一条缝 → 光溢出 → 巨物出现）、段落换“世界观”（Eras Tour 按专辑时代换色彩性格）、整面屏变纯色光源把舞台和人群染成一色。
**镜头**：观众席后方超广角（剪影手臂、荧光棒海）、侧面低机位仰拍、无人机掠过人群穿过激光、推近到屏框出画进入屏内世界。
**光色**：黑底 + 一个主色 + 一个强调色（深蓝/冰白、黑/熔岩橙、黑/品红青）；铬银迪斯科超色彩；钨丝暖黄胶片。
**案例**：Beyoncé《Renaissance》（圆形门洞与滑动视频圆盘）；Anyma《Genesys》在 Sphere，机械人形一拳打破球幕探身而出。

> 夜晚体育场，从观众席最后排高处俯瞰，前景是举起的手臂剪影和摇动的荧光棒海。舞台后方一块极宽的弧形 LED 主屏，两侧各三根细长竖向塔屏，舞台地面也是 LED。前奏时所有屏几乎全黑，只有主屏中央一条细细的金色水平光线随底鼓微微呼吸；预副歌里光线逐渐变亮变粗，薄雾中几道白色光柱缓慢抬起。副歌第一拍落下，光线从中央向左右对称炸开，化作金色粒子流沿塔屏向上冲去，在主屏上汇聚成一只展翅凤凰轮廓，翅膀从主屏延伸到两侧塔屏；同时二十多道白色光束在薄雾中扇形张开、随每小节摆动，金色纸屑飘落。镜头缓慢前推带轻微手持晃动，现场直播质感，深黑背景中只有金色与暖白。

## 2. Club / DJ / VJ / 电音节

**文化**：VJ 跟着 DJ 实时混合视频循环；Beeple 式 C4D 抽象科幻，也有朋克海报拼贴、卡通刺击帧的低保真路线。
**分流派词汇**：Techno 黑白工业、混凝土、单色红/绿激光、扫描线、故障；House/Disco 迪斯科球反光、暖粉紫、VHS；Melodic Techno 黑底冷白、巨型雕塑人形、慢速宏大；Bass/Dubstep 撕裂、像素崩坏、强 RGB 分离。
**能量曲线**：Build-up 隧道加速、频闪间隔缩短、画面收窄成一点、亮度抬升；Drop 前静默一拍全黑，随后全屏爆发、元素从中心外冲；Breakdown 慢、宽、单色、粒子漂浮。频闪按 1/4 或 1/8 拍；Loop 思维，周期运动首尾相接。
**观感要强烈**：VJ 和电子 MV 的 drop 和副歌，观众要的是感官冲击：画面整片大变化而不是局部小变化。每个高能镜头都写一个大事件，比如整个空间瞬间翻成另一种颜色、所有光源同时炸亮、画面被光完全吞没再从黑里炸回来、镜头以极高速度冲过激光隧道、主体被复制成一片阵列、几何图形撑满整屏旋转。相邻镜头换色、换尺度、换方向，形成强对比；一个高能段里同一画面不超过一两拍。后期再叠卡拍的冲推、色差、反相、闪白和色相翻转，做法见 [后期包装](post-production.md)。
**镜头**：DJ 台背后拍向人群并反打大屏、贴地低机位看光束扫过头顶、俯拍人群被激光网覆盖。
**案例**：Tomorrowland 2023《Adscendo》巨鹰主舞台；Eric Prydz HOLO 前层透明幕上漂浮的 DNA 双螺旋。

> 废弃混凝土仓库改成的地下夜店，空间弥漫浓重白色烟雾。舞池尽头整面墙是低分辨率 LED 点阵屏，只有黑白两色：一条水平白线随底鼓上下跳动，每到第四拍整面屏翻成纯白再瞬间回黑。钢梁上一排单色红激光在烟雾中切出锋利平面，缓慢从左向右扫过舞池上方。Build-up 中白线跳动越来越密，激光扫动加速，屏幕边缘逐渐变暗收拢成中央一个亮点；Drop 前一拍全场漆黑无声，随后整面屏与所有激光同时亮起，红色光片在烟雾里炸成放射状扇面，人群剪影同时跃起。镜头从舞池中央低机位缓慢推向 DJ 台，粗颗粒，只有黑、白、红三色，冷硬、重复、催眠。

## 3. Livehouse / 乐队现场与歌词屏

**气质**：近、糙、热。低舞台、观众贴台、灯少而硬、烟雾浓、手持。
**歌词屏做法**：后墙投影一行巨大白色歌词、乐手的影子遮住几个字；打字机逐字打出带闪烁光标（民谣/独立）；复印海报、胶带、手写涂鸦质感（朋克/后朋克）；大合唱段只放一句超大字。
**词汇**：PAR 灯硬色块（红、琥珀、钴蓝）、逆光剪影、鼓棒溅汗、音箱墙、投影光束里的灰尘、stage dive、16mm 颗粒、过曝。
**案例**：早期乐队演出放投影是 VJ 的起源之一；国内 Livehouse 常见一台投影配歌词与图形。

> 狭小的地下 Livehouse，天花板很低，空气满是烟雾。后墙被一台老投影仪投出一行巨大的白色手写歌词“我们都是不发光的星星”，字边缘带复印机般的粗糙噪点，微微闪烁。四人乐队在字前演奏，主唱的影子投在歌词上遮住几个字。只有两盏红色 PAR 灯从侧后方打来，把乐手勾成红色轮廓，正面几乎全黑。主歌时鼓手只敲边击；副歌鼓点全开，贝斯手猛地扫弦，镲片在逆光中闪出亮边，投影随每个重拍闪一下白。贴台手持，偶尔被前排后脑勺挡住，16 毫米胶片颗粒，高反差，红黑为主。

## 4. 动态字体 / 歌词视频（Kinetic Typography）

**分类**：Motion typography（字形不变、整体运动）与 Fluid typography（字形本身拉伸、融化、溶解）。情绪主要来自时间和缓动：快而锐利 = 紧迫能量，慢而柔和 = 平静奢华。
**技法**：Slam 砸入（配重拍）；Scale pop 回弹；Stagger 逐字错峰（说唱）；Mask reveal；Tracking 字距拉开（长音）；3D 挤出翻转；整屏一词每拍替换；卡拉 OK 高亮条；描边叠层（Y2K）；融化滴落；Glitch 错位；Type as world（字是建筑，镜头在字间飞行，常作 hero shot）。
**分工**：模型写长文字不稳，中文尤甚；让模型生成“字所在的世界”和短词材质，用引号写确切内容，精确歌词与卡拍交给后期。
**案例**：霓虹灯管字与立体金属字片头是最常见的两种 hero 形态。

> 一片无边的黑色镜面地面上矗立着三个巨大的立体汉字“不 回 头”，每个字十几米高，由抛光红色金属制成，边缘有细细的白色倒角高光。主歌里镜头贴着镜面低空缓慢滑行，远处天空是深紫到黑的渐变，薄雾缓慢移动。预副歌镜头加速，从第一个字的笔画缝隙中穿过，金属表面掠过流动的反射光带，每一拍字的边缘高光亮一次。副歌第一拍，镜头穿过最后一个字后急速上升、回转，俯瞰三个字整齐排列，三个字同时从底部亮起红色内光，镜面倒影完整清晰。画面干净、锐利、对称，高端片头动画质感。

## 5. 产品 / 道具英雄镜头（含国潮）

**语法**：环绕、宏距滑动、爆炸拆解后合拢、产品从粒子中凝结或分解重组。
**词汇**：深色背景上的轮廓光；玻璃/陶瓷瓶身两道竖条高光（两侧长条柔光箱）；光扫划过 Logo 闪出星芒；皇冠飞溅、液体缎带环绕、倒酒拉丝、液滴悬停；成分元素环绕旋转；镜面台、水面、云海底座；品牌色统治画面（中国红 + 金 + 黑）。
**国潮**：中国红、青花蓝，水墨、剪纸、年画技法与夸张造型；元素有祥云、回纹、龙鳞、青绿山水、宣纸、红墙金瓦、斗拱、灯笼、篆刻、书法笔触、锦鲤、仙鹤。现代化处理：金属化（祥云变金色浮雕）、发光化（回纹变霓虹灯管）、粒子化（水墨变黑色粒子烟）、立体化（剪纸变多层纸雕）。“赛博·紫禁”把红墙龙纹与赛博光效融合。
**案例**：Houdini 饮料飞溅英雄镜头；白酒片头常见国风卷轴展开与朱红大门开启。

> 夜色中一座巨大的朱红宫门矗立在黑色镜面广场上，门钉金色，门楣斗拱被青色霓虹灯管勾出轮廓。前奏只有低沉鼓声，薄雾贴地流动。一声重鼓，两扇宫门缓缓向内打开，门缝溢出金色光芒和翻滚白烟；门后是一条无限延伸的隧道，隧道壁由层层半透明金色全息回纹与祥云组成，随节拍一圈圈向内推进。副歌落下时，一只通体赤红、表面金色龙鳞浮雕的酒瓶从隧道深处旋转飞出，穿过宫门在广场中央减速悬停、缓慢自转半圈，两侧竖条白色高光与暖金轮廓光勾出瓶形，一道光扫从左到右划过瓶肩闪出星芒；空气中红色粒子一笔一笔写出书法笔触后化作火星消散。红、金、青三色，高对比，广告级 CG 质感。

## 6. 3D 抽象 / 动态图形循环

**词汇**：软体果冻球挤压弹跳、铬与液态金属、虹彩薄膜、丝绸布料飘动、分形晶体生长、克隆阵列波浪起伏、玻璃棱镜色散与焦散、颗粒色差模拟质感。
**运动**：核心是周期：旋转整圈、波浪一个周期、进画出画。oddly satisfying：穿缝挤压、齿轮咬合。慢 loop 配 Lo-fi/R&B/氛围，快速弹跳配流行电子，碰撞与落地可落在节拍上。
**镜头光色**：正交或长焦（图形感）、棚拍柔光；马卡龙同色系背景与物体，或黑底 + 彩色反射物。
**案例**：Beeple 每日渲染与 VJ 循环。

> 纯黑背景中悬浮一团液态铬金属，表面如镜，倒映周围几条缓慢移动的品红与青色霓虹光带。主歌里金属团缓慢自转，每个底鼓表面泛起一圈同心波纹；预副歌它被拉伸成一条扭曲丝带，边缘滴下几滴水银般的液滴，液滴在空中停顿后被吸回主体，节奏越来越紧。副歌第一拍整团猛地收缩成光滑圆球，随即展开成一朵花瓣层叠的抽象花形，霓虹光带同时加速环绕。镜头以极慢速度环绕，浅景深，安静、性感、未来感。

## 7. 二次元 / 动画特效

**技法**：冲击帧（命中或重拍 1–2 帧纯白/去饱和，下一帧反色或黑白剪影）；集中线/速度线（背景画线、角色清晰）；作画（sakuga）段落：夸张透视、拖影 smear、作画密度骤增；赛璐璐硬边特效（锯齿火、折线雷、月牙斩击、漫画冲击星）；hit stop 命中微停 2–4 帧；新海诚式光线（层积云体积天空、变形镜头光晕、云缝斜射光、蓝橙高饱和渐变）；樱花雪雨粒子、漫画分格、拟声字。
**段落**：主歌风景日常电车窗边；预副歌风起、花瓣加速、上摇天空；副歌作画、速度线、冲击帧、法阵展开；桥段慢镜、褪色回忆、单色剪影。
**案例**：《原神》风格化特效；新海诚《你的名字》的天空与光。

> 日本热血动画风格，赛璐璐上色，硬边阴影。夜晚城市天台，少年站在边缘，身后是霓虹闪烁的高楼群。预副歌他握紧拳头，周身燃起锯齿状扁平图形层层叠加的橙红火焰，火焰随鼓点一下下窜高。副歌第一拍他猛地蹬地跃起，背景瞬间变成放射状白色集中线，角色保持清晰，镜头以夸张仰视透视跟随冲向天空。拳头击出的重拍：画面停顿一瞬，切成高反差黑白剪影，再反色一帧，随后火焰化作巨大环形冲击波向四周扩散，漫画冲击星从拳头处放射。动作快、张力强、作画密度高。

## 8. 其他模式

- **K-pop 舞台 / VCR**：全场统一应援色、队形站在 LED 地屏上、透明 LED 立方体（TWICE 360° 舞台）、喷火彩带炮、每首歌一个概念世界；VCR 是电影化预制短片（BLACKPINK《Born Pink》）。摇臂大弧线、成员特写快切。开场片结构（黑屏 → 符号 → 世界 → 标题砸入 → 灯亮）可直接作 MV 前奏。
- **全息纱幕**：前层纱幕/透明屏 + 后层大屏，“半透明发光的”“悬浮半空”“能透过它看到后面的舞台”“前后两层有明显距离”。
- **裸眼 3D 大屏**：城市转角弧形巨屏，屏内画出盒子透视，物体越过盒子边缘破框而出（巨浪拍出、产品飞出）。
- **Es Devlin 式装置**：一个巨大几何体即整个舞台（旋转立方体、环、圆盘），屏随几何体运动，镜面与水面制造无限反射，诗句作为光投在建筑上。
- **晚会 / 庆典大屏**：满屏金红、烟花、祥云、巨幅书法、朱红大门开启光芒溢出、卷轴展开、锦鲤跃龙门；适合国风流行与贺岁歌。

## 写法要点

写“屏内内容”和“屏所在空间”两层；事件顺序挂在段落和拍点上；微小人群对比巨型主体制造尺度；限定色板；质感词具体（现场直播质感、16mm 颗粒、广告 CG、赛璐璐上色）；镜头运动一到两个即可。
