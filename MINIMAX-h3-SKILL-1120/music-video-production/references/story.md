# 故事与内容

这是一份剧作与 MV 叙事知识：概念、框架、技法、案例和取舍，按需挑选组合，不是固定流程。案例的作品名和导演可公开查证，具体镜头细节以原片为准。

用户给了角色、事件或明确要剧情时，故事就是内容事实，任何风格都不改写它；用户只给氛围、表演或主题词时，可以做表演、概念或歌词视觉型，主题词本身不等于故事。风格（色彩、材质、成像、包装）也不改写故事事实：普通卧室不因拼贴风变成纸片房，千禧风不擅自把时代改到 2000 年。

剧情 MV 里人物可以不唱，演唱的处理见 [歌曲、时间轴与口型](music-and-lipsync.md)；镜头怎么拍、怎么接见 [分镜](storyboard.md)。

## 1. MV 不是缩短的电影

- 结构由歌曲先定："歌就是节拍表"。
- 叙事通常是"部分的"（Carol Vernallis）：故事世界慢慢显露，带空隙和重复，更像"隐藏然后揭示一个主题"。清楚的意象系统加一两次真转折，常比塞满情节有力。
- 声画关系是第二条叙事线：剪辑节奏、运镜、色彩变化本身在讲情绪弧线。

### 内容类型

| 类型 | 核心 | 常见失败 |
|---|---|---|
| 表演型 | 演唱、演奏、舞蹈 | 灯光机位不变，第二分钟就闷 |
| 叙事型 | 人物、事件、变化 | 镜头不够，后半段重复填充 |
| 概念型 | 一条视觉规则或变形贯穿全片 | 沦为氛围剪辑，缺少继续看的理由 |
| 歌词视觉型 | 文字、图形随歌词出现 | 像卡拉 OK 字幕 |
| 混合型 | 表演 + 叙事 / 概念 | 两条线互不相干 |

常见且稳的混合：副歌给表演，主歌推进叙事，桥段让叙事兑现。

### 叙事密度光谱

纯表演 → 表演 + 氛围意象 → 表演 + 暗示叙事（不交代因果）→ 表演 + 完整小故事 → 纯叙事、歌手入戏 → 短片化（对白、音乐中断）。越往后代入越强，执行难度和音乐被稀释的风险也越高。选档位看歌词有无故事、艺人是否出镜、资源（生成时"角色一致性 × 场景数 × 镜头数"约等于风险）。

## 2. 剧作基础的压缩

- **欲望 / 阻碍 / 变化**：角色想要什么、什么挡着、做了什么、因此变成什么。人物 = 压力下的选择（McKee），MV 里一个不可逆动作就够：把钥匙留在桌上、删掉照片、转身离开。被动发呆的主角最难看。
- **转折**只有动作或揭示两种；伏笔最省时的载体是物件。- **三幕**：主歌一建置，主歌二到桥段对抗升级，最后副歌和尾声解决。
- **起承转合**：起短，承可长，转引入意外视角，合要短；张力可来自对比而非冲突，适合抒情、古风。常"先定结局再倒推"。
- **Save the Cat / 英雄之旅** 在 MV 里常只取几拍：开场画面、催化剂、跨越门槛（对副歌进入）、低谷（桥段）、终场画面（与开场同构图、意义不同）。
- **故事脊梁**（皮克斯）：从前…每天…直到有一天…因此…因此…直到最后。填得满就有因果链。巧合可以制造麻烦，不宜用来解围。
- **Show, don't tell**：潜台词在行为、物件、构图里。"她想他"→"摆了两副碗筷又收起一副"。具体动词和名词比形容词更好拍，也更好写进提示词。
- **弧光的最小形态**：状态翻转（被困→出走）、关系翻转（并肩→背对）、认知翻转（回忆里的人早已不在）。

## 3. 歌曲结构与故事的映射

一种常见范式：

| 段落 | 常承担 |
|---|---|
| 前奏 | 地点、色调、主角，意象首次出现，最好带一个问题 |
| 主歌一 | 日常与欲望 |
| 预副歌 | 蓄力、景别收紧 |
| 副歌一 | 招牌画面（可做缩略图的一帧） |
| 主歌二 | 同一世界升级或退化，而非重复 |
| 副歌二 | 招牌画面换尺度、天气、人数 |
| 桥段 | 唯一的真转折：决定、断裂或揭示；色调常在此换一次 |
| 最后副歌 | 招牌画面带着新意义回归 |
| 尾声 | 停住的画面，与开场呼应 |

其他范式：两线交替（主歌现在、副歌回忆，桥段相遇）；单一过程（一次逃跑、一天）；章节式；循环叠加（随编曲加层，Gondry）；反向操作（最静的画面压在最强的副歌）。

**歌词与画面**（Andrew Goodwin）：图解（直接演歌词，逐句图解最易平庸）、放大（围绕核心情绪加码，最常用）、断裂（画面与歌词矛盾，制造反讽）。延伸：平行（另讲一个情绪同构的故事）、锚定（Barthes，画面改写歌词意义）、互文（引用电影、绘画、前辈形象）。

**节拍对位**：硬切落强拍显推动，落弱拍显慵懒；剪辑密度本身是结构工具；动作对鼓点。

## 4. 视觉叙事技法

- **母题**：反复出现的物件、颜色、动作或空间，每次状态变化即叙事。会换主人或位置的物件（钥匙、信、伞、耳机、车票）能扛起整条结构；普遍物件 + 私人化用法最平衡。
- **重复与变奏**：同一构图出现三次、每次改一个变量；开场 / 结尾同机位、状态相反。
- **时间流逝**：季节、光线、积雪积灰；服装与物件磨旧；同机位叠化（《飞屋环游记》开场）；延时与光影扫墙；跨时间匹配剪辑（小时候的手 → 长大的手做同一动作）；时间标记物（旧手机、车票）会被观众认真读。
- **闪回与多时间线**：每条时间线固定视觉编码（调色、画幅、颗粒、季节），全片一致；平行蒙太奇并列互文，交叉蒙太奇最终相交。
- **蒙太奇**：爱森斯坦五法（节拍、节奏、调性、泛音、理性）；叙事蒙太奇（连续、平行、交叉）、表现蒙太奇（隐喻、对比、重复）、画面内蒙太奇（回忆与现实同框）。
- **匹配剪辑**：图形（月亮 → 灯 → 瞳孔）、动作（推门跨进另一时空）、视线（看 → 所见）、声音（钟声延续）、概念（流泪 → 雨打窗）。
- **库里肖夫效应**：同一张中性脸接汤、棺材、孩子，被读成饥饿、悲伤、温柔。表情可以克制，情绪交给"接什么"——对生成视频尤其省力。
- **空间与运镜**：空间转换即转折；一镜到底让观众在同一时空承受急转；前景 / 背景分层制造反讽。
- **不用台词的转折手段**：行为、物件、地点、服化、剪辑节奏、镜头与光、色彩。相邻段落换用不同手段，变化更可感。

## 5. 故事的逻辑与空间

故事要在物理上和因果上都能被拍出来。观众（和视频模型）看到的只是一个个镜头，镜头之间的事实需要自洽。

- **信息流**：谁在什么时候知道什么。误会、错过、揭示都建立在信息差上——观众知道而角色不知道产生紧张，角色知道而观众不知道产生好奇。信息何时、经由哪个画面传递，决定转折是否成立。
- **因果连续**：每个状态变化有可见的原因（门为什么开了，伞为什么在她手里）。跳过原因会被读成剪错。
- **地点少而清楚**：两三个地点、每个出现多次多种尺度，比十个一闪而过的地点更好懂。每个地点的地理是固定的：门、窗、座位、桌子在哪一侧，从哪里进出，地点之间如何连通（走廊通向天台、窗外看到的就是下一场的街）。
- **相对位置与银幕方向**：A 在画左、B 在画右，朝向一致观众就不迷路；跨越轴线或互换位置会被读成关系变化，宜有意为之。
- **道具的归属与状态**：同一物件在谁手里、处于什么状态（湿 / 干、折起 / 展开、完整 / 撕碎）随时间演变，前后镜头需对得上。
- **时间与天气一致**：同一场戏的时段、光向、雨雪状态连续；变化本身就是时间流逝的信号。
- **动作简单可信**：视频模型擅长单人、物理上合理的动作（走、坐、回头、递出、撑伞、推门）；复杂交接、多人纠缠、精细手部操作、违反空间的走位容易崩坏。复杂事件拆成几个简单动作加剪辑更稳。
- **题目与前提要上画面**：标题或设定里的核心元素（某个地点、物件、天气、关系）应在画面中可见并被使用，否则观众无从对应。
- **情感靠可见的互动**：爱情、思念、疏离主要通过视线、距离、身体朝向、触碰与回避、手势来读，道具只是辅助。两个人之间距离的变化本身就是情节。
- **写进提示词**：成熟的导演会把这些事实直接写进每个镜头的描述——人物在画左还是画右、面朝哪里、手里拿着什么、物件状态、时段光线——视频模型看不到前后镜头，只有写明的事实才能被保持。

## 6. 让观众看得懂

- 一句话设定；静音测试（关声能懂多少）。
- 3 分钟里清楚建立 1–2 个主要人物，靠剪影、发型、服装色、标志物件识别。
- 建立镜头交代"在哪、谁和谁、多远"；距离与遮挡（玻璃、门框、人群）即关系。
- 先让观众关心人，再交代背景；关键信息给特写或停顿；前几秒给一个问题。
- 非线性靠固定编码；循环第二次多一个细节。

## 7. 常见弱点

| 现象 | 可参考的思路 |
|---|---|
| 像预告片、情节过密 | 每段一句话、一个转折；用物件代替一场戏 |
| 太淡、什么都没发生 | 一个清楚的"想要"和一次不可逆动作；首尾状态不同 |
| 三段副歌一样 | 招牌画面变奏：尺度、天气、人数、意义 |
| 看不懂 | 静音测试；时间线编码；强化人物识别；补齐空间与因果 |
| 逐句图解显得小 | 换成放大或平行 |
| 符号拼贴 | 一两个母题，被拿起、传递、丢下、找回 |
| 主角被动 | 给一个压力下的选择，用行为代替表情 |
| 结尾无力或靠巧合 | 先定终场画面，结局来自人物选择或伏笔 |
| 角色漂移 | 固定服装色、发型、配饰；减少人物和场景数 |

情节密度与留白没有标准答案；多数成功的叙事 MV 是一条简单情节线加大量意象和表演。

### 氛围好看但故事弱时

画面美而故事散，通常是每组都在“走、看、停、等”，人物一直在过渡状态，没有事情发生。检查：

- **每一组有没有一个事件。** 一个具体的、看得见的变化：拿到了什么、失去了什么、遇见了谁、做了一个决定、被什么打断。没有事件的组只是氛围，连续两三组都没有，观众就失去跟随的理由。
- **有没有第二个人或一个对手。** 只有主角独自行走的故事很难有张力。另一个人（哪怕只是背影、声音、留下的痕迹）、一个阻碍、一条规则，都能制造关系和冲突。
- **高潮在哪。** 至少一处情绪真正爆发的时刻（奔跑、哭、喊、撕、扔、拥抱、对峙），放在最强的副歌或桥段。全片情绪平铺，就像一段很美的空镜合集。
- **剪辑本身在讲故事。** 情绪高点用快速闪回、交叉剪辑、记忆碎片（半秒到一秒的短镜头接连闪过）加速；安静段再放长镜头。全片都是 4–5 秒的匀速镜头，节奏会拖。

## 8. 故事母型

- 等待：在固定地点等可能不来的人（站台、长椅、灯、信）。
- 出走：离开让人窒息的地方（行李、钥匙、门、公路）。
- 重逢 / 错过：同城一次次擦肩（路口、电车两侧）。
- 告别仪式：烧掉、埋掉、寄出、放生某样东西。
- 回溯：在现在的空间里看见过去（旧房子、旧照片）。
- 循环：同一天重复，直到做出不同选择（闹钟、同一路口）。
- 变身 / 觉醒：显露另一面（镜子、面具、服装）。
- 对决：两股力量正面冲突（对峙构图、对称空间）。
- 守护：为另一个人挡住某物（伞、外套、背影）。
- 寓言 / 设定：超现实规则影射现实，规则清楚并逐段升级。
- 一天：从早到晚的压缩时间（光线变化、日常动作变奏）。
- 群像：不同人各自的片段，最后汇合。

母型可叠加（等待 + 回溯）或倒置（期待出走却留下）。

## 9. 情绪曲线

- 跟随音乐能量最稳；反向曲线（越响越静）制造悬空；延迟释放把完全的高潮留给最后副歌；双峰（外部事件在副歌二，情感落点在尾声）；高密度段之间留呼吸点（空镜、背影、物件特写）。
- 常见倾向（可反用）：孤独 = 大远景、冷色、长镜头；紧张 = 特写、手持、快剪；回忆 = 暖色逆光、溶接；释放 = 远景航拍、随鼓点大剪；压迫 = 俯拍、框中框；梦境 = 雾、叠化。

## 10. 案例

- Michael Jackson《Thriller》（John Landis）：完整短片叙事，视觉压过歌曲。
- Adele《Hello》（Xavier Dolan）：现在的空房子与暖色闪回交叉，简单结构加强表演。
- Taylor Swift《All Too Well: The Short Film》（Taylor Swift）：章节化的关系时刻，走向短片。
- Radiohead《Karma Police》（Jonathan Glazer）：一个处境 + 一次反转，主观镜头。
- M.I.A.《Born Free》（Romain Gavras）：一句话设定的寓言，后面全靠升级。
- Kylie Minogue《Come Into My World》（Michel Gondry）：每绕一圈多一层复制，规则对应编曲叠加。
- OK Go《Here It Goes Again》（Trish Sie）：一镜到底，悬念在执行本身。
- Childish Gambino《This Is America》（Hiro Murai）：前景舞蹈、背景暴力的空间分层。
- Kendrick Lamar《HUMBLE.》（Dave Meyers & the little homies）：tableaux 拼贴，每帧一个立场。
- Fatboy Slim《Weapon of Choice》（Spike Jonze）：一人一空间一次超现实升级。
- RADWIMPS《前前前世》段落（新海诚，《你的名字。》）：整首歌长度的蒙太奇压缩两人的日常交换，节奏先于画面。
- YOASOBI《夜に駆ける》（藍にいな）：明快旋律包裹死亡叙事的声画反差。

## 快速自检

- 每个段落能否用一句"我们看到什么"描述，桥段有没有真转折？
- 位置、朝向、手中物件、时段天气在相邻镜头间是否连贯？
- 关掉声音，人物关系和关键转折还看得懂吗？
- 镜头、场景、人物数量与生成资源匹配吗？
