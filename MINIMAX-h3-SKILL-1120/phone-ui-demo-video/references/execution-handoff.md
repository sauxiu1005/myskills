# 制作交接与复现

## 简报

按目标、已确认决策、输入材料、交付物和来源组织简报。写清事实、画幅、时长、声音路线、分镜与素材版本；修订沿用原工程，不凭文字重建已有代码。只交付 Skill 包时不启动影片制作。

## 执行条件

模板以实际加载位置为准，缺文件就说明阻塞。复用现有运行时，新增依赖或字体遵循已有授权，不捏造环境能力。

先做确定性、资源和依赖检查，再抽真实关键帧；语法检查不等于抽帧。技术验证可用 0.5–3 秒小样验证真实浏览器、编码和声音，截图回归使用交付分辨率。模拟截图只能证明算法，不能代替真实渲染。

构建与客观参数检查后交用户审阅；不凭自我验收扩展重做范围。交付 MP4、单文件 HTML、源码 ZIP 和分镜，保留来源与许可证。HTML 预览不是在线编辑器，只报告实际可用的编辑能力。

## 字体

本包不附带字体。先核实所需字形覆盖；document.fonts.ready 不证明字形齐全。使用用户提供的已授权字体或经同意获得的可分发字体；声明 @font-face 时，路径、来源和许可证随工程交付。缺字形时保留工程并报告阻塞，不删除版权文件来通过检查。

## 旧工程升级

保留原源码与成片，备份导出脚本后同步新版 scripts/phone-ui.mjs、scripts/frame-capture.mjs、scripts/package.json 和 lock，或以新版 CLI 处理原工程。不重新 init，不覆盖自定义 HTML/CSS/JS。

新版渲染报告应包含 frame_capture.mode: consecutive-pixel-match，说明稳定截图保护确实执行；该字段不表示用户验收。旧 MP4 不会自动变化，需重新导出新版本。
