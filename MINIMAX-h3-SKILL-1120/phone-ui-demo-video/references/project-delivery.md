# 制作环境与项目交付

作品目录保存当前影片，技能目录只提供模板和脚本。使用真实可访问路径，不改模板原件，不覆盖已有作品。

## 环境与依赖

- Node 22+；Chrome / Chromium；scripts/package.json 固定的 puppeteer-core；FFmpeg 与 ffprobe。
- 浏览器启动独立无头实例，可用 CHROME_PATH 指定，不连接用户的日常浏览器。
- puppeteer-core 依次从 PUPPETEER_MODULE、作品 scripts、作品根目录、Skill scripts 查找。已有兼容模块可复用绝对入口；获准后可在作品目录执行 npm ci 安装固定依赖。
- FFMPEG_PATH、FFPROBE_PATH 可指定现有可执行文件，不改用户全局环境。
- doctor 检查依赖。bundle 与预览只需 Node；抽帧需要浏览器；成片还需 FFmpeg。缺失时说明影响并确认安装方式，或先交付分镜、预览与源码，明确视频受阻。
- 渲染前核对所需字形，字体及许可见 [执行交接](execution-handoff.md)。

## 项目材料

每部影片集中保存分镜文档、代表关键帧、单文件 HTML 预览、MP4 和可编辑源码。独立画幅或静音变体分别命名。原始截图与 Logo 保持不变，工程副本记录来源；修改时间、字体和布局复用已有素材。

素材优先使用用户已有或已授权资料。界面文字、数字、Logo 和控件由代码绘制。确需生成壁纸、音乐或旁白时，先确定用途和授权范围，保存实际结果及来源，再纳入工程。远程素材本地化，导出浏览器只访问工程及内嵌资源。

源码包包含 HTML/CSS/JS、assets、scripts、package.json、lock、LICENSE 和 EXPORT.md，排除 node_modules、浏览器、临时帧及账号信息；换目录解压后应可按说明复现。

## 声音

- 默认从 story.js 事件表合成系统音效，导出 48 kHz WAV 并封装 AAC，无额外配乐或旁白。
- 外部音乐或旁白按实测时长对齐，混为 final-mix.wav 后用 --audio 导出，不重复叠加随包音效。旁白先有实际音轨再逐句配画面，不自动克隆或替换声音。
- 用户要求静音时用 --silent，输出无音轨。响度数据不等于听感验收。

## 导出与验收

1. 编码前确认同一时间点连续两次截图稳定；持续异常停止并保存诊断，不交付已知坏帧。
2. export 输出视频和参数报告，核对尺寸、帧数、帧率、时长、音轨与完整解码。
3. bundle 输出单文件预览；检查播放、暂停、切镜和重播。没有交互检查能力时明确未验证，不以语法或无头测试替代。
4. 交付实际可访问的视频、预览、源码、关键帧与分镜，说明未完成项。本地生成不等于用户已能访问，更不等于用户验收。
5. 由用户审阅画面和听感，按反馈时间码局部修订并保存新版本，同步预览、源码与分镜。

失败读取 .failed.json；同一原因最多两次修正重试，仍失败保留日志并说明恢复条件。长渲染遵循 [任务跟踪](rendering.md#长任务执行与恢复)，保留原任务句柄，状态未知先核对，不重复启动。

包文件校验：node scripts/verify-package.mjs。它校验分发文件，不代表已生成影片。
