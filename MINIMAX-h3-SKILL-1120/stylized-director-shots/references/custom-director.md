# 其他导演：临时分支（未收录导演）

用户在 STEP 0 选择"其他导演"，或点名了导演库里没有的导演时使用。目标是在本次任务里，用证据先做出这位导演的风格卡与配色色卡，经用户确认后再走 STEP 1–5；色卡同样强制作为第 1 张参考图。临时分支默认不写入导演库。

## 1. 确认导演与作品范围

- 用户只写了名字时，确认是哪一位导演（同名或译名不清时用选择框给 2–3 个候选）。
- 选 3–4 部代表作作为依据，优先用户点名的作品；用一句话说明为什么选这几部。导演风格前后差异很大时，只覆盖选定作品，在风格卡里写明"本临时分支只基于这几部作品"。
- 不能确认身份、或找不到足够作品依据时，如实告诉用户，不凭空编写风格。

## 2. 收集依据（剧照 + 用户上传）

- **先用用户上传的截图**；不足时用网络图片搜索补齐，每部作品 2–3 张有代表性的剧照（不同光线或场景），总数 6–12 张。搜索词写"片名 + 年份 + still / cinematography"。
- 剧照与用户截图**只用于分析和取色**，存入项目的研究对象中，不作为生成参考图上传，不当作成品，也不复制其中的角色、服装、道具或场景。
- 记录每张图的来源（用户上传或网页链接）和对应作品。
- 可补充公开的摄影或导演访谈作为文字依据；引用时写出处，没有出处的说法标为"本技能观察"。

## 3. 分析风格（按现有分支的章节写）

把结论写成一份临时分支文档，章节与已收录分支一致，但可以精简：

- 参考作品与依据清单
- 它不是什么（最容易被误读成的样子，2–3 条）
- 画面规则：构图、空间、光线、材质
- 配色方案：2–3 套，见第 4 节
- 运镜规则：景别、机位与焦段建议、运动的起点 → 终点与动机
- 剪辑规则：镜头时长建议、切点、衔接、转场、节奏递进
- 声画同步规则
- 角色与场景造型（仅在用户未指定时）、不复制清单
- 自检清单

每条规则区分依据：**剧照可见**（构图、光色、景别）与**作品知识**（运镜、剪辑、声音，静帧看不出）。作品知识部分措辞保守，写成"本任务的转译建议"，不说成导演本人的规定。

## 4. 生成配色方案与色卡

1. 按作品或光线情境把剧照分成 2–3 组，每组对应一套方案，方案之间要能区分。
2. 每组运行取色脚本（在 Skill 根目录）：
   `python3 scripts/sample_stills.py [--user] <工作目录>/<方案ID>-sample.json <剧照1> <剧照2> ...`
   脚本只给出该组剧照的中位切分取样草稿，必须人工复核：按色彩角色归类（背景主色、阴影、光源高光、小面积强调、肤色保护），删掉落在人脸上的肤色，强调色只保留真实物件或光源上的颜色，补写 `desc`。
3. 写成与已收录导演同结构的 `schemes.json`（每套含 `fits`、`avoid`、`light`、`contrast`、`roles`、`sources`、`stills`），放在项目工作目录 `custom-directors/<导演英文名>/`，**不放进 Skill 的 `assets/palettes/`**。色值来源标为 `sampled_from_web_still` 或 `sampled_from_user_still`，面积标为建议值。
4. 渲染色卡：`python3 scripts/render_palette_cards.py custom-directors/<导演英文名>`，得到无文字的 `<方案ID>-card.png` 与带标注的 `preview.png`。
5. 色卡与预览图存入项目，归入这位导演的临时分支对象。

## 5. 风格卡确认（停下等待）

在出镜头表之前，把风格卡交给用户确认，不产生费用：

- 导演、所依据的作品与剧照来源
- 画面 / 运镜 / 剪辑 / 声音 各 1–2 句要点和"它不是什么"
- 2–3 套配色方案：名称、适合与不适合的剧情、预览图
- 依据的局限（例如"运镜与剪辑来自作品知识，静帧无法验证"）

用选择框让用户选一套配色方案（推荐项排第一），或直接提出修改。确认后按 STEP 1–5 继续，STEP 2 读取这份临时分支和它的 `schemes.json`，STEP 5 的色卡强制参考与提交前核对同样适用。

## 6. 结束时询问是否入库

任务完成后问用户：要不要把这位导演正式加入导演库。用户同意才按 SKILL 的"扩充导演"写入 Skill（补全分支章节、把方案与色卡移入 `assets/palettes/<director>/`、更新菜单、触发词、description、`meta.yaml` 并升级版本）；不同意就只保留在项目里。

## 自检

- [ ] 风格结论都能指向剧照或注明出处；静帧看不出的部分标为转译建议。
- [ ] 色卡由剧照取样并人工复核，无文字、无肤色色块；色值来源与面积标注齐全。
- [ ] 剧照没有作为生成参考上传；生成只上传所选方案色卡（第 1 张）和人物、场景参考。
- [ ] 风格卡经用户确认后才出镜头表；临时分支没有未经同意写入 Skill。
