# 分支：丹尼斯·维伦纽瓦｜巨构与静压

> 本分支是从下列具体作品中提炼的创作转译，不是维伦纽瓦全部作品的固定公式。焦段、秒数为本任务建议。

## 视觉参考作品

- 《边境杀手》（2015）：边境航拍的地形尺度、隧道剪影段落、持续低频造成的压力。
- 《降临》（2016）：雾中悬浮的单体巨构、人物在巨大空间中的渺小、缓慢进入舱体的揭示。
- 《银翼杀手2049》（2017）：橙色雾霾中的巨型雕像与建筑，简洁几何室内与大面积负空间。
- 《沙丘》（2021）与《沙丘2》（2024）：沙漠与巨型飞行器、粗野主义建筑的尺度对比，远景与脸部近景的交替。

## 不是什么

- 不是每个镜头都慢、都远。远景只用于建立尺度、转折和揭示；每段必须有脸部或手部近景承接情绪。
- 不是无动机的缓慢推进。没有信息或情绪目标的推镜一律改为固定。
- 不是只有灰黄调色。压力来自尺度、停留和声音，调色只是统一色域。

## 画面规则

**构图**
- 尺度镜：人物占画面高度约 1/10 或更小，放在三分线外侧或画面底部；巨构占据大部分画面，作为压在人物上的体量。
- 负空间：大面积天空、雾、墙面、沙地或天花板，人物视线指向负空间，暗示画外存在。
- 地平线极低（强调体量和天空）或极高（强调地面与人物被吞没），避免居中平庸的地平线。
- 近景简洁：背景是一片模糊色块或干净墙面，不让细节分散注意力。

**空间**
- 巨构是几何的、少细节的：方块、长墙、单体、圆柱、平滑表面；用简单形状造成不可理解的体量。
- 门槛空间：隧道、舱门、长走廊、电梯井，把"进入"变成事件。
- 横向延展（地平线、长墙）与竖向压迫（高墙、天井）交替使用。

**色彩**（导演确定后按剧情选一个方案并贯穿；方案互斥。配色方案的选择、颜色角色写法和参考素材分工见 `references/palette-and-references.md`。）
- **V1 降临雾灰**：灰绿雾灰为背景，深青灰暗部，冷白柔和高光，默认不设强调色。适合等待、接触未知、沉思。
- **V2 沙丘2沙金**：浅沙与赭褐为背景，暖褐近黑阴影，沙漠金阳光；落日橙只用于剧本里真实存在的火光、落日或灯。适合烈日、荒原、命运感。
- **V3 宿敌黄雾**：浑浊的土黄与橄榄黄环境，黄绿黑暗部；人物保留原本肤色，不被黄雾染成蜡黄。适合城市、室内、身份不安。
- 每场只用一个主导色域，低饱和；对比主要来自明度：亮背景上的暗剪影，暗室里的一道亮缝。
- 色值来源与纠正说明：`assets/user-sources/villeneuve/SOURCE-NOTES.md`；色卡与预览：`assets/palettes/villeneuve/`。

**光线**
- 大面积柔和光源：阴天漫射、天光、顶部大窗；或强逆光把人物压成剪影。
- 人物脸部常有一半处于暗部；光源逻辑来自真实存在的窗、门缝、天光。
- 尘霾、雾气、烟分出空间层次，让远处的巨构变淡。

**材质**
- 粗粝混凝土、玄武岩、沙、哑光金属、厚重布料；表面吸光不反光，避免亮面高光的轻浮感。

## 角色与场景造型（仅在用户未指定或获准设计时）

- **轮廓**：被功能性装备简化成几何块的身形——长披挂、兜帽、面罩、背负设备；远景中只剩一个清楚的竖条或三角形。
- **服装与材质**：风化、磨损的防护布料与哑光硬件，颜色贴近环境（雾灰、沙色、石色），只靠明度与环境区分。
- **面部**：面罩或兜帽遮住部分面部，近景时露出眼睛与额头；保留原本肤色。
- **道具**：功能性的测量、记录或通讯工具（测距仪、标尺、信号器），动作小而精确。
- **场景**：巨大、单一、几何化的结构（巨墙、方碑、深坑、柱阵）与大面积负空间；雾或尘中的漫射光，几乎没有硬影；人物在大全景中极小。
- **不复制**：不做弗雷曼人蒸馏服、具体外星飞船或电影中的标志造型。
- 低成本单次样片的写法见 `references/sample-mode.md`。

## 运镜规则

**景别**：远景（尺度）与近景/特写（脸、眼、手）交替，减少中景。一场典型结构：尺度远景 → 近景 → 更大的揭示远景 → 特写。

**机位与焦段建议**
- 远处长焦压缩（约 85–135mm 等效）：把巨构和人物叠在同一平面，让巨构显得近而压迫。
- 广角低机位仰视（约 24–35mm 等效）：人物在前景，巨构向上延伸。
- 脸部近景约 35–50mm 等效，机位与眼平或略低。
- 高空垂直俯视：用于地形与渺小人物，只在场景开头或转折使用。

**运动**
- 静止镜头为主，运动本身就是事件。
- 缓慢推进：起点 = 人物与环境的平衡构图；终点 = 信息或情绪焦点（门缝后的光、脸上的决定、手上的物件）；速度极慢，接近难以察觉，持续 5–10 秒；动机 = 人物正在意识到或决定某事。
- 遮挡揭示：起点 = 遮挡物（舱壁、沙丘脊线、门、雾）占满画面；终点 = 巨构或关键空间完整出现，人物在前景成剪影作为尺度参照；以缓慢上升或横移完成。
- 跟随：从人物背后缓慢跟随进入门槛空间，保持距离，不贴近。

## 剪辑规则

**镜头时长分配（建议）**：尺度/揭示镜 6–12 秒；近景 3–6 秒；张力高点可出现 1–2 秒的短促冲击切，但一段内最多一两次。

**切点**
- 动作完成后多停一拍（约 1–2 秒）才切，让观众开始不安：停留是本分支的核心。
- 推进镜头在到达终点并稳定之后切，不在运动中途切。

**衔接**
- 延迟反打：人物看向画外，先给一两拍不揭示所见之物，再切到所见之物的远景。
- 声音桥：下一场的低频、环境声提前 1–2 秒进入（前置声音），或上一场的持续声拖入下一场（后置声音），以声音而非画面带动转场。
- 大小反差切：从特写硬切到最大尺度的远景，或反向。

**转场**：硬切、切黑、切到强光或白雾；不用花哨转场。

**节奏递进**：长—长—更长的停留累积压力，然后一次画面与声音的打破（突然的巨响或突然的完全寂静），之后回到缓慢。

## 声画同步规则

- 声音设计与音乐边界模糊：持续低频嗡鸣、喉音或人声质感、被放大的环境声（风、机器、呼吸），参考作品中约翰·约翰逊、汉斯·季默的声音质感；按用户版权要求选择原创或授权音乐。
- 巨构揭示时低频逐渐膨胀，峰值对齐画面露出最大体量的那一帧。
- 对白前后留静默；对白按原文，语速不为风格加快。
- 寂静可作为冲击点：在观众预期巨响时切掉所有声音。
- 脚步、门、物件声干燥近距离，与远处空间的混响形成大小对比。

## 提示词写法

分三层写，导演名不能代替具体描述：

- **图像提示词（静态）**：人物与环境的尺度比例、负空间位置、按所选方案写的颜色角色、光源方向、材质。
- **视频提示词（单镜）**：起始画面 → 结束画面、人物动作、运镜速度（如"几乎察觉不到的缓慢推进约8秒"）、声音（低频、环境声）。
- **剪辑说明**：停留时长、延迟反打、声音桥的提前量单独写。

示例（V1 方案）：
- 图像："灰绿雾灰的大面积墙面与天光为背景，深青灰暗部，人物很小地站在画面右下角，巨大的混凝土墙占满画面左侧三分之二；顶部天光柔和漫射成冷白高光，无强调色；人物保留原本肤色。不要把色卡上的色块、文字或排版画进画面，不复制任何电影角色或场景。"
- 视频："固定机位约4秒：人物从画面右侧边缘推门走入，停步，画面继续停留；持续低频嗡鸣，门轴声干燥而近。"
- 剪辑说明："人物停步后再停 1.5 秒才切；下一镜的低频提前 1 秒进入。"

## 工具限制与替代

- 极慢推进：生成时明确写"几乎察觉不到的缓慢推进"及起止构图；若生成结果运动过快，改为固定机位并依靠停留时长。
- 巨构尺度：若生成画面尺度不准，先生成环境参考图确定比例，再作为视频首帧参考；低成本样片不追加参考图时，用文字写清人物占画面高度的比例（例如"人物高度约为画面的十分之一"）。
- 收尾动作：实测 H3 中 1.5 秒的结尾镜"走进门洞消失"没有出现，人物只是静立。结尾镜不短于 2 秒，并把结束画面写成具体状态（"画面里只剩空的门洞和雾"）。
- 寂静：原生音频常保持持续低频，不会按提示词完全静音；寂静段需在剪辑中处理。
- 声音桥为剪辑中的音频前置或后置处理，需在可编辑产物中保留分轨。

## 自检清单

- [ ] 远景与近景交替，没有连续三个以上慢远景。
- [ ] 每个推进都有起点、终点和人物动机。
- [ ] 至少一处停留和一处声音桥。
- [ ] 低频峰值或寂静与揭示帧对齐。
- [ ] 只用所选的一个配色方案（V1/V2/V3）；强调色只来自剧本中的真实光源；图像提示词、视频提示词与剪辑说明分开写。
