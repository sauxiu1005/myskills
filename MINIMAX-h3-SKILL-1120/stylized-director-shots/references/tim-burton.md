# 分支：蒂姆·伯顿｜哥特童话

> 本分支是从下列具体作品中提炼的创作转译，用于给已有剧情提供一套连贯的视听执行，不是伯顿全部作品的固定公式。焦段、秒数为本任务建议。

## 视觉参考作品

- 《剪刀手爱德华》（1990）：粉彩整齐的郊区与山顶哥特城堡的两个世界对照。
- 《蝙蝠侠归来》（1992）：表现主义城市布景、雪夜中的剪影与高耸建筑。
- 《断头谷》（1999）：去饱和的雾林与村庄，红色只留给血与关键物。
- 《僵尸新娘》（2005）：生者世界灰冷、亡者世界鲜艳的色彩反转。
- 《科学怪狗》（2012）：黑白画面中的怪诞小镇空间与角色反应喜剧。

## 不是什么

- 不是堆骷髅、蝙蝠、南瓜、墓碑等符号；剧本没有的物件不加入，除非只是不改变剧情含义的布景纹理且已标注。
- 不是全片压暗加冷蓝滤镜；关键在轮廓可读和"两个世界"的反差。
- 用户已经给出角色时，不把角色改成伯顿式造型；角色身份与设定保持不变，怪诞感来自空间、光影、服装材质的处理和镜头距离。只有用户未指定或同意由你设计时，才按下方"角色与场景造型"设计原创角色。
- 不是只套黑白滤镜。辨识度首先来自瘦长轮廓、倾斜的手工布景和"揭示—古怪反应"的节奏，颜色只是统一方式。

## 画面规则

**构图**
- 剪影可读优先：每场至少一个镜头让角色完整轮廓落在较亮背景（窗、月、雾、浅色墙）前，四肢与道具形成清楚的外形。
- 竖向细长元素主导：尖顶、门框、楼梯栏杆、枯枝、细长家具，把画面切成高窄格。
- "正常世界"用居中对称、过分整齐的排列（重复的房屋、整齐的餐具），制造可疑的秩序；"异常世界"用倾斜的门窗线和弯曲透视。
- 角色常被框在门框、窗框、拱门中，像童话插图的画框。

**空间**
- 表现主义布景：墙角、门窗略微不垂直，走廊被拉长，楼梯呈螺旋；地面可用棋盘格或螺旋图案强化透视。
- 用遮挡建立好奇：门缝、钥匙孔、帘子、栏杆、雾后先露一部分，再揭示整体。
- 尺度夸张但不写实：家具略高、门略窄，使角色显得纤细或局促。

**色彩**（导演确定后按剧情选一个方案并贯穿；方案互斥。配色方案的选择、颜色角色写法和参考素材分工见 `references/palette-and-references.md`。）
- **B1 科学怪狗黑白**：纯黑白灰阶，硬光与剪影；关键物靠光线和明度突出（例如落在唯一一束白光里）。黑白方案不套用任何彩色色卡，色卡与默认生成都不含彩色。只有用户明确要求"黑白+局部色"改编时，才在提示词中用文字说明哪一个剧本物件保留颜色，不改色卡。
- **B2 剪刀手爱德华粉彩与哥特**：日常世界是过分整齐的薄荷绿、粉、天蓝粉彩，低反差；哥特世界是炭黑与石灰色、冷月光，高反差。适合有"两个世界"的剧情。
- **B3 阴间大法师2彩色怪诞**：深青绿夜色为底，红色只落在招牌、灯、服装局部这些真实物件上。
- 局部色和强调色必须绑定叙事意义，不能随意点缀。用户资料中的紫橙绿通用卡不作为默认滤镜（原因见 `assets/user-sources/burton/SOURCE-NOTES.md`）。
- 色卡与预览：`assets/palettes/burton/`。

**光线**
- 硬侧光和顶光，影子边缘清楚、形状夸张，可让影子先于人物出现在墙上。
- 轮廓光勾出剪影；月光偏冷蓝，烛光与室内灯偏琥珀。
- 雾、烟、尘把纵深分成前中后三层，每层明暗不同。

**材质**
- 手工感：缝线、补丁、剥落墙纸、铸铁卷花、蜡、旧纸、木纹裂缝，表面带轻微不完美。
- 眼部阴影较深的效果只通过光线实现；人物保留原本肤色，不为风格把肤色改白或改成统一色值，不改变角色身份设定。

## 角色与场景造型（仅在用户未指定或获准设计时）

- **轮廓**：瘦长、竖向夸张，细长四肢与手指，高领或窄肩把脖子拉长；剪影一眼可读。
- **发型与面部**：凌乱、蓬起或向上翘的头发；眼部阴影较深只靠光线做出，保留原本肤色，不画成苍白妆。
- **服装与材质**：窄长外套、条纹或格纹、缝补痕迹、旧皮革与黄铜扣件；手工、略不完美。
- **道具**：带机关、能"揭示"的手工物件（钟表、音乐盒、发条装置），尺寸或形状略夸张。
- **场景**：倾斜的墙与门框、螺旋楼梯或弯曲透视、挂满手工物件的拥挤布景；冷月光为主，少量暖色实用光（台灯、炉火、机械内部灯）只落在真实光源上，此时选 B3 等彩色方案，不只用 B1 黑白。
- **幽默**：来自揭示之后人物古怪、克制的反应和喜剧停顿，不加恐怖事件。
- **不复制**：不做剪刀手、白脸黑眼圈、条纹西装鬼魂等具体电影角色造型。
- 低成本单次样片的写法见 `references/sample-mode.md`。

## 运镜规则

**景别**：宽景建立怪诞空间 → 中景展示姿态 → 近景或特写捕捉眼睛与表情反应。避免大量中景平均覆盖。

**机位与焦段建议**
- 略低机位让建筑、门框高耸；需要渺小感时用高位俯视，让角色落在图案地面中心。
- 讲述童话的段落用正面平视居中。
- 建议广角 18–25mm 等效拉长透视用于空间与揭示；反应近景约 40–50mm 等效，减少畸变以便看清表情。

**运动**
- 揭示运动：起点 = 遮挡物、剪影或局部细节（门缝、栏杆、树枝、影子）；终点 = 完整怪诞空间或关键物体入画；速度 = 缓慢平稳的推进、横移或升降，约 3–6 秒；动机 = 角色的好奇心或视线。
- 穿越开场：机位穿过铁门、树林、窗户进入空间，像翻开故事书，只用于场景开端。
- 反应镜头基本固定，不运动，让表情本身成为笑点或惊惧点。
- 少用手持；需要不安时用缓慢倾斜（荷兰角逐渐加大）而非晃动。

## 剪辑规则

**镜头时长分配（建议）**：建立/揭示镜 4–7 秒；反应镜 1.5–3 秒；喜剧停顿在反应后额外留 0.5–1 秒。

**切点**
- 揭示运动到达终点后再停约 0.5 秒，然后切到角色反应。
- 反应镜在眼神或表情达到峰值后切回所见之物或下一节拍。

**衔接**
- 视线三段式：角色看 → 所见之物 → 角色反应，是本分支的基本单元。
- 形状匹配：圆形（月亮、钟面、眼睛、盘子）或竖长形（尖顶、烛台、人影）跨镜呼应，用于场景转换。
- 剪影衔接：上一镜剪影离开画面，下一镜从剪影或阴影中开始。

**转场**：以硬切为主；童话段落可克制地使用虹膜（圆形收放）或叠化，一个短片不超过 1–2 次；黑场用于章节感。

**节奏递进**：前段慢揭示累积好奇；中段"揭示—反应"对子频率加快；高潮或结尾用一个最奇异、最完整的空间全景收住，并给最后的反应留足停顿。

## 声画同步规则

- 音乐质感像童话讲述：钢片琴、童声或女声合唱、3/4 拍华尔兹、管风琴、低音管（参考作品中长期合作者丹尼·艾夫曼的配乐质感），按用户版权要求选择原创或授权音乐。
- 音效夸张而清晰：门轴吱呀、钟摆、风声、木地板响，每个空间有一个标志性声音。
- 揭示运动的终点对齐音乐乐句结尾或一个乐器的进入。
- 反应镜头留半拍静默或一个滑稽音效，笑点在声音停住时落地。
- 关键物件（B3 的强调色物件，或用户要求局部色时的那件物件）第一次出现时配一个独特音色动机，之后每次出现重复它。
- 对白按原文，不为风格改词；对白期间音乐让位到低音量。

## 提示词写法

分三层写，导演名不能代替具体描述：

- **图像提示词（静态）**：风格转译关键词（表现主义布景、手工质感）+ 本镜构图 + 空间 + 光线 + 按所选方案写的颜色角色（背景主色、阴影、光源高光、小面积强调、肤色保护）+ 材质。
- **视频提示词（单镜）**：起始画面 → 结束画面、剧本中的角色动作、运镜方向和速度、本镜光色、声音（模型支持时）。
- **剪辑说明**：揭示与反应的切点、形状匹配、虹膜或黑场转场单独写，不塞进视频提示词。

示例（B1 方案）：
- 图像："黑白画面，表现主义室内，门框略微倾斜、走廊被拉长；中灰墙面为背景，深黑阴影占据画面两侧，硬侧光在墙上投出夸张人影，边缘光勾出门框；桌上的小物落在吊灯唯一一束白光里，是画面中最亮的元素；画面纯灰阶，无任何彩色；人物原本肤色的深浅保留为对应的灰度层次。不要把色卡上的色块、文字或排版画进画面，不复制任何电影角色或场景。"
- 视频："起始画面是门缝里一道细长白光，镜头缓慢推进约4秒，门被推开后停在高窄门框中完整的人物剪影；木地板吱呀声，钢片琴单音在镜头停住时落下。"
- 剪辑说明："剪影立定后停 0.5 秒切到屋内揭示镜；屋内揭示到位后再切人物反应。"

## 工具限制与替代

- 揭示推进、穿越式运镜：优先在视频生成中描述起点与终点；若穿越失败，拆成"门外 → 门内"两镜，用剪影遮挡切连接。
- 局部色彩（仅当用户明确要求局部色改编时）：若生成结果无法稳定保留单色，可在剪辑调色中对真实生成画面做局部保色，并在交付说明中写明是后期处理。
- 虹膜转场为剪辑转场，不是镜头内效果。
- 黑白：实测 H3 按 B1 生成时输出的是带残留色的去饱和画面，不是纯灰阶。需要纯黑白时在剪辑中对真实画面去色，并在交付中注明是后期处理。
- 状态变化（门合拢、灯熄灭）在单次多镜头生成中容易丢失：全片只安排一处，放在结尾镜，结尾镜不短于 2 秒。

## 自检清单

- [ ] 至少一个剪影可读的镜头；有明确的两世界或单一色彩策略。
- [ ] 每个揭示都有遮挡起点、空间终点和角色动机，随后接反应。
- [ ] 没有为风格加入剧本之外的骷髅、怪物或事件。
- [ ] 揭示终点与音乐乐句或音色动机对齐，反应留停顿。
- [ ] 只用所选的一个配色方案（B1/B2/B3）；黑白方案没有套用彩色色卡；图像提示词、视频提示词与剪辑说明分开写。
