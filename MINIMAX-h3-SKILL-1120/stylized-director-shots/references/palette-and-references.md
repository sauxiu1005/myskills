# 配色方案与参考素材使用规则（所有分支共用）

## 1. 选配色方案

导演确定后，读取该导演的 `assets/palettes/<导演>/schemes.json`，按剧情从 2–3 个方案中选**一个**：

| 导演 | 方案文件 | 方案 |
|---|---|---|
| 蒂姆·伯顿 | `assets/palettes/burton/schemes.json` | B1 科学怪狗黑白 / B2 剪刀手爱德华粉彩与哥特 / B3 阴间大法师2彩色怪诞 |
| 丹尼斯·维伦纽瓦 | `assets/palettes/villeneuve/schemes.json` | V1 降临雾灰 / V2 沙丘2沙金 / V3 宿敌黄雾 |
| 扎克·施奈德 | `assets/palettes/snyder/schemes.json` | S1 300日景暖铜红 / S2 300夜景冷钢蓝 |
| 埃德加·赖特 | `assets/palettes/wright/schemes.json` | W1 日常动作原色强调 / W2 Soho钠灯霓虹 / W3 Soho当代灰冷 |

- 依据每个方案的 `fits`（适合的剧情）和 `avoid`（不适合的剧情），对照剧本的时间、地点、光源和情绪来选择。
- 在镜头表前用一句话说明选了哪个方案、为什么选；用户已经指定方案时直接沿用。不为配色单独增加确认轮次。
- 方案互斥：不把同一位导演的几个方案或不同导演的颜色混成一张通用滤镜。剧本中确实出现日夜或两个世界的切换时，可以按场次切换到同一导演的另一个方案，并在镜头表里逐场写明。
- 人工预览：`assets/palettes/<导演>/preview.png` 或 `preview.svg`。

## 2. 颜色怎么写

提示词按色彩角色描述，不堆 HEX：

- **背景主色**：大面积环境（天空、墙、地面、雾）是什么颜色和明度。
- **阴影**：暗部偏什么色、压得多深。
- **光源与高光**：光来自哪里（窗、天光、钠灯、逆光），高光是什么颜色。
- **小面积强调色**：只能落在剧本里已有的物件或真实光源上；方案写"不设色"时就不加。B1 黑白方案默认纯灰阶；用户明确要求"黑白+局部色"改编时，才用文字说明哪个物件保留颜色，色卡不变。
- **肤色保护**：保留每个角色原本的肤色（以人物参考或剧本设定为准），环境色只影响光照方向与明暗，不把肤色染偏，也不把不同肤色统一成某个色值。方案不为肤色提供 HEX，色卡中也没有肤色色块；黑白方案中把原本肤色的深浅保留为对应灰度。

HEX 只在调色说明或剪辑调色备注里作为参考值出现。`schemes.json` 中每个色值都标注了来源性质，引用时保留这些标注，不要把它们说成从影片提取的数值：

- `user_real_palette_unverified`：用户截图取色，方法未核实
- `user_design_suggestion`：用户设计建议
- `sampled_from_user_still`：本技能对单帧截图的取样，只代表这一帧
- `manual_suggestion`：人工建议色值

面积比例都是建议值，不是官方 LUT 或全片统计。

## 3. 参考素材分工

| 素材 | 只负责 | 不负责 |
|---|---|---|
| 方案色卡 `<ID>-card.png`（无文字） | 影调、光色、色彩角色 | 构图、机位、人物、场景内容 |
| 人物参考（用户提供或已生成的角色图） | 人物身份、外观、服装 | 颜色基调、构图 |
| 场景/构图参考（用户提供或已生成的场景图） | 空间、布局、构图 | 人物身份 |
| 分镜/镜头表 | 运动、动作、剪辑节奏 | 颜色 |

- **强制**：每次生成都把所选方案的 `<ID>-card.png` 作为第 1 张参考图上传，写明它只用来控制颜色，同时按第 2 节用文字写颜色角色。模型不接受图像参考时停下告诉用户，经用户明确同意才改为纯文字，并在交付说明中注明。细则与提交前核对见 SKILL 的 STEP 5。
- 每次使用色卡都附上这句：**"不要把色卡上的色块、文字、编号或排版画进画面；色卡只控制影调与光色，不决定构图、机位、人物或场景；不复制任何电影角色、服装、道具或场景。"**
- 用户资料里的影调色卡（`assets/user-sources/*/影调色卡.png`、`palette_card.svg`）带标题和文字，只作为来源存档，不上传给生成。
- `assets/stills/` 下的电影截图只作影调研究，默认不作为生成参考图上传，见 `assets/stills/STILLS.md`。

## 4. 提示词分层

- **图像提示词**：只写静态画面，包括主体与姿态、构图与景别、空间、光线与色彩角色、材质。不写运镜和剪辑。
- **视频提示词**：一条只对应一个镜头，写起始画面 → 结束画面、主体动作、镜头运动的方向和速度、本镜的光色、本镜声音（模型支持时）。
- **剪辑说明**：切点、衔接、转场、变速、声音桥、调色统一在剪辑说明中单独描述。不要把多个镜头的组接写进一条视频提示词，冒充一个镜头内的运镜。

## 5. 不采用的内容

用户资料中提到的模型名称、版本、参数与"权重/优先级"写法都未经核实，不作为执行依据。具体审阅结论见 `assets/user-sources/villeneuve/SOURCE-NOTES.md` 与 `assets/user-sources/burton/SOURCE-NOTES.md`；施奈德、赖特的资料见 `assets/palettes/snyder/NOTES.md` 与 `assets/palettes/wright/NOTES.md`。
