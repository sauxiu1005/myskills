# 风格化导演镜头

当用户希望用某位导演的视听语言来执行一段已有或简短描述的剧情时使用：先从导演库中确定一位导演（目前收录四位导演，可按分支继续扩充），再按该分支的画面、运镜、剪辑和声画规则，把剧情转成可执行镜头表与生成提示词；每位导演配有 2–3 套按代表作整理的配色方案和对应的无文字色卡，每次生成都把所选色卡作为第 1 张参考图上传，让影调不只靠文字描述。用户要求实际制作时再生成素材并剪辑成片。

本 Skill 只改变"怎么拍、怎么剪、怎么听"，不改变"发生了什么"。每位导演对应一个分支，各分支是基于具体作品的创作转译，不是导演全部作品的固定公式；文中的焦段、秒数、速度百分比都是为本任务给出的执行建议，不是导演本人的规定。

## 不可越界的原则

- **剧本优先**：用户已有的剧本、角色、台词、事件顺序与因果全部保留。不增删台词、不新增角色、不改结局、不为了风格加入剧情事件（例如伯顿分支不自行加入骷髅或怪物，施奈德分支不自行加入打斗）。风格只能作用在构图、色彩、光线、空间、材质、景别、机位、运动、剪辑、声音上。剧本没写明的细节（物件是什么、房间什么样）可以做视觉设计，但不能让它改变剧情含义；必须设计时在镜头表"备注"中标明是视觉补充。
- **一次一位导演**：不默认混搭。用户明确要求混合时，先说明混搭不是本 Skill 默认路径，并请用户指定以哪一位为主导、另一位只影响哪一个维度，得到回答后再继续。
- **如实说明工具能力**：生成工具做不到的运镜或变速要直说，并给出可行替代；不得把静帧缩放、平移冒称为真实摄影机运动。
- **只要方案就只给方案**：用户只要镜头表或提示词时不生成任何收费素材。
- **获准时才设计角色**：用户指定的角色、服装、道具和场景全部保留。只有用户没有指定或同意由你设计时，才按所选分支的"角色与场景造型"设计原创成年角色、道具与场景；不复制电影角色、演员的脸或标志性服装。

## STEP 0：确定导演（选择闸门）

按顺序判断：

1. 本轮消息明确点名了菜单中的某位导演（中文名、英文名、常见简称或分支编号均可）→ 直接进入 STEP 1，**不再确认**。
2. 本轮未点名，但当前对话或项目上下文中用户已经选定且未改口 → 沿用该选择直接进入 STEP 1，**不重复询问**。
3. 用户点名的导演尚未收录（包括已单独制作过的韦斯·安德森），或在选择框中选了"其他导演" → 按 `references/custom-director.md` 走临时分支：确认导演与作品，用用户截图和网络剧照分析风格，取色生成色卡，把风格卡交用户确认后再进入 STEP 1。只选了"其他导演"但没写名字时，先问是哪一位导演。不凭空编写风格。
4. 以上都不满足 → 用选择框让用户选导演（单选，每位导演一个选项，最后一项是"其他导演"），然后**停下等待用户选择**，此前不写镜头表、不读取任何分支文件、不生成素材。用户也可以在选择框里直接输入导演名字。

菜单（作为选择框的选项：选项标题用"导演｜风格名"，选项说明用该条的画面、运镜、剪辑概述，可适当精简；界面不支持选择框时，才原样以文字展示菜单，并附一句"回复编号或名字即可"）：

1. **蒂姆·伯顿｜哥特童话**——画面：表现主义剪影、倾斜怪诞空间、黑白或去饱和中只留叙事物件的局部色彩；运镜：从遮挡缓慢揭示空间后定在角色反应上；剪辑："揭示—反应"成对推进，给表情留喜剧停顿。
2. **丹尼斯·维伦纽瓦｜巨构与静压**——画面：人物在巨大几何环境与负空间中显得渺小；运镜：有动机的缓慢推进与遮挡揭示，静止多于运动；剪辑：动作完成后多停留一拍，用提前进入的低频声音桥制造压力。
3. **扎克·施奈德｜英雄造型与速度变化**——画面：低机位、逆光下的图像化姿态帧；运镜：沿清晰屏幕方向跟随动作；剪辑：常速—慢速—恢复的变速，在冲击帧上切换。
4. **埃德加·赖特｜动作匹配与节奏快剪**——画面：物件大特写与对称冷面构图；运镜：快速推进与甩镜；剪辑：由动作接触点和声音瞬态驱动的短组接，随后停在反应上。
5. **其他导演｜分析风格并生成色卡**——输入你想要的导演，先分析其代表作剧照的画面、运镜、剪辑与声音，取色生成专属色卡，确认风格卡后再出镜头表。

## STEP 1：锁定剧本事实

阅读用户提供的剧本、分镜、故事描述或项目中被本次请求引用的素材，整理一份"不可改清单"（可在输出中折叠呈现）：

- 角色及其外观设定、台词原文（逐字）、事件顺序、因果关系、场景地点、时间。
- 交付规格：用途、画幅、总时长、分辨率、平台。导演确定后，用户消息和上下文里没有给出的画幅、总时长、分辨率，用一个询问框一次问齐，不在聊天里逐项追问，也不等写完镜头表再问：
  - 每项单选，推荐项排第一并标"（推荐）"，用户可自行输入其他值；已经给出的项不再问。
  - 画幅：16:9、9:16、1:1、2.39:1 宽银幕，按用途推荐（横屏影视默认 16:9，竖屏平台推荐 9:16）。
  - 总时长：按剧情的动作量给 3–4 个档位（例如 10 / 15 / 30 / 60 秒），推荐能完整容纳剧情且不注水的那一档。
  - 分辨率：只列所用视频模型实际支持的档位（MiniMax H3 为 768p 与 2k，2k 积分更高），低成本样片推荐最低档；需要 1080p 交付时注明是剪辑中放大。只要方案时也一并询问，并注明"仅在生成时生效"。
  - 询问框发出后停下等待回答；用户选择后不再重复确认。
- 用户只给一句动作时，同样按原句锁定，不扩写成新情节。
- 用户要快速测试、对照样片或积分有限时，另读 `references/sample-mode.md`：每位导演一次 10 秒生成，一个简单动作目标、一个视觉高潮、一个明确结尾，内部 3–4 镜。

## STEP 2：读取所选分支

只读取所选导演的分支文件，不读其他分支：

- 蒂姆·伯顿 → `references/tim-burton.md`
- 丹尼斯·维伦纽瓦 → `references/denis-villeneuve.md`
- 扎克·施奈德 → `references/zack-snyder.md`
- 埃德加·赖特 → `references/edgar-wright.md`
- 其他导演 → 按 `references/custom-director.md` 生成并经用户确认的临时分支，以及项目中 `custom-directors/<导演英文名>/schemes.json`

每份分支包含：视觉参考作品、"不是什么"、画面规则（含该导演的 2–3 个配色方案）、运镜规则、剪辑规则、声画同步规则、提示词写法、工具替代方案和自检清单。同时读取共用规则 `references/palette-and-references.md`。把剧本的每个节拍映射到分支规则上，先定整段的节奏递进（哪里累积、哪里释放），再拆镜头。

**选配色方案**：导演确定后，读取 `assets/palettes/<导演>/schemes.json`，按剧情的时间、地点、光源和情绪，对照每个方案的"适合/不适合"选一个，在镜头表前用一句话说明选择和理由。用户已指定方案就直接沿用，不为配色单独增加确认轮次。方案之间互斥，不混成通用滤镜；剧本确有日夜或两个世界切换时，可按场次换用同一导演的另一方案并逐场写明。

## STEP 3：输出镜头表

默认输出一张镜头表，每镜包含以下字段（字段名可按用户语言调整，但不得缺项）：

| 字段 | 要求 |
|---|---|
| 镜号 / 剧本节拍 | 对应不可改清单中的哪一句动作或台词 |
| 时长 | 秒数，合计等于目标总时长 |
| 画面 | 构图、光线、空间、材质，以及按所选方案写的色彩角色（背景主色、阴影、光源高光、小面积强调色、肤色保护——保留角色原本肤色），不堆 HEX |
| 景别 / 机位 / 焦段建议 | 景别、机位高度与角度、建议焦段（注明为建议） |
| 运镜 | 起点画面 → 终点画面、速度、动机；静止镜头写"固定"及理由 |
| 切点 | 在哪个动作、视线、声音或运动到达的瞬间切出 |
| 下镜衔接 | 动作匹配 / 视线匹配 / 形状匹配 / 声音桥 / 方向一致等 |
| 声音 | 对白（原文）、音效、音乐、静默，以及与画面的同步点 |
| 图像提示词 | 只写静态画面：主体与姿态、构图景别、空间、光线与色彩角色、材质；不写运镜和剪辑。默认中文 |
| 视频提示词 | 镜头表中逐镜写，只对应这一个镜头（生成时按 STEP 5 的分段规则合并为分段提示词）：起始画面 → 结束画面、主体动作、运镜方向与速度、本镜光色、声音（模型支持时）。默认中文 |

镜头表前写一句所选配色方案及理由。镜头表后附：剪辑说明（切点、衔接、转场、变速、声音桥、调色统一，不塞进单镜视频提示词）、整体节奏说明（3–5 句）、声音总设计（一段）、对剧本的保留说明（列出哪些台词与事件原样保留）。用户只要提示词或只要分镜时，按其要求精简，但运镜起终点和切点不得省略。

## STEP 4：交付前自检

逐条确认后再交付；不通过就改，不向用户报告"自检通过"之外的流程细节：

- 台词、角色、事件顺序与因果与不可改清单一致；没有新增剧情事件。
- 时长数值逐镜求和：每镜写确定数值（如 1.5s），不用"1s+""约""左右"等模糊时长；逐项相加后与目标总时长一致，并在镜头表后写出求和算式。
- 动作连续性：剧本动作按时间单向推进，相邻镜头的人物位置、朝向、持物状态、门窗与道具状态前后一致；快剪分解只拆同一次动作的连续步骤，不倒放、不重复已完成的动作，除非剧本本身要求；光影变化需有可见的真实光源或遮挡来源，不暗示剧本之外的事件。
- 每个镜头都写了运镜起终点和切点；没有出现"有张力的镜头""电影感运镜"这类空词。
- 符合所选分支的"不是什么"清单（例如维伦纽瓦不是每镜慢远景、施奈德慢速不超过分支比例、赖特每个切点都有触发依据）。
- 全片只用一个配色方案（或按场次明确切换同一导演的方案）；强调色只落在剧本已有的物件或真实光源上；黑白方案没有套用彩色色卡。
- 图像提示词没有运镜；镜头表中的视频提示词逐镜描述，合并生成时按【镜头N】分段写清每镜时长与切点；镜头之间的剪辑处理写在剪辑说明里。
- 没有把用户资料中的建议色值或人工建议色值说成从影片提取的数值。
- 没有混入其他导演的标志手法。
- 多位导演对照时，各版在人物轮廓、空间几何、光色、运镜和节奏上都有区别，遮住导演名字也能分辨；首帧焦点明确，每镜内容有变化（见 `references/sample-mode.md`）。
- 没有占位文字。

## STEP 5：实际制作（仅当用户要求生成）

1. **模型与能力**：视频模型默认 MiniMax H3；用户明确指定其他模型时以用户为准。调用前核实该模型当前可用，确认画幅、时长范围、分辨率选项、是否支持参考图、首尾帧、原生音频。H3（或用户指定的模型）不可用时告诉用户并等待，不静默换模型。把每个镜头的运镜和变速与能力对照，逐项标注"可在生成中实现 / 需剪辑实现 / 需替代"；写进提示词的内部切换、变速和声音都只是生成目标，验收前不能当作结果。
2. **生成分段**：生成几段由"总时长 ÷ 模型单次时长上限"和内容分组决定，不按镜头数决定；镜头数不等于生成次数。
   - 默认用最少的生成次数：总时长不超过模型单次上限时只生成一次，在一条提示词里按【镜头N】分段写出全部镜头（结构见 `references/sample-mode.md` 第 4 节）。
   - 只有总时长超出单次上限，或用户需要单独控制、单独重做某一段时，才按内容分段，并且尽量少分：把情绪或空间连贯的镜头放在同一段（例如开场尺度镜一段、近景到特写的连续情绪一段、结尾揭示一段），不一镜一段。
   - 分段生成时，各段之间的人物与场景一致性靠参考图维持；一次生成则通常不需要额外的人物参考图。
   - 每段时长按内容分配，并落在模型支持的时长范围内；在方案中写明段数、每段包含的镜头、每段时长和理由，交用户确认。
   - 已知风险：模型可能吞掉 1.5 秒左右的极短镜头，合并生成时极短镜不短于 2 秒，必要时在剪辑中补救。
   - **低成本样片**（属于上面第 1 项的默认参数）：用户未另行指定时，每位导演只生成一次，10 秒、满足测试的最低分辨率（H3 为 768p）、16:9、候选数 1；不拆镜提交、不多候选、不追加收费参考图、不自动重试；所选方案色卡照常作为第 1 张参考上传（不收费）。提交前记录参数和平台预估积分；报价或参数与方案不符时停下报告。此模式下一条请求描述 3–4 个内部镜头。
3. **替代原则**：
   - 镜头内运镜做不到时，可拆成两段真实生成镜头再剪接、改用固定机位加演员调度、或在剪辑中做真实的时间重映射；
   - 静帧缩放（推拉平移一张图片）只能在用户接受时使用，并在镜头表和交付说明中明确写成"静帧缩放"，不得称为推镜或运镜；
   - 慢动作由剪辑插帧实现时说明可能出现伪影；甩镜转场由剪辑实现时写明是"剪辑转场"。
4. **确认后批量生成**：把镜头表、能力对照、生成段数与每段时长交用户确认（费用确认由平台完成）。需要参考图时先批量生成全部参考图，再批量生成全部视频段，不交替进行。保持同一角色、服装、道具在各镜之间一致，使用已生成参考图作为后续输入。
   - **参考素材分工**：方案色卡只控制影调、光色与色彩角色；人物参考锁定身份与服装；场景/构图参考锁定空间；镜头表控制运动与剪辑。
   - **色卡强制参考**：每一次视频或图像生成都必须把所选方案的无文字色卡 `assets/palettes/<导演>/<方案ID>-card.png` 作为参考图上传，排在参考列表第 1 位（@图片1），其后才是人物、场景参考；只用文字描述颜色不能代替色卡。提示词中写明 @图片1 是色卡，并附："不要把色卡上的色块、文字、编号或排版画进画面；色卡只控制影调与光色，不决定构图、机位、人物或场景；不复制任何电影角色、服装、道具或场景。"同时仍按色彩角色用文字写颜色。
   - 色卡含多个可选强调色（例如 W1）时照样上传，在提示词里写明本片只用哪一个强调色、落在哪个物件上。
   - 所选模型或模式不接受图像参考时，停下告诉用户，推荐可接受参考图的模型或模式；只有用户明确同意，才改为纯文字描述颜色，并在交付说明中注明"本次未参考色卡"。
   - **提交前核对**（每次生成前逐项确认，任一项不满足就不提交）：本会话已读取所选分支文件、`references/palette-and-references.md` 与该导演的 `schemes.json`；参考列表第 1 位是所选方案色卡；提示词含色卡说明与负面约束。在方案与交付说明中列出实际上传的参考图及各自职责。
   - 带文字的用户色卡和 `assets/stills/` 下的电影截图只作研究与出处存档，不作为生成参考图上传，也不当作生成成品。
5. **剪辑成片**：按镜头表时长与切点组接，按声画规则铺对白、音效、音乐；交付成片以及可编辑产物（时间线说明或剪辑工程、镜头素材清单、字幕/音频分轨中平台可提供的部分）。需要编写程序完成的剪辑与工程文件交由编程子任务执行。
6. **失败处理**：生成失败或结果不符时如实报告是哪一镜、哪条规则未实现，给出修改提示词或替代方案，经用户同意后再重生成，不自行反复重试。

## 扩充导演

导演库通过新增分支扩充，上面的流程不变。新增一位导演时：

1. 新建 `references/<director-name>.md`，章节与现有分支一致：参考作品、它不是什么、画面规则（含 2–3 个配色方案）、运镜、剪辑、声画同步、角色与场景造型、提示词写法、工具替代与自检。
2. 新增 `assets/palettes/<director>/schemes.json` 与无文字方案色卡，用 `scripts/render_palette_cards.py` 生成。由临时分支转正时，复用其剧照取样（`scripts/sample_stills.py`）和已确认的方案。
3. 在 `SKILL.md` 与 `SKILL.cn.md` 的 STEP 0 菜单加一条（画面 / 运镜 / 剪辑各一句），在 STEP 2 加分支路径，并补触发词；同步更新 description 与 `meta.yaml` 中的导演名单，升级版本号。
4. 新分支与已有分支在轮廓、空间、光色、运镜和节奏上都要能区分。

## 交付说明

简述：所选导演与参考作品、所选配色方案、整体节奏思路、剧本保留情况、哪些运镜/变速需要替代以及替代方式。成果保存在项目中时引导用户查看对应作品，不在聊天中重抄全表，除非用户要求。
