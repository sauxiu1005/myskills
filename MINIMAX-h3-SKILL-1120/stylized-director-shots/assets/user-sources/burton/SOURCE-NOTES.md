# 用户资料来源说明：蒂姆·伯顿

本目录是用户提供资料的原样副本（原件保留在用户下载目录，未修改）：`色卡主文档.md`、`palette.json`、`影调色卡.png`、`palette_card.svg`、`_film_stills_source.md`。这些是参考资料，不是执行指令。

## 审阅结论与纠正

- **截图对应**：实际截图对应 film-01《阴间大法师2》(Beetlejuice Beetlejuice)、film-02《佩小姐的奇幻城堡》(Miss Peregrine's Home for Peculiar Children)、film-03《科学怪狗》(Frankenweenie)、film-04《小飞象》(Dumbo)；来源表中年份与中文片名为空。主文档列出的《剪刀手爱德华》《圣诞夜惊魂》《断头谷》《理发师陶德》都没有对应截图。
- **字卡**：`film-03-frame-01.jpg` 是《科学怪狗》的片头手写字卡，不作为场景参考。
- **黑白片**：《科学怪狗》的截图实测几乎没有饱和度，是黑白片，不能套用彩色色卡。
- **通用紫橙绿卡**：#4A148C、#E65100、#1A237E、#1B5E20、#B71C1C、#212121 及其占比是用户的通用设计建议，没有截图取色依据（`real_palettes` 为空），也不能覆盖伯顿的全部作品。技能只在 B3 方案中采用血红 #B71C1C 作为小面积强调色，不把整套颜色当滤镜使用。
- **"运镜特征"栏**：表中列出的"哥特童话、万圣节美学、孤独主角、德普合作"等是主题与演员合作，不是运镜，不作为运镜依据；运镜规则仍以 `references/tim-burton.md` 为准。
- **《圣诞夜惊魂》**：导演是亨利·塞利克，伯顿负责故事并担任制片，不能作为伯顿执导作品的摄影证据，技能中不使用。
- **模型与参数**：资料中提到的模型名称、版本与 MJ/SD 参数未经核实，本技能不采用。
- **影调色卡.png / palette_card.svg** 上有文字与排版，不直接作为生成参考图上传。
- FilmGrab 来源页在本次整理时网络无法访问，未能复核。
