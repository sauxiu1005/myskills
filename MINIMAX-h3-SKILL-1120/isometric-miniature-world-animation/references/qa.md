# 等轴动画验收

验收基于实际渲染和最终文件。先正常速度完整看一遍，再检查主要动作、文字出现、最密集帧与片尾；有声音时实际试听。没有播放/听审条件的项目标为未验证，不靠脚本存在或参数声明推断通过。

## 必查项

| 项目 | 验证方式与通过条件 |
| --- | --- |
| 投影 | 相机为正交；方向恒定；投影后的地面轴为±30°，三轴单位长度一致；远近同尺度。只看单个物体旋转不代表相机角度变化 |
| 场景语义 | 城市交通、办公室协作或机房数据流能从动作看懂；连接有来源与目的地；不是只有方块随机跳动 |
| 生长 | 底面固定，立面长起，顶盖落位；错峰和过冲不造成穿地、穿墙、瞬移或长期悬空 |
| 运动 | 速度/焦点有变化，过渡可读；运动包、车辆等沿路径连续；回拉不引入透视或旋转 |
| 文字 | 与用户原文逐项核对；真实字体无缺字；投影后仍易读；长句有阅读时间；无遗留 ISOPOLIS/案例数字/额外副题 |
| 遮挡 | 重要主体不被标签覆盖；DOM引线不会穿过应遮挡它的物体；平移和zoom后锚点仍对齐 |
| 材质 | 三面明暗可辨，AO不脏黑，阴影接地，窗格和细线不闪烁，辉光不吞字 |
| 环境与整片色彩 | 按 [环境风格](environment-style.md) 并排检查开场、生长、运行、片尾：浅色渐变和粉彩层级连贯；暗面可读，地形/楼群/水面分色；云与点阵不抢标题、不遮地标、不闪烁；无意外夜景、厚重黑影、灰雾或过曝。用户明确暗色选择优先 |
| 确定性 | 相同渲染环境、分辨率和采样设置下，直接渲染 t 与乱序渲染后回到 t 的帧一致；比较前后跳转，不只比较同一次顺播 |
| 输出 | ffprobe实测尺寸、fps、时长、编码与音轨；完整解码无错误；无意外空帧/裁切 |
| 声音 | 有声需求确有音轨；落点对齐、旁白可辨、头尾无突断；响度和真峰值报告实测；静音需求确实无声 |
| Design | 最终画布节点播放、暂停恢复、中段跳转和片尾通过；源码入口可访问并说明编辑范围 |

用模型轴或临时投影标尺做角度检查，正式成片移除测试标尺。注意抗锯齿与子像素采样可能造成像素级噪声，确定性比较先固定设备、GPU、字体与采样，不能跨机器要求字节完全相同。

## 文件检测示例

针对最终实际文件运行；工具不可用时记录未测，不编造数字：

```sh
ffprobe -v error -show_streams -show_format -of json video.mp4
ffmpeg -v error -i video.mp4 -f null -
ffmpeg -hide_banner -i video.mp4 -af loudnorm=I=-14:TP=-1:LRA=11:print_format=json -f null -
```

最后一条只用于有音轨文件的测量参考，读取输入响度/峰值，不将滤镜目标误报为实测结果。需要规范混音时可用测量后的两遍流程，编码后复测最终 AAC。

## 反馈格式

`编号 | 时间位置 | 观察到的现象 | 对观看的影响 | 修改建议 | 验证状态`

分清交付阻碍（错误文字、文件不可播、缺用户要求）、观看问题（遮挡、节奏不清）、可选美术改进。修复明确缺陷后重新检查相关区间和相邻衔接；不存在的问题不为了凑数而添加。可用1–5分辅助讨论，但不宣称行业认证或保证获奖；优先报告证据。

只创建本技能包时，检查结构、引用、许可证、源码快照完整性、描述与用户需求覆盖即可。不要把文档检查说成视频质量、声音、Design运行或画布播放已经通过。
