# 可变制作提示词

根据简报填写以下内容；花括号是待替换字段，正式执行前替换，不能把占位文字放进成片。用户未给的选择按 SKILL.md 默认值推断。此模板用于指导代码制作，不是交给视频模型的镜头提示词。

```text
你负责在当前 Design 项目制作一支等轴 2.5D 微缩世界动画，完成空间设计、动作、代码、文字与声音。

【输出】
主题：{用户创意}
观众与核心信息：{观众；需要看懂的一件事}
场景：{小城市/办公室切片/数据机房/自定义}
尺寸、帧率、时长：{宽×高；fps；秒}
声音：{静音/音乐音效/已有音乐/旁白需求}
必须出现的文字：{逐字列出；无则写无}
配色与素材：{用户选择及实际可访问素材}

【叙事】
把核心信息变成物体之间可见的行动和关系，先说明起点、变化、结果。
用建立空间、组件生长、系统运行、整体揭示组织节奏，按本次内容调整时长。
开场迅速出现视觉线索，中段有明确焦点，片尾保留足够阅读时间与细微活动。
小城市体现交通与连接，办公室体现装配与协作，机房体现请求、处理和反馈；不只给原城市换标题。

【必须保持的视觉机制】
Three.js 正交相机，方位角 45°、仰角约 35.264°，地面投影线与水平成 ±30°。
无透视灭点；远近同尺度；统一网格；三面明暗清楚；柔光、接触阴影和克制 AO。
相机方向固定，以平行滑轨和正交 zoom 展示空间，不能绕转成透视镜头。
组件从基底生长，底座、立面、顶盖错峰，伴随适度过冲、回弹与次级动作。
道路、家具、管线、数据包遵循场景空间。若用分层视差，物体和附属标签共同移动。

【背景环境与整片配色】
先读 references/environment-style.md，默认采用原案例日间粉彩风格，不启用 v5 夜景分支。
浅色渐变背景、少量白色圆润云团、低对比等轴点阵、浅色分层地台、薄荷绿地与粉彩主体，柔光和浅色补光保持暗面可读。
环境贯穿开场、生长、运行与片尾；主题适用时加入树簇、水面和轻微环境动作，云与装饰避开标题和关键地标。
可按用户选择改变色相，但不自动加入深蓝暮色、大面积灰棕山体、黑色投影或压暗边角；用户明确要求夜景时才覆盖默认。
将背景阶段、色彩角色和环境元素写入 brief.json.style.environment；检查 shader、材质、灯光、阴影和后期的实际生效参数。
并排检查各阶段的真实渲染与日间参考；整体明快、地形楼群分色、环境连续，不以只改背景或整体提曝光作为完成标准。

【文字】
按给定内容保留文字、标点、数字与品牌拼写。无文字时移除所有案例字标。
短招牌可贴在场景面；信息牌世界锚定并采用对应等轴面；长句和字幕保持清晰平排。
使用覆盖目标语言的合法字体，等待字体加载，核对实际渲染字形与投影后边界。
不添加未要求的英文、副题、署名或无依据的性能指标。

【工程】
参考随技能附带的 demos/03-isometric 11 个文件，按源码地图复用投影、缓动、渲染和文字机制。
不要直接在技能目录改作品；将必要代码放到新的项目目录。
尺寸、文案、字体、颜色、种子与事件表可编辑；任何时刻画面均由 t 唯一确定。
提供 window.DEMO、异步 window.renderAt(t)，依赖全部就绪后才置 window.__ready=true。
先验证关键帧和低分辨率预览，再通过宿主允许的渲染能力逐帧输出。
声音与动作读同一事件表，缺失上游音频库时使用当前可用的合法声音路线并记录差异。

【检查与交付】
实际检查等轴角度、主体遮挡、中文字体、阅读时间、快动作、随机跳转一致性与文件参数。
交付 MP4、可编辑源码及依赖、创作简报、事件表、许可记录和有证据的验收结果。
使用 Design 的真实上传/画布入口，验证播放、暂停、跳转与片尾；平台不可访问时明确未验证步骤。
```

原始英文提示词见 [上游原文](../vendor/mg-styles-15/prompts/03-isometric.md)。它的固定十秒、案例品牌、评分目标与创作假设不覆盖用户选择；投影冲突按本技能工程说明纠正。
