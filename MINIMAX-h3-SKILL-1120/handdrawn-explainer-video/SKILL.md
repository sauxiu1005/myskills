# 手绘讲解视频

交付可播放视频、封面、字幕与口播稿。画面由本包的 Python + FFmpeg 脚本确定性逐笔绘制与合成；生图、配音、转写使用当前执行环境提供的能力。运行环境、输入准备与文件交付见[渲染工作流](references/rendering-workflow.md)，制作前先读。

展示手部选择前，先运行 `python scripts/prepare_selection.py <jobDir>`，打开返回的项目内选择页，或展示其中下载的手部图片。七张原尺寸手部/画笔预设不随包分发，而是从固定 GitHub Release 地址按需下载，验证大小与 SHA-256 后缓存在技能目录外；画风参考图与预览仍随包提供。用户已明确手部时，渲染只下载所选预设。首次使用需联网，校验合格的缓存支持离线；不得直接打开未准备的包内选择页或在失败时替换手部。见[手部按需下载](references/hand-downloads.md)。

## 制作前必须展示画风与真人手部选择

先提取主题、正文和用户已明确的设置。先读[必选画风与真人手部](references/visual-selection.md)，展示包内真实画风预览及六款真人质感手部（作为可查看文件展示），不能只口头列名，更不能省略选择。没有主题才索要主题；已有设置不重复询问。

开始生成配音和图片前，一次性请用户选择以下尚未明确的项目，不预选、不设置超时默认：

| 项目 | 展示方式 |
|---|---|
| 视频语言 | 中文、英文或用户指定语言 |
| 时长 | 例如约30秒、约60秒，或用户指定；也可明确选择按内容决定 |
| 画幅与分辨率 | 横屏16:9、竖屏9:16、方形1:1，并明确分辨率；展示当前环境可完成的规格 |
| 画风 | 1–13 号共 13 种带真实预览的画风；也可接受用户描述或明确委托模型匹配。每种都带画风参考图，每张插画都把它作为画风参考传入 |
| 绘制工具 | 仅画笔，或选择具体预设手臂；按需展示真实素材 |
| 背景音乐 | 不添加、添加，或由用户提供音乐；选择添加时确认可用来源与音乐风格 |

可以用一张选择表或一次问答收集，允许用户一句话回答全部项目。未回答项保持待选择，不把沉默当作授权或自动沿用旧默认。等待时可整理已有内容、检查能力，不能开始依赖未选设置的素材生成。用户明确说“你来决定”时，只为其委托的项目选择并记录理由，无需再确认；不要将普通“继续”理解为全部委托。

设置完成后简短复述实际方案并制作，不增加批准环节。字幕保持单层，可按已选画面设计清晰排版；此版不提供笔杆广告、浮动水印、音色克隆和自定义手部生成。设置记录见[制作选择](references/production-options.md)。

## 制作流程

1. **准备环境、检查能力、确定脚本。** 先运行 `scripts/install_runtime.sh --check` 检查 Python 与 FFmpeg（使用已核验的可执行文件）；缺失时说明要安装的内容，征得用户同意后运行 `scripts/install_runtime.sh` 安装，详见[运行对接](references/rendering-workflow.md)。再执行环境准备脚本（已核验 FFmpeg + 独立虚拟环境），再按[运行环境](references/local-runtime.md)确认生图、完整配音、时间戳和合成能力，只报告实际缺失项。在当前项目下建立任务目录。写完整口播稿与分镜，例如30秒通常2—3个完整画面；以实测语速为准，不机械凑页数。改编保留原文条件和来源。写入 `design.json`，字段见[创作与分镜](references/story-design.md)。
2. **先锁定旁白。** 用 可用语音合成能力一次生成完整旁白（选真实音色），或复用用户认可的整篇音频，转成 WAV 母带。保留自然换气和句尾。用 带时间码转写取得实测时间戳并核对原稿后写入对齐文件，禁止估算后冒充实测。格式见[连续旁白](references/continuous-narration.md)。无配音能力时一次说明缺口并请求录音；不生成无声成片冒充完成。
3. **先代表图，再扩展。** 首次生图前读取[美术指导](dependencies/sweety-image-art-direction/GUIDE.md)，同一任务继续沿用；每张图只补本图简报和完整提示词，不反复加载未变化的指南。按[画风与绘制](references/style-and-drawing.md)准备计划并预检，调用 `art_direction.py bind-evidence` 自动绑定记录，再用 可用图像生成能力出图。先检查一张代表图的主体、接触关系和可分部位性，再批量生成其余图。图像清理使用 `clean_image.py`（处理任务目录内副本）。封面复用已审主视觉并以可编辑文字排版，通常无需另生一张图。
4. **按语音编排。** 看图标注真实部位和遮挡，整幅先描线再填色，两阶段顺序一致，断笔抬笔，颜色随笔刷出现。默认使用平缓笔触：只描主要轮廓并显示加粗铅笔草稿线，相连线条一笔画完、手部移动平滑，纹理随上色出现；用户明确要求逐线精细描绘时才改用 `detailed`。人物不能整块扫描或淡入。正文只写关键词，字幕承担完整口播。先规划整幅布局，底部字幕区域预留字幕高度及至少 24 像素间距，正文、标记和插画保持在其上方并留出可见间隙；build 会拒绝在字幕显示时侵入字幕区域的绘制内容。复杂度超过语音窗口时减少细节。准确字段和命令见[运行格式](references/runtime-contract.md)。
5. **短段检查、完整导出。** 先渲染包含文字、轮廓、填色和字幕的代表段，检查笔尖、手臂、遮挡与可读性；通过后整片只渲染一次。运行 `verify`，实际查看完成画面和各页运动片段，按[检查规则](references/quality-gates.md)记录证据，再 `finalize`。失败只修对应层，不重新生成未受影响的声音和图片。

## 交付与修订

把成片与封面作为项目文件交付并优先展示，附可编辑字幕与脚本；详细提示词和检查记录留在任务目录，交付文字简短。字幕放 `outputs/editing/`，避免播放器自动加载出第二层。按实际选择说明是否添加背景音乐，不使用固定的“默认无配乐”声明。未实际听音要明确“主观听感未验收”，不以工程检查代替听感结论。

修改画风只重做受影响插画、封面与绘制路径；修改字幕只重建相关层；母带不变就复用对齐结果。检查结果必须匹配当前文件，不自动填通过。所有任务资料写当前项目下的独立任务目录，不修改安装包、不自动发布。
