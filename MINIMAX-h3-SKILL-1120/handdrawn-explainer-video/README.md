# handdrawn-explainer-video（逐笔手绘讲解视频）

输入主题、文章或口播稿，生成带封面、旁白和字幕的手绘讲解视频。入口为 SKILL.md。

画风和真人手部必须展示真实预览并记录用户选择。六款真人质感手臂和13张画风预览及其画风参考图直接随包提供，未选择或选项不匹配时生产检查拒绝继续。制作前一次收集语言、时长、画幅与分辨率、画风、绘制工具和背景音乐选择；不预选、不超时默认，已有选择不重复询问。保留画风与预设手部选择、完整旁白、逐字与分部位绘制、字幕和成片检查。移除笔杆广告、水印、音色克隆、个人声音库、网页选择器和大型导演/动效依赖。

本包依赖宿主实际提供生图、配音和对齐能力；本地合成需要Python依赖、FFmpeg与字体，见 references/local-runtime.md；电脑缺 Python 或 FFmpeg 时用 scripts/install_runtime.sh 检查并安装（以检测结果为准）。未包含平台私有API适配器，目标平台导入与工具调度仍需平台内试运行。
