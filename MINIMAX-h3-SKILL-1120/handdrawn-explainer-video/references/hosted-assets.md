# 素材分发与校验

六款真人质感手臂与仅画笔原图不包含在压缩包中，按用户选择从固定 Release 地址下载到本机缓存，并按大小和 SHA-256 校验；联网失败或校验失败时明确报错，不使用替代图。全部画风预览与本包自有参考图随包提供，由 assets/local-manifest.json 按大小和 SHA-256 校验。生产原图与画风预览的来源及哈希记录见 hosted-manifest.json；预览图本地可用，选择和渲染选定手部需要联网或已有有效缓存。

手部是原版的真人质感图像预设，不宣称是真人实拍素材。六款都含可见手指与手腕/袖子；仅画笔为独立第七项，只能由用户明确选择。

库内少数画风配方仍可能要求额外参考锚点；按所选配方实际需要获取，不下载整个依赖库。缓存使用 HANDDRAW_ASSET_CACHE 或 ~/.cache/sweety-handdraw-video。
