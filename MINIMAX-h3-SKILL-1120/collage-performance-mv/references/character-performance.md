# 角色表演、视频素材与唇同步

> 执行规则：视频质量默认由用户查看确认，用户通过即可采用或完成交付。本文的视听核验、逐帧检查、质量阈值与自动修复方法仅供用户明确要求排查/测试时使用，不作为默认生成或继续制作的前置条件。制作参数、素材约束与文件交付步骤仍执行。

## 两条轨与三种角色功能

内部表演是嘴、下颌、眼神、头肩、躯干、手臂和衣发；外部贴图是整体位置、尺度、旋转、遮罩、队列和层级。两轨分开设计，共用时间轴。移动静态卡可以是图形设计，不能冒充内部演唱。

| 角色功能 | 动态要求 |
|---|---|
| 演唱/表演主唱 | 有声乐的视频镜头必须对上对应声部的真实唱词与嘴形，并有眼神、头肩和手势；不能用只跳舞、随机张嘴或整卡晃动替代 |
| 群体/伴舞 | 真实舞步、重心、躯干与手臂联动，具有连续衔接和队形变化；仅依次出现、复制排列或站定不算舞蹈。伴舞无需对口型，口型项记 not_applicable |
| 叙事贴图/档案/隐喻 | 可有意静止，以位置、数量、遮挡和文字表达关系；不能以此规避全部主唱口型 |

按本次音乐选择可穿插的表演亮点：主歌可用走步、转头、指向与情绪变化；副歌可用侧步—重心转换—躯干律动—手臂路线—转身—落定衔接。选择适合角色和模型能力的动作，不强求高难度或完整舞段；短动作可反复循环。主唱默认多用稳定的半身、中近景和面部演唱特写，优先表现清楚的口型、眼神、头肩律动与手势；只在少量舞蹈亮点安排清晰的中全景/全身，保留脚步和重心，不为展示完整舞步而扩大所有镜头景别。

performance-map 每镜记录 performer_id、role、source_mode、action_intent、preparation、accent、recovery、gaze、expression、secondary_motion、mouth_mode、cutout_motion、audio_range、clip_range、timeline_range。字段是本 Skill 约定，不是平台 API。

## 默认：视频模型制作内部表演

先完成标准角色卡与全片出镜规划，只为视频需求清单中的镜头用同身份干净单视角图生成短动作素材。人声分析只辅助选段，不能自动将所有有人声的区间变成视频任务；静态贴图区间不提交动作/唇同步任务。优先使用支持参考引导表演的 MiniMax H3；用户指定且能力相符的模型优先，先核对实际时长、参考输入与音频支持。首次视频生成前按入口文件询问720P/1080P，选定后同批小样/正式片/补片沿用；未选择不提交。模型做连续角色运动；版式、文字、数字、背景切换和拍点图形由合成控制。

提示明确固定/可控相机、完整动作范围、手脚边界、可分割背景、稳定光线、一段可读的演唱、动作或情绪片段（可留前后余量供剪辑），锁定身份/服装/饰物，无额外人物和文字。只需人物动作的片源默认均匀纯色棚底和固定/可控机位；仅分镜明确保留摄影棚背景时使用布景及适量跟拍。文字、拼贴、UI 与剪辑不得烘焙进模型片源。模型不保证透明视频，普通 RGB MP4 不能写成带 alpha。

> 以〔单视角/角色卡〕为身份服装参考，固定相机，〔半身动作/胸部以上演唱/面部口型特写；仅少量镜头用全身〕，背景〔已检查不与人物衣发/肤色/配饰冲突的均匀纯色无缝底〕，背景无渐变、纹理、道具、文字、地平线和明显投影，前景光线稳定、不染背景色，人物全动作不出框。轻微重心准备后双手抬起在胸前交叉，短暂强调，再展开并落回；看向镜头，头肩与手臂联动，袖子随动作变化。动作完整，不截手，不增加人物，不改脸或衣服，不生成字幕/图形，遵循〔场景限制〕。〔仅当工具支持：用指定歌曲区间驱动演唱〕。

优先选半身动作或面部演唱特写作为代表片段交用户查看（分镜确有需要时再补少量全身舞蹈），再按镜头表准备足够的不同表演素材；单个短片通过不代表全曲覆盖。片头尾留动作余量，时长遵循实际平台限制。复用非演唱动作循环时检查准备、回收和接缝；不要无目的地生成整曲长视频。

### 按目标景别生成清晰片源

为半身动作、演唱近景和面部特写分别准备足够清晰的单视角；卡片小格或全身图裁出的脸若像素不足，用图片模型补生成对应景别，保持身份和服装。面部特写保留完整嘴唇、下颌与眼神，手势不挡嘴；半身镜头为手臂运动留边距，避免在腕部/肘部生硬截断。视频提示要求主体清楚对焦、柔和稳定照明、皮肤自然、无附加胶片颗粒；不叠加强景深虚化、柔焦、磨皮或拖影。

全身动作限少量亮点，尽量让单人在源画面高度中占较大比例，同时留头发、手和脚的活动空间。按源人物裁切后的有效像素与最终显示像素安排合成，优先接近原生或缩小使用，避免把低清全身片放大成面部近景。若用户选720P，不自行改1080P；可缩小全身层、改用半身构图，或在确需更高原生分辨率时询问用户。不要以过度锐化或AI上采样承诺原本不存在的脸部细节。效果仍交用户确认，不自动追加清晰度评分或补片循环。

### 模型能力与表演边界

模型名称不保证音频驱动、人物动作或所选清晰度可用。执行前逐项核对能力，不能把历史测试当成本次能力证明。不可用时说明差异并确认支持同等输入的替代，不静默降档或升级。主唱动作、演唱近景、群体动作按用途拆短片，不让一个全身任务同时承担精确口型和复杂群舞。

固定摄影棚机位，背景与服装/发色可区分，手臂展开范围留足安全边距。群体需预留成员间隔；若计划分别抠出每人，避免交叉遮挡。输出后测量实际时长与 fps：请求时长可能与实际返回不同，输入音频短于视频时不要把尾部余量压缩成演唱加速。音频相关/偏移只证明声轨对齐，不证明嘴形。

检查全段的烧录文字、触边和成员粘连。意外字幕可在当前平台确有字幕消除能力时针对该素材修复；否则补片或不用该区间，不能原样进入人物层。触边段优先选干净入出点，或采用有设计依据的半身画框；不能把被裁手脚当完整人物放大。若干净动作不足，优先在现有授权和重试上限内补足/替换表演；允许用照片平移缩放、定格和短动作循环安排画面；按实际内容统计，保持全片人物真实表演片段累计至少60%。

### 纯色人物动作片源

仅供抠像的主唱/伴舞视频默认生成纯色背景，先检查干净单视角参考中的全部主体颜色（包括银饰、半透明袖口、鞋袜和快动作发丝），再选底色。浅色/白色服饰不默认白底；绿衣避绿底、蓝衣避蓝底。选不与主体重合且当前抠像工具可稳定处理的颜色，记录实际色值与选择理由，不为抠像改变已确认服装。白底适合主体轮廓与白色区分明显且分割小样通过的情况；不能把所有白像素全局删除。

用于生成的首帧/单视角图优先通过图片模型或可用编辑工具处理成同一纯色底，锁定原身份、衣服、饰物和细节；不要只在视频提示词里改底色却绑定复杂背景首帧。图片仍可由生图模型制作，纯色制作底不替代正式风格情绪板。

提示要求颜色均匀、无渐变/纹理/布景/道具/文字/可见地平线，背景无明显阴影与反光，主体照明自然稳定、无明显色溢，固定曝光，手脚与头发留动作边距。全身舞蹈允许无缝地面支撑；若出现接触阴影，抠像时另处理，最终纸片阴影由合成生成。背景稳定性也需动态检查，不能只看首帧。

用4–8秒代表段验证：绿/蓝等色底可先试色键并去色溢；白/灰或颜色重叠时用人物分割/精细matte，不做粗暴颜色删除。检查发丝、白衣、银饰、指缝、脚底、运动模糊和快速转身，在亮、暗及实际拼贴底上回放。若边缘缺损/闪烁明显，调整底色、参考首帧或抠像方案，只修失败片源；先通过小样再批量生成。没有真实透明输出时保存RGB视频和匹配的逐帧matte。

### 按构图需要抠像成为动态人物层

保留受控摄影棚背景的表演镜头不强制抠像。需要独立人物层时，用真实分割/抠像/色键工具得到人物 RGB 与逐帧 matte，或实际支持的透明格式。记录视频、mask、fps、尺寸、裁切区域及关联；mask 不得错帧。无 alpha 的 H.264 MP4 可配独立 matte，不能仅改扩展名。

在亮/暗及本片背景上回放：检查发丝、指缝、衣袖、半透明物、快动作、运动模糊、脚底；修色溢、闪烁、轮廓跳动、缺块。静态截图不能证明动态抠像合格。背景复杂无法分割时改素材方案，不把未经设计的矩形背景叫人物贴图。

独立演员层叠于背景之上，外部运动有入口/停留/强调/退出和固定锚点，手势与字词/进度条/物件关联。平面化、拼贴比例、图形阴影允许，未经设计的断肢/缺脸/错位不允许。

## 演唱口型依据真实音轨

锁定原始混音母版与真实唱词。**默认直接从母版截取已规划的演唱视频区间，保留人声和伴奏作为音频驱动，source_separation=none。** “提取含人声的区域”指按时间截取，绝不是去伴奏、做人声分离或消除乐器。不要为了背景音乐存在就先分离人声、强降噪或重新合成人声。成片保留唯一原混音主轨，模型输出声音静音。普通视频提示“正在唱歌”不等于当前歌曲的 lip-sync。

### 先确定出镜区间，再准备驱动音频

1. 先按全片分镜选择主唱视频出现的位置与表演内容，在主要唱段保留主唱存在感，并与平面人物、拼贴和已选择的伴舞贯穿交替。含人声不等于主唱必须视频出镜：静态照片/文字/伴舞镜头可覆盖部分唱段，纯音乐段可安排主唱舞蹈。全片至少60%的实际表演覆盖单独计算，不把人声长度当视频生成需求。
2. 为需要生成的选定镜头建立video-request清单，包含shot_id、performer_id、timeline_range、character_form、generation_needed、vocal_present、lip_sync_required、action_intent、source_audio_range；复用有效片源时记录实际映射，不重复生成。主唱声乐视频的lip_sync_required=true；伴舞无需对口型；主唱静态贴图不需要口型任务。
3. 演唱任务从唯一母版按精确源时间截取**原始混音**。优先在自然乐句附近留少量前后余量，防止截掉首辅音、换气或尾音；按接口最大时长调整。余量只是生成素材的上下文，不扩大全片选定视频的出镜区间，不因此把整段唱词都生成视频。不要拼接不连续唱词、删除中间停顿或自动压缩静音来缩短驱动音频。
4. 保持原速、原调和相同时间基准；必要时只做工具要求的格式/采样率转换，不改变混音比例或时长。保留源文件，导出尽量使用接口支持的高质量格式，避免多次有损转码。用于BPM的低采样单声道分析缓存不能当口型驱动文件。试听截取片段与母版对应区间，检查唱词清晰、起止未切字、无失真/爆音、时长正确；无法试听记未验证。
5. 记录master_audio_hash、source_audio_range、drive_audio_path、drive_duration、audio_transform、timeline_range、clip_range及工具返回的实际偏移。例：全片采用12–16秒，驱动混音取11.5–16.5秒；若已验证驱动0秒对应生成视频0秒，最终取片源0.5–4.5秒。有额外延迟则依据实测修正，不默认首帧即发声，不把余量视频从全片12秒直接开始播放。
6. 仅对清单中的演唱镜头提交原混音驱动小样，展示给用户；用户通过后扩展其他已规划视频。修改镜头时先更新清单及音轨映射，再补生成，不先把全曲生成出来再找用途。

默认不做人声分离。仅用户明确要求，或当前工具明确只接受干声且原混音无法使用时，才评估例外：说明限制并让用户选择保留原混音的其他可用路线或干声处理，不静默切换。用户提供的清晰干声也须与母版核对同一演唱、时长和偏移。分离仅用于转写分析时，将结果标为analysis_only，与驱动文件隔离；不能自动用它替换驱动音频。分离后的含混、金属音、吞字或断续不能视为“更干净”。

此项仅是主唱角色视频出镜的交付要求，伴舞视频无需唇同步，只验收节拍动作、队形与身份，不能只因模型支持动作就判通过。生成前给每个视频使用区间绑定演唱者、对应声部、真实音频裁切和全片入出点；重复唱词也须核对该次发音，不能直接复用另一处口型。只为已选定的主唱演唱视频安排对应真实唱段，其他声乐区间可以按分镜用静态拼贴呈现；生成后把对应原混音与视频一起提供给用户查看。纯音乐/器乐间奏与明确的非演唱角色记录例外理由；声乐段的主唱不得通过改成叙事镜头、背影、远景或遮嘴规避。

若已选动作模型无法用指定歌曲驱动准确口型，采用下列真实可用路线补做唇同步；若技术能力不可用则说明；已有可播放结果交用户判断，用户接受即可采用，不以缺少自动质量验证阻塞。不能把“唱歌”的提示词当验证，也不能静默改为全拼图来满足交付。

按实际能力选择：

1. **音频驱动角色视频**：确实支持给定音频和演唱语言/风格时输入按出镜规划精确裁切的原始混音（含伴奏）与角色参考，保存音频区间、工具、输出时长和偏移。不输出音素 cue 的工具如实记空，不能编造。
2. **动作视频 + 独立唇同步**：允许平台可用的 talking-head/lip-sync 模型处理同一演员视频，检查手势、表情、脸形和遮挡是否保留。只输出头部或破坏身体时改相容路线，不假装无损。
3. **代码嘴形**：真实字词/音素对齐加同角色 viseme。只有句级 ASR 时进一步对齐/人工校正，不能均分冒称精确。音量只调开口幅度，不决定音素；嘴贴片随头部自然融合。

保存 lip_sync_method、drive_audio_kind=original_mix_excerpt（例外注明依据）、source_separation、source_audio、source_range、clip_audio_offset、output_clip、tool_model、cues_if_available、confidence、review_evidence。区分 measured/manual/estimated/unverified。声学启发式、固定音节规则和节拍先验不是训练过的音素强制对齐；回读自己算出的 cue 不是独立准确性证据。

**允许短动作反复循环；有声乐的主唱片段在每次循环或重映射后仍需对上实际歌曲口型。** 默认片源时间 = 源入点 +（全片时间 − 全片入点），速度 1。外部贴图可以随节拍弹入/旋转，内部嘴形继续跟原音频；确需重映射时重新对齐并验证。片源自带声音默认静音，避免叠音。结尾仍演唱时，切到结尾卡不能使嘴形提前停止。

## 可选：用户明确只用代码

静态层/姿势/嘴形可生图；此模式禁用视频模型和 AI 视频唇同步。使用有限角度分层/网格/骨骼或 3D blendshape。关节补足遮挡纹理并留重叠，身体/头/手臂采用一致坐标与缩放，预缩放图层不可再次乘缩放；检查中性和极值动作、接缝、头发遮挡与锚点。

大幅写实抬臂出现硬切关节时改绑定/纹理或合理缩小幅度，不靠全片远景掩盖。准确称照片分层/风格化表演，不称写实生成舞蹈。能力不足说明限制，不擅自切回视频模型。

## 用户查看视频

默认按SKILL.md的用户验收规则执行。视频生成后提供预览、名称和版本，让用户判断口型、动作、人物身份与抠像效果；用户通过即采用，未回复不视为通过。可批量确认多个片段，不自动进行嘴形相关分析、负对照、盲测或多轮补片。

生成指导中的唱词绑定、原混音时间窗、动作构图和纯色背景规则仍需遵循。质量检查或修复仅在用户要求时开展；没有测过的逐字口型误差保持未测，用户通过单独记录，不伪造自动验收结果。
