# 标准情绪板与角色卡

> 执行规则：视频质量默认由用户查看确认，用户通过即可采用或完成交付。本文的视听核验、逐帧检查、质量阈值与自动修复方法仅供用户明确要求排查/测试时使用，不作为默认生成或继续制作的前置条件。制作参数、素材约束与文件交付步骤仍执行。

## 原参考与制作板

每次都执行制作板阶段，保存用户原图与生成板的对应关系。用户给海报、拼贴、服装照或单人照片时，提取色彩、材质、排版、场景/身份信息；不能将附件直接标成“情绪板/角色卡已完成”。已有合格标准板也要做项目检查、补缺与版本记录。

优先用平台图片生成/编辑工具补图，以代码或编辑器排清楚文字和网格。文字说明不能替代视觉板。用户人物优先于风格参考中的人物，不能因海报有另一张脸而换主角。

## 情绪板：多格视觉叙事 + 色带

原帖 photo/1 为 4 列 × 3 行视觉单元，下方一条名称和色值配色栏。本 Skill 默认参考该工作版式，不把它称为行业唯一标准；画幅可适配，但须覆盖：

| 内容 | 本次项目的要求 |
|---|---|
| 人物/群体 | 主唱面部演唱特写、半身动作和不同情绪，少量清晰全身舞蹈；用户选择需要伴舞/群体时给真实舞蹈及队形 |
| 场景 | 远中近空间、布景和光线；摄影棚限制写入相关格 |
| 物件与隐喻 | 与歌词/主题有关的实体道具、微距或尺度反差 |
| 文字与界面 | 标题、歌词字体层级，适合主题的标签/计数/界面 |
| 材质 | 纸、金属、布料、屏幕等可用于拼贴和转场的质感 |
| 运动意图 | 设计示例/箭头/短注解释舞步、重心、手臂路线、动作衔接及镜头景别；展示动态人物贴图、照片平移缩放、短动作循环及周边文字图形的配合 |
| 配色 | 底色、主色、强调色的名称、色值和用途 |

不同格承担不同任务，不能仅把一个人放进 12 个背景。颜色、人物、排版、物件来自当前创意，不照抄原帖工业黑橙和文案。制作说明不进入成片。

提示模板：

> 将〔风格参考〕和〔角色参考〕整理为《主题》MV 的完整制作情绪板。横向 4×3 视觉格加底部色带，以面部演唱特写、半身动作、少量全身舞蹈、适用的群体/队形、摄影棚空间与灯光为主体，保留主题物件、材质、平面拼贴、人物贴图及周边歌词图形示例。各格任务不同，统一色彩和光线。人物身份来自角色参考；海报人物不替换主唱。展示〔舞步/重心/手臂路线/表演衔接〕意图，图形不能抢走表演焦点。保留〔约束〕，不复制参考图姓名、二维码、署名或无关歌词。准确标注后期排版。

## 主唱卡：四向 + 表情 + 细节 + 信息栏

原帖 photo/2：上部正面、3/4、侧面、背面四个全身视图，右侧信息栏；下部四个表情近景、四个服饰/标志物特写。默认按此结构制作本次标准卡。

- 四视图脚底基线、比例、相机距离和中性背景统一，不切掉手脚；同一脸、体型、发型和服装。
- 四个表情按歌曲选择，默认中性、自信态度、演唱开口、强情绪。表情卡不是精确 viseme 表，不能据此声称完成口型。
- 四个细节取真实服装/饰物识别点，如领饰、徽章、面料、鞋，不凭空换装。补出的背面设计注明为生成补充。
- 信息栏写角色 ID、主唱职责、概念、外观锁定项、关键色。年龄/国籍等原帖字段只在用户设定存在且有制作意义时写，不从真人照片猜测。
- 多位主唱分别制作，不把不同人拼为同一人的转面。

提示模板：

> 以〔人物图〕为唯一身份和服装依据，制作 MV 主唱设定板。上排四个同尺度全身：正面、3/4、侧面、背面；下排四个表情近景〔列表〕和四个服饰微距〔列表〕。右侧预留角色 ID、职责、概念、颜色与锁定外观项。中性背景、统一光线、清晰分隔，不截手脚，不改脸/体型/衣服。表情自然，近景不能变成不同人物；准确标签随后排版。

## 群体卡：成员 + 转面 + 队形 + 细节

伴舞/群体卡为可选项。用户未表态时询问是否需要伴舞；已有明确选择则沿用。仅在用户选择需要后另做一张，不能根据风格或参考图自行启用。选择不需要时跳过本节及相关验收，ensemble_sheet 标 not_applicable；待选择时继续主唱与情绪板工作，不提前生成伴舞。原帖 photo/3：顶部成员列队；中部代表成员正/侧/背转面和集体动作队形；底部识别物、状态标记、编号及鞋等细节。约六位成员只是示例，数量依本次创意。

成员 ID 不重复、不意外合体。区分同一资产的设计性复制与不同成员身份。主唱重情绪与手势，群体可同步、错拍、依次显现或改队形；非演唱群体不跟唱。不把原图文字/编号生成错误带入新卡。

## 从板到生产资产

保存 production_moodboard、lead_character_sheet、适用的 ensemble_sheet 独立节点/文件，关联用户参考。board-manifest 记录 id、kind、input_refs、generated_or_reused、supplemented_fields、identity_checks、visual_checks、node_or_path、version、status。

标准卡用于锁身份，也可提取站姿照片用于平面拼贴、平移和缩放。按动作计划提取/补充合适的单视角关键姿态，优先准备半身与面部演唱特写；少量全身舞蹈另保留重心、手脚与安全边界；同一中性图可驱动不同动作，无需为每个动作机械新生图。随后优先提取已通过卡片中的干净单视角人物、表情、场景、物件和纹理；尺寸不足、遮挡或细节不够时才补生成所需单图，不能默认为每个视角重复收费生图。角色视频绑定目标单视角与必要的标准卡，不能让四视图拼板一起动。贴图需要透明或可稳定分割背景，核实工具是否真的输出 alpha。只供后期抠像的视频单视角参考默认整理成与目标视频一致的均匀纯色背景；颜色避开该角色衣发、肤色与配饰，白衣不默认白底。此制作底不改动情绪板的最终视觉风格。

换装请求优先于原参考的服饰锁定：保留用户指定身份，先将新服装写进主唱/伴舞标准卡，再衍生素材。记录 wardrobe_version 和 supersedes；旧片源标不选用。群像人数按角色职责核对，例如一位主唱加四位伴舞是五人画面，不能误报为五位伴舞。氛围群像不能覆盖正式成员 ID 或服装设定。

验收：情绪板内容维度齐全；主唱四向、表情、细节与信息栏齐全且身份一致；用户选择需要时群体卡完整，否则相关项记 not_applicable；单视角资产来自已核对版本；板框/说明/拼版不进入演员层。只修缺失或漂移的格。仅有原参考、未查看的生成图或文本计划时，不得把此阶段标完成。

主唱卡的四向全身用于身份与服装设定，不表示视频需要大量全身舞蹈。演唱特写或半身的单视角若从卡片裁出后像素不足，补生成清晰单图。情绪板与底板保留轻纸纹和撕边，避免重颗粒与全画面脏污感。
