# 制作交付与恢复

视频质量默认由用户查看确认。自动口型评分、逐帧检查和质量修复只在用户明确要求排查或测试时开展；文件存在、能解码、规格正确和预览可访问仍属于交付准备。

## 输入、制作板与表演

1. 保存用户音乐、视觉参考、角色参考及来源。独立维护本次 MV、主唱与可选伴舞的素材清单，记录真实文件、版本及用途；发现已有有效成果时复用。
2. 制作本次标准情绪板和四向主唱卡；用户选择需要伴舞时再制作群体卡。单图不等于完整制作板，已有合格板可复用并补缺。固定有效版本，再提取干净单视角。
3. 先规划全片主唱 video/collage/none 与伴舞时间轴，再选择要生成的表演镜头。不能因检测到人声，就把全部唱段加入视频生成清单。
4. 驱动音频精确截取对应的原始混音，保留人声与伴奏。记录音频哈希、截取余量、原片与成片时间映射；分析缓存不能替代生成用母带。首次视频制作前确认用户所需清晰度并核验支持情况。
5. 优先使用 MiniMax H3 的参考引导表演能力，用户指定且满足输入要求的模型优先。分别核验角色参考、所选清晰度、动作、音频驱动和唇同步，不把历史测试视为当前能力证明。能力不足时说明缺口并确认等效方案。
6. 独立人物层用不与服装、发丝和配饰冲突的均匀纯色背景，先做代表短段验证抠像路线；明确保留摄影棚场景时无需抠像。普通 MP4 不等于带透明通道的视频，必要时保存匹配的 RGB 与逐帧 matte。
7. 先交付代表合成，再扩展全片。人物真实表演累计至少占全片 60%，与平面拼贴贯穿交替；主唱无独立配额，静态拼贴无单次硬上限。人物层在文字与装饰之上，歌词仍需可读。演唱视频使用对应原混音，不以随机张嘴替代；伴舞无需对口型。

用户已确认的方向持续执行，仅在缺少必要输入、待选伴舞、能力差异、预算或依赖用户的视频审核时等待。生成成功与用户接受分别记录，不伪造自动评分。

## 能力与证据

| 能力 | 交付证据 | 不可用时 |
|---|---|---|
| 音乐 | 可播放音频、来源和实测时长 | 保留音乐方案，请求获准素材或可用生成能力 |
| 制作板 | 情绪板、主唱卡、可选伴舞卡的真实图像 | 不用计划或未处理单图冒充完成 |
| 人物动作 | 实际模型名称、参考图与输出短片 | 保留素材，说明影响；改纯代码路线需确认 |
| 歌曲唇同步 | 对应音频区间、片源映射及用户审核 | 独立补做口型；普通唱歌提示不能证明同步 |
| 抠像 | alpha 或匹配 RGB/matte | 不宣称未提供的透明度 |
| 音频分析 | 节拍、歌词时间及测量/估计说明 | 明确未测量项 |
| 代码合成 | 可编辑时间轴、图形、素材与实际渲染入口 | 说明缺少的依赖和未完成部分 |
| 交付 | 可解码 MP4、可访问预览、源码与版本 | 保留本地成果，说明访问或播放缺口 |

## 文件与环境

依赖按实际需求准备，不把安装整套工具栈作为制作板前置条件。所有产物写入当前项目，安装目录保持不变。远程能力与本地路径未必互通，只沿用实际返回且已验证的文件引用。保存视频、遮罩、母带、字体许可与运行入口，重新合成不重复消耗生成任务。

每资产记录逻辑名称、来源类型、提示词、已核验模型名称、路径、版本、制作状态、选用状态和用户审核结果；未知内容留空。制作记录不是供应商请求格式。预览服务如确有需要，只暴露当前产物并绑定本机回环；只结束本任务创建的进程。

## 最终交付

1. 导出 MP4。兼容格式为 H.264 / yuv420p，有声时 AAC，并启用 faststart。确认实测时长、画幅、帧率、唯一主音轨与片源时间映射一致。
2. 向用户提供可播放成片、可编辑源工程、制作板和实际素材清单。保持原速，不重复叠加音乐；生成片原声默认静音。各版本清楚标注，避免误用失败或过期文件。
3. 确认文件实际产生且预览可访问，再请用户审核。用户通过即完成该版本质量验收；未做的自动检查记为未执行。播放异常或用户要求排障时，再测试暂停、跳转和片尾，不能仅凭播放器兜底文字判定失败。
4. 保存完整复现资料。默认不增加重渲染验收；用户要求复现时，从交付包渲染短段，无需重新调用生成模型。

## 失败与恢复

- 先区分文件解码、交付访问、播放与内容反馈。有效文件复用，不因预览故障反复转码或重生成。
- 技术失败先查明确原因，在已有授权内针对原因重试一次；仍失败时选择满足同等要求的可用能力，涉及输出或费用变化先确认，或报告阻塞。
- 音频驱动成功不证明嘴形正确。用户指出口型问题后，仅修对应唱段；允许照片拼贴过渡，但不得称其通过唇同步，且仍满足全片表演覆盖和主要唱段主唱存在感。
- 保留音乐、制作板和成功资产。只回滚受影响层，不擅自更换整个执行环境或重建项目。
- 只更新 Skill 包或通过结构检查，不代表真实付费生成、抠像和完整音乐视频制作已验证。
