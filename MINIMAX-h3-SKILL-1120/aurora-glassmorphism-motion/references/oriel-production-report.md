## 3. 色带（重点）
- **原因定位**：v4 的无损母版没有色带；色带是 x264 在暗部平坦区把细颗粒量化掉后，宏块 DC 台阶形成的轮廓。把 v4 成片左上、右上暗部提亮 5–7 倍放大，可以看到 8×8 / 16×16 的块状台阶。
- **画面端**：
  1. 保留约 1.2% 单色抖动和 Soft Light 颗粒。
  2. 新增 `uDarkGrain = 0.022`：Soft Light 颗粒在接近黑色时会消失，所以在亮度低于约 0.3 的区域额外加一层线性颗粒，让最暗的渐变也有足够噪声。
- **编码端**：
  1. RGB → YUV 改用 zscale 的 error-diffusion 抖动，不再直接截断。
  2. 改为两遍编码，平均 37 Mb/s；`-tune grain`；aq-mode 3、aq-strength 1.3（偏向暗部给码率）；deadzone 0；关闭 dct-decimate。
  3. 成片 45.8 MB（≤ 50 MB）。
- **客观检查**：自写脚本 `band_metric.py`。把成片帧和无损母版帧都做 σ = 6 px 模糊，把颗粒抵消掉，只保留低频误差，即轮廓和块台阶。统计四角和下方中部暗区（亮度 < 60）误差的第 99 百分位。
  - 抽查 0.3、1.0、3.0、5.0、7.5、9.5 s 共 6 帧：**最大 0.83 LSB**，多数在 0.44–0.76 LSB。
  - 对照：CRF 23 普通编码同一位置为 1.16 LSB。
- **目视**：暗部提亮 5–7 倍放大对比 v4 和 v5（`check/v5/dk.png`、`tl.png`）。v4 左上角有明显块状台阶，v5 基本只剩颗粒。但在下方中部青蓝过渡处提亮 7 倍后，仍能隐约看到很弱的条纹，见剩余问题。

## 4. 声音
- **沿用 v4 体系**：D 大调 pad、低频暖层、glock/celesta 琶音、玻璃 tink、VCSL 擦玻璃长音（D#4 移调到 F#5 / D5）、声音 Logo D6–F#6–A6–E7。
- **删去**：光流 air/sparkle/orb chime 和光束 blip 的投射语义。回复三行改为每行一个轻柔的调内 blip，跟随 v1 的出现时间。
- **重新对齐**：所有音效按 v5 cues 重排，包括落定点击、气泡 pop、开关、通知 ding、光扫 ping、orb 鼓起、透镜诞生、划过两段文字、退场、收缩、汇合、Logo、口号。
- **2–5 kHz 收回**：v4 为 12.3%，v5 为 **9.9%**。做法是旋律和 Logo 的 3.5 kHz 提升从 +1.5 dB 改为 −1 dB，玻璃 tink 的高频瞬态改为 4.5 kHz 高通并降 2 dB。
- **结果**：−14.03 LUFS，TP −1.71 dBTP。17 个 cue 在全频和手机外放模拟中都**17/17 可闻**，手机模拟最弱的是 6.65 s 透镜划过回复（+4.1 dB）。

## 8. 剩余问题（诚实说明）
1. **色带没有做到数学意义上的「零」**：暗部提亮 7 倍放大时，下方中部青蓝过渡处仍有很弱的条纹（低频误差 < 1 LSB）。正常观看和 3–4 倍提亮下看不到。要彻底解决需要 10-bit 编码（High 10），但会牺牲部分设备的兼容性，所以没有采用。
2. **颗粒变粗**：为了压住色带，暗部加了线性颗粒，暗部的胶片颗粒感比 v4 明显。
3. **wow 自评 7**：删除叙事后，只剩透镜这一个亮点。
4. **静帧里玻璃感提升有限**：v1 本身已经有磨砂和描边，v5 的增强主要体现在运动中。如果客户主要看静帧截图，差异可能不够明显。
5. **起音检测**：两处 50 ms 是检测器在相邻 cue 之间误选；检测脚本是自写的（本机没有 librosa）。手机外放是数字模拟，没有在真机上试听。
6. **通知入场方式微调**：从「从画面外落下」改为「从上方 30 px 处、带景深落定」，这是为了满足 ≥ 96 px 安全边距。
