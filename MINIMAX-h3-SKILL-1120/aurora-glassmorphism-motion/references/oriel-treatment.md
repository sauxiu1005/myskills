# Oriel — Clarity, in every light.

**风格**：mg-styles-15 · 12-aurora-glass（弥散渐变 / 玻璃拟态）
**规格（建议默认）**：1920×1080 横屏 · 30 fps · 10.000 秒 · 含配乐与音效（−14 LUFS，峰值 ≤ −1 dBTP）
**画面语言**：全部英文

---

## 1. 虚构品牌

- **品牌名**：Oriel（字标用小写 **oriel**）
- **名字由来**：oriel 原意是建筑上向外凸出的玻璃窗，光从多个角度透进来，和"玻璃、光"的风格正好对应。
- **产品**：个人 AI 助手。能听、能理清思路、能替你守住专注时间。
- **口号**：**Clarity, in every light.**
- **品牌气质**：安静、透明、可信，带点高级感。说话克制，不喊口号。
- **Logo 设计**：一枚圆形的液态玻璃透镜，带一圈彩虹色散的边。片中的高光透镜最后就收成这个 Logo，品牌记忆点和风格特征是同一个东西。

## 2. 一句话概念

几张安静的玻璃卡片浮在流动的极光上，展示 Oriel 怎么帮你把杂乱的一天理清楚；接着一枚液态玻璃透镜划过画面，把一切放大、看清，最后收成 Oriel 的 Logo。

## 3. 英文 UI 内容

| 元素 | 画面文案 |
|---|---|
| 输入框卡片 | `Ask Oriel anything` + 闪烁光标 |
| 语音卡片 | 声波动画 + `Listening…` |
| 用户消息气泡 | `Summarize my week in three lines.` |
| Oriel 回复卡片 | `3 meetings moved to Thursday` / `2 drafts ready for review` / `Focus time protected` |
| 开关卡片 | `Focus Mode` ● On · `Private by default` ● On |
| 通知胶囊 | `oriel · Your 9:00 brief is ready` |
| 结尾字标 | **oriel** |
| 结尾口号 | Clarity, in every light. |

字体：Inter 或 Manrope 的 Light / Regular 字重（开源 OFL 授权）。字标用较大字号、轻字重，字间距略微放宽。

## 4. 节拍表（10 秒 / 300 帧）

| 时间 | 画面 | 声音 |
|---|---|---|
| 0.0–0.5 s | **开场钩子**：极光从第一帧就在流动（不出现黑场）；一道 1px 高光沿第一张玻璃卡片的边缘扫过 | 氛围铺底淡入，一声轻柔的闪烁音 |
| 0.5–2.5 s | 输入框卡片和语音卡片带视差、轻微 3D 倾斜浮入；光标闪烁，声波开始呼吸，出现 `Listening…` | 每张卡片落定时一声很轻的界面点击 |
| 2.5–4.5 s | 用户消息出现，Oriel 的三行回复依次淡入并上移 8px；两个开关依次拨到 On | 回复每出一行一声细小的点击，开关两下软"嗒"声 |
| 4.5–6.0 s | 通知胶囊从上方滑入；卡片组成一个完整、有层次的画面，极光逐渐变亮 | 铺底和声逐渐抬升 |
| **6.0–7.5 s** | **高光时刻**：液态玻璃透镜从左向右缓慢划过，真实折射放大背后的极光和卡片文字，边缘带彩虹色散和镜面高光 | 6.3 s 一次柔和的上扬，闪烁音铺满 |
| 7.5–8.8 s | 透镜在画面中央停下、收成圆形 Logo；卡片退入景深并模糊消散；**oriel** 字标淡入 | 和声开始收束 |
| 8.8–10.0 s | **结尾定格**：Logo + **oriel** + `Clarity, in every light.`；极光继续缓慢漂移，透镜轻轻呼吸 | 一个开放的结束和弦，余韵持续到最后 |

所有动作都用平缓的呼吸式缓动，没有快速运动。

## 5. 配色（邻近色，冷调）

- 底色：深靛黑 `#07061A`
- 极光光斑：紫罗兰 `#7B5CFF` · 蔚蓝 `#3D7BFF` · 青 `#3FE0F0` · 少量品红 `#C04DFF`
- 玻璃：白色 6–8% 填充，1px 白色 30% 内描边，圆角 28–36px
- 文字：近白 `#F2F4FF`，次要文字 60% 透明度
- 全画面叠加 4% 噪点，防止渐变出现色带

## 6. 声音方向

电影感的环境氛围铺底（D 大调附近，温暖、开阔），叠加轻柔的闪烁音层，配极轻的界面点击和开关声。高光时刻有一次柔和的上扬，结尾停在开放和弦上。整体安静，不用鼓点。

## 7. 风格核心特征对照

| 核心特征 | 在片中的位置 |
|---|---|
| 大色斑高斯模糊漂移 | 全片底层，4 团光斑沿曲线路径缓慢漂移 |
| 磨砂玻璃卡片 | 输入框、语音、消息、开关、通知共 5 类卡片 |
| 1px 高光描边 | 0–0.5 s 的开场扫光，加上所有卡片的内描边 |
| 邻近色低对比配色 | 紫、蓝、青为主，品红只做点缀 |
| 缓慢呼吸感节奏 | 全片呼吸式缓动，文字只做淡入 + 8px 上移 |
| 液态玻璃透镜（高光时刻） | 6.0–7.5 s 划过画面，随后收成 Logo |
