# 验收：原版检查落到实际文件

依据 DIRECTOR 的“sound → rhythm → camera → directing”和 TECHNIQUE §8；记录 passed / failed / not_run / blocked 与证据路径，不预填成功。

| 项目 | 实际检查 |
|---|---|
| 参考与造型 | 打开原风格帧与本片角色表/风格帧对照；大眼白小瞳孔、分层五官嘴型、可辨轮廓、具体场景与道具，达到原参考的绘制完成度 |
| 原版材质 | 屏幕空间粗线、三态12fps抖线、平涂和硬边阴影；天空色带、装置独占发光色，非平滑渐变替代 |
| 表演与镜头 | 手势有预备动作，行走/奔跑有肢体姿态，表情与声音联动；荒诞揭示有反应镜头，冷场只留下抖线 |
| 时序 | story中台词、字幕、镜头和音效对应同一事件；随机取帧与顺序一致，12fps角色与24fps镜头分离 |
| 声音 | 听核每句实际音频及最终混音；打断准确、无意外串音；cue配乐和动作音效成立，冷场连混响尾一起切除 |
| 字幕 | 按STYLE的字号/换行/说话人色标/阅读时间；画面底部安全区、无缺字遮脸，冷场前清屏；`scripts/check_srt.py` 通过（有序、非空、无重叠、间隔≥20ms） |
| 技术 | 完整解码、尺寸/fps/时长/音轨/响度实测，无意外空帧或裁尾；这项不能替代视觉与声音验收 |
| 工程与交付 | 新作源文件/资源/许可/可重建build齐全；成片可播与源码可编辑分别核验 |

按上游要求至少两轮整片接触表检查，每1–2秒一帧；关键动作约0.2秒帧条；抖线与嘴型另看相邻帧；最终速度完整观看并听审。`ffmpeg fps=1`有偏移，不能据它判定切点，使用原still工具的精确时间。

已知误报：审看可能根据抽帧报告“音效延迟”。修改前先在混音中实测起振相对事件时刻的偏移（79秒成片实测 ≤2.4ms）。

只维护skill时校验包哈希、元数据、相对链接、初始化和拒绝覆盖、ZIP完整性；render、TTS、最终听审、新版成片播放没做就记not_run。技能校验通过不等于成片通过。
