# 风格与创意展开

## 参考图所传达的共同语言

本文件归纳了一组三维角色展示作品的共同美术语言。下面的名称是本技能的描述性分类，不是某位作者或某个引擎的风格名称。文件自包含，使用时不需要提供原始参考图。

共同基底：清楚且略夸张的三维体块；可读的服装层次与机械连接；真实尺度感的织物、皮革、涂装金属；克制的粗糙度变化和边缘磨损；白至浅灰无缝棚景；柔和主光、微弱轮廓光、接地阴影；近似高品质收藏雕像的展示观感。角色形状可以卡通化，材质依然有重量与触感。默认保持清晰景深，不用强虚化掩盖装备。

六个方向并非完全互斥的画风，而是同一三维角色展示体系下的不同题材与造型方向。不引入任何教程中的软件流程、参数或“原角色完全不变”的要求。

## 六个可选主方向

用户可说方向名称或用自然语言描述；无需输入代码。未指定时依据创意选择一项主方向，最多吸收另一项的局部特征，避免把所有风格标签叠在一起。风格不自动决定人数。

| 方向 | 可迁移的视觉规则 | 新角色设计重点 | 避免复刻的典型组合 |
|---|---|---|---|
| A 旧工业机械奇幻 | 不规则铆接装甲、厚重金属与柔软旧布的反差，朴素低饱和色，修长与敦实体块对照 | 从职业决定承重结构与维护痕迹，让形体表达性格 | 不照搬巨锤机体、白发黑衣人物、佝偻老人和兜帽小人的整组配置 |
| B 复古都会冒险 | 有剪裁感的外套、马甲和层叠领口，复古机械小件，黄铜与羊毛对比，优雅或顽皮的姿态 | 根据新职业创造制服、头部识别点与便携工具，维持时代感的一致性 | 不复刻高帽风衣人物、球形头侍者、披风巨机和红巾机体的组合 |
| C 洁净硬表面科幻 | 大块装甲与精细内骨架分层，明确面板分缝，少量强调色，干净表面上的局部使用痕迹 | 通过用途设计胸廓、头部传感器与肢体机械，设定可信尺度和维护方式 | 不照搬白色尖角红纹巨机、宇航服人物与蹲姿维修者的构图及配件 |
| D 轻装武侠与机械武者 | 修长比例、利落剪裁、布料与甲片的节奏，轻盈重心和有张力的动作轮廓 | 为角色创造新的运动方式、工具或兵器、护具组织，不依赖相同刀剑与发型 | 不复刻金发白衣持刀人物或白甲红眼机械武者的造型和动作 |
| E 怪趣工坊与童话机械 | 圆钝与尖长形体并置，柔和旧漆色，夸张体型，织物触感，友善但有怪趣的表情 | 用职业和性格决定独特轮廓；团队成员共享世界感但避免同款身材和服装 | 不复刻绿甲持锤机体、黑衣尖帽人物、白胡须矮胖人物及原队伍阵容 |
| F 动态科幻收藏雕像 | 可读的动作线、功能性科技服装、受力衣褶、装备惯性、三维材质和简洁棚景 | 为新职业设计独立轮廓与动作目的，完整展示手脚与道具 | 不复刻白发黑衣奔跑者、原动作轮廓或教程中的整套服装；不默认鱼眼与速度模糊 |

用户明确要二维、平涂或水彩时，遵从该方向并移除冲突的三维材质要求；不要因为参考上并列很多风格词而全部照抄。原先的 3A 写实方向仍可明确调用，不强制切换为夸张人物。

## 从一句话补成可生成的设计

用以下顺序在内部完成短小的设计决策，只向用户展示必要的一两句概念说明。

1. **找创意核心**：职业／物种、行为动机、情绪、世界题材。用户只给“机器人”时可补一个具体职业；用户说“孤独的邮差机器人”时保留孤独与邮差，不改成战斗机甲。
2. **建立独特轮廓**：选择长短、宽窄、圆方、重轻的主对比。用一种主要形状组织轮廓，再用一种辅助形状打破单调。不要所有角色都小头宽肩长腿。
3. **让功能产生细节**：主道具与职业相关；连接件、口袋、开口、磨损解释它如何使用。通常选择一个主辨识点、两三个辅助点即可，不堆满无用途零件。
4. **给性格可见证据**：用重心、肩颈、手势、视线与装备维护状态表达性格；“害羞”可表现为稍内收的肩和珍惜地抱住工具，不能只把情绪词塞进提示词。
5. **设定配色与材质**：通常一个主色、一个辅色、少量强调色；选择两到四种主要材质，区分涂装层、裸金属、织物、皮革等。不要为贴近参考而固定全部角色白甲、红眼或旧绿色。
6. **确定人数与版式**：严格遵从用户人数；“搭档”是两位，“小队”未指定时默认三位。单角色多姿态与多角色群像分开。三视图的人物重复不是三个人。
7. **做原创性检查**：仅对新角色创作检查能否凭整体剪影、头部、服装和核心道具组合认出某个风格参考角色。若能，回到功能与轮廓重新设计，不能只换色。已有原创角色的转面／三视图派生不适用此规则，必须保留其身份与材质，改读 [母版派生与质感保真](turnaround-fidelity.md)。

团队增加一层关系设计：每人拥有不同的任务、体型与主道具，共享两三种材质或色彩线索。通过视线、姿态或一个简单交互说明关系，避免为了“有故事”而加入复杂场景。

## 通用主视觉提示词结构

下面是新角色创作的组织框架，提交前删除字段标签、填实变量并移除不适用段落。不得用于已有角色的三视图派生，尤其不能把末句的“不要复制”带入派生任务。已有母版时读 turnaround-fidelity.md；从零创建三视图时读 prompt-patterns.md。

```text
创作一张原创{角色／搭档／团队／动作}设定图，画面恰好有{人数}位不同角色，采用{一个主方向}，以{形体语言}构造角色，呈现可信物理材质与高品质三维收藏雕像观感。

核心创意是{一句话职业、性格反差与功能}。{逐个角色的体型、头部、服装剪裁、主道具、挂点与功能结构；同角色多姿态时明确身份相同}。采用{配色关系}，表现{每种材质的具体表面证据}，细节集中在功能与接触区域。

{版式、视角、姿态、动作目的或角色关系}。{人数超过一时的相对身高、站位、视线、道具归属和遮挡边界}。全身、手脚和主要道具完整入画，轮廓清楚，保留适当留白，重心和接触关系可信。

白至浅灰的无缝棚景，柔和漫射主光、轻微轮廓光与接地阴影，清楚的立体体块，织物有厚度、金属有重量，所有角色共享一致的光向与材质表现。没有场景装饰、标题、标签、文字或水印。不要复制风格参考图中的人物面容、发型、服装组合、机甲头部、标志性道具或姿态；创造符合上述创意的新角色。
```

“PBR”“Octane 观感”等只能描述审美，不宣称实际使用渲染器。“8K”或“超精细”不代替生成分辨率参数。图像生成输出不是可编辑三维资产。

## 一句话输入示例

以下是说明自动展开方式的独立原创方向，不是每次必须生成的固定角色库。新任务应围绕用户创意继续变化。

| 简单输入 | 自动展开的设计重点 | 风格／版式 |
|---|---|---|
| “一个胆小的旧锅炉机器人园丁” | 梨形低重心机体、折叠浇灌臂、抱着育苗盒、烧蓝钢与灰蓝旧漆；无巨锤或骑士头盔 | A／单人 |
| “会偷听秘密的发条旅馆接待员” | 斜肩短外套、折页式听音装置、账本夹、酒红羊毛与暗黄铜，用侧头姿态表现机警 | B／单人 |
| “温柔的深海维修机甲和它的导航员” | 宽扁传感头、耐压装甲、柔性维修钳，导航员持声呐板；统一水蓝与深灰、视线交互 | C／双人 |
| “靠风筝送信的机械游侠” | 轻薄叠甲、可收放绳盘、短斗篷、伸展但平衡的落地姿态，铜灰与赭色 | D／单人动作 |
| “一支修补梦境的小队” | 圆胖织梦师、细长陶瓷修复人偶、矮壮灯具搬运机器人，三种轮廓、统一布料与釉面语言 | E／三人群像 |
| “正在急停的未来城市送药员” | 向后压低重心、脚掌制动、侧腰恒温药盒、少量反光织带、青蓝与暖灰；避免奔跑模板 | F／单人动作 |

### 完整示例：旧锅炉机器人园丁

```text
创作一张原创旧工业机械奇幻角色全身设定图，只有一个胆小的旧锅炉机器人园丁，采用夸张清楚的三维造型和可信的收藏雕像材质。机体为矮而宽的梨形，头部是偏置的小型横向观察窗，身体由厚薄不同的圆弧壳板组成，背后有带保护罩的小型排气管。左臂为可折叠浇灌装置，喷口收起，右手小心抱着一只木制育苗盒。双肩稍内收，视线朝向盒里的幼苗，短腿稳稳站立，让胆小而细心的性格可见。

灰蓝旧漆是主色，烧蓝钢框架与少量浅铜连接件形成对比；边缘磨损露出底材，关节附近有少量油渍，育苗盒有真实木纹与轻微潮湿痕迹。软管沿躯干侧面固定，在肩肘处保留弯曲余量；育苗盒与手掌真实接触，不悬空。零件数量克制，主要轮廓清楚，不添加武器或无功能尖刺。

竖向构图，轻微三分之四视角，完整露出排气管、手指、双脚和育苗盒，四周留白。白至浅灰无缝背景，柔和漫射棚光、微弱轮廓光和接地阴影。金属有重量、木材与旧漆质感分明，保持风格化比例，不转成真人。无文字、标签、场景装饰与水印。重新设计全部头部、轮廓和功能件，不复制任何参考图角色。
```

### 完整示例：深海维修搭档

```text
创作一张原创科幻角色搭档设定图，画面恰好有两位角色：温柔的深海维修机甲和成年导航员。采用洁净硬表面设计与可信三维收藏雕像质感。机甲约为导航员身高的两倍，宽扁的横向传感头没有尖角，胸部采用分层耐压护罩，腰部短而稳定，腿部宽实。水蓝涂装与深灰关节构成主色，少量琥珀色状态灯作为点缀。机械手采用三瓣柔性维修夹，夹片与腕部连接清楚，肩肘具有活动空间。

导航员身形结实，穿暖灰短夹克、深蓝工作裤和耐水靴，腰侧固定折叠式声呐板，没有宇航头盔。机甲在画面左后方微微俯身，空着的一只维修夹张开向上；导航员在右前方站稳，抬起声呐板向机甲展示，两者视线汇聚在板上。两人的手和工具各自清楚可辨，导航员不遮住机甲的主要关节，所有脚部和工具完整入画。

机甲的大面积装甲保持洁净，只在维护口边缘有少量擦痕；夹克有细密织纹和肘部压褶，靴面为哑光橡胶。白灰无缝棚景，无海底场景，统一柔和灯光和地面接触阴影，竖向构图与适当留白。没有文字或水印。创造新的头部、胸甲、服装和姿态组合，不复制参考图中的尖角白甲机体、维修者或构图。
```
