# 母版派生与质感保真

## 要解决的问题

三视图是同一角色的观察方向与排版变化，不是再次设计一个“相似角色”。将原来的角色描述重复提交，并不能替代实际图像参考。工作流应分别约束身份、渲染表现、姿态和版式。

常见漂移表现：单角色图的脸部有细腻的体积明暗和肤色过渡，发丝有细分束与光泽，衣物有织纹、厚度和细微粗糙度；而三视图的头发变成块状，面部与裸露肢体的明暗被简化，衣服纹样、护腕和装备数量也被改写。这是身份、设计和材质同时漂移，不能只靠锐化或加“超写实”一词处理。没有真实生成记录时，不断言是某项模型机制导致。

避免漂移的关键：把单角色图作为母版实际传入；“不复制风格参考角色”的规则不用于同一原创角色的派生；三视图提示词在约束结构和排版的同时，明确继承母版的面部、皮肤、头发与体块。

## 1. 锁定母版与参考职责

- 用户已有满意单角色图：直接将该图设为 `MASTER`，记录实际文件／资源与版本，不再创建新脸。用户给出好坏对比时，满意图是 `MASTER`，问题图是 `LAYOUT_OR_REPAIR`，明确后者只能提供版式或待修复区域。
- 从零生成三视图：先做一张单角色全身母版，交用户确认后再派生。用户明确要求一次出板或预算不足时，不自动增加任务，直接出板并说明保真限制。
- 必须把母版作为参考图实际传入当前生图入口。入口不支持参考图时，不声称纯文字生成能锁定身份；交付可执行提示词并说明能力缺口，不悄悄换模型。
- 入口支持多张参考且脸部在全身图里太小时，可补充同一母版的脸部、躯干材质裁切，分别命名 `MASTER_FACE`、`MASTER_MATERIAL`。它们来自同一张图，不是另行生成人脸。只有能真实绑定时才在提示词中引用。
- 旧三视图若明显污染身份或材质，优先不绑定它，改用文字写版式。不要默认多图输入总比单图更好。
- 裁切与排版使用当前可用的图像处理能力完成，不虚构裁切文件、不猜测参考权重参数，也不假定固定随机种子能保证身份。

## 2. 提取身份与材质保持项

根据实际母版写短小、可比对的约束。仅记录看得见的特征，不凭主观补成另一套漂亮脸。

| 类别 | 必须继承 | 允许变化 |
|---|---|---|
| 面部身份 | 脸部轮廓、下颌、眼型与间距、鼻唇形状、肤色、痣或妆容等可见识别点 | 观察方向；姿态标准化所需的轻微表情调整 |
| 身体 | 头身比、肩胯宽度、躯干与四肢比例、有意的风格化程度 | 统一自然站姿；随视角产生的遮挡 |
| 皮肤 | 柔和体积明暗、细微色差、适度高光、母版本身的表面细腻度 | 随方向自然变化的明暗；不强制复制像素级高光位置 |
| 头发 | 发型结构、发际线、分缝、鬓发、发束尺度与细丝光泽 | 转面后的可见区域；不改成雕刻槽纹或塑料块 |
| 衣物与道具 | 剪裁、纹样分布尺度、扣件、缝线、挂点、数量；织纹、厚度、反射与粗糙度关系 | 随姿态合理改变的褶皱与反光 |
| 整体呈现 | 原本的三维渲染观感、材质分离、色调和体块层次 | 为清楚展示适当调整光线；不能变成低模预览或平涂 |

背面不可见区域标为设计补全：沿用既有裁片和纹样语言，避免新增大徽章、绑带、饰物等显著设计。一旦形成合格背面，记录该版本为后续补充依据，不让每次重做自由变化。

## 3. 姿态、相机与灯光分开约束

默认将动态母版统一转成轻松中性站姿，明确“只改变姿态与观察方向，身份、身体比例、材质不变”。三视图采用一致的相机尺度和弱透视，不使用让鼻子、眼睛或头身比变化的广角效果。

“正交感”只描述投影，“白底”只描述背景；两者均不要求取消体积光影。采用柔和但有方向的主光与补光，保留脸颊、鼻翼、锁骨、臂部的体积层次，避免无阴影的平均照亮。各视图保持相同灯光方案与曝光感，允许转面导致合理高光变化。不要同时写“高对比电影硬光”“完全无阴影”“均匀平光”。

## 4. 保障人物和脸部的有效像素

整张板分辨率不等于每个人物的分辨率。把三个人物和三块细节放进横向整板，会改变每张脸与身体可用的像素和构图空间；不要用“8K质感”或额外头像格来掩盖全身图里的小脸。

- 从实际图片读取尺寸，结合人物在图中的占比判断脸是否足够可读，不以聊天界面缩略图尺寸代替原文件。
- 优先把画面高度留给完整人物，减少无用边距。未要求细节时先交三视图；要求细节时可另页，或使用支持且符合预算的更大原生尺寸。不可擅自删去用户要求的局部。
- 一次整板生成被用户接受就采用，不无条件拆分。若用户反馈整板反复压缩脸部或渲染简化，改为“同母版约束下分别生成高分辨率正／侧／背视图，再排版”。每张都绑定母版；必要时加用户已确认的正面图保持姿态，不能仅用上一张生成结果逐代传递。
- 分开生成时统一姿态、相机尺度、灯光和背景；合成时按相同头身高度等比缩放，不能非等比拉伸对齐。保留各方向原生大图，与整板一起交付，避免最终缩小的排版图成为唯一文件。
- 拆分生成须在用户预算和剩余修正轮数内，不能静默扩成大量收费任务。普通放大不恢复缺失的面部信息；生成式细化可能改变脸，只可在母版约束下使用，并提醒用户重点比对脸部。

## 5. 母版派生提示词

使用前必须绑定真实母版。去掉未提供的参考名称，填写从母版观察到的具体保持项。不要把新角色模板里的“重新设计脸型”“不要复制参考角色”混进来。

```text
以已提供的 MASTER 单角色图为唯一角色身份、身体比例、服装设计和材质呈现基准，制作这个同一角色的正面、角色自身右侧面、背面三视图。这里是同一既定角色的转面展示，不重新设计角色，不重新选择画风。

保留母版的{脸型、眼型与间距、鼻唇、妆容或识别点}、{发际线、发型、发束和细丝表现}、{头身比和身体比例}。保持{服装剪裁、纹样尺度与分布、扣件、道具数量和身体左右挂点}。不可见的背部按已有服装与材质逻辑克制补全，不新增显眼图案或饰物。

继承母版细腻的三维表面与体块表现：皮肤保留{实际可见的肤色过渡与柔和高光}，面部、肩颈和四肢有自然体积明暗；头发保留分束与细丝反射；服装保留{实际材质的织纹、厚度、粗糙度与反光特征}，道具保留{实际材质特征}。维持母版本身的风格化程度，不改成另一种真人或卡通脸，不简化成平涂、塑料皮肤、块状头发或低模材质预览。

将母版姿态统一调整为{中性站姿说明}，三幅中姿态相同，只改变观察方向。横向并排，正面、角色自身右侧面、背面从左至右排列，头顶与足底对齐，人物等比例、全身完整、各格留白克制。采用弱透视与相同相机尺度，保持母版级别的材质与体积，不把正交感当成取消光照。柔和有方向的棚光与适量补光，保持脸、裸露肢体、衣物表面的层次，干净背景与轻微接地阴影。无文字、水印、额外人物或装备。{仅在明确要求时添加的细节安排}。
```

若分视图生成，将版式段改为“本次只输出一张完整的{方向}全身图”，保留其余同一母版、姿态和材质约束；最后进行排版。

## 6. 审阅要点与有限修复

成图交用户审阅时，附上下列判断顺序作为核查要点；用户反馈问题或要求核查时，按其范围同时查看母版与结果。先以相近脸部大小并排比较五官和发型，再看原生像素下是否真的有细节；必要的裁切不等于上采样恢复细节。正面与母版的三分之四视角有合理透视差，不能要求轮廓逐像素重合。

按以下顺序判定：

1. 仍是同一张脸、相同头身比例与风格化程度吗？若不是，先修身份。
2. 皮肤体块和过渡、头发细束、衣物厚度与材质反光是否保持同一档表现？若明显变成另一种渲染风格，不通过。
3. 裁片、纹样、护腕、饰品、道具数量与挂点有没有被改写？不要把脸部问题修好后漏掉造型漂移。
4. 三幅姿态、尺度和布局是否一致？下方局部是否真的对应全身图？

身份或质感广泛漂移时从母版重新派生，不只对坏三视图加“更精细”。只在少数部位有问题且入口支持编辑时用母版指导局部修复，并检查边界、肤色与全身协调。修正前说明改动并获用户同意；同一问题最多两轮定向修正，不为每张视图另开两轮。未解决则明确问题，不以“无法完全一致”掩盖当前缺陷，也不保证图像生成能达到严格三维转台的一致性。
