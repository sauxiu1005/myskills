# 三视图提示词模板与示例

本文件只在三视图／结构细节板模式下使用。单人主视觉、搭档、群像或动作展示见 [风格与创意展开](style-and-ideation.md)，不要自动套用这里的自然站姿与三视图布局。

**已有单角色母版时，不使用下面的新角色文生图模板。** 改用 [母版派生与质感保真](turnaround-fidelity.md) 的参考图模板，继承母版的身份与呈现质量。下面的沙漠游侠仅用于从零创作，不能覆盖已有角色的脸型、服装和材质。

## 可复用模板

将花括号全部替换为本次具体设定；删去不适用项。若用户已指定其他美术或版式，改写相应段落。仅在明确需要局部细节板时保留下排部分；不能为三个局部牺牲全身图脸部的有效尺寸。将单角色设计中确定的皮肤、头发、身体体块和服装材质描述原样继承到三视图提示词，不因“建模参考”改用另一种渲染表现。

```text
设计一张{美术风格与用途}的{年龄段、身份与核心特征}角色设定板。纯白背景，上方从左至右并排放置等比例的正面、角色自身右侧面和背面全身图，头顶与足底对齐，身体比例、姿态和装备尺度保持相同，采用弱透视、正交感表现。人物保持同一自然站姿，只改变观察方向，头、手、脚及外扩装备完整入画。下方整齐排列{连接结构}、{活动结构}和{装备挂接或服装细节}的局部放大图，留白充分，不遮挡全身图。

人物具有{脸型、发型、体型与辨识特征}，穿着{由内到外的服装层级、主辅配色与轮廓}。{角色自身左／右侧的特殊结构}。{部件连接、承重路径、关节运动与间隙}。{逐件装备的数量、身体挂点、朝向、固定方式和高低层次}。通过{真实开衩、分层或背面展示}呈现关键连接处，保留合理遮挡，全板完整交代装备。

三个视图属于同一人物、同一套服装与装备。{列出重要左右位置}始终保持在角色自身相同位置，不随画面左右改变。{列出少量带扣、接缝、破口或补丁锚点}在可见视图中连续对应。局部放大图与全身图共享相同部件形状、连接关系、固定件与磨损位置，不是另一套结构。

分别表现{材质一及表面证据}、{材质二及表面证据}、{材质三及表面证据}。材质对比清楚，磨损符合受力与接触位置，照明柔和均匀，不以暗部掩盖结构。不要添加场景、文字、标签、箭头、边框或水印，不要多余肢体、额外装备、悬空挂件或穿插。
```

## 完整示例：年轻沙漠女游侠

这是用户提供创意的具体预设，供同类角色使用；不要把本例的性别、环境或义肢设成所有角色的要求。

### 本例固定设定

- 年轻成年女性沙漠游侠，3A 写实游戏美术；沙色、浅米色、旧棕皮革，金属作为局部对比。
- 防风护目镜、浅色旧披风；角色自身右臂从肩部开始为机械义肢，左臂为自然手臂。
- 右肩座由胸背承力带固定；肩座、上臂、肘关节、前臂、手腕、掌部与五指结构顺序连贯。
- 左腰一个水囊，右后腰一个地图筒；为补齐原始提示词未定的挂点，短刀放右前腰、工具包放左后腰，高低错开。用户另有要求时更新此项。
- 连续性锚点：胸前承力带扣、右侧披风开衩缺口、水囊固定带和地图筒束带。保持相对身体位置，仅在实际可见的视角中核查。
- 下排依次为机械肩座、肘关节、腰部装备挂接放大图；第三格可采用后侧观察方向以显示后腰挂点。

### 可直接提交的提示词

```text
设计一张3A写实游戏的年轻成年沙漠女游侠角色设定板，纯白背景。上方从左至右并排放置等比例的正面、角色自身右侧面和背面全身图，头顶与足底对齐，体型、身高、头身比例和装备尺度完全一致。人物保持同一放松的自然站姿，双臂略离躯干，让腰部挂点清楚可读，只改变观察方向，采用弱透视、正交感的角色设计表现。三幅全身图均完整展示头部、双手、靴子与披风轮廓。下方排列机械肩座、肘关节和腰部装备挂接的局部放大图，层级清楚，充分留白。

人物戴防风护目镜，穿浅米色旧披风、沙色内层衣物与旧棕色皮革束带。角色自身右臂从肩部开始为完整机械义肢，左臂为自然手臂；正面图中的机械臂位于观者左侧，背面图中位于观者右侧，右侧面图展示同一条机械臂。机械肩座通过胸前与背部连续衔接的承力带固定，重量传递到躯干。上臂框架连接肩座和肘部，肘部具有清晰转轴、限位结构与活动间隙，线缆沿内侧布置并在关节处留出弯曲余量。前臂经手腕连接掌部，五指各自的关节链与掌部连接对应，拇指位于正确一侧，结构不互相穿插。

角色左腰挂一个水囊，右后腰固定一个地图筒，右前腰悬挂一把带鞘短刀，左后腰悬挂一个工具包。各件装备通过可见的带扣、束带或挂环固定，短刀和工具包高低错层，不互相遮死、不悬空。披风在右肩连接区和腰部采用合理开口与开衩，使机械肩座及主要挂接关系可见，前后视图保持同一裁片和下摆形状。正面、侧面和背面共同完整交代所有装备，保留真实遮挡，不把身体画成透明。

三视图中的胸前承力带扣、背部带路、衣物缝线、披风右侧开衩缺口、水囊固定带、地图筒束带及装备位置连续对应，身体左右始终以角色自身为准。下方机械肩座放大图展示肩座与胸背承力带连接；肘关节放大图展示同一转轴、限位件和线缆余量；腰部挂接放大图从后侧展示同一地图筒、工具包、腰带和挂环。所有放大图与全身图使用同一套结构、相同部件比例与固定件布局，不另行设计。

分别表现黄铜表面凹处氧化、钢件接触边擦伤、皮革带扣孔位与受力处压痕、织物开衩和下摆毛边；旧化有使用逻辑，金属、皮革与织物质感明确区分。采用柔和均匀的中性照明，面容与结构清晰。画面不添加场景、标题、文字、编号、箭头、标尺或水印，不出现额外肢体、重复装备或裁切的脚部。
```

## 定向修正模板

根据用户指出或确认的具体问题填写，传入原图且入口支持编辑时使用。若不支持编辑，将修正要求并入完整提示词重新生成，不伪称局部编辑。

```text
以当前设定板为基础，保留角色脸型、体型、配色、站姿、三视图排列、其余装备和已正确的结构。只修正以下可见问题：{指出具体视图／局部及错误}。正确设定为：{角色自身左右、挂点、部件连接或材质要求}。同步更新所有受此变化影响的视图和局部图，使{连续性锚点}仍然对应；不移动无关装备，不改变服装版型，不增加文字或场景。
```

例如：背面图把地图筒误挂到左后腰时，应指定“移到角色自身右后腰，匹配右侧面图的高度、束带数量和朝向；同步修正腰部放大图中的同一挂点”，不能翻转整个背面图。
