# 声音与验收

## 同一事件轴

读取编译时间线中的帧、秒和接触事件。音乐、拟音、UI 提示音分轨；用户需要旁白时另设轨。短点击/落地声按接触帧，起跳 boing、移动 whoosh 可提前，反馈提示音与状态改变对齐。不要给每次移动都加同一种夸张音效。

缺省可用轻快电子/lo-fi纯音乐，约120 BPM只是创作起点。12秒/30fps时一拍可为15帧，但用户音乐按实测节拍和段落编排，不把提示词中的 BPM 当检测结果。音乐保留引子、动作展开和结尾尾音；接触优先，非整拍事件不硬移。

声音来源优先用户素材、平台实际可用生成能力、本地合成。生成音乐不能承诺精确到帧，须后期剪辑、拉齐和混音。本地可用 Python 的 numpy/scipy 或当前可用音频库合成包络、振荡器、滤波噪声、UI blip、敲击和滑行音；不强制安装某一库或下载大型模型。

默认48kHz立体声WAV工作母带，音乐与SFX独立保存。合成器采用短淡入淡出防爆音。最终峰值与响度按交付要求控制；可从约-1dBTP限幅开始但需要实测，不能把 sample peak 当 true peak 或 RMS 当 LUFS。录音/旁白出现时降低配乐遮盖，避免削波和尾音截断。

分段测量能发现异常突峰/长静音，不能证明听感自然。实际试听已编码成片确认节拍、音效材质和音画同步；无法听审则标明未听审。

## 编码

根据实际序列与格式生成 FFmpeg 命令。例如以下是工程约定，不是随包已经生成的文件：

```sh
ffmpeg -framerate 30 -start_number 1 -i frames/frame_%04d.png -i sound/final-mix.wav -map 0:v:0 -map 1:a:0 -frames:v 360 -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 320k -t 12 -movflags +faststart delivery/final.mp4
ffprobe -v error -show_format -show_streams -of json delivery/final.mp4
ffmpeg -v error -i delivery/final.mp4 -f null -
```

替换帧率、数量、尺寸与路径，提前检查序列连续。混音需覆盖目标时长且尾音已收束，不依赖 shortest 隐藏素材不足。透明视频按真实支持格式交付，不把普通H.264 MP4称作透明。

## 验收清单

| 检查 | 判据 |
|---|---|
| 参考保真 | 角色身份、主色、界面结构和重要文字保持一致；推演项有记录 |
| 因果 | 每个主要动作有可见前后态；作品预览随软件内部时间/参数变化 |
| 接触 | 手脚实际触达、无漂浮穿模；拖拽物体与手不分离；按压后回弹 |
| 构图 | 顶点/快移/片尾不意外裁角色；中远景跟拍保留角色、操作目标与反馈，近景不持续遮住界面；顺播有适度位移视差和节奏变化，关键结果不被角色和景深挡住 |
| 质感 | 控件贴近界面，仅有薄边、浅浮雕和轻微接触阴影；无厚积木按钮、竖墙滑块或高杆播放头；UI无大面积反射白块，字清楚，角色无不必要色偏 |
| 声音 | 拟音与接触同步，无突兀爆音、削波、意外静音、重复混音 |
| 文件 | 完整解码，尺寸、时长、帧率、帧数、音轨正确，首尾无缺帧 |
| 可编辑性 | 实际交付.blend及完整依赖包；异目录解压后可打开，无缺失依赖；角色主要部件可选择、网格/材质可修改，副本中完成局部建模修改并保存重开及代表帧渲染；代码与事件轴对应最终版本，附修改说明 |
| Design | 实际画布播放、暂停恢复、跳转、片尾检查通过或明确未完成 |

交付QA记录区分 `pass / failed / not_tested / blocked`，提供实际证据路径或观察，不把数据检查代替视觉和听觉验收。
