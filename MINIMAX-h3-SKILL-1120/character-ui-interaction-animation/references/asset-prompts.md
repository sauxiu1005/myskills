# Design 生图资产

先发现实际工具并读取参数。下列模板绑定真实参考文件/资源 ID；记录提示词、实际模型、任务 ID、结果版本和验收。只补需要的资产，避免为简单位移反复生成人物。

## 角色转面

> 以用户角色图为身份参考，保留剪影、头身比、面部、衣着、配件和主色。制作同一角色中性姿态的正面、侧面、背面建模参考，同尺度、正交观感、均匀光照。不可见区域按原设计合理推演，保持身份一致，无文字、无额外道具。

生成视图须比对一致性，不称为同一网格的精确正交投影。

## 动作姿态

> 同一角色与服装比例，制作本次需要的【蓄力蹲下/腾空/脚底着地/双手推卡片/骑滑块/挥手】姿态。完整显示手脚，光向、风格和项目一致，不生成软件界面或按钮文字。

## 透明部件或道具

> 制作【所需对象】，与角色材质和光照一致，轮廓清晰、四周留边、无白边、透明背景，无文字、无烘焙地面阴影。

使用正式透明参数；验证实际 alpha 与边缘。若不能输出透明图，用可用抠图能力处理，不把棋盘格当透明。

## 背景

> 为漂浮界面舞台制作【指定环境】，光向与三维场景一致，目标区域留白、低对比，无额外界面、文字、标志。

重要 UI、用户名、文章标题、Logo、尺寸和数值保持原素材或代码绘制。生成的参考图不等于可编辑模型或正式渲染成果。
