# 角色与界面分析

为来源赋 ID，保存原文件、尺寸、用途。截图记录浏览器壳/系统栏、缩放、裁切、可见区域；辨认不了的文字不猜。多张图按初态、操作态、完成态排序。

角色记录剪影、头身比、关键色、面部结构、服装配件、材质、可动部件和不可变特征。看不到的侧背面标为推演。单张复杂人物图不足以保证完整三维转身：采用经过说明的贴纸/2.5D 路线，或完成实际模型与绑定；不默认为通用玩偶。

## 界面拆层

按独立运动需求拆分：背景/窗口壳、导航/主体/侧栏/时间线、按钮/手柄/卡片、选中态/数字/进度/作品画布、角色与前景。纹理、碰撞、发光与文字随对应面板一起移动。长网页的固定导航和滚动内容分离，不能整体移动截图冒充滚动。

面板边界采用 `[x,y,w,h]`，接触点采用逻辑像素 `[u,v]`。原图先映射到逻辑坐标，再乘纹理倍率裁切。禁止把 2× 纹理坐标当成 1× 布局坐标。

## 界面类型与动作语义

以下是候选设计，不是经过验证的产品功能。选与用户截图和软件版本一致的动作。

| 类型 | 动作候选 | 必须呈现的反馈 | 避免 |
|---|---|---|---|
| 博客 | 推文章卡、攀目录、拉阅读进度、拨主题开关 | 正文展开、章节定位、进度和配色变化 | 根据首页编造用户履历或正文 |
| Instagram | 跨九宫格、拉出照片、拨轮播、触心形 | 图片放大、轮播变化、心形反馈 | 将动画里的点赞/增长称为真实账号结果 |
| App/网页 | 按主按钮、拖滑块、切 Tab、搬卡片 | loading→结果、参数联动、内容切换 | 所有按钮只闪亮一下 |
| PR 风格 | 拖片段入轨、推剪切点、拉播放头、放标题 | 片段吸附、预览对应切换、字幕出现 | 播放头走但预览不变 |
| AE 风格 | 踩工具、插关键帧、踢效果、骑播放头 | 作品元素出现、属性/关键帧吻合、效果与播放可见 | 用电影时间代替作品内部时间 |
| CAD 风格 | 抓草图点、拉挤出手柄、转视角、贴尺寸 | 草图闭合、实体沿轴拉伸、视图与标注联动 | 用屏幕像素冒充工程尺寸 |

未提供的文案/照片优先请求或用明确标识的演示内容。产品事实需要截图、录屏或官方资料支持，精确复现某版本时核验该版本；戏剧化操作不应变成虚假的产品能力展示。

## 接触与动作

- 跳：压低重心→加速→顶点→脚底落点→板面轻压→回弹。
- 按：手脚触达目标才触发反馈，按钮行程沿面板法线。
- 推拉：手与物体绑定到共同坐标，身体补偿，不能手已离开物体仍继续推。
- 拖拽：拾取、保持接触偏移、目标高亮、释放与吸附依次发生。
- 骑滑块/播放头：先绑定再运动，UI 参数随控件变化，结束解绑。
- 平面立体化：同一剪影逐渐显露体积，用遮挡/阴影支撑变化，不突然换人物。

落点以渲染帧判断；模型比例、面板、相机变化后重查接触。关键文字和结果保留阅读时间，角色不长期挡住它们。
