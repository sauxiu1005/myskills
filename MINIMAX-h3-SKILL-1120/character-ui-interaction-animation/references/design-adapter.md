# Design 接入与交付

## 能力发现

只制作技能时交付ZIP，不启动付费媒体任务、不自动发布。完整包保留一个 `character-ui-interaction-animation/` 根目录，含入口、引用、脚本、资产与元数据。不要只上传 SKILL.md 而遗漏所引用内容。

实际运行时，从当前正式工具/界面发现项目文件、代码执行、图片生成、资源上传、视频节点、剪辑、预览与项目入口。使用真实 schema 和当前返回值，不猜工具名、模型ID、内部接口或云端文件路径。本机/云端不默认共享文件系统。

记录实际模型、skillRoot、projectRoot、运行时和渲染设备；不把本次作者机器的绝对路径写入作品脚本。生成资产保留真实任务/资源ID和版本；未知字段为 null，不能填伪造成功值。

## 生图与工程

用户上传的角色/截图作为输入资产，按用途调用实际生图/编辑工具补缺。保持已接受的角色身份，先验证代表资产再扩展。不用生成模型重画精确文字和UI。生图输出验收后进入项目资产目录，建模仍由真实几何/绑定完成。

无Blender执行能力：交付已完成的分析、资产、代码和可运行说明，标记待渲染；无Design通道：可完成本地视频，标记待导入。不能把这两种状态说成端到端成片交付。

## 导入与播放

1. 本地编码后完整解码、查看关键帧并试听，验证最终文件。
2. 通过正式上传/导入入口进入用户目标项目，记录返回资源和节点版本；不把绝对文件路径当远程URL。
3. 若需经平台剪辑再导出到画布，仅使用当前可见的真实入口。导入已混音视频后避免重复叠配乐。
4. 在最终画布播放器检查画面/时间推进、暂停恢复、中段跳转、片尾；资源列表或剪辑器可播不能代替画布验证。
5. 每项失败至多两次有原因和调整的重试，未知提交先查状态避免重复；受阻保留已完成产物和恢复条件。

## 可编辑工程入口

优先使用平台实际返回/复制的项目或编辑器链接，打开确认本次最终版本与可编辑源工程可访问。只有成片的节点不是三维编辑器，下载ZIP不等于直接进入编辑器，不为获取链接自动公开发布。

交付必须包含真实 `.blend` 与完整依赖包，并遵循 [Blender 工程交付](production.md#可编辑-blender-工程交付) 的建模可编辑性要求。有真实入口时最终给“打开可编辑工程”；本地交付给“打开 Blender 工程（.blend）”及“下载完整工程包”，说明包含外部依赖时应保持解压目录结构。平台仅支持 ZIP 时明确包内 `.blend` 的准确路径，不以代码包、视频节点或只有脚本的目录替代。链接未验证就注明。不得猜URL、深链或工程ID。

技能包本地保存不代表已在Design安装/更新；只有用户请求安装时才通过实际入口导入，并核对解析的名称和版本。
