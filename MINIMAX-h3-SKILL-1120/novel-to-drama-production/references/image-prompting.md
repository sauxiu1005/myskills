# 图片默认与质感规范

## 1. 参数与范围

- 默认图片模型 **GPT Image 2**、清晰度 **1K**；用户明确指定其他选择时优先。运行时发现实际模型ID与合法参数，不能把2.5当成2，也不能只在提示词里写模型名称。
- 分开保存模型、分辨率档、质量设置、画幅、实际输出宽高与导出宽高。1K是工具档位，不保证所有比例均为1024×1024。不擅自提高质量档、分辨率或成本。
- 场景和分镜采用项目已确认画幅，提示词与工具参数一致；独立身份参考可保留所需视图比例。禁止拉伸人物来适配画幅。
- 仅要求修改skill、默认模型/清晰度或提示词规范时，只编辑技能文件，不执行项目生图、资产替换或后续制作；仅要求提示词时不提交生图；编辑时先查看原图，并通过真实参考参数绑定身份和场景。
- 以下自然材质规范针对写实项目。动画、插画、油画等保留用户已确认画风，不一概强制去掉其有意的风格化光泽。

## 2. 先诊断，再改提示词

实际查看原图，指出具体问题及位置：例如台阶整面像镜子、干墙与湿地同样发亮、皮肤被磨平、布料呈塑料硬壳、室内所有物件均匀橙亮。只描述已观察到的缺陷，未看人物近景时不能声称其皮肤有问题。

把“电影感、杰作、8K、极致细节、湿亮反光、HDR”一类宽泛强化词改写成可观察的限制。模型切换不能保证去除油感；过亮、微对比过强、材质同质化和过度平滑应分别处理。不要通过全图压暗、模糊、重颗粒或假划痕掩盖缺陷。

## 3. 提示词的六段结构

1. **任务与固定项**：新建还是参考编辑；固定脸型、年龄、发型、服装材质/纹样、场景空间与镜头内容。明确本次只变哪些方面。
2. **主体、动作与构图**：可见人物/物件、姿态、景别、相对位置与已确认画幅；无人场景明确无人。
3. **按物件描述材质**：给主要表面各自的反光和纹理，而非全局“逼真”。
4. **干湿分布**：哪里淋雨、哪里遮蔽、哪里仅水滴或脚印；反光随水膜和视角变化，不能所有表面同样湿亮。
5. **有来源的照明与成像**：实际光源位置、大小、方向、强弱和衰减；自然曝光与适量细节。摄影术语只是视觉描述，不是物理精度保证。
6. **少量针对性排除**：只排除当前缺陷，如美容磨皮、蜡质皮肤、塑料织物、全表面镜面反光、HDR光晕、过锐化。工具支持独立负向参数才使用，否则写入正文。

## 4. 写实材质与光线

| 对象 | 正面描述 | 避免误改 |
| --- | --- | --- |
| 人物皮肤 | 细微自然纹理、轻微色差，面部水珠局部亮点；疲倦但正常肤色 | 不用巨大毛孔/满脸污垢替代细节，不把苍白变成灰尸脸 |
| 红色戏袍 | 保持原织物与纹样；褶皱随重力，丝质柔和方向性光泽，湿处压暗 | 不改棉布，不变皮革或塑料壳，不抹掉刺绣 |
| 旧木/漆门 | 大部分低光泽，磨损处与水滴局部反射，清楚木质与漆层差异 | 不整面打蜡，不为了去油清除年代感 |
| 墙灰/水泥/砖石 | 粉质或粗糙漫反射，受雨区域深色，遮蔽区较干 | 不把粗糙墙面做成釉面，不让雨夜完全无水 |
| 积水 | 反射位于水面和迎光角度，被涟漪打碎；与粗糙干处交错 | 不让每块砖/每级台阶均像镜面 |
| 金属/玻璃 | 与材质一致的有限高光和真实边缘 | 不是所有东西都哑光，保留必要金属与玻璃质感 |
| 室内 | 家具与地面通常干燥，湿脚印和滴水范围局部发亮 | 不把整间屋子做成雨水浸透的摄影棚 |

煤油灯作为小范围暖光源，亮度随距离衰减；雨窗冷天光是较弱的柔和填充，保留光线照不到的区域。限制全图橙蓝染色、发光轮廓、泛光与均匀补光。保留暗部层次和正常色彩，不把低饱和、低对比固定为所有故事的美学。

## 5. 《戏鬼回家》示例：门外

以下是有对应参考时的编辑模板，实际生成必须绑定原场景图；模型/1K/16:9在工具参数中另设。

> 以所附沈家门外图为参考，保持旧绿漆木门、黄铜锁、门左绿色铁皮报刊箱、台阶和墙体的位置、形状与比例。16:9横屏，人眼高度略斜的三分之二视角，无人。只修订材质与照明。暴雨夜，屋檐下的墙灰偏干，呈粉质粗糙表面，近地面受雨处颜色较深。旧门漆低光泽，局部磨损与零散水滴可见；黄铜锁只有小面积金属亮点。水泥台阶粗糙，积水处才反射门缝暖光，水纹把反射打散，表面保留不连续的粗糙暗部，不整面镜面发亮。门缝煤油灯光局部温暖，向外迅速减弱；柔和微弱的雨夜天光保留墙面与门的层次。实拍剧照般自然曝光、克制色彩与适量细节。无全表面油膜、HDR光晕、过锐化或夸张橙蓝染色。

## 6. 《戏鬼回家》示例：沈砚近景

实际绑定已选身份锚点与原近景，保留近景原取景比例或项目明确指定的横屏构图。

> 保持参考图中沈砚的同一面孔、年龄、骨相、发型、表情、红戏袍款式和刺绣，只调整皮肤、衣料和照明质感。雨后疲惫的近景，几缕湿发贴额，面颊零散水珠仅在迎光处形成小亮点。肤色苍白但自然，保留细微皮肤纹理和轻微色差，脸颊与额头大部分呈柔和漫反射，不覆连续油膜，不磨皮，也不强化粗大毛孔。红戏袍保留原丝质的柔和方向性光泽，湿处压暗，布料褶皱有自然重力感。沿用原光源方向，以柔和局部光照显出五官，暗部保留层次，无额外美容轮廓光。无蜡像皮肤、塑料衣料、HDR光晕与全局锐化。

## 7. 审图、版本与依赖

以下流程仅在用户要求实际图片生成或质感修订时执行；维护本规范不需要生成测试图。先选一张场景、一张人物作为代表图，用新参数和针对性提示词编辑。保留旧版并排比较：身份与空间是否一致、材质是否可区分、反光是否局部且合理、干湿逻辑是否成立、光线是否有来源、细节是否保留。根据实际缺陷每张至多一次定向重试；没有实际查看就标记未审阅。

记录完整prompt、实际模型ID/参数、输出尺寸、输入参考版本、任务ID、产物ID及审图意见。新旧版明确关联，审阅通过才推广至相关后续提示词。替换资产后标记依赖旧资产的镜头需要复核；既有视频不会自动更新。仅完成图片修订时，明确哪些视频仍用旧图，按授权范围推进后续制作。
