# 小说改编与短剧制作

**Novel-to-Drama Production** · `novel-to-drama-production`

**v1.2.1** 将小说或已有剧本制作到短剧成片：分集大纲、人物与美术设定、对白剧本、站位分镜、参考图、逐镜视频、配音与系统面板、剪辑混音、字幕、渲染验收。支持完整制作，也支持单阶段检查、续写与修改。交付可播放视频、可编辑工程或重建文件、字幕、可用声音轨、素材清单与画布报告。技能编排当前可用工具，不自带在线模型或媒体引擎，也不绑定执行技能的对话模型。

## 使用

通过技能导入入口上传完整 ZIP；保持目录结构，不单独导入七个归档模块。技能在当前项目中读取原文与素材、创建文稿、调用可用图片、视频、声音、剪辑和导出工具，并在画布组织交付物。具体能力以当前会话实际工具为准，不需要安装归档服务或填写外部 API 密钥。

示例：

1. “使用小说改编与短剧制作，把这篇小说改编为 12 集都市悬疑短剧，每集 2 分钟，继续完成配音、剪辑和最终成片。”
2. “基于这个剧本安排人物开场站位，再做分镜和视频提示词。”
3. “给这个原创人物制作正面、侧面、背面和面部参考图，放在当前项目里。”
4. “复用现有视频，补齐系统配音和面板，完成混音、字幕及成片验收。”

已选模型、画风、画幅和审核方式沿用已有要求。仅要提示词时不启动出图。图片派生实际绑定同一个已选锚点，保存版本与依赖；不把提示词、示例图片或提交中的任务标为完成。

## 报告查看与画布交付

已生成的大纲、角色、美术、剧本、站位、分镜报告、角色图册、后期报告和成片验收报告，默认按阶段归入画布“制作报告”分组，并设置可点击的报告总览。每份报告使用明确的类型／集号／版本标题，生成后即放置，逐个核对能否打开；角色报告与站位报告保留独立入口。原始JSON作为次级文件，不代替可读报告。仅产出本次范围内的阶段；工具不支持时如实说明画布缺口并交付真实文件链接。仅修改skill不会自动调整现有项目。

## 图片默认设置

仅修改技能或提示词规范时不触发项目生图。实际生图与图片编辑默认 **GPT Image 2、1K**，用户指定优先。模型与参数按当前能力核实，GPT Image 2.5不作同名替代；记录真实输出尺寸。写实画面通过材质、局部干湿和实际光源减少油亮塑料感，先审代表图再推广；详见[图片提示词与质感规范](references/image-prompting.md)。

## 后续视频默认设置

用户要求继续视频制作时默认使用 SD2.0。首次视频生成前询问用户所需清晰度，按当前模型可用档位给出选项，收到答案后才提交生成；同一项目已有明确选择则沿用。768P不是全局默认值，图片清晰度与成片导出尺寸也不替代视频清晰度选择。模型或所选档位不可用时说明限制并询问替代，不自动切换。

## 成片流程与完成标准

[逐镜制作](references/video-production.md) → [后期与成片交付](references/post-production.md)。以锁定剧本建立独立声音覆盖表，核对对白、内心独白和系统内容，避免漏句或原生对白重复配音；系统面板后期制作并实际检查遮挡。沿用合格素材，有限定向修复，保存可编辑时间线和声音分轨。

实际导出后检查规格、完整解码、全片视听与台词覆盖；通过关键验收并核实交付后才称成片完成。素材列表、生成中的任务和未验收导出不等于成片。首次视频清晰度仍需明确选择；预算、用户指定审核方式及现有授权保持有效，不新增逐阶段确认关卡。仅更新技能不执行任何项目生成。

[后期清单约定](references/post-manifest.md) 配合以下脚本检查时间线结构、视频空缺、裁切越界、漏台词、意外语音重叠和面板时间；它不替代真实媒体与视听检查：

```bash
python3 scripts/check-timeline.py /absolute/project/post/manifest.json
python3 scripts/check-timeline.py /absolute/project/post/manifest.json --require-local
python3 scripts/test-timeline.py
```
