# 液态字标动效 Liquid Logo Motion

依据 [原文](https://github.com/Vincentwei1021/mg-styles-15/blob/main/prompts/07-liquid.md) 及其示范站点的评审标准、示范片与源码整理的制作技能。承担导演、动效设计、工程实现和声音设计，制作一支有明确风格、精细动作与完整声音的液态短片。来源范围见 [来源说明](references/provenance.md)，示范片拆解见 [示范片要点](references/reference-film-notes.md)。

目标是这一风格最经典、也最惊艳的形态，达到奖项入围或高端商业水准。干净但像模板的结果视为失败。参照水准：Buck、ManvsMachine、Ordinary Folk、Giant Ant、Territory Studio、Apple 发布会动效、Pentagram 动态识别，以及 Behance / Motionographer 精选和抖音、B站头部设计账号。

## 输出规格

原文规格：1920×1080，30fps，精确 10.000 秒、300 帧；H.264 MP4（yuv420p），48kHz 双声道 AAC；综合响度 −14 LUFS，真峰值不高于 −1 dBTP。最终文件命名为 `video.mp4`。

原文允许修改故事、品牌名、文案、配色和输出尺寸，例如改为 1080×1920 竖屏。保留下文“标志性技法”，它决定作品能否一眼被认出是液态风格；用户明确提出其他规格时遵循用户要求。

## 建议技术路线

使用 HTML/WebGL2 片元着色器，以二维 SDF metaballs 的平滑并集表现液体融合，通过场梯度构建法线与伪三维光照，用文字 SDF 实现字标聚合。如果另一条路线能明确提高质量，可以采用并解释原因。

执行环境需要网页渲染能力（Node 与 Chrome）以及 ffmpeg。采用以下固定约定：

- 影片是一个网页，`window.renderAt(t)` 按时间 t 绘制任意一帧，`window.DEMO = { width, height, fps, duration, motionBlur: { samples, shutter } }` 声明规格，准备完成后设置 `window.__ready = true`。
- 渲染脚本用无头 Chrome（macOS 使用 `--use-angle=metal` 等硬件 WebGL 参数）逐帧截图，ffmpeg 编码并合入音轨。脚本支持三种用法：只出指定时刻的静帧、半分辨率预览、全分辨率正式渲染（CRF 约 14）。
- 也可通过 Blender 脚本输出 PNG 序列。

### 渲染与材质要点

- **高动态范围管线**：场景输出到 RGBA16F 浮点缓冲，提取高光后用多级缩小图做泛光，最后在后期处理中做色调映射、轻颗粒和暗角，减少色带并加强光泽。
- **半透明果冻材质**：在法线光照之外，加入折射偏移、薄处透光、焦散亮斑与菲涅耳边缘光；字母和液团内部可散布少量气泡。避免只有不透明色块加高光。
- **镜面地面**：开场设置深色镜面地面或水平面，液滴着地有倒影、王冠状水花和挤压，为液体提供空间与重量。
- **文字 SDF**：每个字母单独生成距离场（可放入 RGBA 不同通道），记录各自中心点，便于逐字母聚合、连桥和断裂。生成时用亚像素精度的 alpha 初始化加精确欧氏距离变换，再做轻微高斯平滑，避免字形中轴在液体高度场上出现折痕。
- **字体加载**：使用 `font-display: block` 和 `document.fonts.load(...)` 等待字体就绪后再生成 SDF，杜绝字体回退。优先选择圆润、软衬线或高字重的开源字体，例如 Fraunces Soft、Unbounded。

## 创意起点：液态创世

采用深梅紫背景，液体呈橙、粉、紫的糖果色变化；通过镜面高光、折射和菲涅耳边缘光体现黏稠体积。画面应有光泽、有机且充满能量，避免只表现为平面的色块。

| 时间 | 画面动作 |
| --- | --- |
| 0–2 秒 | 液滴落下并飞溅，着地时发生挤压变形 |
| 2–4 秒 | 液团黏连融合，出现细颈、断裂和回弹，次级液滴稍晚跟随 |
| 4–6 秒 | 大液浪扫过画面完成转场，前沿带错相位起伏 |
| 6–8.5 秒 | 液体逐渐聚合成字标，例如原创文字 FLUX |
| 8.5–10 秒 | 字标最后一滴落下并激起涟漪，保持结束构图 |

声音方向包括气泡、黏液、倾倒、飞溅、滴落、低频渐强及有光泽的合成器铺底。可以重新设计概念和故事节拍，但必须保留液态风格的辨识度。

### 让创意更强的手法

- **品牌名与概念合一**：最好让字标本身就是故事，例如示范片用“drop.”（一滴）讲“万物始于一滴”。用户已指定品牌名时，让故事服务于该名称的含义或字形。
- **一滴对应一个字母**：字标中的每个字母由一颗可追踪的液滴在原位充盈长成，观众能看清来源和灌注方向；避免大量液珠同时“长”出整词。
- **色彩叙事**：开场只出现一种颜色，之后逐步引入第二、第三色；最后各字母沿用引入顺序形成从左到右的渐变。
- **转场带观众进入液体**：液浪转场分为涌入、浸没、揭开三段。浸没段画面完全处于液体内部，有上浮光斑和气泡，再由波浪前沿揭开下一场景。
- **主次两层字标**：用户在第 0 步选择添加副标时，在最后一滴落下后加一行很细的副标，置于字标下方，按用户确认的语言和文字排版，保持八成左右的留白；用户选择不加副标时省略这一层。
- **结尾持续存活**：字标成形后有果冻般回弹，底部挂着一滴将落未落的液滴，落下后激起同心圆涟漪；结束构图保持 0.8–1.4 秒并保留微动。

## 镜头语言（虚拟摄像机）

液态短片不能用固定全景从头拍到尾。示范片的动感很大一部分来自虚拟摄像机：开场在微距里贴着液滴，随动作逐步拉开，在重击点上冲击，最后在字标上缓慢推近。制作时必须设计一条镜头轨道，并写进节拍表。

- **实现方式**：在着色器的世界坐标外加一层二维摄像机 `cam = { zoom, cx, cy }`，画面坐标 = (世界坐标 − 中心) × zoom + 画面中心。镜头关键帧写成 `[t, zoom, cx, cy]` 列表，用非均匀 Catmull-Rom 插值保证速度连续，不出现顿挫；所有液体、倒影、地面和光照都经过同一个摄像机。
- **开场微距**：第一帧从约 5× 的微距开始，紧贴正在形成或下落的首滴（液滴约占画面宽度三成），跟着下落向下摇；首滴着地时王冠水花约占画面四成。
- **跟随拉开**：随着后续液滴落下，镜头逐步拉开到约 2.6×→2.1×→1.6×，并横向追随当前落点（中心在各落点间移动），让每次着地都在画面里有位置。
- **追随动势**：液团跃起、拉丝时镜头跟着抬升或下沉；动作的方向就是镜头移动的方向，用于引导视线和衔接下一段。
- **穿透转场**：液浪或大液团来临时，镜头快速推入液体（指数加速），让液体颜色填满画面作为遮罩；在浸没段从液体内部向后拉出，再揭开下一场景。
- **重击冲击**：每次着地叠加一个衰减振荡的缩放冲击，约 `zoom × (1 + A·e^(−t/0.16)·sin(2π·3.2·t))`，A 取 1.3%–2.2%，最大一滴用最大值；液浪冲击约 1.6%。字标成形瞬间做一次硬推：2 帧内放大到约 1.07，再用 12 帧回落到 1.02。
- **结尾慢推**：字标成形后到片尾，用正弦缓动持续慢推约 4%–5%（总倍率约 1.065），同时纵向微调保持字标光学居中；主光源在结尾段缓慢移动，让高光在字母上滑过。镜头保持“活着”，但不能抢字标。
- **节奏规律**：动作段快进、展示段慢出；镜头重音对齐节拍表中的重击点，冲击和推拉都由同一份 cues.json 驱动。
- **检查**：低分辨率预览时专门检查镜头：首帧是否已在运动，转场处是否由镜头和液体共同完成，冲击是否和声音起音同帧，结尾是否保有微推而不僵死。避免镜头匀速平移、无缘无故的抖动，以及缩放导致字标或液滴越出安全边距。

## 标志性技法

- **波浪遮罩转场**：波浪形前沿扫过画面，设置 3–5 个错相位凸起。
- **Metaball 融合**：可使用平滑距离场；另一种方法是高斯模糊后收紧 alpha 阈值，使相邻液团自然黏合。原文给出的模糊起点为 20px 以上，AE 可用 Levels，Web 可用 feColorMatrix。
- **拉丝、断裂、回弹**：主体离开时保留细颈，断裂瞬间两端各回弹 2–3 帧。
- **甩出式缓动**：参考 `cubic-bezier(0.22,1,0.36,1)`，形成前快后慢的动势，避免液体匀速平移。
- **次级跟随**：小液滴比主体延迟 2–3 帧，着地时压扁。
- **有机轮廓**：保持流动、滴落、融合和曲线感；用元素运动承担转场，避免依靠普通交叉淡化。

## 制作流程

### 0. 确认主标题与副标

开始制作前，先向用户确认以下两项，得到答复后再进入创意与节拍；用户在请求中已明确给出的项不再重复询问：

- **主标题 / 品牌名**：请用户输入字标文字，逐字保持其拼写、大小写和标点，不自行改写或纠正；若用户没有现成名称，可提供 2–3 个原创候选供其选择。
- **是否需要副标**：询问是否在字标下方加一行副标，提供“不加副标（推荐保持简洁）”“由用户输入副标文字”“由我拟写几条候选”三个选项。副标可以不添加；用户选择添加时，再确认使用的语言（仅中文、仅英文或中英双语），文字逐字使用用户确认的版本。

不添加副标时，结尾只保留主字标与涟漪微动，不出现任何副标文字。

### 1. 创意与节拍表

明确一个清晰创意。前 0.5 秒建立吸引点，开场空白或黑画面不超过 0.3 秒；能量逐步上升，在总时长约 60%–75% 设置主视觉高潮。结束构图保持约 0.8–1.2 秒，同时留少量微动。

将各项风格特征和镜头关键帧安排到具体时刻，写成一份节拍表文件（如 `cues.json`），画面、镜头和声音都只读取这一份：

- 先定速度和调性，例如 150 BPM（每拍 0.4 秒）、D 大调。
- 着地、融合、断裂、液浪、字标成形、最后滴落等重击点对齐到拍子，再取整到具体帧。
- 同类动作按拍子均匀分布，例如每拍一次着地、每拍一次融合，形成可感知的节奏。
- 由画面实际算出的时刻（如浪前沿越过画面中线）回写到节拍表，再交给声音使用。

### 2. 先看关键帧

先建立视觉效果，在 6–10 个关键时刻渲染全分辨率静帧并实际查看。每张都应达到可作海报的水平。检查构图、层级、留白、字距、行距、字重对比、中文标点及约 5% 安全边距；修正拥挤、默认模板感和排版问题后再继续。

### 3. 动画预览

低分辨率预览动作编排和镜头轨道，按“镜头语言”一节逐项检查镜头。最快运动逐帧检查间距、缓动、运动弧线、重叠、预备动作、跟随和适当的运动模糊。避免非预期停滞，使忙与静的对比跟随音乐节奏。

### 4. 声音制作

按同一节拍表制作符合风格的音乐与音效：

- 每次液滴着地配一个调内有音高的点状音色（马林巴、木鱼、拨弦合成器等），让落点连成旋律，而不只是噪声。
- 拉丝断裂配上扬滑音或气泡音，液浪配倾倒与冲刷声，字标成形配低频冲击，最后一滴配一声清亮的“叮”。
- 有光泽的合成器铺底与低频渐强承担能量曲线。
- 视觉重击对齐声音起音；正式渲染后用起音检测核对，偏差控制在一帧（约 33 毫秒）以内。
- 母带达到 −14 LUFS、真峰值不高于 −1 dBTP，同时保留动态，不把响度范围压得过平（示范片约 5 LU）。

### 5. 正式渲染与检查

全分辨率导出，按需要加入运动模糊。检查时长、分辨率、帧率、音轨、响度和真峰值；检查黑帧、字体回退、缺字、边缘裁切、细线闪烁及渐变色带。发现问题后修正并重新检查。

### 6. 独立评审

成片后按 [评审标准](references/review-rubric.md) 做一次独立评审：评审方视自己为未参与制作的评委，不沿用制作过程中的判断。

- 取材：每 0.5 秒一帧的缩略图总表、最快动作与高潮附近的连续帧、5–8 个关键时刻的全分辨率帧。
- 七项打分并列出关键问题和 5–10 条按影响排序的修改建议；每条写明时间码、可观察的问题、原因和具体做法（缓动曲线、帧数、像素、色值、字体或版式），至少一条用于提升惊艳感。
- 把评审结果与建议交给用户，由用户决定是否按建议再修改一轮。修改前保留当前版本；修改后重新渲染、重新检查，并说明采纳或跳过了哪些建议及原因。

### 7. 自评

诚实说明最强项、最弱项以及增加时间后会改进的部分。分别对风格还原、创意、动作、设计排版、画面完成度与质感、声音同步、技术质量作 1–10 分自评，使用完整尺度：5 = 合格的学生作品，6 = 模板水平，7 = 扎实的专业水平，8 = 高端机构水平，9 = 奖项入围，10 = 世界顶尖。大多数首版应在 5–7 分，不要虚高。这些是主观评价尺度，不是实测认证。优先改善最低项。

## 制作约束

- 每帧由时间 t 确定，随机使用固定种子；物理与粒子预计算或用解析方法实现。不依赖实时钟或状态触发式 CSS 转场。
- 素材采用 CC0、公有领域、OFL、Apache 或其他允许免费商用的资源，在报告中记录来源和许可。
- 按原文使用原创品牌名，不采用真实品牌商标；用户指定的品牌名逐字保持。
- 屏幕文字准确自然；中文表述、标点及字形均需检查。
- 动作具有明确缓动、预备、跟随、错落、弧线和适合风格的挤压拉伸，物理感一致。
- 画面有明确构图、网格和排版层级，控制配色；颗粒、辉光、暗角仅在符合风格时使用。
- 无非预期抖动、跳变、锯齿、色带、字体回退或半加载图片；声音应有音乐性、风格一致且同步。
- 以下情况视为关键问题，必须修正：看起来通用或像 AI 模板、中文不自然、字体回退或缺字、任何规格不达标。

## 交付

交付 `video.mp4` 与简短报告。报告包括：

- 两句话概念说明。
- 带时间码的节拍表。
- 各项液态特征如何实现，以及镜头轨道（关键帧与冲击点）。
- 实际技术路线。
- 实测时长、分辨率、帧率、响度、响度范围和真峰值，以及主要重击点的音画偏差。
- 三项最主要的不足。
- 七项自评分数；如已进行独立评审，附评审分数与修改建议。
- 素材与许可。
