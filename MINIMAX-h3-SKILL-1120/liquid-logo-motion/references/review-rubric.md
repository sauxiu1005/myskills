# 独立评审标准 / Review rubric

整理自 mg-styles-15 仓库 `rubric.md`。原片都按“制作 → 独立评审 → 按评审修改 → 再评审”迭代，示范片改了两轮。

## 评审方设定

评审方是资深动效评委（参照 Motionographer 编辑、Buck / ManvsMachine 创意总监、抖音 / B站头部设计账号负责人），没有参与制作。要严格、精确，目标是让作品达到奖项或高端商业水准；客气没有用，具体才有用。

## 1. 取材

- 每 0.5 秒一帧的缩略图总表。
- 最快、最重要动作及高潮附近的连续帧。
- 5–8 个关键时刻的全分辨率帧，查看边缘、排版、锯齿、色带、质感和裁切。

## 2. 规格核对

精确 10.00 秒；分辨率与帧率符合规格；有音轨；响度约 −14 LUFS（±1）；真峰值 ≤ −1 dBTP；除有意设计外无黑帧、无非预期静止段；视觉重击与声音起音对齐。

## 3. 七项打分（1–10）

5 = 合格的学生作品；6 = 模板水平；7 = 扎实的专业水平；8 = 高端机构水平；9 = 奖项入围；10 = 世界顶尖。大多数首版应在 5–7 分，不要虚高。

| 维度 | 看什么 |
| --- | --- |
| 风格还原 style_fidelity | 一眼认出的经典形态；每项标志特征与技法都出现且做对 |
| 创意 concept_wow | 清晰概念、前 0.5 秒吸引点、明确高潮、令人满意的结束画面 |
| 动作 motion_craft | 缓动、间距、重叠、预备与跟随、弧线、转场、运动模糊；无死板或抖动 |
| 设计排版 design_typography | 构图、层级、网格、字体排版（含中文）、配色、留白 |
| 完成度与质感 finish_texture | 光照、质感、颗粒、辉光与细节符合风格；无色带、锯齿或瑕疵 |
| 声音同步 sound_sync | 音乐性、风格正确、音效设计、与画面同步、混音与母带 |
| 技术 technical | 规格达标、字体加载、无故障、裁切或跳变 |

## 4. 修改建议

5–10 条，按对整体观感的影响排序。每条写：时间码；可观察的问题；为什么重要；具体做法（技法与数值：缓动曲线、帧数、像素、色值、字体、版式调整）。宁可少数大幅升级，也不要大量细枝末节；至少一条用于提升惊艳感，而不只是抛光。

## 5. 关键问题

以下一律标为关键：看起来通用或像 AI 模板；中文不自然；字体回退或缺字（豆腐块）；任何规格不达标。

输出：分数表、关键问题、修改建议清单。

## 按评审修改

- 先保留当前视频与源码作为第 N 版。
- 落实全部关键问题和高影响建议；有更好的方案可以替换，并说明理由；看到更大的提升空间（尤其惊艳感）可以超出清单；不要削弱评审列出的优点。
- 全分辨率重新渲染，重新核对规格并查看画面，确认修改真正生效。
- 报告采纳和跳过了哪些建议及原因。

评审结果先交给用户，由用户决定是否修改。
