# 示范片要点 / Reference film notes

示范片：「drop.」万物始于一滴（mg-styles-15 · 07-liquid）。1920×1080、30fps、10.000 秒、H.264 High yuv420p；AAC 48kHz 双声道。实测综合响度 −14.0 LUFS，响度范围 5.3 LU，真峰值 −2.7 dBTP。

## 节拍表（cues.json 摘录）

150 BPM，每拍 0.4 秒，D 大调。

| 段落 | 时刻（秒） | 说明 |
| --- | --- | --- |
| pour / rain | 0.0 / 0.4 | 倾倒起手；四次着地 0.4、0.8、1.2、1.6，每拍一次 |
| fuse | 2.0 | 三次融合 2.0、2.4、2.8，每拍一次 |
| leap / thread_snap / apex | 3.2 / 3.433 / 3.6 | 跃起、拉丝断裂、顶点 |
| flood / immersed / reveal | 4.0 / 4.42 / 4.85 | 液浪涌入、全屏浸没、揭开；三层液幕错开 0.07 秒进出 |
| gather / drop / logo_snap | 5.75 / 6.4 / 6.4 | 聚合、字标成形，字母连桥 6.417–6.483 依次断开 |
| glint | 7.1–7.2 | 字标高光扫过 |
| drip / ripple | 7.6 / 8.4 | 最后一滴落下并激起涟漪；副标随后补齐 |
| outro / end | 8.8 / 10.0 | 音乐收尾、结束构图 |

液浪的声音重击点由画面实测（液幕前沿越过画面中线）回写节拍表，再取整到帧。

## 画面观察

- 深紫镜面地面：橙色首滴着地激起王冠状水花，有倒影与挤压。
- 颜色逐步加入：先橙，后粉、紫，多颗液滴弹跳滑行。
- 粉紫液团被向上拉成细颈与悬垂液泡，断裂后切入粉色“液体内部”，有上浮光斑与气泡。
- 四颗液滴横排，后方粉色浪涌包裹；四滴分别在原位长成 d、r、o、p，形成从橙到紫的左右渐变。
- 字母为半透明果冻质感，有折射、焦散、菲涅耳边缘与内部小气泡；字体为 Fraunces 72pt 900 Soft 静态实例（软衬线、圆润）。
- p 底部挂滴、落下、涟漪；随后细体白字中英副标「万物始于一滴 / EVERYTHING BEGINS AS A DROP」出现在字标下方；留白约八成。

## 镜头观察（scene.js 的 CAM 与 punch）

镜头关键帧 `[t, zoom, cx, cy]`，非均匀 Catmull-Rom 插值：

| t | zoom | 中心 | 说明 |
| --- | --- | --- | --- |
| 0.0 | 5.3 | (640, 398) | 微距贴住倾倒的液泡 |
| 0.167–0.42 | 4.9→3.3 | y 452→800 | 随下落下摇，0.40 王冠约占画面 38% |
| 0.8 / 1.2 | 2.6 / 2.15 | x 1010 / 745 | 横向追随第二、三滴落点 |
| 1.7–3.05 | 1.6→1.72 | 约 (880–960, 760) | 融合段宽景，轻微推近 |
| 3.6 / 4.0 | 1.46 / 1.42 | y 590 / 640 | 跃起时镜头上抬 |
| 4.6–5.9 | 1.2→1.0 | 回到 (960, 540) | 液浪后拉开到全景 |
| 5.9–10 | 1.0 | 固定 | 由冲击与慢推提供动感 |

- 着地冲击：`punch += A·wob(t − tLand, 3.2Hz, 0.16s)`，普通滴 A=0.013，最大一滴 0.022；液浪冲击 0.016（3.0Hz，0.2s）。
- 字标成形：2 帧内 zoom ×1.07，12 帧回落到 1.02；之后正弦缓动慢推到约 1.065，纵向补偿 −60×(zmul−1) 保持居中。
- 结尾主光源移动，高光在字母上滑过。
- 画面观察：穿透液团进入粉色内部空间完成转场，随上浮液滴上升，字标成形时有冲击微抖，结尾慢推近乎静止。

## 声音观察

- 明快的电子 / 马林巴音色；每次着地对应一个有音高的木质敲击加水滴声。
- 拉丝与浸没段配上扬滑音、风铃感与气泡声。
- 字标成形配饱满低频冲击与液体涌动；最后一滴配短促清亮的“叮咚”，混响自然收尾。

## 工程要点

- `engine.js`：WebGL2，场景渲染到 RGBA16F，半分辨率高光缓冲生成多级缩小图做泛光，最后后期合成；字体排版层另用 RGBA8 纹理。
- `textsdf.js`：逐字母 SDF，每个字母占一个通道；TinySDF 式亚像素 alpha 初始化 + Felzenszwalb 精确距离变换 + 轻微高斯平滑，避免中轴折痕。
- `index.html`：`font-display: block` 与逐个 `document.fonts.load` 等待字体；`window.DEMO` 声明运动模糊 `{ samples, shutter: 0.5 }`；字标按墨迹包围盒光学居中。
- `harness/render.mjs`：页面提供 `window.renderAt(t)` 与 `window.__ready`；支持 `--stills`、`--scale 0.5`、`--crf 14`、`--mb`、`--shutter`；macOS 使用 `--use-angle=metal`。
