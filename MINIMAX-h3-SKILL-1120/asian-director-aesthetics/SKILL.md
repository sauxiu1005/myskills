# 亚洲导演风格美学

将导演风格转化为可见的空间、光色、人物行为和镜头选择。以具体作品分支为依据，导演名只作索引，不用标签堆砌代替设计。适用于静帧、关键帧、视频镜头、分镜表、色卡方案与提示词；只在用户明确要生成时才产出媒体。

## 步骤 1：确认需求与交付类型

- 保留用户的主体、人物身份、场景、时代、参考素材、画幅与交付类型（提示词／色卡／分镜／静帧／视频）。
- 没有具体作品时选择合适分支，不把现代题材擅自改成古装。缺失细节可按场景补全；只有决定性歧义才提问。
- 生成前确定画幅，视频还须确定时长，优先沿用用户已明确指定或确认的输出规格，不重复询问。只有用户明确指定某份素材作为画幅或时间依据时，才依据其实际尺寸或时长继承相应规格；电影或导演风格参考本身不自动决定输出画幅与时长。规格缺失时给出建议并询问，来源规格与能力限制冲突时先说明并取得调整同意。只写提示词时可标注建议规格，不将其冒充用户确认。
- 多步骤制作按可独立审阅的成果推进，每步交付后请用户确认再继续。只有用户明确要求直接完成或另行约定节奏时才省略中间确认；常规细节不反复询问。
- 仅要求总结、比较或提示词时，不启动媒体生成。

### 28 位导演可视化色卡

进行选色、色卡交付或色彩提示词设计时，先读[色卡使用指南](references/color-palettes.md)，再按需查看 `assets/color-palettes/` 下对应导演的 PNG 与 JSON。每张包含六个主色与四个情绪参考色，依据用户资料中的 HEX 补绘，非原片逐帧实测；等宽色块不代表构图占比。具体作品研究与用户参考图优先。这些卡片补充选色锚点，不替代人物、构图、光影或材质证据；既有参考图调用规则继续适用。

### 生图统一使用内部导演色卡

- 生成图片、首帧、关键视觉图、关键帧或人物锚点时，先读取所选导演的PNG和JSON，将实际PNG载入当前项目，并作为每次相关生图的颜色参考输入；仅在提示词写色名或HEX不算已完成此步骤。已在项目中的同一色卡直接复用，不重复导入。
- 色卡仅负责所选颜色：结合具体作品与场景选择主辅色并落实到物体和光源，不强制使用全部颜色或等宽占比；不得复制卡片文字、色块、标签或排版。身份、服装与布局参考职责独立，用户当前明确要求及作品分支优先。黑白作品仅使用适用明度／中性色，动画不因此增加真人胶片纹理。
- 生成前核对图片参考能力和可用槽位。色卡缺失、模型不支持或无法同时容纳必要身份／布局参考时，先说明并请用户选择兼容模型、调整参考安排或明确批准文字配色；不静默降级、不移除身份参考或擅自更换模型。用户明确禁止图片参考时遵从，标注为获准的文字配色例外；一般生图不默认退回此例外。
- 仅方案／提示词任务不生成媒体，说明后续生图所用的色卡职责即可。续改已有画面时仍传对应色卡，仅调整获准范围并保留未改颜色。视频优先继承已确认关键帧的色光，不把色卡当作视频字面首帧；视频是否另用颜色参考由当前输入能力与已确认方案决定。
- 保存实际采用的色卡与生成输入依据，交付说明区分“已传入PNG色卡”与“获准文字配色例外”。这是用户采纳的工作方式，不宣称色卡必然提升电影感、精确还原HEX或代表导演官方色彩标准。

### 外部视觉参考的选择与使用

本版不随包携带电影截图。涉及已覆盖的王家卫、张艺谋、贾樟柯场景关系时，读取 `references/bundled-visual-references.md` 作为纯文字研究，不将其当成本次生成已可用的图片证据。区分冷衣料与暖市集、暖黄与粉红米白室内，不统一将王家卫套成绿色或冷光。

- 使用本次用户提供或明确选用的实际参考，选择最少适用素材并分配职责；身份参考与当前明确约束优先于通用风格资料。
- 需要且能力支持参考图生成时，将实际选中图片载入当前项目并真正传入。文件名、历史追溯编号与文字研究不等于模型看到了图片。
- 从风格参考转译色光与材质关系，不继承演员脸、标志性站位、服装或画内文字；不从静帧推断动作与声音，不在未分配规格职责时继承来源画幅。
- 没有可用图片时明确标注纯文字转译，不声称参考图生成、不强制联网找图、不静默换模型或扩大范围。未来向公开Skill新增图片须另行解决分发权利，署名不等于授权。

## 步骤 3：设计视觉方案

1. 先确定人物、动作与空间，再选两三项最有辨识度且互相支持的特征。把“孤独”转成两人之间的门框与空白，把“权力”转成人物大小和站位；不要把主题词填入运镜栏。
2. 配色以主色、辅色、强调色组成，说明色彩落在哪些衣料、墙面、道具或光源上。HEX 是设计参考，不保证生成器精确还原。比例、焦距、色温和光比若需给出，标为本次方案建议，不冒充导演惯用的固定参数。
3. 人物造型符合用户设定及所选作品语境，写明年龄感、衣着材质、妆发、姿态和关系。未指定时从故事场景推断，不默认通用时装模特、不从风格参考继承演员面孔、不按地域或职业简化人物。
4. 静帧只呈现一个可见瞬间；长镜头、音乐、剪辑转译为纵深、姿态和画外暗示。视频说明起始构图、动作进程、镜头路径和结束状态，复杂动作拆成可执行镜头。
5. 用户提供参考图时，为每张图分配职责（人物身份、场景布局、色光、动作节奏），参考图优先于本包通用色值。

### 创作纠错与可执行表现

在完整视觉方案编写前，以及处理人物、空间、色光或动作反馈时，读取 `references/creative-refinement.md`；只应用与本次任务相关的条目。这是本项目迭代提炼的设计方法，不是导演的固定摄影规律。

- 未指定真人身份时设计原创人物；“明星气质”不等于明星面孔，吸引力服务于角色而非模板化美颜。已有身份约束优先。
- 先建立设施位置、出入口、通行、透视及接触关系，再设计遮挡与色光；主体和环境的新旧程度、照明、反射、纹理要统一。
- 分开处理太暗、太灰、太淡与过度模糊；保留有意剪影与空气透视，不把电影感等同于暗灰糊。
- 将气势、风感、飘逸与运镜转为可见的动作、受力、幅度、节奏和结束状态；抽帧、运动拖影与手持晃动分别设计，不因导演名一律添加。
- 根据空间与动作设计同步且有距离层次的环境音，明确音乐及对白；遵守静音等明确要求，不默认所有作品禁用配乐。

## 步骤 4：交付提示词或方案

方案说明、导演说明、确认问题与交付摘要使用用户当前的交互语言；用户明确指定回复语言时优先遵从。不得依据本文件或参考资料的语言推断交互语言。可复制提示词正文的语言单独按用户要求及下述目标模型写作规则确定。

交付简短的“导演／作品分支／视觉重点”，再给可直接使用的主提示词、镜头表或色卡方案。按需附少量避免项，不强制每次展示全套理论。采用用户设定的推荐模型：视频提示词未指定平台时默认面向 MiniMax H3，用户要求通用版或其他模型时遵从；图片提示词默认面向 Seedream。H3 提交正文默认英文，中文对白和画面文字保持原文；用户明确要求中文提示词时使用中文。使用用户当前交互语言的方案说明与可复制正文分开呈现，不强制展示中间推理。参考文档中的 H3 字段仅是提示词正文组织示例，不是调用参数或当前接口规范。

无法取得当前写作指南时，不阻塞仅提示词交付：可提供明确标注“尚未核对最新格式”的草稿，分开说明已确认要求与不确定的写法，不声称已经核验最新指南。实际生成前仍核对当前平台能力与输入；只有确有必要条件无法确认时，才暂停受影响的生成并询问。不得因此静默更换模型、改变已确认规格或跳过审批，也不为取得指南而要求安装、登录或付费调用。

## 步骤 5：生成媒体（仅在用户明确要求时）

- **模型偏好**：生图推荐 Seedream，生视频推荐 MiniMax H3。优先级为：用户本次明确指定的模型 > 上述偏好 > 能满足任务的其他可用模型。推荐 Seedream 用于参考引导的配色与身份保持，推荐 MiniMax H3 用于动作和声音协同；生成前核实当前能力。这些是推荐而非强制限制。
- 生成前查看当前可用模型与能力，按实际支持的画幅、时长、参考素材与声音能力适配提示词。首选或用户指定模型不可用，或不支持必要功能（参考图、编辑、人物一致性等）时，说明原因，列出经能力核对的兼容替代及关键差异，等待用户明确选定后再生成；即使替代不改变已确认规格与范围，也不得自动切换。用户要求只用某模型时，未经其明确同意不得替换；涉及规格或范围变化须一并确认。已明确选定的替代方案在条件不变时不重复询问；模型选择确认不替代视频提示词等既有审批。交付时注明实际使用的模型。
- 没有兼容模型时，暂停受影响的生成并说明具体限制，让用户选择接入可用能力、调整要求或暂止于方案；可先交付视觉方案、分镜与提示词，但须明确成片尚未生成，不以文本交付冒充成片。
- **视频流程**：需要新建首帧、关键帧或人物锚点时，设计视觉方案 → 生成所需首帧、关键视觉图、关键帧或人物锚点 → 用户确认图片 → 基于已确认图片交付详细逐镜视频提示词 → 用户确认提示词 → 生成视频片段 → 按下述规则完成所需组装 → 交付成片并交用户审阅。图片确认不代表动作、运镜或视频提交已获确认。已有合适且已确认的素材或无需图片输入时，跳过生图，不跳过视频提示词交付与确认环节。仅要求静态图时，不自动延伸到视频提示词或视频生成。
- 同一步骤内输入就绪且彼此独立的图片或视频可批量制作；依赖新图片的视频须待图片确认、以及随后详细视频提示词确认后进行。不得为套用固定流程扩大生成数量。
- 同一人物出现在多张图片、导演风格对比图或多个视频镜头时，各相关产物须实际复用共同的身份参考，不能只靠重复人物文字描述。已有适用且已确认的参考直接复用，不重生；没有时，先按约定的审批节奏建立并确认共同视觉锚点，再制作依赖它的产物，适用且已确认的首张成果也可充当锚点。群像保留不同人物身份及关系，不复制同一身份填充其他人物，也不无必要地拆分参考。保持用户要求的最终交付数量；锚点准备若超出已授权范围，先说明并取得同意。身份参考不自动充当视频字面首帧，视频提示词仍独立确认。
- 视频生成前结合详细视频提示词向用户确认分镜、时长与画幅，因为视频成本高且难以局部修改；未变化且已确认的规格不重复询问。
- 默认不加字幕；旁白或对白不等于需要字幕，用户明确要求时才加。
- 按创作对象组织并保存方案与产物，沿用实际返回素材，不凭文字重述替代引用。同一内容的修订保留身份与版本历史；不重复导入已经交付的结果。

### 必经的视频提示词交付环节（图片确认后、视频生成前）

这是可独立审阅的交付物，不是隐藏的内部撰写步骤。沿用实际已确认图片及其素材职责；关键视觉图不自动等于视频的字面首帧。保持已确认的人物身份、服装、空间、光线和配色，不用文字重述替代图片引用。

每镜交付：参考素材职责与起始构图；时长及动作时间节拍（不等于切镜）；人物位置、朝向、视线与动作进程；镜头起点、运动路径、速度／节奏及结束构图；结束时人物与道具状态、与下一镜的连续性；环境声、音效、音乐、对白需求，或适用时明确无声。未知项注明待定，不虚构已确认的对白或规格。使用用户当前交互语言提供简短导演说明，并另附可直接复制的提示词正文，语言和模型格式遵循步骤 4。

将详细提示词保存到相应创作对象并交用户审阅，请用户确认或调整动作、运镜、结束状态与声音，然后停在视频提交之前。图片确认或此前的高层分镜确认均不免除本环节。用户明确要求直接完成或另行约定节奏时，仍须编写并保存详细提示词，只省略获准跳过的确认停顿。仅要求提示词时止于提示词交付，不授权生成。

### 单条与多段视频的成片交付

- **交付单位**：一次生成已满足约定的一条视频，可直接作为成片交用户审阅，不强制拆镜或再拼接。用户要一条由多个独立片段组成的成片时，片段是中间产物，必须完成组装才能宣称成片完成；用户要多条独立视频时保持分别交付，不擅自合并。
- **组装前确认**：结合逐镜提示词和既有分镜记录片段顺序、各段取用范围、目标总时长、最终画幅／分辨率及声音处理，在最终组装前按约定节奏取得确认。已确认且未变化的内容不重复询问；明确要求直接完成时仅省略已获准跳过的停顿，不免除规格记录，也不授权改变范围。尚未确定的裁切／留边／缩放、时长取舍或新增内容须先解决，不能静默裁画面、删镜头、加速、拉伸或压缩画质来凑规格。
- **片段与声音**：使用实际成功返回的片段，先核对文件可用性及客观时长、尺寸、音轨信息，再按确认顺序组装。保留已批准的声音方案和原有片段音轨，只有已明确要求静音、替换或混音时才相应处理；无声片段不得导致后续片段音频丢失。按方案处理接点，避免对白截断、重复叠音和非预期空白；如需新的剪辑决定，先询问。不因组装擅自生成配乐、旁白、音效或添加字幕。
- **交付凭据**：一条多段成片须有实际导出的最终视频文件，并作为项目交付物供用户访问；沿用返回路径，不重复导入已交付结果。根据工具回执和客观参数核对实际总时长、画幅／分辨率及音轨是否符合已确认规格，说明差异或尚未验证项，保留原片段和版本。参数核对不等于主动分析成品质检，不得据此宣称视觉、表演或听感已验收；最终成果交用户审阅。
- **失败与未完成**：组装能力不可用、规格冲突未解决、导出失败或结果状态不明时，保留成功片段，说明阻碍、已完成部分和可选下一步；状态不明先查询既有任务，不重复提交。仅交付片段或方案时明确标注“成片未完成”。不自动重试、重生成或扩大制作范围；获授权后只补做必要的失败或缺失部分。

## 步骤 6：检查与修正

提交前检查方案：用户约束是否保留、光源与空间是否成立、人物关系是否可见、作品分支是否一致、静帧是否误写成时间流程、视频动作是否适合时长。媒体分析用于理解输入素材与读取客观参数，不用于主动验收自己的生成结果。

生成后呈现实际成果，请用户审阅，不自行分析成品质检、追加修复或重生成。用户明确要求核查时，才按其指定范围分析；不能查看时如实说明。用户反馈主体错误时优先修身份与动作，风格泛化时修空间、光源和材质，多镜头不一致时修人物、道具与光色连续性。提出追加调整时说明改动并获得同意。

生成失败时保留成功产物，说明失败与可用恢复选项，不自动重试或重新提交。用户明确要求重试后才继续；同一问题经两次获授权的修正仍失败时，解释限制并重新讨论方案。状态未知时先确认原任务结果，避免重复生成或扣费。不把文本结构检查称为媒体效果验证。

## 使用边界

- 作品视觉是导演与摄影、美术、服装、剪辑等共同创作；不把一部影片的所有视觉特征都归给导演。
- 保持作品之间的差异。张艺谋可以水墨，姜文可以黑白，关锦鹏可以现代冷调；不要把标签当终身定律。
- 默认单一导演、单一作品分支。混合风格仅在用户要求时使用，并分配职责，例如构图取杨德昌、色光取王家卫，解决空间和表演冲突。
- 不统一添加霓虹、雨水、颗粒、浅景深、超宽画幅、对称或慢动作；每项都须有场景依据。
- 色卡可约束色光，不应同时决定人物身份、构图和动作。
- 只做创作转译，不复刻可识别的原片画面或原片对白。不从导演或电影风格参考中继承演员面孔；用户明确指定的真人身份是独立的身份约束，按适用的安全与权利规则处理，仅要求风格不授权采用演员面孔。
- 原包含未核实内容、错列作品及平台宣传判断；`references/sources.md` 记录了取舍，不要重新把未核实内容当硬性指令。
