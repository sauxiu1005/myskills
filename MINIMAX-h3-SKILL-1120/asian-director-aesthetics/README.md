# 亚洲导演风格美学 · 0.2.17

将28位亚洲导演的作品视觉语言转化为原创场景的色彩、光影、构图、人物行为与镜头设计，按需交付方案、色卡、分镜、提示词、图像或视频成片；不用于电影百科或原片复刻。

## 包内容

- `SKILL.md` / `SKILL.cn.md`：英文与中文运行入口，工作流、约束及确认点对应。
- `meta.yaml`：双语展示元数据；作者MiniMax Design，来源official，按提交方确认保留。
- `references/`：28位导演条目、场景研究、选择与创作方法、提示词流程及来源说明。
- `assets/color-palettes/`：28套六主色／四参考色色卡的PNG、SVG、JSON，以及总览和离线浏览页。
- `assets/director-references/`：仅文字索引，不含电影截图。
- `CHANGELOG.md` / `VALIDATION.md`：版本摘要与本候选包的验证范围。

## 独立交付的检查回执

平台提交安装包为 `asian-director-aesthetics.zip`，可独立导入完整Skill。检查回执作为可选审核记录另行保存，不包含在ZIP内，也不是安装依赖；需要核对时，应使用与当前安装包哈希对应的回执。旧版回执仅适用于其记录的原始包，不因公开文件名相同而用于其他修订。

## 使用方式

导入完整Skill文件夹，保持目录名与name一致为`asian-director-aesthetics`；只复制入口会丢失参考资料。安装或更新按目标平台流程进行，避免将备份安装成第二份同名Skill。文件更新不等于应用已重新加载。

提供原创主体、场景、参考或创意，说明希望交付什么；可指定导演、影片、媒介、画幅及视频时长。已有适用且已确认的素材优先复用。仅要求方案或提示词时不生成媒体。

指定导演时按需读取对应作品分支，不堆叠风格标签；用户身份与约束优先。电影场景研究是文字资料，不作为当次图像输入，不继承演员面孔或原片布局。

生图推荐Seedream，视频推荐MiniMax H3，用户当前指定优先；实际执行前核对可用能力，替代模型不静默切换。H3提示词正文默认英文，中文台词保留原文，用户明确要求中文时遵从。视频按约定节奏确认方案、所需图片及详细动作／运镜／声音提示词，再生成及完成必要组装。成品交用户审阅，不主动质检、追加生成或自动重试。

## 生图色卡要求

图片、首帧、关键帧及人物锚点统一实际传入对应内部PNG色卡，限定颜色职责；不只写色名或HEX。人物和布局参考保留独立职责，作品分支和当前用户要求优先。能力／槽位／素材冲突先确认，不静默降级；明确禁止图片参考或批准文字配色才使用例外。视频沿用已确认关键帧，不将色卡充当视频首帧。此为用户采纳的方式，不是电影感效果保证。
