# 来源、范围与勘误

## 来源范围

主要资料为用户提供的 `导演视觉风格色卡_SKILL` 文件夹：三期 `SKILL.md`，以及编号022、045、055、065、073、086、096、099、117、122、123、165、186、187条目的色卡主文档、结构化色板与提示词资料。

本次阅读三份入口、相关色卡主文档和结构化风格字段，并抽查图像与视频模板的转译规则。没有逐张检查原片剧照，没有执行媒体生成。来源清单及文件校验值见 [source-manifest.json](source-manifest.json)，其用途为追溯，不能代替事实核验。

本 skill 是根据这些资料重新编写的创作指南，不是原模板汇编。最初包含14位华语导演；2026-11-05按用户要求增加14位亚洲导演，陈英雄作为越南／法国创作语境条目纳入，不归为华语导演。不是中国导演的完整名录。

## 保留与修改

- 保留：按导演查找、参考具体作品、色彩与空间结合、色卡与人物素材职责分开、视频动作连续性。
- 重写：将抽象主题和形容词转成具体人物、构图、光源、材质与动作；按作品分支处理互相冲突的风格。
- 去除：强制询问模型、必须逐字照抄、默认生成四张、不能改风格段落、无证据的模型审美排名。
- 不沿用：平台版本、时长及素材数量上限、把模板自称“官方规则”的表述，以及固定百分比光比、统一胶片颗粒等泛化要求。
- 色值：只摘录原包主色板的色名及HEX，去掉固定占比。本次未验证其为原片取色。部分 `real_palettes` 条目的 `sources` 为空，也未记录可复现的帧位与采样过程，因此不将这些字段标成已验证测量结果。
- 原包中“高光偏对称照明”“阴影偏多伦多阳光”“长镜头观察色”等混淆类别的词语已转译或剔除。

## 重点核对与纠正

核对日期：2026-10-29。以下仅支持所列事实，不表示全部视觉解读都经过外部验证。

1. **《新龙门客栈》**：原包直接归入徐克导演式参考；本版注明徐克监制、李惠民导演的关联关系，不当作徐克独立导演作品。香港电影资料馆刊物明确区分二者职务：[香港电影资料馆通讯](https://www.filmarchive.gov.hk/documents/6.-Research-and-Publication/06-03_newsletter/newsletter10_c.pdf)。
2. **《断·桥》**：原包误列入毕赣条目，本版排除。发行方明确导演为李玉：[CHENG CHENG FILMS](https://www.chengchengfilm.com/thefallenbridge)。毕赣条目主要采用原包的《路边野餐》《地球最后的夜晚》，不尝试补全最新片单。
3. **《牯岭街少年杀人事件》时代**：原包称50年代，本版按1960年代处理；戛纳资料明确故事开始于1960年的台北：[戛纳影片资料](https://www.festival-cannes.com/en/f/gu-ling-jie-shao-nian-sha-ren-shi-jian/)。
4. **未核实资料**：部分原包“活跃年代”看起来使用出生年份，片目及年份也有可疑项。本版不复制完整生平和片年表；没有证据时删去，不补写确定说法。

## 证据和创作建议的边界

作品署名、故事年代属于可核实事实；“以门框表现疏离”“以中轴表现权力”等是依据资料作出的视觉分析和创作转译；示例提示词、机位、时长与动作属于新设计。使用本 skill 时保留这种区分，不把建议表述为导演本人说过的话或原片摄影参数。
