# 参考视频分析

## 证据与边界

文件：DMnmDsC9z0gcgSUX (1).mp4。2026-10-16 直接用 ffprobe 检查原文件：视频 1440×1440、60/1 fps、840 帧、14.000 秒，H.264；AAC 双声道 48 kHz，音轨约 14.059 秒。容器总时长约 14.059 秒。不要把应用中的代理预览尺寸当成原片尺寸。

以每秒 4 帧联系表和 7.8 秒细节帧检查视觉；下表是约略分段，边界可能相差约 0.25 秒，不是逐帧反求的源工程。没有试听与测量原音轨，因此不对曲风、精确 BPM、音效位置作事实断言。画面可见“made in code”等字样，但它只能佐证创作意图，不能证明使用了某种框架。

## 风格

属于极简产品 UI motion study / 单形态连续变形展示。暖灰背景、黑色胶囊和白色卡片占主导，投影使控件微微浮起；少量橙粉紫渐变只在音乐封面。文字无衬线，确切字体无法从图像可靠判定；Geist、Inter 或合适系统字体可作为实现候选，不声称原片使用其中某款。

主体居中，不同状态占画面的面积变化明显。视频主要通过容器尺寸变化展示层次；仅凭抽帧不能区分全部相机缩放与对象缩放，不能反推为必须强烈推拉的镜头。

## 实现起点（建议值，不是实测源参数）

以 1000×1000 逻辑画布描述布局：Generate 宽约 440、高 135；播放器约 690×440；音量条约 800×125；图表约 770×590。以抽帧对照校准，不作为固定尺寸。主体通常位于中心附近。

背景可从 #EFEFEA 起步；黑 #050505、白 #FFFFFF、次文字 #858585。阴影可分接触阴影与较大柔和阴影；边框只用于浅卡片的轮廓。所有颜色均需按原片校准。

建议交互反馈 80–140 ms、主形变 220–420 ms、大卡片展开 350–550 ms、内容退场 60–100 ms、进场 100–160 ms。形变时子内容错开 40–80 ms，不能长时间重叠。弹簧建议阻尼比 0.82–1.0，少量过冲，具体数值以视觉为准。

最关键的观感来自：一个对象始终存在、操作引出反馈、前后缘错速的拉伸、正文清晰、动作落稳后短暂停留。仅有圆角与阴影不能复现这种风格。
