# 创意方向与前 3 秒开场

> **适用**：当前任务需要确定或比较创意方向与开场时读取。

## Hook 的定义

Hook 是观众在开头实际看到和听到、让其愿意继续看的内容。前 3 秒优先建立观看理由，但不是开场的硬截止线；同一个动作、问题、对话或变化可以在 3 秒后继续兑现。它可以由首帧、人物或产品动作、口播、声音、准确的后期文字或剪辑共同完成。

信息角度、内容形式、使用场景和运镜都会影响 Hook，但它们本身不是 Hook：

- 受众处境：谁为什么会在意。
- 信息角度：这条视频主要承诺什么价值或观点。
- 展示与证明：观众通过什么动作、状态、细节、比较或个人体验理解它。
- 内容形式：整条内容如何展开，例如试用、教程、review、vlog、question card、对谈 / podcast 或表演。
- 具体开场：开头首先发生什么。

内部按这个顺序判断，不把这些术语变成用户要填写的表格。

## 1. 先确定一条内容线

从一个具体受众处境和一个有来源的产品价值出发。内容密度由总时长、内容形式和观看节奏决定：较短内容通常聚焦一个核心信息；更长内容可以通过完整操作、观察、比较、观点或情境推进承载更多内容，但不靠重复卖点或拖长静止画面填满时长。


## 2. 寻找不同的观看理由

先问每个方向：观众为什么愿意多看下一秒？可从以下机制获得启发，但不逐项覆盖，也不限于这些机制：

- 先看到结果、对比或正在发生的变化。
- 一个具体使用麻烦、限制或待回答的问题已经出现。
- 测试、挑战、教程、试穿或比较已经开始。
- 一个明确观点、坦白、反常识判断或与预期有依据的落差已经出现。
- 一个具体、可识别的生活观察通过幽默、自嘲、角色扮演、情境表演或剪辑节奏被放大；笑点来自处境，不拿虚构效果和人物出丑硬造梗。
- 产品通过有关联的意外动作、反差事件或人物反应进入。
- 一段提问、朋友反应、评论回复、街访、对谈、采访或其它社会语境打开内容。
- 声音、触感、ASMR、材质细节或其它感官信息先于完整解释建立兴趣。
- 有动机的构图、视点或视觉 pattern break 先改变观看预期；夸张、表演或超现实视觉隐喻也可以成立，只要服务当前核心信息。
- 一句话已经说到观点最具体的部分，像观众进入一段正在发生的对谈、podcast 或采访；先成立一个值得聊的观察、矛盾或经验，产品可以在场，随后作为例子进入，不让主持人用产品问题替广告递话。
- 有意义的局部、过程或信息缺口等待揭晓。
- 立即给出对目标受众有用的答案、步骤、规格或判断。

评论卡和普通问题可以作为创作形式，但不要把它们当成固定模板。

发散时优先改变底层的注意力机制，而不是只换动作、景别或台词。视觉 / 动作、信息 / 观点、对话 / 社会语境、感官 / 声音、幽默 / 表演等都只是创作空间，不是必须覆盖的配额；产品适合表达个人判断、经验或回答具体问题时，不要让所有方向都退化成拿起、贴近、试用和展示细节。

## 3. 写成可执行的开场

每个方向需要让用户能够想象：

- 第一眼看到的具体主体与状态。
- 首个有意义的动作、变化或信息。
- 第一耳听到的口播、对话、环境声、音效或有意静默。
- 它接下来会顺着展开什么。

不要求每项都出现，也不要求必须悬念、反转或快速切镜。人物近景的一句话、连续动作、安静观察或直接展示都可以成为强开场，判断标准是即时观看价值，而不是刺激元素数量。

开场依赖可读评论、价格或短文案时，记录准确文字需求，并按当前能力选择可靠的文字呈现路径；这不等于开启全片字幕。

## 4. 需要用户参与时如何呈现方向

当不同开场会实质改变观看体验、无法从上下文可靠推断偏好，或存在一个明显更强且用户未必意识到的创意机会时，把这个高杠杆选择交给用户。用户明确把某个方向设为硬约束时不重新开题。

先内部发散，再保留一组底层观看机制真正不同、可以直接执行的方向。候选数量由创意空间决定，不固定；不要为了显得丰富制造伪差异。用户已有方向但没有把它设为硬约束时，可以把它与明显更强的替代方向并列，而不是默认沿用。

呈现保持简洁：

```text
label：便于区分的短名称
description：开头具体发生的视听内容，以及它如何进入本条核心信息
```

描述控制在 1–2 行，不塞完整脚本。可以包含一句真正决定差异的短口播，但不写“吸睛、抓人、最稳、转化高”等自我评价。事实边界在内部执行，不给每个选项机械追加免责声明；只有某个限制会改变用户选择时才说明。

如果一个方向明显更适合当前目标，可以推荐它并给出极短理由；没有明显赢家时不强行排序。需要继续发散时，可以让用户探索一组新的方向，不把首轮候选当成穷尽菜单，也不固定“再来几个”的数量。

## 完成条件

每个被呈现或采用的方向都应满足：

1. 去掉标签后仍是可拍、可听的具体内容。
2. 开头已经给出即时回报，或建立值得继续看的具体问题。
3. 能直接进入第一镜或一个有明确切换理由的短镜头组。
4. 后续能够自然承接当前核心信息，不需要换一个内容方向来补救开场。
5. 同时呈现多个方向时，它们获得下一秒观看的理由确实不同，不只是换动作、景别或形容词。

用户认为方向不够好、给出修改意见或提出疑问时，吸收反馈形成新的方向；旧候选不是必须从中选择的菜单。是否需要再次让用户确认，遵循当前协作节奏，而不是在本文件中额外增加固定确认。
