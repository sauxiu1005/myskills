# 创作者方向与身份连续性

> **适用**：当前采用的创意包含一个或多个可见创作者 / 角色，或需要跨镜头、跨 clip 或后续修改保持人物身份与人物关系时读取。

人物不是产品旁边的通用模特。创作者方向应该让观众相信：这个人为什么会在这个生活处境里使用、评价、提问或回应这个产品。

## 1. 从当前创意形成角色方向

本文件不重新决定内容形式。以用户已经明确或当前采用的创意方向为前提，把一个或多个人物角色具体化。

先判断本条内容更靠近哪种创作关系，它们不是互斥模板，也可以在同一条内容里形成连续谱：

- **UGC** 更像用户自己的记录：使用处境熟悉，拍摄介入较低，反应、动作和表达可信。真实不等于故意拍土、拍乱或降低画质。
- **KOC / creator content** 在可信基础上更有作者性，可以体现创作者的选品、观点、造型、空间、镜头与表达选择，但仍然像这个创作者会主动发布的内容。

再结合产品、受众、目标市场、生活阶段、使用场景和内容主题，确定真正会影响画面的部分：

- 这个人与产品、观众和其它角色是什么关系。
- 人物此刻处在什么具体生活情境，为什么会被记录。
- 造型轮廓、色彩、发型、妆容、配件或个人习惯中哪些选择支持这个角色。
- 人物如何使用、观察、评价或回应产品。
- 人物与镜头、拍摄者之间是什么关系。

人物具体性来自相互一致的生活选择，不来自“华裔妈妈、ins 博主、男生 KOC、职场女性、真实用户”这类标签本身。

当不同人物方向会实质改变观看体验且无法从上下文可靠判断，或存在一个明显更适合当前目标的人物方向值得用户知道时，用当前交互能力给用户少量结构化 casting 选择。候选数量不固定；有明显更适合当前目标的方向才推荐，否则不强行排序。

## 2. 让人物符合目标市场与受众

目标市场会影响 casting、styling、setting、language / accent 和 recording behavior，但不要把某个市场简单等同于固定族裔、性别、年龄或审美模板。

判断标准是这个人物是否在目标受众看来像真实存在于该市场与使用情境中的创作者，而不是“长得像某个国家的人”。城市、生活方式、职业或生活阶段、穿着、空间、语言和拍摄习惯共同构成 market fit。

## 3. 选择拍摄关系

先确定当前内容需要观众看清什么，再决定谁拿相机、为什么此刻开始拍，以及镜头与人物之间的关系。

自拍、镜前记录、朋友跟拍、固定机位、桌面 POV、街访或其它方式都可以；选择来自当前内容行为和观看需要，不从产品品类或“UGC 感”直接套用。

自拍由拍摄者与镜头的关系决定，人物拿着手机不等于对镜自拍。镜面只有在人物通过反射完成检查、比较或表达，且这个行为对当前内容有意义时才使用。

相机行为由拍摄关系自然推出。临时手持记录可以有轻微晃动和取景修正；朋友跟拍可以有跟随感；固定机位不需要为了“真实”强行加入晃动。不要把同一套相机效果复制到所有视频。

## 4. 只在连续性需要时维护身份

不为了流程默认创建人物锚。只有同一人物需要跨镜头、跨 clip 或后续版本持续被识别时，才建立可复用的身份 reference；多人内容还要保持人物之间的角色对应与关系，不只分别锁定几张脸。

需要身份连续性时，使用当前模型支持的最小可靠机制。它可以是用户提供的人物图、身份 reference、角色 ID、视频 reference 或当前能力支持的其它方式；不要把某一种 anchor 形式写成永久前提。

如果当前模型路线需要生成身份锚：

- 长期 identity reference 只固定需要跨 clip 保持的人物身份、稳定造型与内容气质。
- 当前动作、表情、产品交互、配角、场景、精确机位和构图由各自镜头决定，不因为 identity reference 已经出现过某个状态就继续复现。
- 用户已有适合的人物素材时优先沿用，不再生成不同身份的替代人物。
- 避免为同一身份叠加相互冲突的多张长期 reference。

非穿戴产品通常不需要把产品塞进人物身份 reference；产品外观继续由产品自身的可靠来源承担。

## 5. 人物与产品关系

服装、鞋、包、眼镜、首饰、穿戴设备或其它强依赖人体关系的产品，只有在当前内容确实需要保持上身、佩戴、手持或尺度关系时，才建立对应的交互 reference。

建立这类关系时沿用 `source-routing.md` 已确认的尺度与使用依据；生成 reference 只负责保持关系，不反向成为新的事实来源。

只服务某个镜头的动作与姿态属于当前镜头，不升级为全片长期身份设定。

## 6. 视觉可信度

人物真实感来自具体身份、行为、生活逻辑和自然的人体差异，不靠刻意降低制作质量，也不靠人为增加瑕疵。面部是清晰主体时，避免过度对称和过度精修；轻微的 facial asymmetry 或其它自然差异可以保留，但不作为固定尾缀。

## 完成条件

- 当前内容涉及的每个人物及人物关系，在分镜与 references 中都有清楚、稳定的对应。
- 需要持续识别的人物使用最小、可复用且不冲突的 identity reference；不需要持续识别时不额外创建。
- 人物方向、拍摄关系与视觉呈现共同服务当前受众、情境和创作者视角。
