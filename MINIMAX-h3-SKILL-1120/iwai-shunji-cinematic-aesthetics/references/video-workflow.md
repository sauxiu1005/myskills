# 视频流程与 prompt

适用于单镜头、文生视频、图生视频和叙事短片。先检查工具的实际时长、画幅、参考图、首尾帧、音频与结果获取能力。以下为通用创作结构，不假设特定厂商字段。

## 制作

1. **确定范围。** 单镜头不用完整剧本；叙事短片用一句话说明人物在片前和片后的变化。把感受转成动作、注意力或物件意义的变化。
2. **建立时间表。** 多镜头列出镜号、成片起止时间、景别、动作、运镜、结束状态与声音。计入转场重叠，使总时长符合要求。生成片段时长不匹配时可裁切，并说明无法精确控制的部分。
3. **固定视觉。** 使用共同人物与场景设定；有参考图或连续性需求时优先考虑图生视频。关键帧是可运动的单一画面，不用拼贴、分镜板或烧入黑边的截图。
4. **审阅分镜后再生成视频。** 成品视频（包括样片）都须先完成分镜脚本文档与对应参考图，并由用户明确确认后才能生成。已有关键帧可以复用为参考，但不能代替分镜文档、整组镜头参考图或用户确认；纯文生视频同样先提供可审阅的分镜参考图。
5. **组织运动。** 每镜写起始状态、主要动作和结束状态，选择一种主要运镜并安排环境运动。正常速度为建议，用户要求慢动作时按其意图执行。
6. **剪辑与声音。** 根据注意力、动作与声音选剪辑点；动作后的停留服务情绪。现场声、画外声、主观声音或原创音乐按故事需要选择。
7. **实际检查。** 检查完整运动与声音，在首、中、尾帧检查身份和空间。只抽帧不能证明运动流畅，不能观看或听取的部分标明未验证。

## 连续性

保留人物 ID、外观、服装、左右手道具、场景出入口、光向、目光目标和运动方向。承接镜头记录上一镜结束状态与下一镜起始状态，避免无缘由跳位置、换手或换光向。

焦点、景别与机位可以有意变化。不要同时堆叠环绕、推近、变焦、走位与复杂表演；复杂动作可拆镜，用户明确要求一镜到底时设计可执行的完整路径。

## 剧本与分镜 prompt

```text
创作[总时长]原创剧情短片，主题是[具体关系或情绪变化]。
人物与场景：[既定设定]。视觉模式：[模式及必要调整]。
通过动作、物件和声音表现人物从[初始状态]到[结束状态]的变化。
输出简短梗概和分镜表：镜号、成片起止时间、景别、主体动作、摄影机运动、光色、声音、情绪作用。
计算每镜长度与转场重叠，使总时长满足要求。
分别输出每镜关键帧 prompt（需要时）和动态 prompt。
```

## 图生视频 prompt

实际传入参考图，用真实文件标识或工具资产 ID 关联镜号。模板变量填写完再调用。

```text
以提供的[参考图标识]为起始画面，生成[工具支持的时长]连续镜头。
保持[人物、服装、道具、场景、光向等固定项]。
开始时：[姿态、位置与目光]。
接着：[一个主要动作及自然停顿]。
结束时：[可用于剪辑或衔接的状态]。
摄影机：[一种明确运动或固定观察]，保持[必要构图关系]。
环境：[风、衣料、树叶、雨水等具体微运动]。
动作节奏：[正常速度、呼吸、重心或用户指定节奏]。
声音：[工具支持时的要求，否则移至后期声音方案]。
```

图生视频重点写固定项和变化，无需重新堆叠全部画面细节。用户明确要求新事物出现时允许对应变化。

## 文生视频 prompt

```text
[画幅]写实剧情电影，[时长]单镜头。
[人物识别、服装与道具]处于[地点、季节、天气与空间布局]。
[起始状态]，随后[具体动作]，最后[结束状态与停留]。
[景别和主体位置]，摄影机[一种主要运动]。
[光源方向、主色、材质与所选风格模块]。
[环境运动]，真实重心、呼吸与动作节奏。
[有意义的声音设计，按工具能力处理]。
```

## 示例：完整单镜 / 春日微光

```text
约8秒横向写实剧情电影单镜头。年轻女性穿米白棉衬衫和深蓝长裙，站在搬空一半的旧公寓，手中拿着小便签。木地板、浅色墙面，画面左侧有窗和空椅子。
开始时她低头阅读；读完后，捏着纸边的手指慢慢放松，停顿，再看向左侧空椅子。结束时仍望着空位，留出短暂呼吸。
中景，人物位于右侧，摄影机缓慢向前移动但始终保留左侧椅子。春日散射光从左后方进入，衣袖边缘明亮，面部细节清楚；浅木色、米白和少量嫩绿，柔和自然材质。窗帘轻轻起伏，人物以正常速度动作。
声音为纸张摩擦和远处街声，最后只出现几个稀疏原创钢琴音。
```

## 声音与剪辑

- 用实际工具完成所需声音；不能合成音频时交付声音表，明确视频是否无声。文字描述不算加入音轨。
- 音乐强弱、进入时机与环境声共同服务情绪，不是每个镜头都必须配钢琴或保持沉默。
- 声音桥可连接镜头；对白、口型与动作需匹配。不自动加入无关字幕或对白。
- 统一色彩以连续性为目的，保留不同场景合理光色变化。颗粒与光晕若逐帧闪烁，可减弱或后期统一处理。
- 黑边、字幕与指定画幅在成片阶段有控制地处理；prompt 不等于编码设置已实现。

## 交付与能力不足

交付真实视频、必要预览、分镜和最终 prompt，记录参考图、工具支持参数与实际成片信息。核对时长、尺寸、画幅和音轨，区分检测结果与创作设定。

只有生成工具没有拼接能力时，交付实际片段并说明尚未合成。没有视频生成工具时，交付可做的关键帧、逐镜动态 prompt、时间表与声音方案，明确“视频未生成”。只有用户接受动效相册时才采用静帧推拉，并如实命名交付类型。
