# 图片流程与 prompt

适用于单图、同主题组图、参考图风格化、电影静帧和视频关键帧。静态任务无需动作时间轴、配乐或剪辑表。

## 制作

1. 判断新建还是编辑。编辑先看原图，列出需保持的主体身份、姿态、物件、文字、建筑和画幅，只改变用户授权的部分。
2. 选择风格，把情绪转为一个可见关系。单图挑一个决定性瞬间，不在同一张图描述“先走进来再坐下”。
3. 写出主体位置、景别、前中后景、空位、光源方向、色彩与材质。电影静帧不默认烧入黑边或字幕。
4. 调用真实图像生成或编辑工具，用其参考机制实际传入参考图。按用户数量、画幅与文字需求设置。
5. 查看成图，依据验收规则做必要局部修正。不能仅凭 prompt 宣称画面正确。

## 系列一致性

先选代表画面作为后续参考。固定身份、服装、道具、场景与光向，让景别、姿态和观察位置产生变化。优先复用实际参考图或工具支持的一致性机制；同一段文字或 seed 都不能保证身份一致。

有明确张数时交付逐张图片，除非用户要求拼贴或分镜板，否则不以多格图片替代。分镜板可用于比较，不能自动成为图生视频输入。

## 文生图模板

将方括号变量替换成具体内容，省略不适用字段；发送给工具前不保留未填写变量。

```text
写实电影画面，[画幅与用途]。
[主体识别特征、服装/材质]位于[具体地点、季节、天气]。
画面捕捉[一个瞬间姿态或物件关系]，通过[可见细节]表现[情绪]。
[景别、主体位置、前中后景、留白与空间关系]。
[光源方向与性质]照亮[具体位置]，暗部保留[细节]。
[主色与点色]，[所选风格的光学与质地描述]。
[必要保留项]；[仅与该图有关的限制]。
```

静帧写观察位置，无需描述摄影机如何移动；动作瞬间用姿态与有依据的运动模糊表达。

## 分镜参考图模型默认值

分镜参考图（包括单镜头分镜、环境空镜、校园空间分镜和分镜图组）默认使用 GPT Image 2。除非用户明确要求 GPT Image 2.5，否则不得将 GPT Image 2.5 作为分镜图默认模型；模型不可用时，应在生成前说明替代方案。该规则只约束分镜参考图，不覆盖用户对其他图片资产的明确模型选择。

## 参考图编辑模板

```text
以提供的图片为编辑基础。
保留：[人物身份、发型、服装、姿态、构图、物件、文字或建筑结构]。
调整：[用户要求改变的光线、色彩、天气、背景或材质]。
将[具体光源]调整为[方向和柔硬程度]，保留[关键细节]。
采用[一个风格模块]，使[具体空间关系]传达[情绪]。
输出[画幅/尺寸需求]，保持未列入修改范围的元素一致。
```

参考图与指令冲突时，用户修改意图优先。明确要求换服装时，新服装成为固定项；仅做光色编辑时，不自动增添雪、换季节、改脸或移动建筑。

## 示例：无人静物 / 冬日追忆

```text
横向写实电影静帧。一间旧屋的木桌上放着一只喝完茶的白瓷杯和一张折起的信纸，另一把椅子稍微离开桌沿，画面中没有人物。
平视偏低的中近景，杯子在右侧，左侧保留椅背和空位，前景只有少量桌沿。冬日冷白窗光从左后方进入，木面仍保留温暖棕色，杯沿反光柔和，纸张纤维与木纹清楚。
轻微高光晕染，细腻自然材质，通过使用过的杯子与空椅子表现刚刚结束的陪伴。
```

## 示例：人物与环境 / 盛夏疏离

```text
横向写实电影画面。盛夏下午，一位穿淡灰棉衬衫的年轻人站在郊区公交站的遮阳棚边，手里握着车票，望向空无一人的道路尽头。
广角远景，人物只占画面小部分，置于右下方；左侧是长长的道路与浓绿树丛。明亮夏日天空与棚下有层次的阴影并存，衬衫褶皱和皮肤保留真实纹理。鲜明绿色，细微数字影像质感，风景开阔，人物显得孤立。
```

## 示例：城市照片编辑 / 春日微光

```text
编辑提供的街角照片，保留建筑轮廓、招牌文字、道路透视、现有人物数量和画幅。
将光色调整为柔和雨后日光，墙面保留原有材质，植物绿色更通透但自然，地面保留适量湿润反光。主体清晰，远景柔和，整体以浅木色、米白和自然绿色为主。
通过柔和光线与生活细节产生轻盈感，不新增樱花、人物或虚构文字。
```

## 文字与交付

需要精确可读的文字时单独记录原文。模型无法稳定实现时，采用可用的排版或后期方式完成并检查，不悄悄删除文字要求。图片编辑仍使用环境指定的图像编辑工具。

单图交付真实图像，简述方向；用户需要时附完整 prompt。系列保存逐图 prompt、固定设定、参考图标识和支持的生成参数。视频关键帧另记录人物位置、目光、手持道具、出入口和光向。
