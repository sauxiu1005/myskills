# 验收与针对性修正

依据实际可见、可听结果判断，不凭提示词预期自动填“通过”。

## 图片

- 主体、数量、画幅、文字与参考图保留项是否满足要求？
- 人脸、手、物件与建筑是否合理，原图身份或结构是否无意改变？
- 光源是否有空间依据，重要细节是否被过曝或柔焦吞没？
- 色彩与材质是否符合模式，是否泛化为粉色滤镜、霓虹绿或厚颗粒？
- 情绪是否有可见载体：动作、目光、空位、物件关系或环境细节？

## 视频追加

- 观看完整片段，检查人物漂移、道具变形、背景融化、曝光闪烁和动作速度。
- 对照首、中、尾帧检查身份与空间，不用三帧替代完整运动检查。
- 检查目光目标、走位方向、道具换手、光向和镜头衔接，判断变化是否有意。
- 有音频时实际听取，检查时机、口型、声音桥、音轨缺失与明显失真。
- 读取媒体信息核对总时长、尺寸和音轨；参数正确不代表美学或动作通过。

## 修改

写清“镜号或位置 → 实际问题 → 最小修改 → 保留项”。优先保留成功画面与人物设定，针对问题局部编辑或重生成。用户预算优先，未指定时通常最多两轮修正；仍未解决则交付最佳结果并标注问题，不无限抽卡。

| 问题 | 修正方向 |
|---|---|
| 像摆拍广告 | 改成具体的日常注意力与微动作，减少正面微笑与磨皮 |
| 发白发糊 | 限制光晕在明亮边缘，恢复面部、材质和空间明暗 |
| 只剩统一滤镜 | 回到光源、物件关系及模式的色彩逻辑 |
| 像被拖动的照片 | 明确呼吸、重心及一项环境运动，检查实际结果 |
| 人物或道具漂移 | 增强实际参考约束，减少复杂动作，必要时缩短或拆镜 |
| 每镜都旋转推拉 | 按镜头用途改为固定观察或单一低幅运动 |

```text
修改[具体图像或镜号]：当前可见问题是[观察与时间位置]。
保留已经成功的[人物、构图、光线或动作]。
只调整[明确变量]，让[可观察的目标]成立。
```

负面提示仅在工具支持时使用，并针对当前问题。可选：`蜡质皮肤、过度锐化、厚重柔焦、道具变形、无动机镜头旋转`。不要全局排除自然运动模糊、所有阴影或全部手持，这会破坏部分模式。

## 状态措辞

- `已检查`：确实看过或听过的内容及结论。
- `待验证`：缺少观看、听取或检测能力的部分。
- `未生成`：只有提示词、分镜或关键帧而无对应媒体。

交付只报告影响使用的残留问题，不必展示全部内部检查表。
