# 文案编导：从文字到像素场景（Copy to Scene）

本 Skill 的主要输入是文案、歌词或旁白。先编导，再分镜：把文字拆成**语义节拍**，每拍设计一个看得懂的状态变化，再决定视角、像素密度与特效。画面质量首先取决于角色/场景是否一眼可认、视觉点子是否准确；像素密度只是基础条件，不是唯一指标。

## 1. 语义节拍表（每拍一行，必须全部填写）

| 字段 | 写什么 |
|---|---|
| 原文 | 逐字引用这一拍的文案/歌词/旁白 |
| 含义/情绪 | 这句话真正在说什么；情绪是铺垫、转折、包袱、高潮还是收束 |
| 视觉命题 | 一句话："让观众看到 ___ 变成 ___" |
| 场景与主体 | 在哪、谁/什么；复用哪些已建立的角色与道具 |
| 隐喻/直述 | 直述（照字面画）或隐喻（选自 §3 修辞库），并写明映射关系 |
| 起始状态→关键动作→结果状态 | 三段都必须可见；结果状态与起始状态不同 |
| 景别/构图 | 全景/中景/特写/俯视/等距/侧面/UI 叠层；主体位置 |
| 触发词或音频时间 | 有音频：实测时间码；无音频：标"拟定 mm:ss.ff" |
| 转场与复用资产 | 如何从上一拍过来（同位置变形、拉开、硬切、tile 转场）；本拍新建/复用的资产 |

### 节拍规则

- **每拍必须发生状态变化**：数量变了、身份变了、空间变了、关系变了、尺度变了或情绪反应出现。没有变化的拍要么合并，要么重新设计。
- 禁止：只把关键词画成图标排列；静止图片配字幕；所有句子在同一个固定舞台上换道具；每句都套同一种修辞。
- 抽象比喻必须保留原句意思，不得偷换褒贬或因果。
- 科普隐喻不得歪曲真实机制；所涉机制需核查，不确定时改用直述。
- 一句长文案可拆成 2 拍（铺垫/包袱）；两句短文案可合成 1 拍，但时长仍服从阅读或演唱。

## 2. 拆拍流程

没有文案、只要展示片或动态封面时，先写一个 ≤10 秒的小故事（主角—目标—阻碍—反转—结果），再按下列流程拆拍；不做没有故事的纯特效串烧。

1. 通读全文，标出结构：开场钩子 → 推进 → 转折 → 高潮 → 回扣。
2. 逐句写"含义/情绪"，找出可具象的名词与动词（数量、职业、地点、关系、结果）。
3. 为每拍选直述或一种修辞（§3），检查相邻拍不重复同一修辞超过 2 次。
4. 设计角色与资产复用表：主角（轮廓关键词、配色）、重复配角、主场景；按句意选择连续变形（同一空间延续）或新场景（话题、时间、地点真的改变时）；无论哪种，都复用角色与视觉母题维持连续性。
5. 写起始→动作→结果，选景别；把关键结果留出可读停顿（≥12 帧）。
6. 时间：拿到音频后按实测节拍/字幕时间对齐切点；没有音频只能写拟定时间，并在交付中说明"未做音频节拍验证"。

## 3. 视觉修辞库（按文案选择，不要所有主题都套游戏 UI）

| 修辞 | 适合的文案 | 做法 | 起始→动作→结果示例 |
|---|---|---|---|
| 场景同构变形 | 身份/生活/行业转换 | 同一机位、同一布局，物件逐一替换为新语义对应物（桌→餐桌、服务器→冰箱） | 办公室 → 物件逐个翻转为厨具 → 同位置的餐厅 |
| 数量增长 | 积累、收入、工作量、成果 | 可数物件堆积、计数器跳动，最后揭示容器（金库、仓库） | 一枚硬币 → 叠加计数 → 拉开见满仓 |
| 身份角色化 | 人物定位、团队分工 | 角色卡/职业卡（立绘+名称+属性），只在需要"定位"时用 | 普通人 → 卡片翻转 → 带职业的角色卡 |
| 关系/冲突游戏化 | 竞争、挑战、合作 | 血条、对战、协作推进；只表现结构，不夸大冲突 | 对峙 → 一次关键行动 → 血条变化/目标达成 |
| 尺度揭示 | 揭示真相、身份反转、"原来…" | 镜头拉开，画面变成屏幕/模型/书页的一部分 | 游戏画面 → 后拉 → 手持设备与手指 |
| 奖励与反应 | 认可、收获、情绪回报 | 奖章、爱心、+1、旁观者反应；奖励必须紧跟动作结果 | 完成 → 奖励弹出 → 角色反应停顿 |
| 过程剖面 | 科普机制、流程 | 剖开容器看内部流动（见知识讲解示例） | 外观 → 剖开 → 内部过程可见 |
| 结尾回扣 | 收束 | 回到开场的场景/道具，状态已改变；或胜利/定格 | 开场电脑 → 结尾同一电脑，屏幕内容已不同 |
| 直述 | 具体事件、动作 | 照字面拍好；不是所有句子都需要比喻 | 人物做事 → 结果可见 |

## 4. 动画分层（每拍按优先级分配动画预算）

1. **语义主动作**（最高）：表达这句意思的那个变化——变形、堆积、拉开、血条下降。必须最清楚、最先被看到。
2. **角色反应**：主体或旁观者对结果的反应（转头、举手、爱心），在主动作完成后 4–12 帧出现。
3. **环境微动**：一拍三/一拍四的小动态（灯闪、屏幕滚动、蒸汽），不抢主动作。
4. **特效辅助**：为主动作加重点（冲击环、粒子、闪光），每拍 0–2 种。

关键结果留出可读停顿；同一时刻只有一个视觉焦点。切镜点服从句意（铺垫结束、包袱落地、情绪转折），而非固定秒数。

## 5. 一致性

- 主角/重复角色：轮廓关键词、主色、配饰在所有拍一致；不同景别可重绘为不同像素尺寸。
- 字幕位置、UI 风格（边框、字体、配色）全片统一；UI 只在修辞需要时出现。
- 侧视构图可以用，问题是"所有拍都是横向跑跳"。按节拍选择侧视、俯视、等距、特写、屏幕内外等。

## 6. 质量判断顺序

1. 每拍的意思是否一眼看懂（不看字幕也能猜到大意）
2. 角色/场景是否可识别、全片连贯
3. 视觉点子是否准确、有新意、不误导
4. 动画层次与节奏停顿
5. 像素纪律与密度（色板、网格、细节）

密度不能靠随机噪点或满屏抖色凑指标：细节应来自结构、材质、表情和可识别物体。非单色块比例只证明画面不是简单放大，不代表美术质量。
