# 美式厚涂动画：造型、色面与笔触

## 单张参考与文字补充

本风格只保留 [角色造型参考](images/09-american-character-shapes.jpg)：不同角色的长短、宽窄、重心与衣服剪影明显不同，脸和颈部有棱角平面，形状与角色性格相互支持；暖光与冷暗部形成清楚的大色面。白底、粉色横线、四人阵列及参考人物外貌不作为当前任务的默认布局或角色模板。

环境依据当前内容原图重新设计为棱角化建筑、概括植物、分层色面与顺形笔触，和人物共享光线与配色。油画厚涂、黄金时段暖逆光、蓝紫暗部与叙事绘制要求由下方文字补充，不能声称单张造型图已展示全部工艺。已移除额外叙事拼图，不查找或要求恢复它。最终融合造型与表面语言，而非复制参考人物或题材。

“cel-shaded”和“wet-into-wet”不互相抵消：先划分清楚的大明暗面，再在同一明暗组内部柔和混色；关键转折处保留干刷和硬边。皮肤通透指暖光影响和薄层色彩，不是透明度参数，更不是湿亮、玻璃或蜡。

## 中文可复用版本

> 美式三渲二卡通风格化造型，面部有棱角、脸型略拉长，成年角色成熟而非圆润幼态；古典油画厚涂质感，结构导向的干刷笔触顺着形体走向，色块分层堆叠，大明暗分组清楚，色面内部有柔和湿画法混色。黄金时刻暖逆光，暖橙金轮廓光，冷蓝紫互补暗部，强烈而有主次的冷暖对比；皮肤具有柔和透光和薄层色彩，整体哑光。角色具体设计：[逐人填写外形、比例、衣服、动作与情绪]。环境具体设计：[把原场景的建筑、植物、天空与道具同步转为同一形状语言与画法]。保留[主要事件与接触关系]，人物面貌与环境细节可重新设计。

光照默认值不是新剧情：用户明确要求夜雨、室内或冷色气氛时，以实际环境光源形成相应冷暖关系，不擅自将场景搬到夕阳户外。精确配色、时段和造型要求优先于本卡默认值。

## 可见验收标准

1. 人物脸型、鼻梁、颧部、肩线和衣物剪影具有形状设计，角色彼此不同；不是给写实脸覆盖笔触。
2. 大色面支持体积，干刷沿颧骨、发束、衣褶或建筑平面走向，不是全图相同方向的刮痕。
3. 皮肤哑光而有柔和透光感，冷暖分组清楚，暗部仍能读出眉眼，不能金属化或油亮。
4. 人物与环境均转译，未保留一片摄影树叶或写实天空；主要动作与道具接触成立。

缺形状先修造型，缺绘画感再补顺形笔触，光照不统一再改光。默认一轮针对性修正，不把整段负面清单追加到每次生成。参考图片仅用于指导，本版尚未重新生图验证。
