# Character Policy · 无人物叙事（默认不做人物）

> 本技能**默认不画人物**，也尽量不做人物。故事里"有人"时，用环境、物件、光和痕迹表达人的存在与动作；画面主体是场景、物体、车辆、灯光、文字与几何。整片纯代码绘制与动画，不调用生图或图生视频。

## 1. 为什么

代码绘制的人物与霓虹环境很难在造型和材质上统一，历史测试多次失败（见 §5）。环境、物件与光才是本风格的强项：可控、可循环、与网格/落日/铬同一语言。

## 2. 把"人"翻译成无人物画面

| 故事里的人在做什么 | 无人物表达 |
|---|---|
| 开车 / 骑车 / 夜行 | 车辆或自行车自身运动（车轮、车灯、尾灯拖影），驾驶视角（仪表盘、挡风玻璃、方向盘轮廓），路面网格流动 |
| 走进某地 / 抵达 | 门自动滑开、灯逐段点亮、地面光点由远及近（脚步节奏）、镜头作为主观视角推进 |
| 拿起 / 按下 / 播放 | 物件自己响应：磁带弹出与卷轴转动、按键按下、屏幕亮起、指示灯跳动；可用一道光标或光点代表"触碰" |
| 戴耳机 / 听音乐 | 耳机在台面上亮起、声波环扩散、频谱条跟随节拍、城市灯随音乐脉冲 |
| 钓鱼 / 等待 | 栈桥上靠着的鱼竿、绕线轮自转、浮漂光点与涟漪、竿梢下弯、鱼跃出水面 |
| 情绪（自由、孤独、兴奋） | 景别与运镜（拉远、升起）、色温与光量变化、节奏和配乐 |

原则：每镜仍有一个可读的主事件；主事件由物体、光或相机完成，而不是靠人物表演。

## 3. 用户明确要求出现人物时

1. 先说明本技能人物不是强项，推荐 §2 的无人物表达方案。
2. 用户仍坚持时，人物只作**远景剪影或局部**（背影剪影、窗内轮廓、方向盘上的手部剪影），占画面小、无面部、无复杂表演；动作限于简单剪影移动，由环境承担叙事。
3. 剪影必须与环境同一画风和光向（深色填充 + 洋红/电青边缘光），不得出现简笔小人或贴纸人与立体背景混搭。
4. 交付时如实说明人物仅为剪影处理；需要完整人物表演时建议改用其他技能或方式。

## 4. 验收

- 默认镜头中没有人物；"有人"的意思已经由物件、光或视角传达清楚。
- 每镜一个可读主事件；物体运动真实发生（旋转、开合、点亮），不是静图缩放平移。
- 画风统一：清晰轮廓、大色块、受控渐变、深靛蓝负空间、洋红/电青边光、低颗粒；不写实。
