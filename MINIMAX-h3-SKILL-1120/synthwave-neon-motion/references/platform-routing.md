# Platform Routing · 真实执行路由

按镜头选择当前平台实际可用的能力；以下只描述动作，具体模型与参数在执行时按当时的能力说明读取，不写死。

| 环节 | 平台动作 | 注意 |
|---|---|---|
| 风格帧 | 默认：代码渲染风格帧（本地、免费）；可选：图像生成（仅用户明确要求时） | 代码帧与成片同一套绘制代码；中文标题优先后期排版 |
| 场景、物件、道具 | 默认：编写并运行代码，分层矢量 + 轴心关键帧，本地逐帧渲染 | 不以静图缩放平移冒充动作 |
| 人物 | 默认不做；把人的动作翻译成物件、光和视角 | 见 `character-narrative.md`；用户坚持时仅剪影 |
| 产品抠图/分层 | 去背景、图层拆分 | 用于 2.5D 视差与产品合成 |
| 镜头视频（可选生成路线） | 图生视频，单次 4–15 秒（随模型） | 默认关闭；仅用户明确要求时启用；一镜一条；生成后实测时长与帧率 |
| 精确几何/文字/循环 | 编写并运行代码，本地逐帧渲染（免费） | 帧纯函数 + 固定种子；见 scripts/ |
| 真实 3D 运镜 | 三维场景与相机编辑（导演台类能力） | 环绕、遮挡、准确透视 |
| 配乐 | 默认：`scripts/lofi_score.py` 本地合成 lo-fi（免费，与事件表对齐，见 `lofi-score.md`）；可选：器乐配乐生成（付费，用户同意后） | 生成的配乐需实测起音再对齐事件表 |
| 剪辑合成 | 视频拼接、裁剪/叠加/混音转码、时间线剪辑与字幕 | 标题、字幕、VHS 收尾在此统一 |
| 放大/补帧 | 视频增强、超分 | 只改分辨率/帧率，不改内容 |

默认整片纯代码，不调用生图与图生视频。用户明确要求生成时，付费生成（图像、视频、配乐）前向用户确认；预算未确认时只准备提示词，不提交任务试价；代码渲染与剪辑类本地处理无需额外确认；用户已授权整片时，素材自查通过后直接继续，不重复加审批。
