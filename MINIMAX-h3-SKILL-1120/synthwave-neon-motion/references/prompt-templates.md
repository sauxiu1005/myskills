# Prompt Templates · 提示词模板

原则：**默认路线为纯代码，镜头按 §6 写成无人物代码规格；§1、§2 的生图/图生视频提示词只在用户明确要求生成时使用。图像提示词只写静态画面；视频提示词只写主体主动作 + 一个相机运动 + 场景运动；字幕、标题、声音另列给后期。** 中文为默认语言。用户的文案原样放进文字层清单，不改写。

## 1. 静帧 / 风格关键帧（只写凝固的一帧）

```
【主体】{主体，材质与姿态，位置（三分线/居中）}
【场景】80年代合成器浪潮夜景：深靛蓝到黑紫的夜空与稀疏星点，地平线上一轮橙粉条纹落日（下半部有越往下越宽的水平镂空条纹），远处洋红到电青渐变的线框山脉{或几何建筑/城市剪影}，地面是向地平线汇聚的洋红霓虹透视网格。
【层次】前景{暗色剪影，如棕榈/立柱}，中景主体，后景落日与山脉，三层清晰分离。
【光】主体左侧洋红边缘光、右侧电青边缘光，顶部一条白色铬高光；落日色在镜面上反射；受控辉光，轮廓清楚不发糊。
【构图与镜头】{景别}，{机位高度，如低机位}，{焦段感，如 35mm 广角透视}，地平线位于画面下{1/3}。
【色板】{色板名与 4–6 个色值}
【强度】{克制/标准/浓郁}
【质感】{复古默认：细腻可见但克制的胶片颗粒，暗部微微抬起，高光柔和，最亮霓虹周围轻微红橙光晕；明确要 VHS/CRT 时再写：轻微扫描线 / 1–2px 色边（二选一或都不写）；清洁产品图：颗粒很轻或无}
【避免】整体紫粉滤镜、主体被染成单色、文字乱码、多余文字、画面元素堆满。
画幅 {16:9}。
```
需要中文标题时：静帧里留出标题区域，标题由排版叠加；只有对文字精度要求不高时才让生图模型直接写字，并核对每个字。

## 2. 视频（从已确认关键帧出发，一镜一条）

```
以参考图为首帧，保持主体外形、材质和色板不变。
主体动作：{一个主事件，含起始→结束状态，如"铬金属耳机从侧面缓慢转正 20 度，金属高光从左上扫到右下"}。
相机运动：{一个运镜，如"低机位缓慢向前推进，地平线保持水平"}。
场景运动：{背景动作，如"地面霓虹网格持续向镜头流动，落日条纹缓慢向下滚动，远山随推进轻微视差"}。
节奏：{铺垫→爆发→停留，如"前 1.5 秒匀速巡航，1.5–2.5 秒明显加速、车尾灯拉出光轨，最后 1.5 秒速度回落并稳住"}。
附属动作（≤2）：{如"车尾灯拖出红色光轨""近处立柱快速掠过镜头"}。
保持：画面中无文字、无字幕、无新增物体，风格不漂移。
```
注意：不写"多个镜头切换"，除非模型支持并确有必要；时长用模型允许的值并在生成后实测。

## 3. 后期单列（不进视频提示词）

```
文字层：{逐条：原文 / 出现帧 / 消失帧 / 字体气质（铬金属粗黑、霓虹手写、等宽 OSD）/ 位置}
声音：{默认 lo-fi：72 BPM 电钢琴七和弦 + 圆润贝斯 + 松弛鼓 + 黑胶噪声（见 lofi-score.md）；用户指定时改合成器浪潮等；重音帧列表；音效：霓虹点亮"叮"、擦除气流声、磁带停转}
收尾：{bloom 强度；胶片层：颗粒档位（关/低/标准/强）、暗部轻抬、halation、weave；视频层（独立选用）：扫描线、色边、跟踪扰动转场；暗角}
```

## 5. 动效与质感写法提醒

- 视频提示词只描述**可见的主体/环境/相机动作**；颗粒、色边等质感优先放后期统一加，模型不保证颗粒一致。
- 增强动效按 `motion-fx-library.md` 选 1 主 + ≤2 辅，写清起止状态；不要列一串关键词（"霓虹、故障、星芒、光晕、拖影……"）。

## 6. 无人物镜头规格（默认，纯代码）

这是交给代码实现的规格，不是生图提示词。

```
用途：{镜头号 / 节拍}，16:9，{帧数}帧。
画风：精致图形化复古 Synthwave——清晰外轮廓、大色块分面、受控渐变，深靛蓝负空间，洋红/电青边缘光色带，暖橙到粉主光渐变；低颗粒。
故事里的人在做什么：{原动作} → 无人物表达：{物件/光/视角如何完成它，见 character-narrative.md §2}。
主事件（关键帧）：{物件名} 绕 {轴心} {旋转/开合/点亮/弹出}；关键姿势与帧号：{F0, F? 预备, F? 主动作, F? 过冲, F? 停}；缓动：{…}；跟随：{附属部件延迟 2–4 帧}。
场景：{几何场景元素与各自运动：道路流动、网格、落日、线框、屏幕、灯管}。
相机：{运镜编号与速度变化}；主观视角时写明机位高度。
光/转场：{光事件、动机转场类型与触发帧}。
声音：{与主事件对齐的音效与配乐重音帧}。
禁止：画面出现人物（用户坚持时只用小尺寸无面部剪影）；静图缩放平移冒充动作；写实纹理。
```
