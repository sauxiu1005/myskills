# Visual Grammar · 画面语法

> 目标：一眼认出 80s synthwave，同时主体清楚、前中后景分明。它是"搭出来的世界"，不是给普通画面套紫粉滤镜。

## 1. 图层结构（从远到近）

| 层 | 内容 | 规则 |
|---|---|---|
| L0 天空 | 深靛蓝黑 → 紫的竖向渐变；稀疏星点；可选流星 | 顶部最暗（接近 #05030F），越近地平线越亮越紫；渐变要防色带（加 1–2% 细噪） |
| L1 落日 | 圆盘，上黄→中橙→下洋红多段渐变；下半部水平条纹镂空 | 条纹**越往下越宽**、可缓慢向下滚动；外圈两层光晕（紧+散） |
| L2 远景剪影 | 线框山脉、城市天际线、几何建筑（金字塔、方塔、拱门） | 线框颜色随高度从洋红过渡到电青；底部被地平线雾吞没 |
| L3 地平线 | 一条 1–2px 高亮热线 + 雾带 | 是全画面最亮的水平线，分隔天空与地面 |
| L4 地面 | 一点透视霓虹网格，横线向镜头流动 | 线条有紧光核（~4px 感）+ 宽辉光（~30px 感）；远处细线需抗锯齿/淡出，避免闪烁 |
| L5 中景主体 | 产品、物件、车、建筑、Logo、抽象几何（默认无人物） | 必须有明确轮廓：铬高光 + 边缘光（洋红一侧、电青一侧）；与背景亮度分离 |
| L6 前景 | 棕榈剪影、立柱、栏杆、粒子、反光地面 | 用于遮挡揭示与视差；暗部接近纯黑紫，不抢主体 |
| L7 文字层 | 铬金属字、霓虹灯管手写体、等宽 OSD 小字 | 中文用代码/后期排版保证字形；安全边距 ≥5% |
| L8 收尾处理 | 受控 bloom、暗角；胶片层（逐帧颗粒、暗部轻抬、高光柔肩、halation）与视频层（扫描线、色边、跟踪扰动）分开选用 | 统一一次处理；强度见 `palettes/intensity.json`，胶片与视频区别见 `film-texture.md` |

## 2. 主体路由（不限公路汽车）

| 主体 | 放置方式 | 关键材质/光 |
|---|---|---|
| 产品 | 立在网格上的镜面台/悬浮于落日前；三分线或居中 | 铬或亮面：落日色作为环境反射，侧面洋红边缘光，顶部一条白色高光带 |
| 人物 | 默认不做；用物件、光与视角表达人的存在（见 `character-narrative.md`） | 用户坚持时仅小尺寸无面部剪影：深色填充 + 洋红/电青边缘光，与环境同光向 |
| 空间/建筑 | 几何建筑立在网格上，线框描边点亮 | 窗格、立面分割线作为霓虹线 |
| 抽象 MG | 几何体（棱柱、圆环、三角）+ 网格 + 落日 | 形体清楚、数量少，靠节奏而非数量 |
| 品牌片头 | 铬字/Logo 在地平线上方，倒影落在网格 | Logo 必须来自用户；演示用虚构名 |

## 3. 必备特征清单（自检）

1. 透视网格地平线 2. 条纹落日 3. 洋红+电青双霓虹 4. 深夜空渐变 5. 铬金属或高光主体 6. 双层辉光 7. 至少三层深度。
少于 5 项 → 风格不成立；只有调色而无 1/2/5 → 判定为"紫粉滤镜"失败。

## 4. 风格强度（详见 palettes/intensity.json）

- **克制 subtle**：品牌/产品优先。bloom 弱，胶片颗粒低或关闭，无视频伪影，网格亮度低，留大面积暗部。
- **标准 standard**：默认。双层辉光、胶片颗粒标准 + 暗部轻抬 + 局部 halation，落日条纹清晰；扫描线默认关（它是视频伪影，不是胶片）。
- **浓郁 full**：MV/片头。颗粒强，可再选 1–2 项视频伪影（色边 1–2px、短暂跟踪扰动），更强 bloom。仍需保证文字可读，不全程故障。

## 5. 反例（出现即修）

- 整片只有紫粉调色、没有网格/落日/铬 → 加回结构元素。
- bloom 糊掉轮廓、文字发虚 → 先降 bloom 半径，再给文字加暗色描边/底。
- 网格远处摩尔纹闪烁 → 远处线宽淡出、按距离降低对比。
- 元素过多（星、粒子、闪光、故障同时满屏）→ 每镜只留一个主事件。
- 人脸/产品被染成单一洋红 → 主体保留中性主色，霓虹只作边缘光与环境反射。
- 画面里出现人物（简笔、贴纸或代码角色）→ 默认删去，改用物件、光和视角表达；用户坚持时改为剪影。
- 人物或环境出现写实摄影质感（毛孔、皮革微纹理、摄影景深、现代电影截图感）→ 判定画风失败；改用喷绘海报造型语言重出（写实只在用户明确要求时使用）。
- 只凭洋红/电青配色判断"是 Synthwave" → 不成立；先看造型与材质语言。
