# Film Texture · 胶片质感与视频伪影

> "复古"不等于"加扫描线"。**胶片颗粒（film grain）** 和 **VHS/CRT 视频伪影** 是两套不同的物理来源，分开选用、分开调强度。颗粒是质感，不是动作（见 `kinetic-design.md`）。

## 1. 两类来源，别混用

| 类别 | 来源 | 典型表现 | 何时用 |
|---|---|---|---|
| 胶片 Film | 银盐颗粒、片门、胶片曝光 | 逐帧变化的细颗粒、暗部轻抬、高光柔肩、亮核外红橙 halation、轻微画面漂移（gate weave）、曝光呼吸 | "复古 / 80s / 胶片感 / 电影感"请求的**默认**底层质感 |
| 视频 Video / CRT | 磁带、扫描电子束、模拟信号 | 扫描线、色度串扰/色边（chroma bleed / RGB 偏移）、跟踪扰动条、磁带噪声带、短暂掉帧 | 用户明确要 VHS / 录像带 / CRT / 电视屏，或作**短暂转场**（`motion-fx-library.md` FX12） |

规则：扫描线不是胶片；只有颗粒没有扫描线也算"复古"。视频伪影各项**独立开关**，一次最多选 1–2 项，不全部堆满；全程故障禁用。

## 2. 胶片颗粒规格（复古请求默认开启"标准"）

| 项 | 要求 | 原因 |
|---|---|---|
| 逐帧变化 | 每帧不同的颗粒场，由 `seed + 帧号` 决定 | 静态噪点贴图会像"脏镜头"，且一眼看出是贴图 |
| 可复现 | 固定 seed，同参数重渲完全一致 | 便于 A/B 与返修 |
| 颗粒尺寸随输出尺寸 | 颗粒直径 ≈ 输出高度/720 × 1.2–1.4 px（720p≈1.3px，1080p≈2px，4K≈5px）；先在低分辨率生成再放大，形成轻微团簇 | 固定 1px 噪点在 4K 看不见、在缩略图里变成彩色雪花 |
| 亮度相关 | 中间调最强；深黑保留约 45% 底噪；接近纯白/霓虹硬核心降到 ~20% | 真实胶片如此；同时保住霓虹硬核心和文字边缘 |
| 以亮度为主 | 单色颗粒为主，彩色分量 ≤ 约 20% | 强彩色噪点 = "彩色雪花"，像坏信号而非胶片 |
| 强度档 | 关闭 / 低 / 标准 / 强（脚本 `--grain off|low|standard|strong`；0–255 振幅约 5 / 8 / 12） | 产品清洁图用低或关闭；MV/片头可用强 |
| 抗压缩 | 编码时选适合颗粒的设置（如 x264 `-tune grain`、更低 CRF）；交付后抽帧测平坦区高频标准差，与未压缩帧比较 | 颗粒最先被压缩抹掉；"渲染里有、成片里没有"最常见 |

AI 生成路线：在提示词里写"细腻、可见但克制的胶片颗粒，随帧变化，暗部微微抬起"，但**模型不保证**颗粒一致或可见；需要精确颗粒时在后期统一加。

## 3. 可组合的胶片层（按需，不必全开）

| 层 | 做法（代码路线建议值） | 风险控制 |
|---|---|---|
| 暗部轻抬 lifted blacks | `out = out×0.965 + 偏紫黑 (9,5,15)` | 不能抬成灰雾；最暗处仍 < 约 20/255 |
| 高光柔肩 soft shoulder | 亮度 > ~215 后压缩：`k + (x−k)/(1+(x−k)/60)` | 霓虹硬核心仍保持 ~235–245，不压成粉灰 |
| Halation | 取亮度 > ~185 的部分，大半径模糊（≈ 宽/110），染红橙 (255,70,45) 叠加 0.3–0.6 | 只在最亮核心周围；不要整屏发红 |
| Gate weave（可选） | 平滑的亚像素漂移 ≈ ±0.5 px@720p；在**超采样/缩放之前**平移，或取整像素 | 在最终分辨率做双线性亚像素平移会让全画面变软（实测细节下降约 10%） |
| 曝光波动（可选） | 每帧亮度 ±1–1.5 % | 超过 3 % 即成闪烁，禁止 |

## 4. 视频/CRT 伪影（独立选用）

| 项 | 建议值 | 注意 |
|---|---|---|
| 色度串扰 / 色边 | R/B 水平偏移 1–2 px@720p | 文字区域会发虚，标题镜可关 |
| 扫描线 | 隔行变暗 6–12 % | 缩放后易出摩尔纹；竖屏/小屏慎用 |
| 跟踪扰动 | 一条 4–10 % 画高的错位亮带，横扫 4–8 帧 | 只用于转场或一次重音；不全程 |
| 磁带噪声 | 横向噪声条，低透明度 | 与颗粒同时用时把颗粒降一档 |

## 5. 路由

- 复古/80s/胶片请求 → 胶片颗粒"标准" + 暗部轻抬 + 高光柔肩 + 局部 halation；weave/曝光波动可选。
- 明确要 VHS/CRT → 在上面基础上再选 1–2 项视频伪影。
- 清洁产品图、电商白底、需要放大看细节的主视觉 → 颗粒"低"或关闭，不加视频伪影。
- 文字主导镜头 → 颗粒在文字**之下**合成，或文字层单独加较弱颗粒；保证文字可读。

## 6. 自检

1. 逐帧对比两帧平坦区：颗粒位置不同（不是静态贴图）。2. 编码后平坦区高频标准差仍明显高于无颗粒版本。3. 主体轮廓/文字边缘清晰度没有明显下降。4. 霓虹核心仍是亮白芯而不是粉灰。5. 没有彩色雪花、没有全程故障。
