# Workflow & QA · 流程与验证

流程：**语义节拍 → 代码风格帧 → 分镜镜头表 → 代码渲染/合成 → 验证**（默认纯代码；生成路线仅在用户明确要求时启用）。主题已给就推进；默认 10 秒 16:9 30fps，可改。

## 1. 语义节拍表

| 拍 | 原文（一字不改） | 含义/情绪 | 视觉命题 | 起始状态 | 主事件（动作库编号） | 结束状态 | 建议时长 |
|---|---|---|---|---|---|---|---|

规则：每拍一个主事件；高潮约在 60–75% 处；结尾定格 0.8–1.2 秒。无文案时由主题生成 3–4 拍，并标注"助手拟定"。

## 2. 分镜镜头表

| # | 起止帧 [start, end) | 时长 | 景别 | 主体动作 | 场景运动 | 相机（C1–C7） | 文字层 | 声音 | 路线 |
|---|---|---|---|---|---|---|---|---|---|

- 帧区间左闭右开，首镜从 0 开始、末镜结束于总帧数，镜头间无缝无重叠。
- 10 秒片至少两种运镜；相邻镜头运镜不同或方向不同。

## 3. 整数帧事件表（cues.json）

画面、文字、声音共用一份。所有时间是**整数帧**；音频采样位置 = 帧 × 采样率 / fps（48000/30 = 1600 采样/帧，整除）。

```json
{
  "fps": 30, "total_frames": 300, "width": 1920, "height": 1080, "seed": 1986,
  "palette": "neon-sunset", "intensity": "standard", "texture": {"grain": "standard", "halation": 0.6, "weave": false, "video_fx": []}, "energy": "standard",
  "shots": [ {"id": "S1", "start": 0, "end": 105, "camera": "C1", "subject": "…", "scene": ["M1", "M5"]} ],
  "events": [ {"id": "title_slam", "frame": 204, "motion": "M8", "sound": "impact"} ],
  "text": [ {"id": "T1", "content": "用户原文", "in": 204, "out": 300} ],
  "audio_status": "planned"
}
```
`audio_status`：`planned`（拟定，未实测）/ `measured`（已对实际音频测过起音帧）。

## 4. 路线与预算

- 精确几何、文字、Logo 定版、循环 → 代码动画（本地、免费、可确定性重渲）。
- 场景、物件、道具 → 默认纯代码：分层矢量 + 轴心关键帧。
- 人物 → 默认不做；人的动作由物件、光和视角表达；用户坚持时只用小尺寸无面部剪影。见 `character-narrative.md`。
- 生图 / 图生视频 → 仅在用户明确要求时启用；付费前确认；静态生成图不能作为动作的主体。
- 授权与自查：用户已认可画风并授权整片时，代码造型帧、动作短测与成片自查通过后在授权内继续，不重复加审批。
- AI 结果的时长、文字和接缝都要实测，不按提示词宣称。

## 5. 确定性渲染规则（代码路线）

- 每帧 = f(帧序号, 参数, 种子)；不读系统时间，不依赖上一帧状态；随机数用固定种子的哈希。
- 周期运动（网格相位、条纹滚动、星闪）的周期整除循环帧数，才能无缝循环。
- 声音从同一份 cues.json 合成或对齐；默认用 `scripts/lofi_score.py` 合成 lo-fi；重音落在事件帧的首个采样。

## 6. 验证清单（交付前逐项，报告区分三类）

| 类别 | 检查项 | 方法 |
|---|---|---|
| 文本检查 | YAML/JSON 可解析；相对引用文件都存在；description ≤200 字符；镜头帧区间连续、总和=总帧数 | 解析与脚本检查 |
| 本地渲染 | 实测时长、分辨率、帧率、帧数、编码、音频轨（采样率/声道/时长）；切点前后帧与关键帧截图；文字区域对比度；循环首尾帧差；黑帧检测；**胶片颗粒**：编码后平坦区高频标准差 vs 无颗粒版、相邻帧颗粒相关性 ≈ 0（逐帧变化） | ffprobe / 抽帧 / 像素统计 |
| 真实 AI 生成 | 实际时长与参数、主体一致性、风格是否只是滤镜、文字是否乱码 | 生成后实测与人工审阅 |

- 未执行的类别写"未测试"，不算通过。
- 音频只做了合成未做起音检测时，写"音频事件为拟定"。
- 文字可读：标题与背景亮度对比建议 ≥4.5:1（以文字所在区域测），字高 ≥ 画面高 3%。
- 循环接缝：末帧与首帧的平均绝对差应与相邻帧差同量级（比值 ≤ 1.5）。
- 动感：镜头表每镜四层（主体/环境/相机/光）都有内容或写明"有意为空"；每镜有铺垫→爆发→停留；颗粒/扫描线不计为动作（见 `kinetic-design.md`）。
- **风格验收优先**：先看造型与材质语言（轮廓、色块、受控渐变、是否出现写实纹理或电影截图感），再看配色与元素；仅有霓虹配色或任务显示 completed 不算风格通过（见 `character-narrative.md` §4）。
- 无人物：默认镜头中没有人物，"有人"的意思由物件、光或视角传达清楚；物体动作真实发生，静图缩放平移不算（见 `character-narrative.md` §4）。
- 统一性：场景、物件、道具画风、比例、光源方向、接触阴影、透视、颗粒尺度一致。
- 闪烁：亮度剧烈变化每秒 ≤ 3 次；整屏闪白 ≤ 2 帧；视频伪影只在转场或重音出现。
