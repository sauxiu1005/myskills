# Default Soundtrack · Lo-fi（默认配乐）

动态作品**默认配 lo-fi 质感音乐**，由 `scripts/lofi_score.py` 本地程序合成：免费、可复现，与画面读取同一份 `cues.json`。用户指定别的音乐风格、提供音频，或要求静音时按用户要求。来源：LATE TAPE 测试片（0.3.5 测试，用户评价"很有感觉"）。

## 听感配方
- 速度 70–80 BPM（默认 72，一拍 = 25 帧 @30fps），慢、松、带一点拖拍。
- 电钢琴（Rhodes 质感）：七和弦轻扫弦，轻微颤音；默认走 Fmaj7 → Em7 → Dm7 → Cmaj7，每和弦两拍；收尾可落 Cmaj9。
- 稀疏旋律：五声音阶，落在弱拍，数量少，留空白。
- 贝斯：圆润正弦低音，根音 + 八度勾音。
- 鼓：boom-bap，底鼓偏松，军鼓略晚，摇摆八分踩镲；音量靠后。
- 质感层：黑胶噼啪 + 底噪，可选雨声；轻度磁带饱和、抖动，整体高频柔和（约 11 kHz 以上滚降）。

## 结构与画面配合
- **开场先"隔着"**：前段只有闷住的电钢琴（低通）+ 黑胶 + 环境声（`muffled_until`），由画面里的事件（按下播放、开门、开灯）"打开"声音，随后鼓与贝斯进入（`drums_in`）。
- **重音只落在事件帧**：匹配剪接/揭示用低频重音（`accents`），灯牌点亮/标题出现用铃音（`chimes`），擦除转场用气流声（`whooshes`），切点前用反向上扬（`risers`）。
- **结尾磁带停转**（`tape_stop`）：音高下滑到静止，只留黑胶噪声，配合画面淡出。
- 循环作品不用停转，首尾保持同一和弦与底噪，便于接缝。

## 使用
1. 在 `cues.json` 里写 `fps / total_frames / bpm`，与 `workflow-and-qa.md` 模板一致，以及可选的 `chords`、`melody`、`music{...}` 字段（字段说明见脚本开头）。兼容旧字段 `frames`；两者同时提供时必须相等。
2. `python3 scripts/lofi_score.py cues.json score.wav`，再与画面一起封装（ffmpeg `-map 0:v -map 1:a`）。
3. 实测音频时长与画面一致；重音帧与画面事件帧一致。

## 边界
- 这是程序合成的 lo-fi，不是真实乐手录音；质感接近，细节有限。用户想要更像唱片的配乐时，可改用付费的 AI 音乐生成（见 `platform-routing.md`），需用户同意。
- 不使用受版权保护的歌曲或采样。
