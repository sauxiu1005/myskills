# Motion Library · 动作库

> 基础动作 M1–M8。增强的复古霓虹动效（FX1–FX12：逐段点亮、光学拖影、星芒、光环扩散、速度变化、模拟视频转场等）见 `motion-fx-library.md`；四层编排与动感档位见 `kinetic-design.md`。

每个动作写明：**类别**（主体 / 场景 / 相机）、起始状态 → 结束状态、方向、速度曲线、触发、收尾。按主题选用，每镜只让一个动作做主事件，其余作为背景或干脆不用。

缓动缩写：`ease-out-expo`=1-2^(-10t)；`in-out-sine`=-(cos(πt)-1)/2；`out-cubic`=1-(1-t)^3；`in-quad`=t²。帧数按 30fps 给出，换帧率按秒换算。

| # | 动作 | 类别 | 起始 → 结束 | 方向 | 速度曲线 | 触发 | 收尾 |
|---|---|---|---|---|---|---|---|
| M1 | 透视网格流动 | 场景 | 横线位置相位 0 → 1 循环 | 从地平线流向镜头（模拟前进） | 线性（机械运动允许线性）；速度可随节拍提升 20–40% | 开场即开始；主事件时可加速 | 循环相位整数结束，保证接缝；或减速到 0 |
| M2 | 分层视差 | 场景/相机 | 各层偏移 0 → 目标位移 | 与相机运动相反；近层快远层慢（前景 1.0、主体 0.6、山 0.25、落日 0.05） | in-out-sine | 随相机移动 | 与相机同帧停下，不各自漂移 |
| M3 | 轮廓点亮 | 主体/场景 | 线条描边 0% → 100%，亮度 0 → 1 | 沿路径从一端到另一端或从下往上 | 描绘 in-out-sine，亮起 ease-out-expo；可 2–3 次灯管闪烁（帧级 ON/OFF） | 节拍或文案关键词 | 停在满亮，之后只保留 2–3% 呼吸 |
| M4 | 金属高光扫过 | 主体 | 高光带在主体左外 → 右外 | 斜 20–30°，左上到右下 | in-out-sine，持续 12–18 帧 | 主体落定后 4–8 帧 | 扫出后不回扫；同一主体两次间隔 ≥2 秒 |
| M5 | 落日条带揭示 | 场景 | 落日在地平线下 → 升到目标高度；条纹宽度 0 → 设定值 | 向上；条纹向下滚动 | 升起 in-out-sine 1.5–3 秒 | 开场或段落起点 | 停在目标高度，条纹持续慢滚 |
| M6 | 粒子拖尾 | 场景/主体附属 | 粒子从发射点出生 → 寿命结束淡出 | 沿运动反方向或向地平线汇聚 | 位置线性、透明度 out-cubic | 主体快速移动或主事件冲击 | 寿命自然结束；数量 ≤60，不满屏 |
| M7 | 呼吸脉冲 | 场景/主体 | 亮度 1.0 → 1.0+A → 1.0（A=0.1–0.35）；网格可发一圈冲击环 | 冲击环从主体脚下向外扩散 | 冲击 ease-out-expo 上升 2 帧，指数衰减 8–15 帧 | 鼓点/重音帧 | 回到基线；末尾循环时 A 回 0 |
| M8 | 动态排版 | 文字 | 字不可见 → 定版：铬字 2.2→1.0 倍砸入、霓虹字逐笔点亮、等宽字打字机 | 砸入沿镜头轴；逐字左到右 | 砸入 in-quart 2–3 帧 + 回弹衰减；打字 1–2 帧/字 | 主事件/高潮帧 | 定版保持 ≥1 秒；只再给一次高光扫过 |

## 主体 / 场景 / 相机分工

- **主体运动**：产品转台、物件开合、文字砸入、Logo 点亮（M3/M4/M8）。决定"发生了什么"。
- **场景运动**：网格流动、落日升起、粒子、脉冲（M1/M5/M6/M7）。提供氛围与节奏，不抢主事件。
- **相机运动**：见 camera-library.md。决定"怎么看"。
- 同一时刻最多：1 个主体动作 + 1 个相机运动 + 背景场景运动。主事件帧前后 6 帧内不叠第二个主事件。

## 节奏建议（10 秒）

钩子 0–0.5 秒必须有画面（不黑屏）；升级段场景速度上升；高潮（6–7.5 秒）一个主事件 + 脉冲；末段 0.8–1.2 秒定格带微动（呼吸、慢条纹滚动）。
