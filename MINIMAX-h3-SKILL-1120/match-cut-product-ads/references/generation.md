# Design 模型选择与素材生成

先读 `design-adapter.md` 发现真实能力，按 `output-choices.md` 落实规格。图片、视频、音乐、配音、音效优先走 Design 当前入口；不用上游服务的模型 ID、任务参数或历史积分推定本平台行为。

## 模型、预算与任务

用户明确选择优先。未指定时，按参考控制、产品一致性、动作需求、清晰度与预算推荐一条兼容路线，可附一个较省成本备选。模型显示名不等于可提交的模型 ID；平台未提供的参数不传。

- 图片：优先支持参考图编辑、产品外观保持和目标画幅的能力。
- 视频：按首帧、首尾帧、参考图或其他真实支持模式选择。参考图可能只是外观约束，不能把它说成时间关键帧。
- 音乐：优先可生成纯音乐与表达速度/段落的能力；BPM 提示不保证实际拍点。
- 配音：仅在方案需要时使用，匹配语言与合法可用声音。
- 音效：按可见动作生成短拟音；无独立能力时复用用户素材或可用声音库，说明来源。

总预算覆盖定帧、音乐候选、源视频时长、配音、拟音、模型测试和重试；20 秒成片通常需要超过 20 秒源素材。可建议预留 20%—30% 返工空间，用户额度优先。费用不可查询时明确未知，落实可执行任务数量和支出边界后再提交；余额不是授权。

沿用既有方案/规格/额度授权，不重复确认。每个资产默认最多一次有针对性的重试。未知任务先查状态，不能重复扣费提交。按平台真实工具 schema 执行提交、等待、下载或引用；记录 task-map.json，实际支持幂等参数时才使用。

## 定帧与代表镜头

真人路线先应用 [live-action-realism.md](live-action-realism.md) 的摄影方案和定帧检查；用 [look-plan.json](../assets/look-plan.json) 记录本项目的可见目标与证据。最容易暴露缺陷的脸/手和产品交互作为代表镜头，合并到既有试镜预算，不额外增加一轮无条件付费测试。产品外观参考、人物身份参考、摄影气氛参考分别注明用途；不把别的广告演员作为本片产品代言人。

先按 [relay-design.md](relay-design.md) 选择一组能同时验证体验联系和手势匹配的代表接力。两侧提示词沿用同一主锚点、画面位置、手势/接触阶段与方向记录；产品图或官方信息决定可实现的操作方式，不从参考广告推断产品功能。贯穿视觉元素在各镜保留约定特征，并给场景变化留下空间。

1. 产品图按可见面与开合状态分别引用，不用正反两视图拼图作单一物体。官方图固定外观；终态另写清楚，例如完全展开到 180°，不要盲目复制营销照略微弯折的姿势。
2. 先做产品主镜头与一组代表匹配对，按 `review.md` 看原尺寸产品、手部、材料反光和构图。合格后再衍生批量，避免把错误传播到所有镜头。
3. 每镜先有首帧，依赖精确终态时补尾帧。共享构图从同一母图编辑；模型未支持尾帧时仅在指令描述终态，不能声称锁定。
4. 提示词写：场景/时段、参考角色、产品可见面、相机角度、主体中心与占比、主光方向、握法、动作准备状态、材质、保留/修改范围。只描述可见结构；避免为了说“不出现”反而反复提及隐藏部件。
5. 手指必须有真实握持与施力关系。结构错误需换图或重做；单纯位置尺度偏差先用裁切缩放或 `align.py`，再以 `qc.py onion / match` 复核。
6. Logo 和字幕后期叠加；道具必要识别印字可以保留并核对。屏幕内容表达真实使用任务，预演占位图不当成功能证据。
7. 上传/引用后保存真实素材 ID 与源像素；云端素材 ID 与本地路径分开。保留每次版本，勿覆盖合格母图。

图片提示词骨架：`场景和时段 → 产品参考与可见面 → 相机和主体锚点 → 光线/材质 → 手部与动作准备 → 保留范围 → 修改内容 → 禁止的结构错误`。比例使用分镜表的同一组百分比。

## 音乐与粗剪

音乐候选数量按已认可方案和预算确定，通常 2–3 个即可。提示词明确纯音乐、目标 BPM、起势/推进/高潮/结尾重音。分析实际节拍、能量和调性，选择能连续收束到片尾的段落。静帧动态分镜先验证构图、节奏和文字，不冒充最终动作视频。分阶段模式展示粗剪；一次确认模式按现有额度自检后继续。

## 视频与自然动作

H3 人物真实性不仅是指头数量。按摄影方案保留皮肤局部色差、衣物重力、光源方向、暗面和背景纵深，并检查运动过程中是否变成美颜脸、漂浮手或均匀发光。简短写清主要动作的准备、接触、受力、完成与释放；脸部通过视线和反应表现任务，不列一串要求模型同时执行的眨眼/呼吸/微笑动作。具体英文提示和失败处理见 [live-action-realism.md](live-action-realism.md)。

默认逐镜生成后进行匹配剪辑。视频提示词写：参考身份及产品不变量、谁因何动作、握法/重心/视线、运动方向、按秒的起止状态、相机路径、最终结果。产品保持刚体，仅在真实机构处开合。优先完整动作，给选帧留余量；不能靠明显加速掩盖慢动作或手部错误。

只需简单数字旋转/拉远/甩镜时可后期添加，真实空间跟拍和视差需由实际素材或模型实现；两边避免重复添加同一运镜。首尾锁定造成动作拖慢时，可明确动作完成时间，或在不依赖精准尾帧时只约束首帧。

用户指定“同一条视频里完成两个转场”等要求时，把每个转场的触发动作、前后状态、延续方向、时间窗口写入同一任务，合法生成时长需覆盖完整事件。实际检查每次转场；两条独立素材的后期拼接不能作为满足段内事件的证据。

先验证代表动作再扩大批量。检查完整运动及切点附近帧：手部持续合理、产品不变形、方向相符、终态准确、没有停顿/跳变/莫名部件。避开模型常见的开头等待和结尾吸附，采用区间仍需保留用户要求的所有事件。

在实际采用的切出/切入帧及邻近帧检查主锚点位移、接触关系和运动阶段，更新 `relay-plan.json` 的 actual/review。保存真实采用的生成方法与依赖资产；不将共享母图、真实尾帧衍生、单次生成内转场混称为同一种方法。

记录源帧率、采用入出点、时间线区间和速度；按真实时间换算，不能假定某个模型固定 24 或 30 fps。通常实速 0.8–1.25×；结构、物理或关键转场失败需要有针对性重生成，字幕/曝光/几何/剪点优先后期。

## 声音与验收

配音要求干净人声，句间留剪辑余量，短句对应指定动作或产品信息。拟音描述声音来源、接触动作、材质和空间，并把起音对到实际动作帧。源视频自带音轨先决定保留范围，避免与后期配乐叠播。

画面、声音和匹配切点按 `review.md` 分开检查。自动测量不证明手部合理或听感自然；无法播放/听审时明确未验证，不自动记 passed。
