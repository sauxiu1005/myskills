# Design 导演流程

先读真实产品资料，再把“一支宣传片”收敛为一句核心信息。记录产品类别、受众、观看场景、证据材料、输出规格和声音模式。真实 Logo、界面、功能和数据应有来源；创意广告文案可以新写，但不得伪造产品功能或效果数字。

## 选择动作语言

| 信息形状 | 优先语言 | 要避免的问题 |
|---|---|---|
| 主张、情绪 | kinetic-type / generative-field / 3d-object | 无产品识别的通用炫技 |
| 操作流程 | cursor-demo / continuous-morph | 假点击、假界面和不相干结果 |
| 机制、因果 | mechanism / system-diagram / flat-world | 信息还没解释就快切 |
| 数据、证据 | data-story / editorial-collage | 不可追溯的数字、图表误导 |
| 前后变化 | continuous-morph / split compare | 两张静态图之间没有变化逻辑 |
| 能力展示 | showreel / 一个深入制作的作品 | 功能列表变成相同的多页幻灯片 |
| 人物讲述 | talking-head / photo-led / 原创角色 | 给无关故事强加人物 |

具体语法从 [library](library/README.md) 读取，片型见 [formats](library/formats.md)。库中品牌和历史成片是选择语言的例子，不是照搬商标、画面或套用性能承诺的依据。

从品牌实际视觉判断精确/俏皮、克制/活跃、技术/人文、疏/密。让这些判断改变构图、运动力度、字重、停留和声音；“技术产品”不自动等于黑底霓虹，“高级”不自动等于慢镜头。

## 方向卡

用户没有指定风格且愿意选方向时，制作三张真实关键帧。A 是最贴合信息的表达，B 强化一个关键动作，C 换一种仍适合产品的材料或语言。三者的区别应能在静帧和运动设想中看见。

每张卡写：名称、语言、核心句、材料/字体、配色及出处、首3秒、continuous/montage/hybrid 路线、声音、素材风险。允许用户混合 A 的构图和 B 的节奏。若用户要求直接做，自选最有依据的一版继续，不能机械等待选卡。方向关键帧作为图片放进本片作品目录，方向卡写入创作方案，再用选择题请用户选择或混合。

代码/UI 方向以实际渲染截图为主。人物/摄影方向可用平台生成或合法素材作为情绪参考，但应标明“素材方向图”，并尽快验证合成后的实际关键帧。没有生图能力不影响代码动画方向制作。

## Treatment 与节奏

先写节奏计划，再铺全片。用表格记每个事件的秒数与拍点，区分新信息、动作落定、相机交接与读取窗口。音乐驱动可用 `time = beat × 60 / BPM`，有词轴时以实际发声时间为准。

开头尽快建立吸引力；中段有信息和速度的变化；最大揭示落在视听重点；结尾留下品牌或回到循环起点。3秒钩子、100–125 BPM、段落快切等均是可调起点，不覆盖用户指定的安静、极简或无音乐形式。详见 [rhythm](rhythm.md)。

把 hook、hero、最密集帧和片尾从实际动画渲染出来。逐个接缝写清“旧焦点如何交给新焦点”：共用对象、空间移动、形状变化，或有动机的节奏硬切。跨设备演示按 [连续性](product-demo-continuity.md) 让同一任务从发起到结果可追踪。

先完成最难镜头和能验证导入的代表段。确认点只放在会改变作品的地方：交付规格（无法推断时）、方向选择、treatment 与代表段、成片审阅；确认点之间的制作持续推进，不逐个小步骤询问“是否继续”。用户要求直接完成时，按其要求跳过相应确认。
