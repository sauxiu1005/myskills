# Science, education and papers / 科学、教育与论文

## 1. Evidence brief / 证据简报
Read the supplied paper or lesson before diagramming. Record source title and page/section/figure for each claim. If inaccessible, request the relevant content; do not imply you read it. For an open topic, use trustworthy sources for scientific facts; keep links with the brief. If no source-research capability is available, ask for source material when correctness depends on specifics; otherwise use only well-established textbook knowledge, mark it as a teaching simplification, and never cite a source that was not actually consulted.
先读原始材料再作图。每项事实记录题名与页码、章节或图号；无法访问时索取相关内容，不假装读过论文。自由选题先核实科学事实，简报保留来源。当前环境无法查阅资料时，正确性依赖具体细节的向用户索取材料；否则只采用公认的教科书知识并标为教学简化，不引用未实际查阅的来源。

## 2. Audience and diagram contract / 受众与图解约定
Specify one takeaway. Choose teaching illustration, public infographic, method workflow, causal mechanism, apparatus schematic or graphical abstract. A method sequence is not automatically a causal pathway. If the paper reports an association, do not render it as proven causation.
确定一个核心结论，再选教学插图、科普信息图、方法流程、因果机制、装置示意或图形摘要。方法顺序不自动等于因果关系；相关性不能画成已证明因果。

## 3. Fact and relation tables / 事实与关系表
Keep a compact table: component ID; exact label; role; source location; status (reported / hypothesis / teaching simplification / unknown).
Then: from ID; to ID; relationship; direction; conditions; source. State parallel branches and feedback explicitly. Use different line styles for hypotheses and observations, with a legend. Unknowns remain omitted or visibly unknown, never filled by a template default.
建立简表：组件编号、精确标签、作用、来源定位、证据状态（已报告／假说／教学简化／未知）。再列起点、终点、关系、方向、适用条件、来源。明确并行分支与反馈；假说与证据用不同线型及图例。未知内容不以默认值补全。

## 4. Composition and text / 构图与文字
Use a visible reading direction, short verb labels, ample spacing, and consistent symbols. Start with 3–7 grouped stages if appropriate, but never discard necessary conditions to satisfy a count. Split dense figures into overview and detail panels. Preserve required terminology, units, subscripts and inhibition versus activation semantics.
明确阅读方向、简短动词标签、留白及统一符号。可从三至七组阶段开始，但不能为凑数删除必要条件；复杂内容分成总览与细节。保留术语、单位、上下标和激活／抑制差异。

## 5. Visual QA / 图像核对
Compare every rendered label, edge and legend to the tables. Check for introduced arrows, altered terminology, false causal strength, missing branches, overlapping labels and misleading scale. A successful tool response is not a scientific correctness check. If only the prompt can be inspected, label this limitation.
逐项比对实际图中的标签、连线与图例，检查新增箭头、术语变更、过度因果化、分支遗漏、文字遮挡和误导比例。调用成功不代表科学内容正确；若只能检查提示词，明确标记限制。

## 6. Deliverables / 交付物
Final image, reusable prompt when requested, short explanatory caption, source note, and unresolved uncertainties. Keep measured graphs in a deterministic plotting workflow using original data. The extracted template examples are layout examples, not scientific authorities.
交付图片、按需附可复用提示词、简短图注、来源与未解决的不确定项。测量数据图使用原始数据和确定性绘图；提取模板中的样例仅用于布局参考，不是科学依据。
