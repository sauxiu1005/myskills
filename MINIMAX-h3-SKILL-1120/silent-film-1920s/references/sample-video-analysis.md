# Sample video analysis / 示例视频分析

对象：用户本地 `silent-film.mp4`（参考库示例片 *The Runaway Loaf*）。只用于提炼风格语法，**不复用剧情**。
标记：**[文档]** = STYLE.md / DEMO.md 的要求或自述；**[实测]** = 本次用 ffprobe / ffmpeg 数值测量或抽帧查看得到；**[判读]** = 对关键帧/音轨的模型辅助判读（可信度较低，已与实测交叉核对）；**[建议]** = 本 Skill 新增的建议；**[未确认]** = 看不出或证据冲突。

## 1. 文件元信息 [实测]

| 项 | 值 |
|---|---|
| 容器 / 时长 | MP4，54.208 s，总码率约 1.70 Mb/s，11.5 MB |
| 视频 | H.264 High，**1280×720**，SAR 1:1，24 fps 恒定，1301 帧，yuvj420p |
| 音频 | AAC LC，48 kHz 立体声，约 132 kb/s |
| 响度 | 综合 **−14.5 LUFS**，LRA 6.6 LU，真峰值 −0.5 dBFS |

- [文档] 渲染规格为 1920×1080、4:3 片门 1440×1080。[实测] 本文件为 720p 版本；亮区列宽约 x≈160–1120（960 px = 720 的 4:3），与“16:9 内居中 4:3 片门”一致，两侧为暗幕布区。

## 3. 文档要求 vs 实测

| 文档要求 | 实测结果 |
|---|---|
| 4:3 片门居中于 16:9，两侧幕布 | ✅ 相符（720p 版本） |
| 动作 16 fps 采样（追逐 18），损伤每个 24 fps 输出帧变化 | ✅ 追逐段 1/4 帧保持 = 18 fps；其他段因运动很小、颗粒每帧变化，16 fps 保持模式**无法从成片可靠测出** [未确认] |
| 因果链在一个静态宽镜头内完成，不切 | ✅ 19.5–26 s 背景零位移、无切点 |
| 追逐用跟拍 + 前景掠过 | ✅ 背景持续平移；前景路灯向左移动 [判读] |
| iris 开场、收尾停半途让角色看观众 | ✅ 开、收、停顿均可测；“眨眼”在抽帧中**未看到** [未确认] |
| 温情段动机推镜（zoom 1.6→2.1） | ⚠️ 帧条判读未见明显推镜，亮度统计也不足以证明 [未确认] |
| 结尾女孩学主角高举 | ⚠️ 判读为大人高举一半；与文档不一致，未进一步核实 [未确认] |
| 3–5 张卡，每张几个词 | ✅ 3 张正文卡 + 片名 + 结束 |
| 只有钢琴/簧风琴与放映机声，无人声无拟音 | ✅ 判读未听到人声或写实拟音；簧风琴在后段加入 [判读]；静默段可测 |
| 混音 −14 LUFS | ✅ −14.5 LUFS |
| 损伤不遮挡动作 | ✅ 判读：划痕/颗粒细且半透明，未遮挡主体 |

注：音轨判读给出的“10–13 s、24–28 s 音乐停止”与 RMS 实测不符（这两段电平 −11~−23 dBFS），已不采用。

## 4. 从示例提炼、写入本 Skill 的建议 [建议]

- 把“动作采样帧率”和“输出帧率”分开写进每段规划，并在冲印处理中先采样后加损伤；验收时用帧哈希或背景位移检查保持帧模式（`acceptance-checklist.md`）。
- 因果链镜头单独作为一个生成/渲染单元，不跨片段拆分；物体出画到回落留出 2.5–3 s 等待，其中先有一小段空镜，再让“受害者”走到位。
- 静默段 2 秒左右、只留放映机声，放在“物件到达需要它的人”之后。
- iris 收束：约 0.9 s 收到头部大小、停约 1 s、再约 0.4 s 收黑。
- 插字卡与画面之间用硬切；全片转场只用 iris、黑场、硬切、幕布。
