# Acceptance checklist / 验收清单

两类检查必须分开汇报：**A 类可由代理测量**；**B 类是视觉与叙事判断，由用户审阅决定**。A 类全部通过不代表 B 类通过，不能把格式校验写成“视觉验收通过”。

## A. 可测量的格式检查（代理测量并如实报告数值）

- [ ] 分辨率与画幅符合 STEP 0 规格（如 1920×1080 内居中 4:3 片门；或纯 4:3）。
- [ ] 输出帧率 24 fps 恒定；总时长与 cue sheet 误差 ≤ 0.5 s。
- [ ] 动作采样模式：抽取未加损伤的中间结果或用帧哈希/背景位移检查，16 fps 段每 3 帧 1 帧保持，18 fps 段每 4 帧 1 帧保持；损伤层在保持帧上仍变化。
- [ ] 每张插字卡时长 ≥ max(1.8 s, 阅读时间 + 0.6 s)，通常 2.5–3.75 s；`.srt` 文本与卡片原文、时间一致。
- [ ] 音轨：综合响度约 −14 LUFS（±1），真峰值 ≤ −1 dBTP 为宜；生成片段自带音频已去除；规划中的静默段电平明显低于音乐段。
- [ ] 文件可播放、编码与容器符合平台要求；文件体积在可接受范围（颗粒重时用适合颗粒的编码设置）。
- [ ] 代码路线：IK 报告为空（手脚都够得到目标）；帧哈希确认每个输出帧都不同（损伤层逐帧变化）；终版分辨率符合约定档位（720P 或 1080P）。
- [ ] 交付物齐全：成片、故事处理/cue sheet、镜头表、`.srt`，以及代码路线的工程。

## B. 视觉与叙事审阅（呈现给用户判断，不由代理自评）

请用户按以下问题审阅，代理汇总反馈后再修改：
- [ ] **缩略图测试**：每个镜头缩小后，主体剪影与动作是否仍读得出？
- [ ] **画法**：是墨线版画 + 银灰水洗 + 排线，而不是老照片滤镜或写实视频？
- [ ] **因果链**：在一个静态宽镜头内能看懂 A→B→等待→C 吗？等待是否好笑？
- [ ] **表演**：脸平静、身体在演；抓取/差点抓到是否读得出？手臂有没有挡脸？
- [ ] **人物结构**（代码路线）：关节处衣服轮廓连续、脚不滑、转头带肩、不穿脸穿物；三分之四侧脸远侧眼小、近侧眼大、鼻子越过远侧轮廓？
- [ ] **插字卡**：是否只说画面说不出的话？边框是否符合情绪？
- [ ] **损伤即情绪**：混乱段更脏更冷、温情段更干净更暖？关键节拍上损伤是否避开脸、手和物件？
- [ ] **放映感**：片门晃动、闪烁和采样节奏让人感觉“在放映”，而不是卡顿？
- [ ] **iris 与转场**：iris 是否对准目标并在该停处停住？有没有误用叠化或甩镜？
- [ ] **配乐**：钢琴是否“演出”了事件？静默是否托住了关键时刻？
- [ ] **原创性**：没有借用真实影片笑料、流浪汉造型、已发表旋律或参考库示例的剧情与片尾卡？
