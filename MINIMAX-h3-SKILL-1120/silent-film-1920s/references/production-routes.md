# Production routes / 实现路线

参考库的成片是**纯代码渲染**的（Canvas2D 明度绘画 → WebGL2 墨线重绘 → WebGL2 拷贝后期，无生成图像），并带有 cue sheet 驱动的配乐脚本。这些引擎与构建脚本**不是本平台已有工具**。在本平台上按下列路线组织；运行时按当时可用的能力选择具体模型或工具，不在本 Skill 里写死。

## 路线总览

| 环节 | A. 生成路线（默认） | B. 代码绘制路线 | C. 实拍重绘路线 |
|---|---|---|---|
| 适合 | 快速出片、题材多变、人物/场景较复杂 | 要求命中点精确、可编辑工程、可反复改时 | 用户有家庭影像、档案、产品实拍 |
| 风格帧 / 剪影表 | 图像生成 | 代码绘制静帧 | 从素材抽帧后做风格化图像 |
| 镜头 | 视频生成：以风格帧为参考或首帧，每段约 4–15 s | 编码子任务或按用户要求在本地用代码逐帧绘制（可参考 MIT 参考引擎改写并署名） | 以原视频为参考做风格化视频编辑；或编码子任务做“墨线重绘”处理 |
| 插字卡 | 代码渲染文字（`make_intertitle.sh`），图像生成只做无字边框 | 代码 | 代码 |
| 冲印处理 / iris / 片门 | 本地 `print_pass.sh` 或平台媒体编辑的等效处理 | 在渲染程序内完成 | 同 A |
| 配乐 | 按段落生成器乐 | 代码按 cue sheet 生成 | 二者皆可 |
| 拼接与混音 | 媒体编辑拼接 + 混音/响度处理；或时间线剪辑器 | 渲染程序直接输出 | 同 A |

## 各路线的真实限制与对策

**A. 生成路线**
- 视频模型倾向于写实、流畅、带镜头运动：提示词要写“固定机位、不切镜头、版画线描、银灰水洗、排线”，并用风格帧锚定；冲印处理统一采样与损伤，掩盖不同片段间的细微风格差。
- 单段时长有上限：一条因果链必须在一段内完成；装不下就简化链条或改走 B 路线做这一镜。
- 模型可能自带音频：全部去除。
- 模型写的字不可靠：插字卡、招牌文字用代码或后期叠加。
- 人物跨镜一致性：每段都带同一张剪影标识表；身份靠帽子/衣服/工具等剪影标识而非脸部细节。

**B. 代码绘制路线**
- 执行方式：默认交给编码子任务；用户要求不用子任务、只用本地代码时，就在本地完成。两种方式规则相同。
- 交给编码子任务时，在 brief 中写明：目标、已确认的 cue sheet 与镜头表、风格数值（`style-bible.md`）、动作采样规则、插字卡原文、交付物与所属对象。若要改写参考库 `demo/engine/` 代码，要求其获取源码、保留 MIT 声明，并且不复用示例剧情与片尾卡。
- 代价：角色表演受限于简易骨架，适合宽镜头剪影式表演；大特写会像人偶。
- 人物结构、IK、脚、转头和三分之四侧脸透视按 `references/character-rig.md` 执行，这些都是用户纠正过的问题。
- 先确认后渲染：代码路线虽然不花钱，也要先出**关键帧总表**（每个节拍一张、标时间）和必要的人物/脸部检查图，用户确认后再渲染全片。
- **分辨率分两档**：改动作、调节拍、关键帧总表和抽样测试都用 720P 迭代（1280×720 输出，960×720 片门），速度快；定稿时如需更清楚，再用 1080P（1920×1080 输出，1440×1080 片门）渲一遍终版。实测 720P、8 进程并行约 1 分钟渲 720 帧；逐像素处理耗时约与像素数成正比，1080P 约慢 2.2–2.5 倍。
- **把分辨率做成一个参数**：世界坐标与像素无关，镜头缩放乘以“输出尺寸 / 720P 基准”，线宽、颗粒尺度、iris 半径、片门与幕布宽度都按同一比例换算；这样切换终版只改一个尺寸参数。
- 画面与配乐共用同一张节拍表（命中点时间），由它同时驱动动作和音乐。
- 长任务（全片渲染、合成）放后台运行并轮询日志，避免终端超时中断。

**C. 实拍重绘路线**
- 先确认素材权利和人物同意；不重绘可识别的他人肖像用于商业用途，除非用户确认已授权。
- 实拍本身的帧率、手持晃动会被冲印处理的采样与片门晃动统一；剧烈手持建议先稳定再处理。

## 本地脚本

- `scripts/print_pass.sh`：摇片速度 → 动作采样（16/18/20 fps）→ 24 fps 输出 → 单色拷贝 + 棕褐量 → 黑白位与 S 曲线 → 片门晃动/偶发跳帧 → 闪烁 → 时间颗粒 → 黑白竖划痕 → 暗角 → 可选 iris 开/收（含停顿）→ 4:3 片门居中于 1920×1080 → 可选幕布 PNG 叠加。已在合成测试源上验证可运行、输出 24 fps、16/18 fps 保持帧模式正确；**视觉效果未经验收**，首次使用请先处理一个镜头给用户看。iris 使用逐像素表达式，处理较慢（约 10 倍实时），只对需要 iris 的镜头开启。
- `scripts/make_intertitle.sh`：黑底插字卡片段，三种边框级别，按词数自动定时长（2.5–3.75 s）。字体需提供 .ttf/.ttc 路径。
- 两个脚本只依赖 ffmpeg；平台未提供本地执行时，用媒体编辑能力执行等效处理，或交给编码子任务。
