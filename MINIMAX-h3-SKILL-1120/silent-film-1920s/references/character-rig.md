# Character rig & performance / 人物骨架与表演

代码绘制路线（B）和需要修正生成结果时都适用。以下每一条都来自用户在实际制作中指出过的问题，优先级高于“动作好看”。

## 1. 身体结构 [用户纠正]

- **衣服用连续轮廓包住关节**：肩、肘、膝处不能出现“球形关节”或分段断开的描边。做法：所有肢体段先整体描一遍外扩墨线，再整体填色；明暗带沿整条肢体链连续走，不按段各画一截。
- **骨长固定**：上臂、前臂、大腿、小腿长度整片不变；手和脚的目标点用两段 IK 求解，并用“肘/膝朝向提示”选择合理弯向（肘朝后外、膝朝前）。
- **IK 报告**：渲染前逐帧检查手、脚是否够得到目标（目标超出臂长 > 1 px 即记录）。抓取类节拍必须为空；够不到就挪目标或挪身体，不拉长骨头。
- **关节角合理**：肘、膝不反折；插兜、叉腰等手部藏起的姿势要检查肘部是否弯得别扭。

## 2. 重心与脚 [用户纠正]

- **脚不滑**：站立和弯腰时脚钉在地面坐标上；身体前倾时让胯往后退，保持重心在两脚之间，而不是让脚跟着身体移动。
- **先移重心再迈步**：迈步前胯先移到支撑脚上方，抬脚、落脚，再移下一次重心。
- **不做复杂的正面行走**：默片宽镜头里，人物以侧面或四分之三侧面移动最易读，也最不容易穿帮。

## 3. 头、肩与接触 [用户纠正]

- **转头带动肩**：转头时肩线跟着转一部分（约 1/3），不能只有头在脖子上旋转。
- **不穿脸、不穿物**：手臂和道具不能穿过脸、身体或桌面；抓取点要落在物件真实结构上（例如钳子竖直咬住扣件，伞柄朝向抓它的手）。
- **手不挡脸**：笑点节拍上手臂和道具让开脸。

## 4. 三分之四侧脸透视 [用户纠正，问题最严重处]

- 远侧眼更小、更窄，贴近脸的远侧轮廓；近侧眼更大。
- 鼻子越过远侧轮廓，鼻头不过度突出。
- 眉、胡子、嘴同样远短近长：远侧一截短，近侧一截长。
- 耳朵在近侧后方；脸的明暗分界放在近侧颊后部。
- 出关键帧时单独放大一张脸部图检查。

## 5. 表演节奏

- 脸平静，身体演：憋气用挺胸、抬下巴、鼓腮；惊讶用眼珠和眉，不用大张嘴。
- 每个动作先预备、再动作、再停顿；停顿让观众看清结果。
- 眨眼、对视、泄气这类小动作放在节拍表里，与配乐命中点对齐。
