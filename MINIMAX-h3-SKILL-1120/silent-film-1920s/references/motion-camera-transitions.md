# Motion, camera, transitions / 动作、镜头与转场

## 1. 动作采样 ≠ 输出帧率 Hand-cranked sampling

- [文档] 人物与镜头运动按 **16 fps** 采样（快场景欠速到 18 或更高）；闪烁、晃动、颗粒和划痕在每个 **24 fps** 输出帧都变化。正是这种混合让它像“在放映”，而不只是“低帧率”。
- [实测] 示例追逐段：每 4 个输出帧有 1 帧保持 = 18 fps 采样。
- 换算：16 fps → 24 fps 时每 3 帧有 1 帧重复（`#.##.##.`）；18 fps → 每 4 帧 1 帧重复（`##.###.`）。
- **处理顺序**（[建议]，`scripts/print_pass.sh` 已按此实现）：摇片速度（setpts）→ 采样到 16/18 fps → 回到 24 fps（帧重复）→ 再加颗粒/闪烁/晃动/划痕。若先加损伤再重采样，颗粒会在保持帧上冻结，看起来只是卡顿。
- **速度即情绪** [文档]：追逐与慌乱欠速摇片（动作更快，约 1.2–1.4 倍，闪烁更快）；温情回到 16 fps、拷贝更平静。
- [建议] 生成视频模型输出的是流畅运动：不要在提示词里要求“低帧率/卡顿”，而是正常生成，再在冲印处理里统一采样，保证全片一致。

## 2. 表演 Performance

- **面无表情（deadpan）**：脸几乎不变，身体在演——用力前先蹲、定格的姿势、两帧完成的“二次反应”急转头、双手撑膝 [文档]。
- 关键帧 + 缓动的姿势；只有刻意的笑点才“啪”地一下 [文档]。
- 抓取必须让手**正好**落在物体此刻的位置，否则观众读不出来；差点抓到 = 手合上的地方正是物体前一帧所在 [文档]。
- 抬手走侧向（外展），或先把角色转向镜头，避免手臂横过脸 [文档]。
- [建议] 生成路线写动作时用“时间 + 身体部位 + 方向 + 力度”的句式，每个镜头只写 1–3 个动作节拍。

## 3. 镜头词汇 Camera vocabulary [文档]

镜头很重：大多数镜头锁定不动。开头和结尾由题材决定。

| 运动 | 表达 | 适合 |
|---|---|---|
| 锁定大全景 | 完整看到因果；等待本身就是笑点 | 机械笑料、人群、复杂流程 |
| 锁定全景 | 一帧交代前提 | 角色日常、对峙 |
| 跟拍 + 前景掠过 | 追逐、动量 | 追赶、比赛、赶时间送货 |
| iris 开 / 合 | 聚焦一物；一个念头的开始或结束 | 物件、面孔、回忆 |
| iris 半开停住 | 角色与观众交换眼神 | 眨眼、秘密、共谋 |
| 有动机的慢推 | 温柔、领悟 | 下跪、读信、做决定 |
| 遮罩镜头（钥匙孔、望远镜） | 主观视角、偷看 | 侦探、好奇、恋爱 |
| 分屏 / 双重曝光 | 戏法、梦、两地 | 电话、鬼魂、白日梦 |

景别：宽景和中景。转场：iris、淡入淡出黑场、硬切、幕布。同场景内不叠化，不用现代甩镜。

## 4. 静态宽镜头因果链 The chain in one take

- 结构 [文档]：A 触发 B → B 离开画面 → 观众等待 → B 回来击中 C。**等待就是笑点**。
- [实测] 示例中物体出画到落下约 3 s，人物在出画后约 0.75 s 入画并走到位；整段零机位运动、零剪切。
- 失败模式 [文档]：步骤太多、人物太小 → 缩略图里是噪点。示例早期 8 步链在约 64 px 头高时无法阅读，最终只保留一条带停顿的链。
- [建议] 人物身高占画高 1/3–1/2；链条 3–4 步；每一步只有一个运动主体；等待时画面里只留“受害者”的入场。
- [建议] 生成路线：把整条链写成一个连续镜头单元（≤ 模型单次时长），明确“固定机位，不切镜头，不移动”；若模型无法一次完成，改用代码路线绘制这一镜，而不是剪成多段。

## 5. Iris 规则

- 开场在故事的物件上开 iris，结尾收在最后一个眼神上；停在半途让角色看观众 [文档]。
- [实测] 示例开 iris ≈0.5 s；收 iris ≈0.9 s 到头部大小，停 ≈1.4 s，然后收黑。
- iris 中心必须在**片门坐标**中跟踪目标（推镜后也要重新映射）[文档]。
- [建议] `scripts/print_pass.sh --iris-out T --iris-x --iris-y` 提供“收到头部大小 → 停 1 s → 收黑”的固定节奏；中心坐标按归一化片门坐标填写，目标移动时分段处理或改用代码路线。

## 6. 原生招式菜单 Native moves [文档]

一镜因果链；差点抓到；插字卡反转（一张卡重新定义下一个镜头）；欠速混乱（速度与损伤一起上升）；iris 看观众；实拍重绘成版画；呼应动作（开头的动作由另一人带着新含义重复）。只取故事需要的。

## 7. 变化空间 Variation [文档]

- 结构：新闻片（标题卡 + 若干“报道”）；三本情节剧（每本一种染色：琥珀、蓝、玫瑰；反派卡、营救）；戏法片（Méliès 式：一个舞台、一位魔术师、替换剪接让物件出现和变形）。
- 开场：追逐中途切入、拷贝已在转且有划痕；先出一张提问插字卡；放映员视角（放映室光束，再到银幕）。
- 结尾：胶片烧穿、灯光发白；最后一张卡直接对观众说话；锁定宽景淡出、钢琴停在一个和弦上。
