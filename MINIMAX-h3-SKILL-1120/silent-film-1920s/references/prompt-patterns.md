# Prompt patterns / 提示词模式

提示词默认用中文书写（可在末尾附少量英文风格词帮助模型）；按“用途 → 场景 → 主体层级 → 构图机位 → 线与明度 → 拷贝质感 → 限制”的顺序写具体可见的内容，不堆砌空泛形容词。下列方括号为占位，按每个项目的原创故事填写。

## 1. 风格帧（4:3 静帧）

```
用途：[片名] 第 [N] 场风格帧，1920 年代单本默片的放映画面，4:3。
场景：[地点与时间]，[2–3 个关键布景元素]，空间纵深清楚，地面线在画面下三分之一。
主体：[角色 A 的剪影标识：帽子/衣服/工具]，写实比例约 7.5 头身，苍白皮肤、深色眼睑和嘴唇的默片妆；[动作瞬间，用身体姿态表达，脸部平静]。[物件] 位于 [位置]，明度与背景拉开。
构图：锁定机位全景/大全景，人物约占画高 1/3–1/2，主体在中景层，前景留空。
画法：铜版蚀刻与钢笔墨线版画，墨线压在每个形体的暗侧；明度压缩为约 5 级柔和银灰水洗；暗部 45° 排线，最暗处交叉排线；高光是纸白。
拷贝：银盐黑白拷贝，轻微棕褐（[冷/暖]），细颗粒、轻微暗角、少量细竖划痕避开人物与物件。
限制：不是照片、不是 3D 渲染、不是平滑数字渐变；不出现现代物品；不出现文字（招牌留白或用简单图形）；不出现圆顶礼帽+牙刷胡+手杖的组合。
```

## 2. 剪影标识表

```
用途：[角色/产品] 剪影标识表，供后续所有镜头保持一致。
内容：同一角色正面、侧面、背面全身三视图 + 一个关键动作姿势；标注 [帽子/衣服/工具/外形] 三个识别点。
画法：与风格帧相同的墨线版画与银灰水洗，纯浅灰背景，无透视场景。
明度：服装深 0.15–0.3，皮肤 0.8，白色衣物 0.9 以上，保证缩略图里剪影可读。
```

## 3. 视频镜头（以风格帧为参考或首帧）

```
用途：[片名] 镜头 [编号]，时长 [x] 秒，接续参考图的画风与人物。
机位：固定机位 [全景/大全景]，整段不移动、不推拉、不切镜头。（跟拍镜头写：镜头随 [主体] 平移，背景匀速向 [方向] 卷动，前景 [路灯/栏杆] 更快掠过。）
动作（按时间）：0–[t1] 秒 [主体] [身体部位+方向+力度]；[t1]–[t2] 秒 [物件] [运动与停顿]；[t2]–[t3] 秒 画面内只剩 [环境]，等待；[t3]– 秒 [另一角色] 从 [方向] 走入、停在 [位置]，[物件] 落下击中。
表演：脸几乎不变，用身体表达；动作有预备与定格，抓取时手正好落在物件位置。
画风：全程保持墨线版画、银灰水洗与排线，线条轻微逐帧抖动；黑白，无彩色。
声音：无对白、无拟音（成片会另配钢琴）。
限制：不写实化、不出现文字、不出现现代物品、不叠化转场。
```

## 4. 无字插字卡边框底图（可选）

```
用途：默片插字卡底图，4:3，纯黑底，中央大面积留空供后期排字。
边框：[喊叫=一道粗直线框 / 叙述=双线框+阶梯形四角+扇形纹 / 温情=细藤蔓与小花沿边]，米白墨色，装饰艺术风格，手绘轻微不均匀。
限制：不出现任何字母或文字，中央 70% 区域完全空白。
```

## 5. 配乐段落（生成路线）

```
原创 1920 年代默片影院钢琴伴奏，[段落名：Hurry/Misterioso/Tenderly…]，立式钢琴独奏[可加簧风琴]，[速度] BPM，[调性/情绪]，跨步左手，[该段关键音型：下行刮奏/减七颤音/前臂音簇…]，时长约 [x] 秒，无人声、无鼓、无现代合成器，干净录音室收音带轻微房间感。
```
