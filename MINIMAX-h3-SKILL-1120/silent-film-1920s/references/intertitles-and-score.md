# Intertitles and score / 插字卡与配乐

## 1. 插字卡 Intertitles

- 插字卡**就是字幕**；另附 `.srt` 列出卡片文字与时间 [文档]。
- 时长：`max(1.8 s, 阅读时间 + 0.6 s)`，常用 2.5–3.75 s [文档]；[实测] 示例正文卡 2.5–2.9 s。
- 每张卡几个词；短片 3–5 张；**不解释画面已经展示的内容** [文档]。
- 黑底手绘卡 + 装饰艺术边框，边框随情绪 [文档]：
  - 喊叫：一道粗线，文字抖动；
  - 叙述：双线 + 阶梯形角 + 扇形纹；
  - 温情：藤蔓与小花。
- 字体（OFL）[文档]：标题与喊叫用小型大写展示衬线体（如 Playfair Display SC）；叙述与对白用斜体旧式衬线体（如 Old Standard TT Italic）。
- [建议] 中文插字卡：用宋体/明朝类衬线字体，竖排或横排均可，每卡不超过约 12 个汉字；标点用全角引号表示对白。
- [建议] 卡片文字用代码渲染（`scripts/make_intertitle.sh`：`-l shout|narration|tender`），再走冲印处理；图像模型只用来做无文字的装饰边框底图。脚本的边框是简化几何版，藤蔓/扇形等精细纹样需要底图或代码绘制。

## 2. 配乐：乐器就是音效 Score [文档]

- 立式钢琴（可选簧风琴、剧院管风琴、小提琴或小编制）为每个事件演奏，就像影院现场。
- 拟音式伴奏词汇（按需选用）：低音半音爬行（潜行）、倚音（眨眼）、前臂音簇（撞击）、渐强减七颤音（等待）、低音隆隆颤音（风暴、机器）、“叮……咚”（空无）、减和弦突强（惊吓）、琶音和弦（开门、揭示）、下行刮奏（跌落）、低音“嘣”（弹跳）、神经质颤音（犹豫）、小二度（东西碎裂）。
- Photoplay 写法：跨步左手；按情绪段落组织（Hurry、Misterioso、Agitato、Tenderly、Maestoso），像 cue sheet；主题在结尾变奏回归。**只用原创音乐**。
- **无拟音、无人声**；放映机是环境声：灯泡咔嗒、马达启动、抓片爪与马达的嗡鸣、片尾胶片在收片盘上拍打。
- **静默** = 音乐停下，只剩放映机；用来托住一个定格时刻。
- 混音：先轻压钢琴击锤瞬态，再响度归一到 −14 LUFS；颗粒放在画面里。

## 3. 实测参照 [实测]

示例片综合 −14.5 LUFS，真峰值 −0.5 dBFS；开头约 1.5 s 只有放映机/暗屏，随后片名音乐进入；约 32.7–35.0 s 静默（只剩约 −31 dBFS 的放映机声），出现在物件到达孩子脚边之后、对白卡之前；片尾约 52.6 s 起只剩放映机声。音轨判读：钢琴贯穿，后段加入簧风琴类音色，未听到人声与写实拟音。

## 4. 在本平台做配乐 [建议]

- **生成路线**：音乐生成能做原创器乐，但不接受参考音频，也无法保证命中点落在指定帧。做法：按 cue sheet 每个情绪段落单独生成一段钢琴器乐（写明乐器、速度、调性情绪、“1920s photoplay / stride piano / 无人声”），以乐句为单位修剪画面；关键命中点（跌落、撞击）放在乐段的起点或重音处；段落之间用静默或放映机声衔接。
- **代码路线**：当命中点必须 0 ms 对齐时，由编码子任务或本地代码从 cue sheet 直接写配乐（采样钢琴或合成），画面与配乐共用同一时间表。采样需自行获取并遵守许可（如 CC0）。
- **放映机声**：可由代码合成（马达嗡鸣 + 周期性抓片咔嗒 + 低频机械噪声），或使用用户提供 / 已授权的素材。
- 爆炸、闪光类大命中点：低音重和弦叠一段低通噪声气声，比单用钢琴更有冲击，仍不算写实拟音。
- 响度归一的实操：先用限幅器压住钢琴击锤尖峰，再分两遍做响度归一（第一遍测量，第二遍带入测量值并用线性模式），避免动态被压扁、真峰值超标；目标约 −14 LUFS，真峰值 ≤ −1 dBTP。
- 生成视频自带的音轨一律去除。
